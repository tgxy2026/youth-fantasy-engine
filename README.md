## 写在前面（请先读这段）

**1. 这是一款使用 AI 辅助开发的项目。**

从第一行代码到现在，开发过程大量借助了 AI 编程工具。这点我先摊开讲，不藏着。

**2. 数据位置和联网范围，请按你使用的形态与功能确认。**

- 桌面与便携版的手动写作、资料查看和本地检查可以离线使用；AI 功能需要你配置的本地或云端模型服务。
- 使用云端模型时，本次功能取用的正文与资料会发往你配置的端点；网页版云端模式还会把账号资料保存到服务器。各 AI 入口可查看数据来源说明。
- 除模型请求外，自动检查更新、联网检索、云盘同步和网页版账号/存储也可能联网。使用本地模型不等于所有功能都离线；请按需关闭更新检查及其他联网功能。

**3. 关于内置的 AI 功能，我的立场是「辅助，不是代笔」。**

软件内置了一整套 AI 能力：一键续写、整章改写、一键拆书、创意写作、角色扮演推演……但设计这些功能的**本意是辅助创作** —— 帮你把设定理顺、把大纲排好、在卡壳的地方推一把，让你写得更顺，而不是替你写。

**我不建议使用 AI 大规模生成小说正文。**

如果你只是想玩玩、图个新鲜，那无所谓，功能就在那儿。但如果你真心想成为一名网络小说作者 —— **不建议**。作品得是你自己的，这条路没有捷径可走。

## 它解决什么问题

写长篇，真正的敌人往往不是"没有灵感"，而是**失控**。你有没有遇到过这些事：

- 世界观写了一箩筐，写到第 80 章想查「主角师父的师门叫什么」，翻了半小时没找着；
- 人物越写越多，谁跟谁什么关系全靠脑子记，写着写着就串了；
- 埋了个伏笔，二十万字以后你自己全忘了，读者倒是记得清清楚楚；
- 大纲在 A 文档、正文在 B 文档、设定在 C 文档，改一处要同步三处；
- 写到一半卡住，想推演「主角这时如果选 X 会怎样」，只能在脑子里空转。

青春幻想引擎就是为这些事做的。

它**不是「AI 帮你写小说」**，而是 —— **把你散落在各个文档里的创作资产，收进一个有结构、能互相关联、能按需喂给 AI 的工作台。**

## 功能总览

**10 个板块，55 个页签。**（完整项目下全部显示；自定义项目里由你在「功能模块」里勾选启用）

| 板块 | 包含页签 |
|---|---|
| **工作面板** | 写作面板 · 模型设置 · 使用指南 |
| **正文写作** | 正文编辑（含分卷 / 章节管理） |
| **灵感工具** | 灵感启发 · 一键拆书 · 创意写作 · 检查工具 · 素材资料 |
| **开书定位** | 作品信息 · 世界设定 · 力量体系 · 政治架构 · 经济基础 · 宗教信仰 · 司法制度 |
| **角色管理** | 主要角色 · 次要角色 · NPC · 人物关系 |
| **世界构建** | 国家势力 · 势力关系 · 地理风物 · 地图编辑 · 种族生物 · 物品资源 · 历史事件 · 名词术语 · 其他设定 · **世界引擎** |
| **大纲规划** | 全书总纲 · 分卷大纲 · 章节细纲 · 章节总表 |
| **酒馆模式** | 控制面板 · 背景设定 · 剧情推演 · 推演报告 · 自由对话 · **跑团互动** · 故事剧本 · 角色卡片 |
| **创作管理** | 伏笔追踪 · 时间脉络 · 情节推演 · 爽点节奏 · 写作进度 · 支线剧情 · 知情权限 · **创作轨迹** |
| **运营维护** | 写作规范 · 设定变更 · 灵感素材 · 读者反馈 · 关于打赏 |

> **3.0 新增页签**加粗标出：**世界引擎**（把整个世界封存成「世界包」，供其它作品引用）、**跑团互动**（AI 当 KP 带团推演）、**创作轨迹**（如实记录创作过程，供自己自证）。
> 另注：《地图》不是独立页签 —— 地图的增删改都在**地图编辑**页左侧列表里完成。

### 几个值得一提的设计

- **角色与关系双轨** —— 角色卡管「这个人是谁」，人物关系表管「谁跟谁什么关系」，可图谱可视化。
- **从总纲到细纲再到正文的完整链路** —— 分卷大纲 → 章节细纲（带事件链）→ 正文，每一层都能喂给 AI。
- **伏笔追踪** —— 埋了什么、在哪一章回收，一张表管到底，埋了不回收会被揪出来。
- **时间脉络** —— 故事内时间线，支持自定义历法，避免"人物年龄对不上"。
- **情节推演** —— 推演分歧点的不同走向，产出推演报告。
- **防剧透机制** —— 可标记「某角色在某章之前不知道某件事」，AI 推演时不会漏嘴。
- **保密等级与 AI 权限** —— `D · 终结（弃用）` 条目不作为设定资料提供给 AI；`S · 绝密` 不等于禁止发送，作者视角仍可使用，角色视角按入口与知情规则取材。请同时检查字段的 AI 参考权限。
- **一键拆书** —— 丢一本参考书进去，自动抽取人物、关系、设定，做成你自己的素材库。
- **酒馆模式** —— 让 AI 扮演你书里的角色跟你对话、推演剧情，用来找感觉、验人设。
- **伴写建议** —— 正文编辑时给出「下一句可以怎么写」的建议，你采纳或忽略，它不会替你写。
- **提示词全开放** —— 所有 AI 提示词都可在设置页里查看和修改。

## 快速开始

提供 **三种形态**，按需选一个即可：

### 方式一：桌面安装版（推荐，免装 Node）

到本仓库的 **Releases** 页面选择已发布版本，下载对应的 `青春幻想引擎-Setup-版本号.exe`，双击安装即可。源码版本可能先于正式发布，下载文件名与可用版本以 Releases 页面为准。

- **无需安装 Node.js**，装完直接能用；
- 数据存在本机用户目录（`%APPDATA%\youth-fantasy-engine`），**不写进安装目录**；
- 支持**应用内检查更新**：发现新版会提示，你点一下才下载。

> ⚠️ Windows 首次运行可能弹 SmartScreen 提示 —— 点「更多信息」→「仍要运行」。这是所有未购买代码签名证书的软件的常规待遇，不等于病毒警告。

### 方式二：便携版（U 盘即走，需 Node.js）

到 **Releases** 页面按系统下载对应的便携包，解压到 U 盘 / 移动硬盘 / 任意本地文件夹：

| 包名 | 启动脚本 | 适用系统 |
|---|---|---|
| `青春幻想引擎-便携版-版本号-Windows.zip` | `启动.bat` | Windows |
| `青春幻想引擎-便携版-版本号-macOS-Linux.zip` | `启动.sh` | macOS / Linux |

体积以对应版本的发布附件为准（两个包的应用本体一样，只是启动脚本不同）。

1. 双击 `启动.bat`（Windows）→ 自动拉起本地服务 → 自动打开浏览器进入写作界面；
2. **无需安装软件主体、不写注册表**，项目资料随 `data/` 目录移动；系统浏览器仍会保留自身缓存和访问记录；
3. 主数据文件在 `data/youth-fantasy-engine-data.json`，外置历史备份等载荷在同级 `blobs/` 中。优先使用应用内导出留档；手工备份便携数据时请复制整个 `data/` 目录，单独复制主 JSON 会遗漏外置载荷。

> ⚠️ 本机需装 **Node.js**（免费，约 30MB）。
> 本地服务**只绑 `127.0.0.1`**，局域网里别人访问不到。
> **自动更新检查 / 云盘同步 / 系统托盘 / 安装卸载 / PDF 直接导出**这几项依赖系统级安装或后台常驻，便携版没有；其余功能全保留。

### 方式三：网页版（免安装，浏览器直接用）

打开即可写作，**不用装 Node、不用下安装包**：<https://youth-fantasy-engine.online>

| 模式 | 谁用 | 数据在哪 | 跨设备 |
|---|---|---|---|
| **游客** | 所有访客，免费 | 存在**你自己的浏览器**里，不上传服务器 | ❌ 换设备或清了浏览数据就找不回 |
| **云端** | **打赏用户**（凭邀请码注册） | 存在服务器上，按账号隔离 | ✅ **唯一支持跨设备的形态** |

- 游客模式**功能不打折，只做提示**：首启向导、项目页入口、登录页都会明说「清浏览数据或换设备后无法找回」，并引导你**自己导出一份备份**。
- 云端模式由**站主亲手发放邀请码**，一张码只能注册一个账号；这张码同时是**找回密码的凭证**（用户名＋邀请码一起校验，拿到别人的码也改不了你的号）。
- 网页版中，云端账号提供直接跨设备访问；游客的浏览器本地库不会自动跨设备。桌面 / 便携版可另行使用导入导出或外部云盘文件同步，切换设备前应关闭软件并等待同步完成。

### 再说一句：从源码运行

```bash
git clone https://gitee.com/tgxy2026/youth-fantasy-engine.git
cd youth-fantasy-engine
npm install
npm run dev            # 浏览器调试：http://localhost:5199
```

打包桌面版：

```bash
npm run build:desktop  # 产物输出到 release/ 目录
```

> 需要 **Node.js 20 或更高版本**。

## 数据与隐私

- **桌面版与便携版**：主数据与外置载荷保存在本机或便携目录；桌面的参考资料/向量索引另有独立存储，按对应功能的导出说明处理。
- **网页游客**：数据在当前浏览器的 IndexedDB；清除浏览器数据或换设备不会自动找回。**网页云端**：数据在服务器上，按账号隔离，并受账号配额限制。
- **模型与联网服务**：云端模型会收到本次发送的资料；检索、更新、账号存储、WebDAV/S3 及外部云盘各使用对应服务。使用第三方云盘同步也会把文件交给该云盘服务处理。
- **备份**：优先使用应用内导出；手工复制文件型资料时，应同时保留主 JSON 与同级 `blobs/`。导出有载荷读取失败提示时，应保留原资料，不把部分导出当作完整副本。
- 图片入库前会先压缩，避免库文件无限膨胀。
- ⚠️ 换设备前请先**关闭软件**并等待云盘同步完成，避免半同步状态造成数据冲突。

## AI 功能说明

### 支持的模型来源

**本地模型（数据不出本机）**

| 类型 | 说明 |
|---|---|
| Ollama | 填本地地址即可，推荐 |
| 本地 OpenAI 兼容服务 | LM Studio / vLLM 等任意兼容实现 |

**云端模型（会把选定上下文上传给该服务商）**

硅基流动 · DeepSeek · 通义千问 · 智谱 GLM · 豆包 · Kimi · MiniMax · 腾讯混元 · 百川智能 · 零一万物 · Groq · OpenRouter · OpenAI · 自定义接口

### 数据会发给谁

**只发给你当前选定的那个模型。**

用本地模型 → 完全不出本机；用云端模型 → 当前会话所需的上下文会上传给该服务商。软件内置上下文预算控制，让你能看清"这次要发多少、发了哪些"。

### 上下文是怎么控制的

- **预算上限**：按**模型上下文窗口的一半**算（下限 8K、上限 200K），超出的内容按优先级裁剪；
- **保密等级**：`D · 终结（弃用）` 条目从设定取材中排除；`S · 绝密` 在作者视角仍可能发送。等级过滤不会自动抹去你在正文或手动输入中粘贴的相同内容，敏感资料还应核对字段的 AI 参考权限与本次数据来源；
- **防剧透**：角色视角推演时，只看该角色在当时的章节节点应该知道的信息。

**3.2.0 本轮重点**（AI 改稿靠不靠得住：你能看见、能决定、能核对）：

- ⭐ **AI 产出的稿先审阅再应用**：「创作轨迹 → 候选审阅」列出待处理的改写稿，逐行显示字数变化与差异；点「应用」才写进正文。**应用前会比对正文**：如果你在期间自己改过这一章，它会拒绝并说明原因，不会把你刚写的东西冲掉
- ⭐ **改完会复检一次**：执行选中条目后，每章标题旁多一句 `复检：原问题已清` / `还剩 N 条没解决` / `复检没跑成`。用的是本地五个检查引擎，**不耗 AI 额度**。以前标「已完成」只代表改过了，现在能知道改好了没
- ⭐ **检查报告能翻回去看**：「创作轨迹 → 检查报告」按章列出当时报了哪几条（来源、章名、级别、引文）。**只有查到「冲突 / 注意」级问题才留档**，全绿的书一份都不存 —— 不占空间也不制造噪音
- ⭐ **引文标了"能不能定位"**：每条问题显示「引文 N/M 可定位」。伏笔 / 文风类问题的引文常来自设定表比对而非正文原句，定位不到时如实显示〔无引文〕，不假装每条都有原文支撑
- ⭐ **诊断不再报喜不报忧**：工单顶部显示「已检 X/Y 章 · 发现 N 个问题 · 留档 N 份」；**没检成的章会点名列出**，不会再出现"诊断完成、没有问题"其实漏检了一半的情况
- ⭐ **实体保留自检**：改写后有哪些已登记的人物 / 势力名没再出现，会在章标题旁提一句，并说明它属于哪个页签。**只提示不判定** —— 少提一次名字常常是合理润色，丢没丢设定你自己判断
- ⭐ **结构化输出开关**：模型设置里可以声明端点支持 JSON 结构化输出（`response_format` / `format`），JSON 类任务更稳。**默认关**，不确定端点支持就别开；开了若端点报 400，会自动撤掉对应参数重试一次
- ⭐ **额度有上限，撞顶会停**：整章改写一条最多 6 次、一次性任务最多 3 次；到顶就停并如实告诉你停在哪，不会在后台空烧额度
- ⭐ **网络卡住不会吞字**：流式输出停滞超时会中断，并把**已经收到的片段**带出来给你看，同时说明「已收到 N 字未采用」。**半截正文不会整章落库** —— 覆盖一半比不落更糟

- **首启向导的模型配置，与「模型设置」彻底同源**：以前首启自己维护一份短名单（云端 5 家、本地 2 家），豆包 / MiniMax / 混元 / 百川 / Groq / OpenRouter 等在首启里**根本看不到**。现在预设直接取自与「模型设置 → 模型配置」**同一份常量**（云端 **14** 家、本地 **6** 家），且「**获取模型列表**」对**所有平台**可见；另加 4 条源码闸防止两边再次不同步。
- **三个界面问题**（主人反馈）：分卷进度的「去写作」按钮曾被压成**竖排一字一行**（定宽图标键塞了文字）→ 已改横向；模型配置窗口**右侧一大片空白** → 改两栏、高度自适应；**并排按钮一高一矮**（「还原出厂」比「保存」矮 9px）→ 统一 size，并顺带体检全仓另修两处。
- **全量六维审计**：11 支扫描器 + 2 道弱引用闸，红线专项全部干净；真问题集中在「**失败可见性**」一类，共修 **8 处**（如导出备份读外置数据失败被静默吞掉、旧版数据「探测失败」被显示成「没找到」）。另把两个「登记已久却没有入口」的能力接上：备份管理页「**孤儿载荷清理**」、世界引擎「**清除溯源**」。

**3.0 大版本亮点**（把世界、过程、游戏都盘活）：

- ⭐ **世界引擎 —— 把整个世界封存起来，给别的书引用**：入口在**世界构建 → 世界引擎**。把你这本书的**整个世界**（世界设定、力量体系、四个制度页签、整个世界构建组）整个抽成一份「**世界包**」存起来，供**其它作品引用**。🔴 两个动作要分清：**「新建世界」是把当前项目的世界抽一份进来**（＝草稿）、**「封存」才是把它固化成不可变版本**（带锁图标）。🔴 **原书改了，已封存的世界版本不会自动跟着变** —— 想要新的就**显式再抽一份**。为什么这么设计？世界一旦被别的书引用就得**稳定**；要是自动同步，你改了这本、那本书的地基跟着塌，那才是灾难。写同宇宙的第二本、第三本，直接引用这个封存版本就行。
- ⭐ **跑团互动 —— AI 当 KP 主持一局**：入口在**酒馆模式 → 跑团互动**。**你写行动，系统掷检定，KP 照着结果演。** 🔴 **检定由系统掷定**、掷完写进提示词，**模型照着它演、不许改写成败**（成败要是交给模型随机发挥，「游戏」就没有规则了）。有**线索板 / 同伴 / 秘密 / 结局判定**四件套，还能**存档、回滚**（一局玩崩了退回去重来）。定位区分：剧情推演是**试演**、自由对话是**陪伴**、跑团是**一局可玩可分叉可复盘的游戏**。
- ⭐ **章后整理 —— 写完一章点一下**：入口在**正文编辑器 → 颉文姬 → 整理**（第六个模式）。把这一章的**事实、伏笔、关系、人物状态**四类变化**一次抽出来**，你看过、勾选，再决定收哪几条进去。🔴 若你回头改了前面已发布的正文，章纲里「这一章之后」的规划可能过时 —— 会主动标「**未来计划待重审**」，核对完点「已处理」清掉标记，**不偷偷用过时规划**。
- ⭐ **一致性审计 —— 自动查出设定自相矛盾**：入口在**灵感工具 → 检查工具 → AI 一致性深度自查**。把世界观、角色、时间脉络交给 AI，对照检查**人名、时间、能力、关系有没有前后矛盾**；还能顺手粘一段正文一起核查。结果按**严重 / 中等 / 提示**分级，并给冲突依据。
- ⭐ **AI 提示词透明 —— 看清 AI 到底收到什么**：**两个入口** —— ① **模型设置 → AI 提示词**（每个 AI 功能的提示词都能看、能改，以前这些只写在代码里）；② **各 AI 功能里的问号气泡**（这个功能**读了哪些数据、明确不读哪些**）。以前你可能有两个误解：以为某个功能读了它其实没读的资料，或者反过来担心它把你的结局、伏笔真相整篇发出去。现在**界面说明与 AI 实际拼装的内容对得上**。
- ⭐ **数值与言行一致**：入口在**酒馆模式 → 自由对话 → 右栏「本场状态」**。角色卡里写的「进度锁」（比如「还不熟，最多点头之交」）如果和你现在的数值档位（好感 / 信任 / 精神）对不上，会**给一行提示**让你去同步改卡。🔴 **只提示，不自动改你的角色卡**。
- ⭐ **AI 运行账本 —— 每次调用都留痕**：入口在**创作轨迹 → AI 运行账本**。记的是**这本书跑过哪些 AI 任务、成没成、产出多少条、消耗多少 token、耗时多久**（与「模型设置」里的消耗统计是同一份数据）。
- ⭐ **作品版本冻结 —— 定稿归档，冻住不动**：入口在**创作轨迹 → 定稿与版本**（右上角）。流程是**完成检查 → 内容指纹绑定 → 发布闸门 → 冻结版本**。有阻塞项时主按钮降级成「**仍要冻结（有 N 项未通过）**」—— **闸门不硬拦，但会提醒你**。🔴 两个细节：**定稿冻结的版本不设上限、不会自动删除**，后续修订保留原版；**「指纹只标注不重跑」** —— 版本指纹与当前稿对不上时只显示「当前稿已改过」，**绝不自动重新冻结**。
- ⭐ **便携版（U 盘版）首次提供**：一个可以装进 U 盘 / 移动硬盘 / 本地任意文件夹的「**自带数据**」版本 —— 双击启动脚本 → 自动拉起本地服务 → 自动打开浏览器进入写作界面。**无需安装、不写注册表**，换电脑随盘即走；当前数据由 `data/youth-fantasy-engine-data.json` 和 `data/blobs/` 外置载荷组成，备份请用应用内「导出数据文件」，或关闭程序后复制整个 `data/` 目录。本地服务**只绑 127.0.0.1**，局域网里别人访问不到。⚠️ 本机需装 **Node.js**；系统浏览器会保留自己的缓存与访问记录。自动更新、云盘同步等能力以当前版本界面和帮助为准。
- ⚠️ **行为变更：作品题材默认不再发给 AI**。以前建项目时选的题材（如「东方修真」）会**自动拼进每一条 AI 请求**，从 3.0 起**默认不再发送** —— 你可能只是想让界面显示「修真」的字段名，不希望它左右文风；发不发应该由你说了算。**想让它发，两条路**：① 项目编辑里打开「**把作品题材告知 AI**」（恢复旧行为）；② 在《作品信息》页的「**类型赛道**」字段自己填（**这段一直会随设定资料发给 AI**，比开关更可控）。题材现在只管「**开书定位组各页签的字段名与示例文案**」。
- 🔧 **其它改进修复**：**校对范围口径统一**（AI 深度校对**永远读完整正文**，旧的「简略模式」会误替换正文、**已移除**；只有「综合诊断」保留完整 / 简略两种范围）；酒馆角色卡**折叠态常驻**（挂到故事下的角色卡折叠后，切走页签再回来不会被重新展开）；酒馆「未整理 N 轮」徽标与右侧按钮**同规格对齐**；酒馆开场白导入不再多一个前导空行；酒馆角色卡 **10 个细字段的界面名与存储键统一**并保留历史别名（之前产出的文件仍能正确导入）；便携版修 4 项隐患（服务崩溃 / Host 校验 / base64 抛错 / 导入取消卡死）；**备份载荷外置**（备份、向量、知识库从整库 JSON 拆成独立文件，双端同构，老数据自动迁移、幂等）。
- 📌 **一句立场**：本软件**不做、也不参与任何「规避 AI 检测」的事情** —— 创作轨迹、证据包只做一件事：**如实记录你的创作过程，供你自己自证**。「AI 辅助占比」统计的是「**AI 累计产出过多少**」，不是「成稿里有多少是 AI 写的」。

**2.9.3 本轮重点**（把边角磨平，给 3.0 打底）：

- ⭐ **故事剧本「导入」支持追加到已有故事**：同一份文本，既能建成新故事，也能**只补词条与剧本**进你选的那个故事（目标故事下拉默认选中你当前在看的那个）。🔴 追加**不改世界设定** —— 已有故事的世界观是它自己的；撞上同名的剧本 / 词条会**红字点出究竟是哪一个并拦下**，由你改名后重来（不自动加序号、也不悄悄替你改名）；若目标故事的世界设定还是「一整段」的老形态，追加词条时会自动把它转成第一条常驻词条（内容不变、仍每轮都带上），界面会提前说明。
- ⭐ **自由对话的开场白独立成「场景引入」**：剧本开场白以前显示成**你自己发的一条消息**（那是为了让模型接住这场戏而刻意这么存的，但看着别扭），现在单独渲染成居中的一块，不带头像、不占任何一侧，只留「编辑」。老会话**零迁移**，翻回去也是新样式；对模型的含义**一字未变**。
- 🔴 **修掉「从云端备份恢复会被静默撤销」**：开着云盘同步时点「从备份恢复」，界面提示「已恢复」并自动刷新，但刷新完数据**又变回去了**。原因是云同步下本机数据文件是「开启同步那一刻的冻结快照」，而恢复只改了内存里那份 —— 重启后合并时冻结的旧文件被当成「本地最新」优先，把恢复结果盖了回去。现在恢复成功会**一并写回本机数据文件**。（升级后建议先手动同步一次。）
- 🔴 **修掉窄窗口下「文字竖排、按钮被裁」**：数据表页的标题与说明在窗口缩小时被压成一条竖缝（一个字一行），右上角的按钮（保存 / 表格 / 时间轴 / 历法规则）被裁掉。根因是页头「左标题 + 右工具条」两栏里，工具条不允许压缩 ⇒ 宽度不够时**全由标题承担压缩**、被压到 0 宽。现在放不下时**工具条自动折行**（按钮全部可见）、标题保底不再塌；同源问题一并修了角色卡页、控制面板页，以及侧栏「界面缩放」那一行的标签竖排。
- 🔴 **修掉酒馆「概率」填不了小数**：世界书词条 / 背景设定每节的「概率」输入框，想填 `0.5` 却打不出小数点 —— 输入 `0.` 就被改写回 `0`，只能填 0 或 1（等于这个功能形同虚设）。现已可正常输入 `0.1~0.9`。
- 🔧 **另外一批修复**：控制面板滚下去找不到保存按钮（页头吸顶 + 右下角常驻悬浮保存）；「全部功能页签」里看不到「模型设置」（该页按分组列举，而「工作面板」这一组被漏掉、整组消失）；自由对话本轮刚提到的世界书触发词**不当轮生效**（要等下一轮，现与剧情模式一致）；AI 参数标签「仅本地」有歧义（实际只有 Ollama 生效，已改「仅 Ollama」）；关于页的联网说明漏了默认开启的启动自动检查；AI 数据来源说明里「不读：D 级条目」重复显示了两遍；「清空全部」并发发送、清不干净还不提示（现逐条等待并如实报剩余条数）；敏感词检测说明写的「约 120 字」与实际（前后各 12 字）不符。
- ✅ **顺带做完一次全六维审计**：11 支自建扫描器 + 2 道项目闸 + 4 路只读子代理逐条验尸后修掉 15 项（1 项会造成界面重复渲染、4 项影响功能、6 项数据与事务边界、若干文案与常量对不上），另 1 项判定「留到 3.0 与酒馆重构一起做」。全过程与逐条依据见 `docs/归档/2.9/2.9.3-六维审计报告-2026-10-10.md`。

**2.9.2 本轮重点**（让 AI 更听你的话）：

- ⭐ **颉文姬新增「续写」**：编辑器里就能续写，而且是可调的 —— 说清**写多少字**（旁边显示本章当前字数）、**往哪个方向写**、**参考哪些资料**（11 项可勾，默认勾细纲 / 主要角色 / 章节摘要 / 写作规范 / 前文章节）。🔴 没勾的一律不读；超预算时实时显示「预计占用 N / 预算 M」并**如实列出哪几项没带进去**；结果落「**建议段**」，你的正文一字不动。它与审读模式的「续写方向」（只给思路）并存。
- ⭐ **颉文姬改稿能填具体要求**：五个动作下方多了「**额外要求**」（每个动作各有一句不同的示例）与「**期望字数**」。🔴 不填就等于以前（请求逐字一致）；动作的「纪律」（如扩写不得凭空造专名）仍在，以你的要求为准但不得放宽。
- ⭐ **模型列表筛选**：接中转站时几百个模型名，现在能一搜即中 —— 支持多词全部命中（`qwen 27b`）、忽略大小写、中间子串，并显示「命中 N / 共 M」；云端与本地 Ollama 两处列表都有。
- ⭐ **模型配置新增「文本生成微调」**：六个采样参数（核采样阈值 / 候选词上限 / 重复惩罚 / 惩罚回看窗口 / 词频惩罚 / 新话题倾向），各带中文名、**推荐值**与**因果说明**。🔴 全部**默认留空 ＝ 不下发**，升级不改变现有模型行为；云端不认的三项灰显「只对本地 Ollama 生效」。
- ⭐ **检查结果会留痕（新增两处趋势）**：投稿前自检（行文分布）与节奏 / 章末钩子跑完后，标题行右侧显示「上次检查 N 条（刚刚）· 比上轮多/少/持平」。🔴 节奏的趋势**只比同一个模型**（换模型重新开始，不混算）。
- ⭐ **优化工单「按类型」视图**：看全局 —— 同一类问题在全书出现几次、分布在哪些章。排序＝严重度分档 → 出现章数降序，不搞加权公式。
- ⭐ **「设定变更」页提示数据体检**：有 `冲突` 级问题时页顶出一行；没问题时页面与以前一字不差（全库扫描实测 11 ms）。
- 🔴 **修掉酒馆控制面板的「调了不生效」**：「候选词上限 / 重复惩罚 / 惩罚回看窗口」是 Ollama 专有，接云端时原本照旧可调却不生效也不报错 —— 现已按本地 / 云端分两态灰显。同类问题（本地 OpenAI 兼容服务 LM Studio / LocalAI 等）一并修。
- 🔴 **修掉两处「看着做完了、其实白做」**：① 投稿前自检的趋势行以前**永远显示「与上轮持平」**（该自检恒定产出固定条数）⇒ 改为只记真正偏离参考区间的项；② 本地 OpenAI 兼容服务上三个参数静默失效。
- 🔧 **续写「前文章节」改取每章末尾**（原取开头）并删掉独立的「上一章结尾」选项（职责重复）；同时修掉「预算从旧章开始分配 ⇒ 紧邻的上一章反被挤出」的方向错误。
- 🔧 **五个动作的示例文案各写各的**（此前共用一句，等于没提示）；并加防呆测试：新增动作忘配示例会直接变红。

**2.9.1 本轮重点**（让已经填好的数据真正被用起来）：

- ⭐ **连续性校验 10 → 14 类**：把「伏笔回收前置条件 / 地理行程与时间线对账 / 爽点间隔登记 / 秘密计划揭晓到点」这四类此前**填了却没人读**的登记字段接进校验。🔴 只提示、绝不改你的数据；解析不出的自由文本（如「半刻」）一律跳过 —— 宁可不报，也不误报。
- ⭐ **检查结果留痕**：伏笔闭环看板 / 连续性校验弹窗顶部显示「上次检查 N 条（3 分钟前）· 比上轮多/少 N 条」—— 从此答得出来「这章比上轮是变好还是变坏」。四个入口（检查工具页 / 稿件体检 / 编辑器弹窗 / 本章体检）共享同一份结果，不再各跑一遍。

- **新增页签**：「其他设定」—— 世界构建的兜底页，前面几张专表放不下的零散设定都有地方放，**而且照样进 AI 的设定资料**。

## 已知限制

- **桌面安装版仅 Windows**（无 Mac / Linux 原生安装包）；**便携版**可跑在 Windows / macOS / Linux，需自装 Node.js 20+。
- **仅简体中文**，暂无多语言支持。
- **便携版**的「自动更新 / 云盘同步 / 系统托盘 / 安装卸载 / PDF 导出」不可用（依赖系统级安装或后台常驻），其余功能齐全。
- **跨设备**：桌面 / 便携走云盘文件夹，**不是实时同步**，换设备前需手动等同步完成；网页版**云端模式**实时存在服务器，但只对打赏用户开放（游客模式数据只在本地浏览器）。
- 超长篇（百万字级）的性能优化仍在进行中。
- 内置 AI 功能需要你自己准备模型（本地或云端），软件本身不附带任何模型。
