## 写在前面（请先读这段）

**1. 这是一款使用 AI 辅助开发的项目。**

从第一行代码到现在，开发过程大量借助了 AI 编程工具。这点我先摊开讲，不藏着。

**2. 数据位置和联网范围，请按你使用的形态与功能确认。**

- 桌面与便携版的手动写作、资料查看和本地检查可以离线使用；AI 功能需要你配置的本地或云端模型服务。
- 使用云端模型时，本次功能取用的正文与资料会发往你配置的端点；网页版云端模式还会把账号资料保存到服务器。各 AI 入口可查看数据来源说明。
- 除模型请求外，自动检查更新、联网检索、云盘同步和网页版账号/存储也可能联网。使用本地模型不等于所有功能都离线；请按需关闭更新检查及其他联网功能。

**3. 关于内置的 AI 功能，我的立场是「辅助，不是代笔」。**

软件内置了一整套 AI 能力：一键续写、整章改写、一键拆书、创意写作、角色扮演推演……但设计这些功能的**本意是辅助创作** —— 帮你把设定理顺、把大纲排好、在卡壳的地方推一把，让你写得更顺，而不是替你写。

**我不建议使用 AI 大规模生成小说正文。**

如果你只是想玩玩、图个新鲜，那无所谓，功能就在那儿。但如果你真心想成为一名网络小说作者 —— **不建议**。作品得是你自己的，这条路没有捷径可走。

## 它解决什么问题

写长篇，真正的敌人往往不是"没有灵感"，而是**失控**。你有没有遇到过这些事：

- 世界观写了一箩筐，写到第 80 章想查「主角师父的师门叫什么」，翻了半小时没找着；
- 人物越写越多，谁跟谁什么关系全靠脑子记，写着写着就串了；
- 埋了个伏笔，二十万字以后你自己全忘了，读者倒是记得清清楚楚；
- 大纲在 A 文档、正文在 B 文档、设定在 C 文档，改一处要同步三处；
- 写到一半卡住，想推演「主角这时如果选 X 会怎样」，只能在脑子里空转。

青春幻想引擎就是为这些事做的。

它**不是「AI 帮你写小说」**，而是 —— **把你散落在各个文档里的创作资产，收进一个有结构、能互相关联、能按需喂给 AI 的工作台。**

### 几个值得一提的设计

- **角色与关系双轨** —— 角色卡管「这个人是谁」，人物关系表管「谁跟谁什么关系」，可图谱可视化。
- **从总纲到细纲再到正文的完整链路** —— 分卷大纲 → 章节细纲（带事件链）→ 正文，每一层都能喂给 AI。
- **伏笔追踪** —— 埋了什么、在哪一章回收，一张表管到底，埋了不回收会被揪出来。
- **时间脉络** —— 故事内时间线，支持自定义历法，避免"人物年龄对不上"。
- **情节推演** —— 推演分歧点的不同走向，产出推演报告。
- **防剧透机制** —— 可标记「某角色在某章之前不知道某件事」，AI 推演时不会漏嘴。
- **保密等级与 AI 权限** —— `D · 终结（弃用）` 条目不作为设定资料提供给 AI；`S · 绝密` 不等于禁止发送，作者视角仍可使用，角色视角按入口与知情规则取材。请同时检查字段的 AI 参考权限。
- **一键拆书** —— 丢一本参考书进去，自动抽取人物、关系、设定，做成你自己的素材库。
- **酒馆模式** —— 让 AI 扮演你书里的角色跟你对话、推演剧情，用来找感觉、验人设。
- **伴写建议** —— 正文编辑时给出「下一句可以怎么写」的建议，你采纳或忽略，它不会替你写。
- **提示词全开放** —— 所有 AI 提示词都可在设置页里查看和修改。

## 快速开始

提供 **三种形态**，按需选一个即可：

### 方式一：桌面安装版（推荐，免装 Node）

到本仓库的 **Releases** 页面选择已发布版本，下载对应的 `青春幻想引擎-Setup-版本号.exe`，双击安装即可。源码版本可能先于正式发布，下载文件名与可用版本以 Releases 页面为准。

- **无需安装 Node.js**，装完直接能用；
- 数据存在本机用户目录（`%APPDATA%\youth-fantasy-engine`），**不写进安装目录**；
- 支持**应用内检查更新**：发现新版会提示，你点一下才下载。

> ⚠️ Windows 首次运行可能弹 SmartScreen 提示 —— 点「更多信息」→「仍要运行」。这是所有未购买代码签名证书的软件的常规待遇，不等于病毒警告。

### 方式二：便携版（U 盘即走，需 Node.js）

到 **Releases** 页面按系统下载对应的便携包，解压到 U 盘 / 移动硬盘 / 任意本地文件夹：

| 包名 | 启动脚本 | 适用系统 |
|---|---|---|
| `青春幻想引擎-便携版-版本号-Windows.zip` | `启动.bat` | Windows |
| `青春幻想引擎-便携版-版本号-macOS-Linux.zip` | `启动.sh` | macOS / Linux |

体积以对应版本的发布附件为准（两个包的应用本体一样，只是启动脚本不同）。

1. 双击 `启动.bat`（Windows）→ 自动拉起本地服务 → 自动打开浏览器进入写作界面；
2. **无需安装软件主体、不写注册表**，项目资料随 `data/` 目录移动；系统浏览器仍会保留自身缓存和访问记录；
3. 主数据文件在 `data/youth-fantasy-engine-data.json`，外置历史备份等载荷在同级 `blobs/` 中。优先使用应用内导出留档；手工备份便携数据时请复制整个 `data/` 目录，单独复制主 JSON 会遗漏外置载荷。

> ⚠️ 本机需装 **Node.js**（免费，约 30MB）。
> 本地服务**只绑 `127.0.0.1`**，局域网里别人访问不到。
> **自动更新检查 / 云盘同步 / 系统托盘 / 安装卸载 / PDF 直接导出**这几项依赖系统级安装或后台常驻，便携版没有；其余功能全保留。

### 方式三：网页版（免安装，浏览器直接用）

打开即可写作，**不用装 Node、不用下安装包**：<https://youth-fantasy-engine.online>

| 模式 | 谁用 | 数据在哪 | 跨设备 |
|---|---|---|---|
| **游客** | 所有访客，免费 | 存在**你自己的浏览器**里，不上传服务器 | ❌ 换设备或清了浏览数据就找不回 |
| **云端** | **打赏用户**（凭邀请码注册） | 存在服务器上，按账号隔离 | ✅ **唯一支持跨设备的形态** |

- 游客模式**功能不打折，只做提示**：首启向导、项目页入口、登录页都会明说「清浏览数据或换设备后无法找回」，并引导你**自己导出一份备份**。
- 云端模式由**站主亲手发放邀请码**，一张码只能注册一个账号；这张码同时是**找回密码的凭证**（用户名＋邀请码一起校验，拿到别人的码也改不了你的号）。
- 从 **3.3.2** 起，登录同一账号可在**项目中心 →「云端同步」→「云端作品」**里把书取回到新设备（点「下载为新书」，接着同一本云端作品写；不覆盖本机已有作品）；游客的浏览器本地库不会自动跨设备。桌面 / 便携版也可另行使用导入导出或外部云盘文件同步，切换设备前应关闭软件并等待同步完成。

### 再说一句：从源码运行

```bash
git clone https://gitee.com/tgxy2026/youth-fantasy-engine.git
cd youth-fantasy-engine
npm install
npm run dev            # 浏览器调试：http://localhost:5199
```

打包桌面版：

```bash

```

> 需要 **Node.js 20 或更高版本**。

## 升级与数据迁移

### 3.x → 3.4.2（直接覆盖安装即可）

- **桌面安装版**：直接覆盖安装。程序数据在独立目录（`%APPDATA%\youth-fantasy-engine`），不会被安装包覆盖；
- **便携版**：解压新包后，把旧包的 `data/` 目录整体拷进新包同级位置；
- **网页版**：刷新页面即最新，无需操作。

3.4.0 没有破坏性结构变更：新增的章节收藏集、导出方案、命名快照都带旧数据默认值；即使回退到旧版本，这些新数据也只会被忽略，不会导致打不开。3.4.1 是 3.4.0 的精修版，只改了 AI 提示词文本、审计工具与致谢名单，**同样没有任何数据结构变更**，从 3.4.0 升级或回退都安全。3.4.2 新增的 `protocol` 是**可选字段**，旧模型配置读进来按原 `type` 自动补默认值；三家新协议与降级逻辑只在显式选择时生效，**未配置新协议时全链路与 3.4.1 逐字一致**。即使回退到 3.4.1，新字段也只会被忽略，不会导致打不开。

### 历史：2.x → 3.0（改名与数据目录迁移）

3.0 把软件正式更名为「**青春幻想引擎**」（旧名 **novel-studio**），**程序数据目录随之改变**：

| | 旧版 | 3.0 |
|---|---|---|
| 数据目录 | `%APPDATA%\novel-studio` | `%APPDATA%\youth-fantasy-engine` |

首次启动 3.0 若检测到旧版数据，会弹出「**发现旧版数据**」向导，点一下就能把旧版的书稿、向量索引、知识库与界面偏好一次性导过来。

- ✅ **数据向后兼容**，不迁移也能用；迁移只是把旧版内容搬过来；
- 🔴 **先完成导入、确认书稿都在，再去卸载旧版**；
- 🔴 **正常只需导一次**（导入＝旧库覆盖新库，重复导会盖回旧数据）；
- 完整指引见 [`docs/归档/3.0/3.0-数据迁移指导.md`](docs/归档/3.0/3.0-数据迁移指导.md)。

## 数据与隐私

- **桌面版与便携版**：主数据与外置载荷保存在本机或便携目录；桌面的参考资料/向量索引另有独立存储，按对应功能的导出说明处理。
- **网页游客**：数据在当前浏览器的 IndexedDB；清除浏览器数据或换设备不会自动找回。**登录账号 / 云端作品**：数据在服务器上，按账号隔离，单账号默认 **200 MB** 配额（含图片与全部历史版本对象）；云端删除先入**回收站保留 30 天**，过期条目与无人引用的上传碎片由服务端定期自动清理。
- **模型与联网服务**：云端模型会收到本次发送的资料；检索、更新、账号存储、WebDAV/S3 及外部云盘各使用对应服务。使用第三方云盘同步也会把文件交给该云盘服务处理。
- **备份**：优先使用应用内导出；手工复制文件型资料时，应同时保留主 JSON 与同级 `blobs/`。导出有载荷读取失败提示时，应保留原资料，不把部分导出当作完整副本。
- 图片入库前会先压缩，避免库文件无限膨胀。
- ⚠️ 换设备前请先**关闭软件**并等待云盘同步完成，避免半同步状态造成数据冲突。

## AI 功能说明

### 支持的模型来源

**本地模型（数据不出本机）**

| 类型 | 说明 |
|---|---|
| Ollama | 填本地地址即可，推荐 |
| 本地 OpenAI 兼容服务 | LM Studio / vLLM 等任意兼容实现 |

**云端模型（会把选定上下文上传给该服务商）**

硅基流动 · DeepSeek · 通义千问 · 智谱 GLM · 豆包 · Kimi · MiniMax · 腾讯混元 · 百川智能 · 零一万物 · Groq · OpenRouter · OpenAI · 自定义接口

### 数据会发给谁

**只发给你当前选定的那个模型。**

用本地模型 → 完全不出本机；用云端模型 → 当前会话所需的上下文会上传给该服务商。软件内置上下文预算控制，让你能看清"这次要发多少、发了哪些"。

### 上下文是怎么控制的

- **预算上限**：按**模型上下文窗口的一半**算（下限 8K，上限跟随所选窗口，最高支持 2M tokens），超出的内容按优先级裁剪；
- **保密等级**：`D · 终结（弃用）` 条目从设定取材中排除；`S · 绝密` 在作者视角仍可能发送。等级过滤不会自动抹去你在正文或手动输入中粘贴的相同内容，敏感资料还应核对字段的 AI 参考权限与本次数据来源；
- **防剧透**：角色视角推演时，只看该角色在当时的章节节点应该知道的信息。

## 已知限制

- **桌面安装版仅 Windows**（无 Mac / Linux 原生安装包）；**便携版**可跑在 Windows / macOS / Linux，需自装 Node.js 20+。
- **仅简体中文**，暂无多语言支持。
- **便携版**的「自动更新 / 云盘同步 / 系统托盘 / 安装卸载 / PDF 导出」不可用（依赖系统级安装或后台常驻），其余功能齐全。
- **跨设备**：从 **3.3.2** 起，登录账号后可在**云端作品库**里逐本接续 —— 手动上传一本之后按保存自动同步（约 20 秒一次，无改动会退避到 5 分钟），新设备「下载为新书」接着写；它仍是**异步接续、不是实时协作**，两台设备同时改同一本会检出冲突交你选。桌面 / 便携也可走云盘文件夹同步，**换设备前需手动等同步完成**；网页版**云端模式**只对打赏用户开放（游客模式数据只在本地浏览器）。
- **超长篇性能**：500 章 / 约 100 万字的夹具已做过开发前后对照（打开正文、筛选、切回均无实质回退）；更大体量仍在持续优化，不承诺固定耗时。
- 内置 AI 功能需要你自己准备模型（本地或云端），软件本身不附带任何模型。
