青春幻想引擎 · 便携版（U 盘版）使用说明
================================================

【它是什么】
  一个可以装进 U 盘 / 移动硬盘 / 本地任意文件夹的「自带数据」版本。
  解压 → 双击 → 浏览器自动打开写作界面。**本机不需要安装任何东西。**

【三个承诺】
  · 免安装：不需要装 Node.js，也不需要装本软件本身。解压即用。
  · 数据随盘走：所有稿件都在本文件夹的 data/ 里，拷走文件夹就是完整备份。
  · 不进设备：不写注册表、不留 %APPDATA% 痕迹、不改系统设置。
    换台电脑，把文件夹拷过去就能接着写。

【目录结构】
  便携版/
    ├── 青春幻想引擎-便携版.exe   ← Windows：双击这个
    │                               （免安装运行时，已内嵌全部依赖）
    ├── 启动.bat                  ← 备用入口（exe 被安全软件拦下时才需要）
    ├── 启动.sh                   ← macOS / Linux 用
    ├── 使用说明.txt              ← 本文件
    ├── scripts/
    │     └── portable-server.mjs   ← 本地服务（别删）
    ├── dist/                     ← 应用本体（别删）
    └── data/                     ← ★ 你的小说数据都在这（首次启动后自动生成）
          └── youth-fantasy-engine-data.json

【怎么用】
  1. 双击「青春幻想引擎-便携版.exe」。
  2. 浏览器会自动打开写作界面，直接开始写。
  3. 写完直接关浏览器即可，数据会自动保存到 data 文件夹（改动后约 0.8 秒自动落盘）。
  4. 想停止服务：关掉那个黑色的命令行窗口。

【数据安全（重要）】
  · 所有数据只有一个文件：data/ 目录里的 youth-fantasy-engine-data.json
  · 备份 = 直接复制这个文件到别处（建议定期做）。
  · 换 U 盘 / 换电脑：把整个「便携版」文件夹拷过去即可，数据跟着走。
  · 写入采用「先写临时文件、再原子改名」——中途断电不会留下半个损坏文件。

【和桌面版怎么互通】
  两个版本的数据格式完全相同，靠「整库 JSON 导入导出」互通：
  · 桌面版 → 便携版：桌面版「设置 → 数据」导出 JSON，
    再在便携版界面里「导入数据文件」。
  · 便携版 → 桌面版：便携版导出 JSON，桌面版「设置 → 数据」导入。
  （两者不直接读对方的数据文件，走导出/导入最稳妥。）

【常见问题】
  Q: 双击 exe 时 Windows 提示「已保护你的电脑」/「未知发布者」？
  A: 因为本软件没有购买代码签名证书。点「更多信息」→「仍要运行」即可，
     只需点这一次。数据完全在你自己的文件夹里，可放心。

  Q: 杀毒软件把 exe 删了 / 隔离了？
  A: 把整个「便携版」文件夹加入杀软白名单，重新解压一次即可。
     暂时不方便的话，双击「启动.bat」也能用（它会回退到系统已装的 Node.js）。

  Q: 双击没反应 / 一闪而过？
  A: 多半是 exe 被杀软拦了。试试「启动.bat」；若提示没有运行时，
     说明本机既没有自带运行时也没有 Node.js —— 重新完整解压一次压缩包。

  Q: 提示端口被占用？
  A: 不用管，服务会自动换一个可用端口。

  Q: 提示「已在运行」？
  A: 说明你之前已经启动过一次（或双击了两次），会自动复用那一个，直接用即可。

  Q: 数据会不会被传到网上？
  A: 不会。本地服务只绑定 127.0.0.1（本机回环地址），
     局域网里其他人都访问不到；便携版本身也不含任何云同步功能。

  Q: 能接 AI 吗？
  A: 可以。本机跑 Ollama 的模型能直接用；
     云端模型需要你自己填密钥（和桌面版一样）。

【与桌面版的差别】
  · 没有：自动更新检查、云盘文件同步、系统托盘、安装/卸载、PDF 直接导出
    （这些依赖系统级安装或后台常驻，便携版跑在浏览器里做不到）。
  · 其余功能全部保留：书稿编辑、世界观、时间线、关系图、
    AI 创意写作、酒馆对话、全文检索、导入导出等。

  详见 docs 里的《3.0 便携版功能对照表》。
