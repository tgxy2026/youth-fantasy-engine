青春幻想引擎 · 便携版使用说明（安装前必读）
================================================

【这是什么】
  一个可以装进 U 盘 / 移动硬盘 / 本地任意文件夹的「自带数据」版本。
  解压即用、数据全在文件夹里，不写注册表、不留 %APPDATA% 痕迹，换电脑随盘即走。

【下载哪个包？】
  · Windows 用户        → 青春幻想引擎-便携版-<版本>-Windows.zip
  · macOS / Linux 用户  → 青春幻想引擎-便携版-<版本>-macOS-Linux.zip
  两个包的应用本体完全一样，只是启动脚本不同：
  Windows 包用「启动.bat」，macOS / Linux 包用「启动.sh」。

【🔴 第一步：安装 Node.js（必读，约 30MB，免费，只需装一次）】
  便携版靠本机的 Node.js 运行，所以使用前要先装它。
  装一次就够 —— 之后把文件夹拷到任何电脑，那台电脑也装一次即可。

  · 官方下载：https://nodejs.org/zh-cn/download
    选 **LTS 长期支持版**即可，要求 Node.js 20 或更高（推荐 20 LTS / 22 LTS）。
  · 国内镜像（下载更快）：https://npmmirror.com/mirrors/node/
    进去后按系统选：Windows 对应 `node-vXX.X.X-x64.msi`，macOS 对应 `node-vXX.X.X.pkg`。
  · 装完怎么确认：
      - Windows：打开「命令提示符」输入  node -v
      - macOS / Linux：打开「终端」输入  node -v
    能显示版本号（如 v22.22.2）就成功了。

【第二步：启动】
  · Windows：双击「启动.bat」
  · macOS / Linux：在终端里执行  bash 启动.sh
    （若提示没有权限，先执行一次  chmod +x 启动.sh  ）
  首次启动会自动探测一个空闲端口，并打开浏览器进入写作界面。
  想停止服务：关掉那个命令行 / 终端窗口即可。

【目录结构】
  便携版-*/
    ├── 启动.bat                   ← Windows：双击这个
    ├── 启动.sh                    ← macOS / Linux：bash 启动.sh
    ├── 使用说明-安装前必读.txt     ← 本文件
    ├── scripts/
    │     └── portable-server.mjs    ← 本地服务（别删）
    ├── dist/                      ← 应用本体（别删）
    └── data/                      ← ★ 你的小说数据都在这（首次启动后自动生成）
          └── youth-fantasy-engine-data.json

【数据安全（重要）】
  · 所有数据只有一个文件：data/ 目录里的 youth-fantasy-engine-data.json
  · 备份 = 直接复制这个文件到别处（建议定期做）。
  · 换 U 盘 / 换电脑：把整个「便携版」文件夹拷过去即可，数据跟着走
    （新电脑同样需要装 Node.js）。
  · 写入采用「先写临时文件、再原子改名」——中途断电不会留下半个损坏文件。

【和桌面版怎么互通】
  两个版本的数据格式完全相同，靠「整库 JSON 导入导出」互通：
  · 桌面版 → 便携版：桌面版「设置 → 数据」导出 JSON，再在便携版界面里「导入数据文件」。
  · 便携版 → 桌面版：便携版导出 JSON，桌面版「设置 → 数据」导入。
  （两者不直接读对方的数据文件，走导出/导入最稳妥。）

【常见问题】
  Q: 双击 启动.bat 没反应 / 一闪而过？
  A: 九成是没装 Node.js。装完再试；若仍提示找不到 node，请装完后**重开一次资源管理器 / 终端**
     （让新的 PATH 生效），不行就重启一次电脑。

  Q: macOS 提示「无法打开，因为无法验证开发者」？
  A: 这是 macOS 对未署名程序的默认拦截。到「系统设置 → 隐私与安全性」拉到底部点「仍要打开」；
     或者干脆用终端方式运行（bash 启动.sh），终端不受该限制。

  Q: Linux 下提示 Permission denied？
  A: 先执行  chmod +x 启动.sh  再运行；或直接用  bash 启动.sh  。

  Q: 提示端口被占用？
  A: 不用管，服务会自动换一个可用端口。

  Q: 提示「已在运行」？
  A: 说明你之前已经启动过一次（或双击了两次），会自动复用那一个，直接用即可。

  Q: 数据会不会被传到网上？
  A: 不会。本地服务只绑定 127.0.0.1（本机回环地址），局域网里其他人都访问不到；
     便携版本身也不含任何云同步功能。

  Q: 能接 AI 吗？
  A: 可以。本机跑 Ollama 的模型能直接用；云端模型需要你自己填密钥（和桌面版一样）。

  Q: 想让 AI 读我的资料（txt / md / docx）怎么办？
  A: 进项目后到「素材资料 → 我的参考资料」页，把文件挂载上去并勾选「启用」，AI 会自动按需读；
     临时想让某一次任务参考一份文件，可在 AI 弹窗里点「附加文件」（仅本次有效，不入库）。

【与桌面版的差别】
  · 没有：自动更新检查、云盘文件同步、系统托盘、安装/卸载、PDF 直接导出
    （这些依赖系统级安装或后台常驻，便携版跑在浏览器里做不到）。
  · 其余功能全部保留：书稿编辑、世界观、时间线、关系图、AI 创意写作、
    酒馆对话、全文检索、导入导出、参考资料与附加文件等。

  详见 docs 里的《3.0 便携版功能对照表》。
