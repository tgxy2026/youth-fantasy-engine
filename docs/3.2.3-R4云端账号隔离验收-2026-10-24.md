# 3.2.3 R4：web-cloud 账号隔离真机级取证

> 日期：2026-10-24｜执行：可可｜基线 `main` / `2c576fc` → 本次提交
> 范围：**本地真实服务 + 临时账号 + 两个独立浏览器上下文**；不碰生产服务、不用真实账号、不给产品加故障开关。
> 版本号仍 3.2.2；未封装、未发布、未部署。

## 1. 为什么这批必须做真环境

方案 §7 对 web-cloud 的要求很具体：

> 「web-cloud 使用两个独立浏览器上下文模拟两设备会话；再用共享 Cookie 的两个标签验证同浏览器场景。
> 会话过期用本地测试服务签发已过期凭证/测试时钟验证，不等待 30 天。」

这句话之前一直是 blocked：四配置里只有 portable 用 HTTP 夹具验过、游客用真浏览器 IDB 验过、桌面用真 Electron/IPC 验过，
**云端账号这条完全空白** —— 而它恰好是最容易串库的一条（Cookie、单会话、旧标签页）。

## 2. 做法

新增 `scripts/audit/probes/web-cloud-save-probe.cjs`：

- 起**本机真实服务**（`server/index.mjs`），`YFE_DATA` 指向 `.workbuddy/tmp/web-cloud-save-*` 隔离目录，`YFE_WWW` 指向本次生产构建，注册模式开；
- 账号是探针自建的**临时账号**（`probe-a-/probe-b-/probe-c-` + 时间戳），校验器会核对 `scope` 里必须声明 throwaway accounts；
- **两个独立持久化 profile** 当两台设备；同浏览器场景用同一 context 换账号；
- 所有请求只允许 `127.0.0.1:<临时端口>`，其它域名一律 abort（不联外网）。

## 3. 15 项检查

| 检查 | 断言要点 |
|---|---|
| page-renders-account | 登录态进入真实页面，注入的 `__YFE_USER__.name` 与账号一致 |
| initial-flags | `WEB=1`、`PORTABLE` 为对象（云端复用 HTTP StoreOps）、**无 GUEST 标记**、有账号名 |
| boot-store | 新账号 GET `/api/data` ⇒ 404 `missing`（不是空壳 200） |
| write-readback | PUT 合法整库 ⇒ 200；再 GET 能读回同一段正文 |
| data-scoped-to-account | 读回的内容确实是本账号写入的那份 |
| **two-accounts** | 另一设备 + 另一账号 ⇒ 404 `missing`，看不到 A 的数据 |
| **same-browser-account-switch** | 同浏览器换账号后页面账号名变、库里也变（不串） |
| switch-back-restores-own-data | 换回原账号，原数据完好 |
| **expired-session** | 同账号在别处登录后，旧会话 PUT ⇒ **401 + `code=SESSION_REPLACED`** |
| stale-write-did-not-land | 被拒的旧会话写入**没有落到**账号库（核对新会话读回） |
| guest-never-writes-server | 未登录（游客）访问 `/api/data` ⇒ **401**，游客不会写服务端 |
| **guest-to-account** | 游客在浏览器里写了本地数据后注册账号 ⇒ 账号库仍 404（不自动上传/不混库） |
| guest-local-data-intact | 那位游客的 IndexedDB 数据仍在原处（没被注册动作动过） |
| no-pageerror | 全程零页面异常 |
| unchanged-inputs | 探针前后源码指纹一致 |

## 4. 证据闸与矩阵

- `scripts/verify/web-cloud-evidence.mjs`：只认「本次构建哈希 + 本次源码指纹 + 15 项齐全且全过 + 隔离目录前缀 `web-cloud-save-` + `server-data` 存在 + 产物哈希一致 + 声明临时账号」。
- `tests/webCloudEvidence.test.ts`（17 条负面对照）：冒充配置、源码/构建过期、缺场景（含专挑 `two-accounts`、`expired-session` 两项）、重复场景、失败场景、页面异常、错误状态、**未声明临时账号**、产物缺失/重复/哈希变/越界、非隔离目录、目录前缀不符 —— 全部拒绝。
- 统一入口新增 `storage.web-cloud-save`（≥14 断言，实 15）。
- 矩阵：**只点亮 `account-isolation/web-cloud`**（四个子场景齐：two-accounts / guest-to-account / same-browser-account-switch / expired-session）。
  `boot-store/web-cloud` **不点亮** —— 缺 restart-readback（本次没做浏览器重启回读）；`write-failure/web-cloud` 也不点亮（配额写失败与故障期导出没验）。
