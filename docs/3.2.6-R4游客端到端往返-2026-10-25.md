# 3.2.6 · R4 游客端到端往返实测（2026-10-25）

> 承接 [R4 端到端往返](3.2.3-R4端到端往返-2026-10-24.md)（桌面 + 云端）与便携往返（`45b1a60`）。
> 本次补齐**游客配置**，`storage.four-profiles` 的四条端到端往返至此全部有据。

## 1. 为什么游客不能照抄另三端

| 端 | 数据在哪 | 怎么判"真的落盘了" |
|---|---|---|
| desktop | 本机 JSON 文件（IPC 写） | 读文件 + 逐次 IPC 回读 |
| portable | `./data/*.json`（HTTP 写） | 读文件 |
| web-cloud | 服务器 `data.json`（HTTP + If-Match） | 读服务端文件 |
| **web-guest** | **浏览器 IndexedDB** | **只能直接读 IDB，没有任何文件可看** |

游客还有两个独有的坑：

1. **导出是浏览器下载**（blob URL + `<a download>`），不是 File System Access API —— 后者 Safari/Firefox 根本没有；
2. **导入是"先清空整库再写入"**，且成功后 `location.reload()`。所以「导入失败」与「导入成功但内容不对」必须分开验。

## 2. 做法（`scripts/verify/web-guest-roundtrip.mjs`）

真实 `server/index.mjs` 的 `/guest` 路由 + 持久化浏览器 profile + 真实下载/真实选文件，
数据根与库都在临时目录，不碰真实数据。

| # | 断言 | 做法 |
|---|---|---|
| 1 | `export-file` | 点导出 → **真实 download** → 解析后库里有一章 = 页面正文 |
| 2 | `export-is-portable-data` | `kind==='portable-data'` 且 `app==='youth-fantasy-engine'` |
| 3 | `changed-in-indexeddb` | 改正文 + Ctrl+S → **直接读 IDB** 确认改动已落库 |
| 4 | `import-page-readback` | 导入（确认框 + 真实 filechooser）→ reload → 页面回到导出那一刻 |
| 5 | `import-indexeddb-readback` | IDB 里那一章 === 导出时的正文 |
| 6 | `import-restart-readback` | **关掉浏览器重开**（同一 profile）→ 仍是那一段 |
| 7 | `no-pageerror` | 全程无页面异常 |

关键设计沿用另三端：**导出后必须先把库改成别的样子并落库**，否则"导回导出那一刻"证明不了任何事。

## 3. 踩到的坑（已写进脚本注释）

### 🔴 `isVisible()` 不等待渲染

第一轮直接超时在 `getByRole('navigation').waitFor()`。原因不是产品没进项目，而是：

```ts
if (await opener.isVisible()) { await opener.click() }   // ← reload 刚回来，卡片还没画出来就返回 false
await page.getByRole('navigation').waitFor()             // ← 于是永远等不到
```

改法：先 `Promise.race([opener.waitFor(visible), nav.waitFor(visible)])`，**任一个出现**再决定要不要点。
这个坑对任何"页面可能停在 A 也可能停在 B"的探针都成立。

### 其余两条（与便携/云端同源，别重踩）

- 不能拿原始 JSON 文本 `includes` 比正文 —— 换行在 JSON 里是 `\n` 两个字符；
- 不能按"第一条章节"比 —— 当前编辑的可能是第 N 章，要判"库里**有一章**等于导出时那段"。

## 5. 边界（别当已验）

- 仍未覆盖：`roundtrip` 矩阵的四个子场景（schema-version / sidecars / secret-stripping / restore-failure），
  以及在途编辑、切项目、关窗时的写失败。
- **游客导出取的是库里的内容**（`collectAll()` 走 `ops.getAll`）—— 保存失败那一刻的草稿只在页面内存，
  导出的备份里**不含**它。这一点按用户决议走提示方案 A：写失败时追加
  「导出的备份不含未保存的草稿，请不要关闭或刷新页面…」（`lib/app/saveFailureHint.ts`），
  不做"导出带上内存草稿"。
- 全程 headless msedge，不代表真实输入法、真实移动端浏览器或 Safari/Firefox 的下载行为。
