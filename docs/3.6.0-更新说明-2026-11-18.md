# 青春幻想引擎 3.6.0 更新说明

> 发布日期：2026-11-18　|　源码版本：`v3.6.0`

3.6.0 是「拆书分析与创意写作闭环」的收口版本：把**作品分析 → 创作参考 → 审读 → 章后整理 → 剧情候选**这条链从「各自能跑」接成「有记录、可追溯、失败说得清」，同时把审计工具升级到能持续守住这条链。

## 一、这个版本新增/强化的能力

### A. 成果记录（新）

拆书分析、参考卡这类「分析产出」不再只留在当次界面里，而是落成**成果记录**：

- 保存为成果后可在成果列表回看，`kept / draft / excluded` 三种状态各自可见；
- **作者标为「已排除」的成果不会被发送**（此前会被当成「未审」照发）；
- 项目导出/导入后，成果随项目走；指向不存在章节的标 `missing` 并降为草稿，不静默丢弃。

### B. 一键拆书：分析结果与范围说明

- 拆书结果明确区分「本次范围内的结论」与「全书结论」，不把局部结果说成全书；
- 失败/未完成会如实标注，不出现「空结果冒充没有变化」。

### C. 创作参考：只发你勾选的

- 参考卡按预算裁剪（最多 12 张 / 约 2400 字），并明确告诉模型「这是别的作品的写法，不要照搬情节人名」；
- 来源过期或读不到时**一条都不发**，并在界面上说明原因；
- 搭配「已排除」语义：排除是作者的否定决定，不会被勾选、也不会被发送。

### D. 审读记录可回看

- 审读运行后会留下摘要记录，可在创作轨迹里回看；失败如实呈现，不生成空记录冒充成功。

### E. 章节保存与章后整理

- 保存与章后整理分开：正文保存成功后，整理失败会明确显示「整理待恢复」，**不宣称整章事务已原子完成**；
- 章后整理页新增「本次会读」标注：**只把本章正文发给模型**，伏笔/关系/角色卡/设定表的比对全在本机做（本次补登记，此前没写）。

### F. 剧情候选

- 候选生成后可应用 / 放弃；放弃的不会再次出现；
- **候选可追溯到检查报告**（3.6.0 新接）：从「检查报告 → 以此发起修订」进来的候选会带上报告 id，候选审阅里能回答「这稿按哪份报告改的」；手填要求改写的候选不带来源，不编造。

### G. 材料检索

- 检索带来源章节，空项目给空态而不是报错；
- 检索策略有基准：生产默认策略在合成语料上召回 100% / 精确 61.1%，并单独测「跨项目不串味」。

### H. 图鉴字段可见性

- 自定义字段的「适用类别」保存为**空数组**时会被拦下，并给出「改为不限类别」的单条动作（此前会存成「图鉴永远不显示」的死配置）；
- 隐藏字段统计与图鉴卡片/详情共用同一份判定，0 个时不占位。

### 其他

- 界面一致性：76 处带文字的 `ghost` 按钮改为有框样式；5 个页面补齐页头帮助问号；
- 同步：修复「记录内容相同但键序不同被判成变了」导致的假冲突副本与反复推送。

## 四、已知限制（如实说明）

1. **三端数据与模型配置不共享**：桌面/便携的模型密钥只存本机，不随导出与云同步扩散；网页版随账号存服务端。
2. **便携版不支持投稿广场与码字排行**（本地写作不受影响）。
3. **章后整理依赖模型**：未配置模型时该功能不可用，界面会如实提示而不是假装完成。
4. **第二台实体设备验收未完成**：不同 DPI / 系统主题下的四项配置验收仍标记为 blocked。
5. **便携版「会话替换」口径未定**：便携版没有会话概念，该策略是否适用待产品确认，因此对应测试项标 blocked。
6. **审计工具的能力边界**：相似度类检查（重复代码、近似模块）仍需人工抽样；审计 `complete` 只代表静态与契约层面通过，不等于功能验收。

## 五、升级建议

- 从 3.5.x 升级：直接安装覆盖即可，数据在原位置（`%APPDATA%\youth-fantasy-engine`）；建议升级前在「设置 → 备份」手动导出一份项目包。
- 从便携版迁移：把旧包内 `data/` 目录整体拷到新包同名位置。
- 遇到问题：优先看「设置 → 使用指南」里的对应条目；数据类问题请附「设置 → 诊断」导出的信息。
