# 档二 · 标准省流版（正式发群用）

【青春幻想引擎 2.8.2 · 更新】

这版主要是**酒馆模式（角色扮演）大升级**，外加修掉三个「看起来没事、其实没生效」的暗坑。

▍怎么拿
群文件 / 群公告自取。覆盖安装即可，老项目数据不动。

▍酒馆改了啥
· 背景设定 / 故事剧本升级成**世界书**：每一节都能写自己的触发词，聊到才带，不再整份塞给模型
· 配了**四色灯**（常驻 / 触发 / 引荐 / 休眠），一眼看清每条什么时候会进上下文
· **注入额度跟着模型窗口自动算**，小窗口的模型也不会再「存得下、注不进」
· 剧情推演加了**分支树**，从哪一场分出来的一眼看得明白
· 自由对话加了**检查点**（一键回到某句话之前，还能撤销）和**语义召回**（聊久了不忘事）
· 同场角色上限 **3 → 6**；用不上的角色可以挂「在场不出声」，不占名额也不吃上下文

▍角色演得更好了
这版对照酒馆（SillyTavern）内置提示词做了取长补短，角色会：
· 更**入戏** —— 把自己当专业演员去演，而不是站在外面描述
· 更**难出戏** —— 你问「你是不是 AI」，Ta 也不认，继续用角色身份接话
· 更**耐看** —— 节奏有起伏、带五感，该铺的动作与过程不会一句话糊弄过去

▍修了什么
三个静默坑（都不报错，但功能其实没生效）：
· 控制面板调了注入比例 → 实际没生效
· 回滚之后旧索引没重建 → AI 会记住「已经退回去、没发生过」的事
· 小窗口模型下，总纲「存得下、注不进」
另有云同步 / 存储 / 世界书等 20 多处修复。

▍一个小提醒
自由对话的记忆是「按角色、跨对话共享」的：回滚会影响这个角色在**别的对话里**记得的事 —— 界面上有提示。
