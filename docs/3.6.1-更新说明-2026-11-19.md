# 青春幻想引擎 3.6.1 更新说明

> 发布日期：2026-11-19　|　源码版本：`v3.6.1`

3.6.1 是「质量与体验收口」版本：没有新页签，主要把上一版记下的债清掉，并把几处用起来别扭的地方改顺。**数据格式没有变化**，直接覆盖安装即可。

## 一、你能直接看到的变化

### A. 搜索替换：先选「本章」还是「全书」

「工具 → 版本与检索」里的「全书搜索替换」改名为**搜索替换**，点开第一件事是选范围：

- **本章**（默认）：只改当前这一章，其它章一个字都不动；
- **全书**：扫全部章节，替换前再确认一次，并写明会动几章。

顺手修掉一个隐患：搜索会看正文与章名，但**替换只改正文**。只命中章名的条目会被标出来、不计入可替换数量——不会再出现「提示替换 3 处、实际只改了 2 处」。

### B. 颉文姬面板：可以拖到你习惯的位置

面板默认仍贴在屏幕右侧（和以前一样），标题栏多了一个锁形开关：

- 打开后可拖标题栏移动，**松手会吸附到最近的边**（上下左右四条边都算，靠角落两边一起贴；离边远就停在原地，中间也放得住）；
- 右下角可以拉宽（300–560），双击标题栏或点复位按钮回到默认位置；
- 旁边的左右箭头可以直接停靠/吸附到另一侧；
- 窗口宽度不足 1180 时自动回落到贴边停靠（不在窄窗口上浮，免得挡住正文）。

同时修掉两个显示问题：吸附右侧只剩半边、上下长度不对（界面缩放没折算），以及改缩放后面板没有跟着重算。

### C. 缩进单位多了「无缩进」

排版 → 缩进单位可选「无缩进」：段落一律顶格，Tab 不再加缩进、回车不继承缩进、粘贴会去掉行首空白，「统一为段首缩进」会把段首空白全部去掉。

### D. 图鉴详情可以「按语义看」

详情里字段分组下方多了一个默认收起的「按语义看（身份 / 动机 / 状态）」，按这三个用途重列一遍并标出处。它只是读取：不写回、不另存一份，要改内容仍回表格改原字段。

### E. 「未来计划待重审」能看到依据了

章后整理里每条待重审的章，右侧多了「看依据」：展开是改动处的「改前 → 改后」片段（各最多 300 字）。依据只留变化的那一小段，不会把整章正文再存一份；更早打的标记没有依据时会如实说明。

### F. 数据文件出问题时，多了一条「复制诊断信息」

顶部红条（数据文件读取失败）现在有一键复制：把版本、平台、数据文件路径（标明默认还是自定义位置）、锁定原因拼成一段话，**不含正文内容**，直接发给作者即可。

另外那颗危险的按钮从「仍用当前内容继续」改名为「**放弃原文件继续**」——它真实后果是用空库覆盖数据文件，名字先把话说清楚。

### G. 致谢名单

新增一位打赏读者（详见「关于打赏」页）。

## 二、修掉的问题

| 问题 | 说明 |
| --- | --- |
| 图鉴里改的字段，正文编辑的设定检索看不到 | 检索原来只认内置列；现在字段清单 = 内置列 ∪ 记录里真实存在的键，图鉴新增/改名的自定义字段、采用模板后的字段都会出现，控件类型也保留（下拉仍是下拉） |
| 浮动面板贴右侧只剩半边、上下长度不对 | 界面缩放会把内联坐标再乘一次，已按缩放折算全部几何 |
| 改界面缩放后浮动面板不重算 | 订阅缩放变化事件，改完立即重新贴合边界 |
| 导入按钮在导入中多了一句悬停提示 | 恢复为 3.6.1 之前的文案（本版不新增用户可见文案） |
| 文案若干处与实现不符 | 「页头本页指引」（实际在左下角）、「请使用 3.4.3 版」（过时指引）、入口名「使用手册/使用指南」不统一、使用指南把旧版本标成「本版新增」、迁移向导里的旧品牌名与自相矛盾表述 |

## 三、工程质量（你看不到，但影响稳定性）

- **未接线模块的能力缺口清零**：`changeEvents`（证据层）与 `semanticView`（图鉴只读投影）已接线；其余 7 条为按需求保留的组件与度量夹具，均已登记性质与理由。
- **零覆盖台账**：13 条安全/数据/算法类文件全部写清「为什么现在不补」与「什么情况下必须补」。
- **死代码与重复实现**：合并了 `stableHash` / `utf8Bytes` 两份逐字节相同的实现；去掉伏笔看板每列的两次全表过滤。
- **审计工具新增两条硬线**（自检 23 → 26 项）：① 缓存界面缩放/窗口尺寸却不订阅变更；② 同名导出且函数体完全相同。这两条正是本版两个真实事故的形态，以后同类问题会在发版前被拦住。
- 全量单测 **498** 条通过；六维审计 complete（970 个源码文件、0 候选）。

## 四、升级与兼容

| 形态 | 怎么升 |
| --- | --- |
| 桌面版 | 直接运行 `青春幻想引擎-Setup-3.6.1.exe` 覆盖安装，项目数据不用动 |
| 便携版 | 用新 zip 替换整个目录（`data/` 目录是你的数据，替换前先复制一份更稳妥） |
| 网页版 | 刷新页面即可（`Ctrl+Shift+R` 强制刷新可立刻拿到新版本） |

- **数据格式未变**：3.6.0 及更早的项目可直接打开；没有迁移步骤。
- 已安装 3.6.0 的用户不需要先卸载再装。

## 五、已知限制

- 便携版不支持投稿广场（与 3.6.0 相同）。
- 窗口宽度不足 1180、或界面缩放较高时，颉文姬面板只能贴边停靠（窄窗口上浮会挡住正文）。
- 搜索替换的「全书」范围只改正文，**改章名请回章节列表或本章标题框**。
