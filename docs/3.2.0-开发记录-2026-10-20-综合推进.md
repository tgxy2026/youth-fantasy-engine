## 🔑 关键设计决策

| 决策 | 依据 |
|---|---|
| `Set` → `Array` 转移表 | esbuild 打包后 `Set` 的 `has` 方法丢失 |
| `completeApplyCandidate` 不校验摘要 | 写盘失败由调用方通过回读摘要检测 |
| 逐行 diff（非 LCS） | 候选文本 200-2000 行，O(n) 足够快 |
| 中文字数 = 汉字数 + 英文词数 | 简单混合统计 |
| 去重键 = 章+来源+证据摘要 | 无证据文本退回标题规则 |
| 可执行 = action≠manual 且 有已定位证据 | 与 §7.2 一致 |

## 🔴 已知限制

1. **Diff 算法**：首版用逐行对比，不引入 LCS。
2. **字数统计**：简单中英文混合统计。
3. **写盘失败检测**：`completeApplyCandidate` 不校验 `afterBodyDigest`，调用方必须先回读。
4. **崩溃核对**：仅覆盖「有 intent 无 receipt」和「有 intent 有 receipt」两种场景。
5. **既有失败**：`BackupPayloadSplit`、`CloudStoreWrapper`、`PortableBackend` 三个 D 批入口失败，与本次无关。
