# 文字海报设计规范 & 提示词模板（联网调研版）

> **用途**：3.0 对外宣传海报的设计依据。第一次做文字海报，先把「怎么才好看、怎么才看得清」查清楚。
> **调研日期**：2026-10-11 ｜ 来源：多篇设计教程 + Qwen 官方/魔搭提示词指南 + 社交平台素材规范
> **适用**：A 组（全部页签卡）/ B 组（3.0 新功能卡）/ 封面三件套

---

## 一、四条「决定 80% 效果」的铁律

来自设计师总结（`versely.studio`），这四条是小白的最大杠杆：

| # | 铁律 | 具体做法 |
|---|---|---|
| 1 | **字体 ≤ 2 种** | 主标题用粗黑体、正文用常规无衬线。**字体多 = 乱，不是创意** |
| 2 | **只有一个最大** | 全局必须有"第一眼读到的东西"。标题/产品/logo 若一样大，视线乱跳 = 信息不落地 |
| 3 | **留白是设计元素，不是浪费** | 版心占 60–70%，**四周留白 ≥10%**。新手本能是填满，**克制才是"专业感"的来源** |
| 4 | **三色原则** | 1 主色 + 1 辅色 + 1 点缀色（点缀 ≤10% 面积）。**颜色逐个凭感觉挑 = 看起来像不同公司的作品** |

## 二、信息层级（三层结构）

| 层级 | 占比 | 字号建议（@1024宽） | 内容 |
|---|---|---|---|
| **主标题** | 15–20% | **≥80px** | 核心卖点（组名 / 功能名） |
| **副标题** | ~10% | 30–50px | 补充说明 |
| **正文/细节** | 5–8% | ≥18px | 页签名 / 说明 / 角标 |

🔴 **字号差要拉开**：主标题 : 正文 **≥ 3 倍**（差距小 = 层级糊，一眼看不出重点）
🔴 **字号比例套黄金比**：副标 ≈ 主标 ÷ 1.618（如主 92px → 副 57px、正文 35px）

## 三、🔴 缩略图可读性（本方案最关键的一条）

### 实测：我们的海报缩到信息流缩略图后会怎样？

原图 1024px 宽 → 缩略图 140px（**比例 0.137**）：

| 元素 | 原字号 | 缩略图后 | 判定 |
|---|---|---|---|
| 主标题（组名） | 92px | **12.6px** | ⚠️ 勉强 |
| 封面主标题 | 110px | **15.0px** | ✅ 可读 |
| 序号 | 54px | 7.4px | ❌ |
| 其余（版本/副标/页签/描述） | 22–40px | 3–5.5px | ❌ |

### 三档检验法（科学判断，别一刀切）

| 档位 | 场景 | 缩放 | 要求 | 当前达标情况 |
|---|---|---|---|---|
| **三秒档** | 信息流扫过（拇指大小） | 140px | **只需认出主题**（主标题） | ⚠️ 需把主标题加到 ≥110px |
| **三米档** | 点开扫一眼 | 480px | 主+副标题可读 | ✅ 基本达标 |
| **一尺档** | 仔细看 | 1024px | 全部可读 | ✅ 达标 |

> 🔴 **结论**：其余小字在缩略图看不清**是正常的**——它们本就属"细看"层级。
> 但**主标题必须撑得住缩略图**，所以：**组名字号 92 → 110px**（缩略图后 15px，达标）。
> 参照物：`公众号首图 900×383`、`小红书竖版 1080×1440`、`抖音竖版 1080×1920`。

### 平台安全区（避免被裁掉）

| 平台 | 比例 | 关键信息位置 |
|---|---|---|
| 小红书图文封面 | 3:4（1080×1440） | **画面上三分之二** |
| 朋友圈单图 | 1:1 | 中央 75% 区域 |
| 短视频竖版封面 | 9:16 | 中部偏上，上下各留 15–20% |

**通用安全区**：四边留 **8–15%**，核心信息放中央。关键信息距边缘 **>15mm**。

## 四、排版技术参数（可直接抄）

| 项目 | 规范值 |
|---|---|
| **行距** | 标题 = 字号 × **1.2–1.4**；正文 = 字号 × **1.5–1.8** |
| **字距** | 中文标题适度加宽（大字宜紧、小字宜松） |
| **对齐** | **居中**（卡）/ **左对齐**（信息块）；❌ 避免两端对齐参差 |
| **文字压图** | 加**半透明色块蒙版 30–50%** 或渐变遮罩，保证对比度 |
| **对比度** | 文字/背景 **≥ 4.5:1**（WebAIM 标准） |
| **纯黑禁忌** | 别用 `#000000`，用**深灰 `#1A1F2E`** 更柔和（本方案底色已深，用浅色字） |
| **视觉动线** | **Z 型**（左上→右上→左下→右下）或 **F 型**；重要信息放视线起点 |
| **构图上1/3** | 主标题放**上部 1/3**（留白区），是视觉焦点 |

### 版面三分（黄金布局）

```
顶部 30%  → 视觉焦点区：序号 + 主标题
中部 40%  → 信息核心区：页签数 + 代表页签
底部 30%  → 辅助信息区：价值描述 + 角标
```

## 五、Qwen-Image 2.1 提示词模板（官方指南提炼）

### 🔴 核心规则（官方明确）

1. **要渲染的文字放进双引号** —— `a title reading "青春幻想引擎"`
2. **引号内绝不改写/翻译**，原样复现（含大小写、标点）
3. **用文字描述字体风格** —— `"标题" 用粗黑体，位于画面上部居中`
4. **中文保持中文**，可指定字体族（**黑体/宋体/楷体**，**实测有效**）
5. **用具体名词+数值替代空泛形容词** —— 别说"好看/高级"，要说"浅原木色木纹""字高占画面 7%"
6. **主动写排除项** —— "不出现任何人物""无文字"（做底图时）

### 防乱码三件套（中文文案标配收尾）

```
① 逐字准确、清晰可读、无错字无乱码；
② 不要生成任何未指定的多余文字；
③ 不要添加未要求的口号或标语。
```

### 中文排版隐性技巧

- 显式说明：**「中文标点、标准行距、从左到右排列、字体为黑体」**
- 字体名**真的有效**：思源宋体→严肃 / 现代圆体、黑体→科普
- 负面词里的**"文字重叠""元素重叠"**对模型是**直接的版面约束信号**，比只写"质量好"精准

### 通用负面词（本方案必备）

```
乱码文字, 文字扭曲, 文字模糊, 文字重叠, 语法错误, 拼写错误,
元素重叠, 拥挤, 布局杂乱, 过度装饰, 水印, 多余边框, 不相关的图形,
低分辨率, 模糊图像, 色彩溢出
```

## 六、本方案的具体整改清单（自查结果）

对比规范，现有脚本 `make_poster.py` 的**问题与整改**：

| # | 问题 | 现状 | 整改 |
|---|---|---|---|
| 1 | 主标题缩略图可读性不足 | 92px → 12.6px | **→ 110px**（缩略图 15px 达标） |
| 2 | 中部留白过大 | 页签区到描述区空 200px+ | 上移 / 加装饰线填充节奏 |
| 3 | 字号层级差不够 | 主 92 : 正文 27 ≈ 3.4x | 保持（已达标），但可提到 4x 更稳 |
| 4 | 配色 | 墨蓝+金 ✅ | 保持（三色原则：深蓝主 + 金点缀 + 白字） |
| 5 | 文字压图对比度 | 底图带光效 | **加半透明暗遮罩**（`draw_cover_generic` 预留） |
| 6 | 安全区 | 四周留白约 12% ✅ | 保持 |

## 七、美术风格参考（科幻方向）

| 要素 | 建议 |
|---|---|
| **主色** | 深空蓝 `#0A0E1A` → `#12203C` |
| **点缀** | 青蓝高光 `#4DA3FF`（≤10% 面积） |
| **辅色/强调** | 低饱和金 `#C9A96A`（标题描边或用在小元素） |
| **底图元素** | 抽象光带 / 电路网格 / 数据粒子 / 体积光（**无具象物**） |
| **字体** | 主标题：微软雅黑 Bold（等效思源黑体 Heavy）；正文：微软雅黑 Regular |
| **氛围关键词** | 极简、现代、未来感、发布会质感、纵深光感 |
