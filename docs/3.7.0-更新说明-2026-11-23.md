# 青春幻想引擎 3.7.0 更新说明（2026-11-23）

> 从 3.6.3 直接升级：本说明合并覆盖 3.6.4 的两项改动（字数统计全语言、码字排行按项目抵扣），不再单独发布 3.6.4。

## 一、正史变了，系统记得住

- **大纲改动 → 未来章待重审**：总纲、卷纲、细纲保存后，受影响的「还没开写」章纲会被标记，并附「改前 → 改后」的引用片段。核对完点「已处理」即可清除；系统不会改你的章纲。
- **已写章节只列建议**：总纲 / 卷纲改动波及已写章时，只生成「已写章节建议复核」清单，不替你判断哪一章真的受影响。
- **章后整理也打标**：整理确认入库后同样提醒一次（以前只在整章改写时提示）。
- **候选 / 报告主动过期**：正文、细纲、本章固定资料任一变化后，待审候选会被标成「已过期」并写明原因；剧情候选还比对所属章正文；推演卡与对照报告会显示「来源已变化 / 报告基于旧稿」。都只提示，不自动改卡、不删候选、不重写正文。

## 二、物品与状态可以按章回溯

- **资源账本**：章后整理新增「物品流转」一类（获得 / 失去 / 转移 / 消耗），必须带正文原句才能勾选写入。物品未登记时只提示「先登记物品」，不凭空建条目。图鉴物品详情新增「流转记录」。
- **连续性检查覆盖物品**：第 N 章写着「某人的某物」而流转账本显示该章它已不在那人手里时，报一条可定位的提示（宁缺毋滥，只认明确归属句）。
- **状态演变**：人物状态与关系变化确认后，额外记一条「第 N 章时是什么状态」（旧值一并留痕）；物品、势力、关系行与角色卡走同一套记录。**角色卡详情**与记录详情都有「状态演变」列表与手动补登。注意它与「设定变更」页签不同：那个记你改字段，这里记剧情内发生了什么。

## 三、观察面：只摆事实

- **全书逐章节奏曲线**：检查工具「节奏与章末钩子」顶部新增本地曲线，可切换字数 / 对话占比 / 平均段长 / 距上个爽点；爽点按登记强度打点。不合成总分、不划区间、不做名次。
- **投稿体检一页**：检查工具页头新增入口，汇总已跑过的开篇结论、平台观察、正文事实与待办条数，注明来源与时间；没跑过的项写「未跑」，不会替你补跑。可复制 JSON 存档。跑过「黄金三章」后，开篇结论会存进本项目并在此页直接引用原话（注明 AI 定性意见、仅供参考）。

## 四、语音灵感（需自备转写服务）

- 灵感夹与随手记的「语音」可录音转文字。需先在「模型设置 → 语音转写」填服务地址、API Key 与模型名：仅支持 OpenAI 兼容的 /audio/transcriptions，**不内置任何服务商预设**。
- 录音必须显式开始 / 结束；上限 120 秒或 10MB，先到先停。
- **隐私**：音频只发送到你填写的服务；本应用不留存、不进备份、不进云同步、不进诊断信息；失败即弃并提示重试。转写文本先放进输入框，核对后再保存；未配置时按钮不可用并写明原因。

## 五、随本版一并生效的 3.6.4 两项

- **字数统计支持所有语言文字（逐字符）**：中文、英文、日文、韩文与混排同一口径；提供「文字」与「文字＋标点」两种统计。历史字数不回填。
- **码字排行按项目分别抵扣**：日榜净增按每本书各自计算，**不同书之间不互相抵消**；删另一本的字不会把你从日榜抹掉。该修复在读时聚合，部署后即生效、无需回填。

## 六、小修

- **EPUB 导出**包含未分卷章节（与 TXT / MD 口径一致），不再静默少章。
- **正文高亮与「正文引用」**：写作途中新增的设定 / 别称会在一小段延迟后自动参与，不必重进编辑器。
- 手册内容版本 +1（含本篇说明的对应条目）。

## 仍未验 / 限制（如实记录）

- 语音转写真机链路需要作者自备可用 Key；本次开发环境无可用转写服务，只验了录音入口与配置闸，转写请求记「未跑：缺转写服务」。
- 三形态（安装版 / 便携版 / 网页版）全量真机验收留待封装阶段，本版开发期仅做了隔离环境下的 Edge 探针。
