## 三、明确禁用（§9.5 授权范围，便携版离线自包含本就不含）

| # | 功能 | 便携版 | 理由 |
|---|---|---|---|
| 20 | 云盘文件同步 | ❌ **禁用** | 依赖 File System Access 句柄 + 桌面 `DESKTOP` 门控；且便携版数据本就随盘走，无需再同步。入口由 `CLOUD_FILE_SYNC=false` **天然隐藏**，无需改代码 |
| 21 | 应用内「检查更新」（自动检查 / 下载安装器） | ❌ **禁用** | 依赖 `HAS_UPDATE_BRIDGE`（主进程下载 + 拉起安装器）；且便携版无「安装」概念。入口按桥隐藏 |
| 22 | 网络代理设置（系统级代理注入） | ❌ **禁用** | 依赖 `HAS_NET_BRIDGE` 的 `setProxy`；浏览器无法改系统代理（可用浏览器自身代理设置替代）。`NetworkProxyPanel.tsx:130` 已有「不可用」提示分支 |
| 23 | 应用内安装 / 卸载 / 系统托盘 / 开机自启 | ❌ **禁用** | 均为系统级安装能力，便携版无安装过程（§9.5 明列） |
| 24 | 真·全屏（B2，F11 无边框全屏） | ⚠️ **降级** | `HAS_WINDOW_BRIDGE=false` ⇒ `toggleFullscreen` 返回 null，`Sidebar` 已按桥隐藏该钮（`Sidebar.tsx:448`）。**浏览器自带 F11 可全屏**，功能不缺只是入口换位置 |

## 五、需要主人哥哥拍板的「待确认项」

### ① 语义检索 / 知识库的独立 IDB 库（#19）
- **现状**：`novel-studio-vec`（向量）/ `-kb`（知识库）是**独立 IDB 库**，刻意不进门面 `lib/db` ⇒ 不进整库 JSON / 同步 / 备份（项目红线）。
- **便携版困境**：浏览器 IDB 不跟随 U 盘 ⇒ 若照搬，便携版数据就**不全**（换机丢失向量/KB）。
- **方案 A（推荐）**：便携模式下把这两库**并入整库 JSON** 的 `stores`（新增 `vecRows` / `kbRows` 两个 store），随 `./data` 落盘。代价：整库 JSON 变大；需改 `storeOps.ts` 的 key 表。
- **方案 B**：便携版**关闭语义检索/知识库**，界面提示「便携版不含向量检索」。
- **方案 C**：保持独立 IDB，文档注明「便携版向量库不随盘走」。

### ② 证据包导出（#10）
- 建议按现成分支：便携版**下载 HTML**，不另做 PDF（中文 PDF 红线要求走 Electron `printToPDF`，浏览器做不到）。

### ③ 联网检索（#18）
- 建议**保留入口**，仅在失败时按 `HAS_NET_BRIDGE=false` 给「浏览器跨域限制」的说明（已有该提示）。不主动隐藏。

### ④ 云端模型跨域（#14）
- 建议**保留**。若某些 API 商不允许浏览器跨域，属其服务端策略；文档提示用户可用支持 CORS 的服务或本地模型。
