## 4. P1：隔离原型（已完成，不入库）

**落点**：`.workbuddy/tmp/p1-agent-track-343/`（git 已忽略，已核实 `git check-ignore` 命中；`src/` 零改动，本轮产品代码改动仅版本号 4 处）。

| 文件 | 内容 |
| --- | --- |
| `backendTrack.mjs` | 后端轨契约最小表达：session 生命周期（create/send/pause/resume/cancel/close）+ 过程事件流（plan/tool/diff/message/artifact/state）+ 产物 descriptor + 能力声明（与 `DriverCapabilities` 同形七键，缺键/非法值明确报错）。受控假 Agent：`unattended=false`、`quota='subscription'`、`embedding=false` |
| `router.mjs` | 三轨路由：保底轨纯透传；无人值守/自动静默链路**永不**路由 Agent（硬闸）；增强轨仅手动 + 显式选择；能力不足 ⇒ **跳过并留痕**（返回 skipped+原因，绝不返回空冒充成功）；每次路由写账本（track/action/reason/backend/quota） |
| `fakeProtocolDriver.mjs` | ChatDriver 同形假 driver，记录调用参数供逐字比对 |
| `run.mjs` | 12 项验收，`node .workbuddy/tmp/p1-agent-track-343/run.mjs` 可复跑 |

**验收结果：12/12 PASS**（`P1_PROTOTYPE_RESULTS {"planned":12,"passed":12,"failed":0}`）：

1. 未配置 Agent：路由纯透传，driver 收到参数与传入深相等、结果原样返回（「与 3.4.2 逐字一致」的原型级证明；产品级由 §2 全量单测 426/0 + src 零改动佐证）
2. 配置 Agent 后默认仍保底轨，Agent session 零创建

4. 能力不足（embedding）⇒ skipped + 账本留痕，result=null 非空串
5. 增强轨手动长任务：plan/tool/message/diff/artifact 事件齐、独立产物、session 收口 closed、**订阅口径如实记账**
6. 增强轨非手动/未显式选择 ⇒ 跳过留痕
7. 取消保留已收片段、状态如实
8. 暂停/恢复续跑、无重复 emit（单排干循环）
9. Agent 结果是 events/artifacts，**无 content 字符串** ⇒ 过程文本不可能混进 sync-json 解析

11. 契约守门（能力缺键 / 非法事件 kind 明确报错）
