## §1 B 方案（提示词反例清单）的实测代价

已实施（提交 `dd3cd5c`）。量化其成本：

| 项 | 值 |
|---|---|
| `EXTRACT_SYS` 长度 | 754 → **1,219** 字符（**+62%**） |

## §2 C 方案（二遍复核）4 个变体实测

同一条基线（缓存），一次跑完，可比：

| 变体 | 额外调用 | 复核耗时 | 模型判泛称 | 其中与登记表冲突 | 兜底后净剔 |
|---|---|---|---|---|---|
| **V1** 仅名单（两档） | +1 | 12.4s | **59 / 60** | 31 | 28 |
| **V2** 名单+类型+描述（两档） | +1 | **175.1s** | **0 / 60** | 0 | 0 |
| **V3** 名单+类型+描述（三档：确定/疑似） | +1 | 16.5s | 33 / 60 | 13 | **20** |
| **V4** 逐章复核（带本章正文）· 保守 | **+6**（调用翻倍） | 25.1s | 35 / 60 | 15 | **20** |
| **V4** 逐章复核 · 宽松 | +6 | 25.1s | 55 / 60 | 30 | 25 |

基线：60 条 / 判重已命中 31（51.7%）/ 抽取 385.1s。

### 2.1 三个致命问题

**① V1（最便宜的路线）整体报废**：模型把 60 条里的 **59 条**全判为泛称——`陈渊`/`青岚宗`/`混沌吞天诀` 一个不留。只有靠登记表兜底才救回 31 条。**单给名单、不给语境，模型等于在赌。**

**② V2 白跑 175 秒**：一条没判（输出 6,373 字全在解释）。同一模型、同一输入，第一轮实验（提示词里少了"不要因为名字像某类别就判泛称"那句）它剔了 33 条 —— 加了一句防过度删除的提示，行为直接翻到另一端。**提示词两句话之差，结果从"删 33"变"删 0"。**

**③ V3/V4 精度不足，且误伤落在核心元素上**：V3 与 V4 保守版都净剔 20 条，交集 16 条（说明有稳定的"泛称核心"），但这个核心里包含：

- `镇界塔`（镇压万族气运的塔，塔灵本体）
- `神契`（神族对苍澜大陆的控制契约）
- `叛神`（老瞎子的前世身份）
- `七道残简`（故事核心目标）
- `封仙路`（三千年被封死的仙界通道）—— 第一轮 V2 也剔了它

逐条判读：**精度约 60%**，约 8 条是真专名被误判。

### 2.2 一个指标陷阱（必须说明）

"兜底后保留里判重命中率 51.7% → 77.5%" **不是改善证据**：兜底把「判重已命中」的条目排除在剔除范围之外，分母自然变好，属**循环论证**。真实评价只能看上面的人工判读精度。

### 2.3 运行稳定性

同一模型、同一输入、同一批 60 条，三次独立运行的结果：

| 轮次 | 抽出条数 | 判重命中 | 耗时 |
|---|---|---|---|
| 第 1 轮 | 63 | 54.0% | 389s |
| 第 2 轮 | 60 | 56.7% | 496.9s |
| 第 3 轮 | 60 | 51.7% | 385.1s |

条数 ±5%、命中率 ±2.5pp、耗时 ±25%。**结论：任何小于 5pp 的"改善"都在噪声内，不能当成果。**

## §3 🔴 两个改变判断的发现

### 3.1 项目自己的登记表里**本来就有**泛称

标准答案（已登记设定）中：`演武场`、`杂役院`、`大比`、`残简`、`玄脉` —— 全是"任何小说都有"的词，**但作者确实把它们登记进了设定表**。

→ 「泛称 = 噪音」这个前提**要修正**。自动剔除会和作者既有的登记习惯打架：把作者本来就要的东西删掉。

### 3.2 真正的噪音是「同一实体的多种写法」

对基线 60 条做纯字符串分析（无模型）：

| 簇 | 组成 |
|---|---|
| 玄脉 | `玄脉` / `三品玄脉` / `四品玄脉` |
| 胎记 | `胎记` / `左腕胎记` / `暗金胎记` |
| 残简 | `残简` / `无名残简` / `七道残简` |
| 塔 | `镇界塔` / `青铜小塔` / `锈塔`（同一物件三种叫法） |
| 功法 | `混沌吞天诀` / `吞天诀` |
| 体质 | `混沌神体` / `神体` |
| 地名 | `南荒秘境` / `南荒`、`山门` / `山门口` |
| 家族 | `陈家` / `陈家先祖` |
| 同名异类 | `[地理]封仙路` + `[术语]封仙路`（同名两条并存） |

**9 簇 / 可合并冗余 12 条 / 占 20%** —— 比 C 净剔的 20 条只少 8 条，但**零幻觉、零额外调用、可单测、可复现**。

（注意：`陈家` vs `陈家先祖` 这类**不是**同一个对象，所以规则要带类型相容 + 长名是短名修饰位的判据，且**以「合并建议」呈现、由作者确认**，不做静默合并。）

## §4 建议

1. ✅ **保留 B**（已在），但**不要再往里加名字** —— 边际收益递减、成本线性上升。
2. 🔴 **C 不上"自动剔除"形态**：精度约 60%、误伤核心专名、提示词微调即行为翻转。
   若仍要 C，只能上**安全形态**：`登记表兜底` + **只降级不删除**（默认不勾 + 行内标注理由），且**固定提示词**保证可复现。收益是默认视图干净些；代价 +1 次调用 / ~15s。
3. ✅ **新增 D（确定性归并）**：把"同物多写法"合进一条（短名进 `aliases`），或以"合并建议"呈现。**这是本轮最确定的收益**。
4. 📌 评价口径固定为：**抽出条数 / 判重命中 / 耗时** 三项，且改动需超过噪声带（条数 ±5%、命中率 ±2.5pp、耗时 ±25%）才能算改善。

## §5 D 方案（同物多写法归并）—— 已实施与实测

### 5.1 规则（`src/lib/flow/draft.ts` → `foldNameVariants`，确定性、**零模型调用**）

| 情形 | 处置 |
|---|---|
| 短名是长名的**后缀**（`吞天诀` ⊂ `混沌吞天诀`），且只被一个长名包含，修饰语不带数字量词 | **自动并入**：短名进别称，描述/证据/来源/额外字段一并合并（只增不减） |
| 短名被**多个**长名共用（`胎记` 既在 `左腕胎记` 又在 `暗金胎记` 里） | **只标「核心词」那条**默认不勾；长名一律**不牵连、不合并** |
| 修饰语带数字/量词（`三品灵脉`、`三品玄脉` 这类**并列层级**） | **不合并**，只标注 |
| 短名在**前缀**位（`青岚宗` ⊂ `青岚宗藏经阁`） | **完全不处理**（见 5.2） |

### 5.2 两次纠错（都是实机数据逼出来的，不是想出来的）

1. 🔴 **前缀位误并**：最初允许「前缀或后缀」，实机 6 章跑出两条真误并 ——
   `青岚宗` 被并进 `青岚宗藏经阁`（宗门 ≠ 它的藏经阁）、`南荒` 被并进 `南荒秘境`（区域 ≠ 区域里的秘境）。
   规律：短名在前缀位时，长名往往是在它后面接了**另一个名词**，指向子体。→ **收窄为只认后缀**，
   并入数从 8 条降到 4 条且**全部正确**。
2. 🔴 **容器连带降级**：原设计把"同核心词的多个长名"也标为疑似。但换成
   `混沌吞天诀` / `噬魂吞天诀` —— **两个不同功法共用词头**，就会把核心实体默认不勾、作者容易漏掉。
   字符串判不出"同物"还是"并列对象"，而**误降级的代价大于留一条重复条目** → 改为**只标核心词**。

### 5.3 实测（示范项目 6 章 / 9 次抽取调用）

| 口径 | 条数 | 🔴 默认写入 |
|---|---|---|
| A 示范项目（登记表已满） | 66 | 29 |
| B 新项目（空登记表）**+ 归并开** | 66 | **63** |
| C 新项目（空登记表）**+ 归并关**（改造前） | 69 | 66 |

- **净收益**：新项目场景默认写入 **66 → 63**（少 3 条重复；三次独立跑动分别少 3 / 4 / 7 条）
- **示范项目场景 29 → 29**：满登记表下同物写法本来就会被判成「疑似已有」而不勾，
  所以**看不出变化是正常的** —— 这条解释了「为什么在示范项目上感觉不到 D」
- 并入明细（末次跑动）：`吞天诀`→`混沌吞天诀`、`神体`→`混沌神体`、`残简`→`无名残简`，**全部正确**
- 负面对照：`foldVariants:false` 时所有标记为空 ✅

### 5.4 界面与测试

- 草稿面板顶部：`已归并 N 条同物写法 · M 条疑似同物（默认不勾）`
- 行内：`已并入 N 个写法` / `疑似同物「X」`（点「详情」有完整说明）
- `全选新建` **不会**勾上疑似同物的行 —— 抽成纯函数 `pickableAsNew` 并单测
  （否则作者一点全选就把刚标好的去重提示撤销了）
- `tests/flowFold.test.ts` **29 条**（含 3 条负面对照：中间包含不并、跨类型不并、共用词头的两个对象不降级）
- `tests/flowAliases.test.ts` ④ 由「已知局限：模型没给别称就合不了」改写为**反向对照**：
  D 补上了该局限；并加关掉归并后回到 2 条的负面对照

> ⚠️ 归并的**量级不大**（每 6 章 3~4 条），但它是**确定的、可复现的、可单测的**；
> 而 C 的名义剔除量（20 条）里有约 8 条是误伤核心专名。两者不是同一性质的收益。
