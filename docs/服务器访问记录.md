# 网页体验版 · 服务器访问记录

> 由「网页体验版反馈巡检」每日 automation 自动汇总服务器 `/var/lib/yfe/access.jsonl`。
> 每次**邀请码校验**与**云端同步调用**都会记一行（真实访客 IP、UA、成败、动作类型），由此可回答「谁来了、谁进门了、谁开了同步」。
> 与 nginx 全量访问日志不同，本记录只聚焦「登录/进门」相关动作，已自动过滤掉普通爬虫与静态资源请求。

## 查看渠道
- **本文件**：每日巡检后自动追加，打开即看（推荐）。
- **实时查看**：`ssh ubuntu@154.8.178.240 'sudo tail -n 20 /var/lib/yfe/access.jsonl'`
- **字段说明**：`ts` 事件时间(UTC)｜`ip` 访客真实 IP（nginx 经 X-Real-IP 透传）｜`ua` 客户端标识｜`type` invite/sync｜`ok` 成败｜`act` enter/reject/pull/push/authfail/conflict｜`code` 用到的邀请码或同步槽位哈希｜`rev` 同步版本号。
