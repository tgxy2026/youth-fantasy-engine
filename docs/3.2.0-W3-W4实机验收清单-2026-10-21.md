### 验收动作（按顺序，每条都要看到预期）

1. [ ] 触发一次**整章改写**（工单面板 → 某章「执行」），完成后回到「创作轨迹」
   - 预期：出现一条 `rewrite` 任务记录（含调用次数、首字耗时、候选 1 条 adopted）
2. [ ] 打开候选块，能看到该候选（改前/改后字数、差异行数）
   - 预期：差异数与实际改动相符；**不是**恒 0
3. [ ] 点「应用」：正文更新、快照留痕
   - 预期：正文变了、章节快照多一条、`status` 变 applied
4. [ ] **条件提交**：先手动改正文 2 个字，再应用**旧**候选
   - 预期：被拒（stale），**正文一个字都没变**；给出"基准已变"的说明
5. [ ] **同章两份候选**：生成两份，应用其中一份
   - 预期：另一份变 `stale`（不是 `discarded`），并写明"同章另一份候选已被应用"
6. [ ] **配额**：连做 6 次改写，看候选列表
   - 预期：每章留最近 5 份；超限**明确提示**，不静默丢
7. [ ] **崩溃恢复**（可选，风险最高，做完记下现象）
   - 应用候选时任务管理器杀掉 Electron，重启后再进候选块
   - 预期三条分支之一：磁盘改后 ⇒ 只补回执；改前 ⇒ 正常再写一次；
     两边都不是 ⇒ `needs-reconcile`（**不许猜**）

### 判定为失败的情形（任一命中就别报"完成"）

- 应用后正文没变 / 变了但不是候选内容
- 被 stale 拒绝但正文被改动
- 候选状态"应用成功"而磁盘没落（重启后消失）
- 同类条目重复出现（去重键失效）

- [ ] 每条能点开看到**证据段号**；定位不到的条目要明说"无法定位"
- [ ] 这些条目**「执行」按钮是禁用的**（可疑 ≠ 确定要改）
- [ ] 把一条标成「跳过」，再刷新工单 → 预期仍是「跳过」（状态不被覆盖）
- [ ] 同章重复生成工单 → 预期不重复堆叠

## 2.5 W4 诊断留档 · 改后复检 · 报告回看（第三项，本次新增）

本轮三块一起落地（`a64d03a` 之后的下一批）：

| 改动 | 落点 | 作者可见变化 |
|---|---|---|
| 词表对齐 | `revision/checkAdapters.ts`（唯一去处） | 本地引擎的「冲突 / 注意」与留存词表「严重 / 中等」不再各写一份映射 |
| 诊断留档 + 检查项状态 | `optimizeTicket.buildTicketDetailed` | 工单顶部显示「已检 X/Y 章 · 留档 N 份」；**没检成的章点名列出**，不再报成"诊断完成、没有问题" |
| 改后复检 | `optimizeTicket.runTicketChapter` | 每章标题旁显示「复检：原问题已清 / N 条没解决 / 复检没跑成」—— 标"已改写"≠"已解决" |
| 报告回看 | `revision/CheckReportPanel`（「创作轨迹」头部「检查报告」） | 能翻回去看当时报了哪几条（含来源与引文） |

### 验收动作

1. [ ] **有问题的书**：生成工单 → 预期顶部出现「已检 X/Y 章」「发现 N 个问题」「留档 N 份」，且留档数 ≤ 有发现的章数
2. [ ] **全绿的书**：生成工单 → 预期 **0 份留档**（A 策略：全绿不落库，不是功能坏了），且界面不报错
3. [ ] 连点 2 次「重新生成工单」，内容没变 → 预期留档份数**不增加**（指纹去重生效）
4. [ ] 同一章连点 6 次（中间改一处制造新发现）→ 预期该章最多留 5 份，更早的被淘汰；另一章一份不少
5. [ ] **执行选中**（勾选几条 → 执行）→ 预期每章改完后标题旁出现复检结论：
      - 问题真被改掉 ⇒ 「原问题已清」
      - 模型没改干净 ⇒ 「N 条没解决」（悬停能看到是哪几条）
      - 复检抛错 ⇒ 「复检没跑成」（**正文照常已改写**，不回滚）
6. [ ] 「创作轨迹」→ 点头部「检查报告」→ 预期看到：章、来源（本地诊断 / 改后复检 / 连写自检）、时间、每条的级别与〔引文〕
7. [ ] 空态：新书/全绿书打开「检查报告」→ 预期说明「只有查到冲突/注意级才留档」，**不是空白页**
8. [ ] 再次生成工单 → 预期报告里的条目并进工单，且**不重复堆叠**（同一问题只一条）
9. [ ] **实体保留自检**（WQ8 方案 A，随改写一起跑）：执行选中后看每章标题旁
   - 预期：动过登记实体的章出现「N 个登记实体改写后没再出现：…」（amber，悬停有说明）
   - 预期：没动到任何登记实体的章**不出现这一行**；空设定表的书不报错、也不显示
   - 🔴 这条**只提示不判定**：不存在"通过/不通过"，别去找红叉

### 判定为失败的情形

- 工单顶部显示"已检 100%"但明明有章没跑到（pending 被吞）
- 「已改写」的章看不到任何复检结论（既没有结论也没有"没跑成"）
- 留档份数无限增长（去重/淘汰失效）
- 回看面板里出现候选正文（载荷 `kind` 串了）
- 每条发现都显示「引文 N/N 可定位」却一条引文都没有（`where` 空却假装有证据）
