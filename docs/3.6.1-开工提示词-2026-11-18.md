### 环境与已知坑（省时间用）

- **F 盘是 SMR 机械盘**：大批量写入后会卡；大文件别写 F 盘。
- **代理**：需要时以环境变量 `HTTPS_PROXY` 当前值为准，端口会变，别硬编码。
- **`npm run build:desktop` 会中途要求外层两步**（本环境子进程被拦成 EBUSY）：先 `rcedit` 补主 exe 元数据，再 `electron-builder --prepackaged` 重打。命令脚本会打印出来，照抄即可。
- **部署**：`bash server/deploy.sh`（www + server，自带备份与自动回滚，不要手工 scp）。
- **Release 附件**：Gitee 用中文文件名 + `curl -F`（Node `spawnSync` 在 Windows 会失败）；GitHub 用 `uploads.github.com` + `curl -k`，资产名沿用 ASCII。发版前先查 Gitee 占用（1 GB 上限），按「保留最近三版」清理。
- **`gh` CLI 未安装**：GitHub 走 curl API，token 在 `~/.git-credentials`，不要打印出来。
- **沙箱偶发**"命令被安全策略拦截"提示，但 git/curl 实际已成功——以命令自身输出为准，别重复执行。
- **不要在审计/验收运行期间改工作树**（会让指纹失效、结论作废）。
- 写补丁脚本时不要用 bash heredoc 传含反斜杠的 Python 字符串（MSYS 会把 `\s` 变成 `/s`）：用 Write 写 `.py` 再执行。
- 测试里改 `globalThis.navigator` 要用 `Object.defineProperty`（Node 22 是只读 getter）。
