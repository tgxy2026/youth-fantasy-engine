# 青春幻想引擎 3.3.3 更新说明

> 一句话：**这一版没有新页签，是把几处"让人心里没底"的地方修实了。**
> 重点是创意写作被关掉后的续写、永久删除字段的收尾，以及一批"只重试失败、不重跑已完成"的省时改动。

---

## 一、创意写作：关掉再开，不再卡在「进行中」

以前跑到一半关掉软件，重开有时会卡在一个尴尬状态：进度条还在转，显示「进行中」，
但既没有任务在跑、也没有草稿可以确认，只剩「中止」和「从头开始」。

这一版把它分成了两种清楚的情况：

| 你上次是怎么停的 | 重开后看到什么 | 该怎么办 |
|---|---|---|
| 正文已经写了几章就关了 | 「上次中止在：第 N 章」+「继续写作」 | 点继续，**只补剩下的章**，写好的不会重写 |
| 停在"等你确认设定/大纲草稿"那一步 | 「上次没跑完（已中断）：进度只作记录，草稿不在磁盘上」 | 草稿本来只在内存里，关掉就没了 —— 直接重新开始即可 |

继续之前会先核对断点，防的是"续写把你已经改过的东西覆盖掉"：

- 已写章节的**正文被你改过** → 提示「正文已改」，拒绝续跑；
- 已写章节**被你删掉** → 提示「缺章」，拒绝续跑。

这两条不是限制，是保命：宁可让你手动确认一次，也不要在背后把改过的稿子冲掉。

## 二、删除字段：一次做完，中途被打断还能接着清

图鉴「字段设置」里的**永久删除**（只想暂时不显示请用「归档」，归档不动任何值）：

- 删除前**自动建一份备份**，备份没建成就不删；
- 字段定义和**各表已填的值一起清掉**，不会出现"字段没了、值还留在库里"；
- 清理过程中被打断（另一个窗口正在写、软件被关掉），重开会提示「清理未完成，可重试」，
  **不会悄悄留下残余值，也不会悄悄删光**；
- 如果另一个窗口在你删除前一瞬间改过字段配置，会提示「已在其他窗口发生变化，请重新打开字段设置」，
  而不是按最新状态闷头删。

## 三、拆书：只重试失败的那些单元

一键拆书长篇小说时会切成很多单元（50 章就是 50 个）。以前某个单元失败，重跑容易把已经成功的也再跑一遍
——白等、白花 token。

现在「只重试失败」是真的只补失败的那几个：实测 50 单元里第 37 个失败，重试只发 1 次请求，
已成功的 49 个结果原样保留。

## 四、图鉴图片：这几条一直是这么做的，这次把证据补上了

- **换图是替换，不是叠加**：换一张之后占用只按新图算，不会两张都留着；
- **删图是真删**：删掉后条目里连图片字段都不再有；
- **用量跨四页合计**：种族生物 / 物品资源 / 国家势力 / 地理风物的图一起算，
  面板底部显示「已用 / 上限」，到上限会拦住并告诉你超了多少；
- 只收 PNG / JPG / WebP，**SVG 会被拒绝**（可执行内容有安全风险），超大图自动等比缩小。

## 五、手册跟着更新了

使用指南里新增两节，都是这次改动直接对应的：

- 创意写作 →「跑到一半关掉了：断点记到哪一章」
- 图鉴 →「永久删除字段：先备份，再删定义与已填值」

## 六、看不见的加固

- 字段的删除与配置写入、任务台账的接管，现在都在**同一段临界区**里完成，
  同源两个窗口不会各写一半（桌面/便携是单进程，本来就没有第二个窗口；主要是网页版多标签）。
- 全量审计（六维静态扫描 + 6 个运行契约）这一版是 **0 缺陷候选、0 失败契约**，
  包括 8 个图表 4421 个真实绘制样本 0 违规、预设路由 44/44、草稿保存失败 3/3、导入导出往返 4/4。

## 七、边界（先说清楚，免得误会）

- 创意续写的断点是**按章**记的：一章写到一半被强杀，那一章会重写（不会只补半章）。
- 「章落库」和「断点记录」不是同一个事务，极端情况下（正好卡在两者之间断电）可能多写一章，
  **不承诺一个字符都不重复**；但绝不会漏写、也不会覆盖你改过的章。
- 字段删除的"同一段临界区"只对**同源同项目的窗口**生效；桌面/便携后端没有跨进程事务。
- 拆书的"只重试失败"只覆盖抽取单元本身；切分、全书汇总、关系整理这些下游步骤会按需重跑。

## 安装与升级

- **桌面安装版**：`青春幻想引擎-Setup-3.3.3.exe`（覆盖安装即可，原有作品与设置不受影响）。
- **便携版（免安装）**：两个按平台分的 zip ——
  `青春幻想引擎-便携版-3.3.3-Windows.zip`（解压后双击 `启动.bat`）、
  `青春幻想引擎-便携版-3.3.3-macOS-Linux.zip`（终端里 `bash 启动.sh`）。
  需要本机有 Node.js 18+；数据写在解压目录的 `data/` 里，**整个文件夹拷走就能换机器**。
- **网页版**：`https://youth-fantasy-engine.online`，用原账号登录即可，已同步到 3.3.3。
- 从 3.3.2 升级：安装器原地升级，**数据目录不变**；本机作品、备份、图鉴图片都在。
