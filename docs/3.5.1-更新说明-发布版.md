## 一、修掉「网页版每次都要重看新手教程」（本次主要问题）

**根因**：引导观看状态模块把「网页云端账号」判成「只存本次会话」，记录只留在内存里，刷新即丢 —— 于是每进一个页签都当成「没看过」重新分步介绍一次。代码注释给的理由是「网页云端没有稳定账号标识」，但服务端从网页账号上线起就在入口 HTML 里注入了 `window.__YFE_USER__.id`，判断已经过时。

**影响人群比看上去大**：服务端的资格判定是 `cloudSync !== false`，**没有该字段的存量账号一律视为已授予云同步资格**。所以「每次重弹」影响的是**全量老用户 + 被授予资格的新账号**；反而是无邀请码新注册的账号（`cloudSync: false`）在旧版本里本来就能记住。

**改法**：

- 引导记录按账号 id 加命名空间（`<原键>@<账号id>`）落到浏览器本地存储，刷新后不再重弹；
- 同一浏览器换账号互不串，切回原账号记录仍在；**命名空间只由账号 id 决定**，所以运营开通 / 关闭云同步资格不会丢记录、也不会突然重弹；
- 旧的无命名空间记录**一次性迁移**进账号空间（含「已关闭自动引导」），老用户不会集体重看一遍；
- 桌面 / 便携 / 游客沿用原来的键，既有「已看过」记录不作废；只有「登录了但服务端确实没给账号标识」才退回会话内记录（按服务端实现实际不会发生）。

> 小提示：以前从没落盘过的账号，**升级后第一次进入还会弹一次**，从那以后就不会再弹了；网页端请强刷一次（`Ctrl+F5`）拿新版本。
> 游客在同一浏览器里也是能记住的，只有隐私模式、清站点数据、换浏览器 / 设备才会重新弹。

## 二、投稿广场离线 / 未登录：不再一屏红条

断网或未登录时，广场外壳原本最多叠四条提示，列表、排行子面板还各自重复报错。现在收敛为**一张中性引导卡**（`role=status`）：说明「广场需要连接云端账号，本地写作与草稿不受任何影响」，给出登录入口与「了解广场」帮助，并写明连接恢复后自动加载、不再重复提示；子面板同时抑制重复的筛选行、错误条、骨架与空态。

## 三、编辑器：章节标题终于读得出来

复核发现真因不是「四栏把标题列挤窄」，而是章行里 `Button` 基类的 `inline-flex` 在样式层叠中顶掉了 `hidden`，导致「＃ / 删除」按钮**永远不隐藏**、常驻吃掉约 80px；再叠加常驻字数，标题列在 1366 / 1440 / 1536 / 2000px 下都只剩 **27px**（拉到 2000px 也一样被截）。

改法是把悬停操作收进普通 `span` 包裹的 `hidden group-hover:flex` 组、字数移入章名 tooltip、拖把改为悬停 / 聚焦才显（键盘可达与 Alt+↑/↓ 保留），**不改四栏断点与拖拽模型**。标题列由 **27px → 122px**，各视口、检索展开 / 收起两态都不再截断。

## 四、少打断、渐进披露

- **备份提醒**：由全屏 Modal 改为**非阻断内联条**，示范项目豁免；写作不再被弹窗拦住。
- **说明渐进披露**：长说明收起来，需要时再展开；温度 / 核采样等高级参数改为**档位化**，不再默认一屏铺满。
- **装饰性警示收敛**：减少不影响判断的 ⚠️ / 🔴 装饰，把视觉重点留给真正需要处理的事。
- **看板娘**：待机从「立绘左缘切片」改为 **80px 圆形头像**（同一张图裁到头部），悬停仍展开全身立绘；双击收边、拖拽换位、键盘操作与 aria 全部保留。

## 五、登录与表单细节

- **重置密码页并入统一的登录视觉**（同一套品牌分栏、卡面与配色），提交键改实心主按钮，并补说明块；🔴 **只改样式层**：表单 id / name / autocomplete / 校验与找回接口、登录注册逻辑零改动；顺手删掉约 7.3KB 已无引用的旧样式。
- **表单与资料面板**：角色基础信息取消垂直居中空白；角色及通用设定的文本框随内容增长、三行后滚动（无限增长的设定草稿箱保持原行为）；表格文本单元格改块级对齐；关于页移除旧版迁移入口、联系方式移到作者信息下方。
- **社区设置**：邀请码 / 昵称输入框与对应按钮统一 40px 高度并在 390 / 768 / 1440 宽度下对齐；**本章资料面板由 18rem 加宽到 24rem**，宽屏正文避让调整为 26rem，窄屏仍受视口约束。
