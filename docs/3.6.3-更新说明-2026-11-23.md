# 青春幻想引擎 3.6.3 更新说明

> 发布日期：2026-11-23　|　源码版本：`v3.6.3`

3.6.3 只做一件事：**把「接第三方 AI 模型被参数卡死」这个问题彻底解决**。
如果你用 Kimi，或者用过 o1 / gpt-5 / deepseek-r1 这类"思考型"模型，大概率撞过这个错。
**数据格式没有变化**，覆盖安装即可，作品与设置都在。

## 一、你能直接看到的变化

### A. 接 Kimi 不再报 `invalid temperature`

之前接 Kimi 的 `kimi-k2.* / kimi-k3`，任何 AI 功能都会报：

```
400 invalid temperature: only 1 is allowed for this model
```

原因有两层，都修了：

1. 这类"思考型"模型把采样参数（温度、top_p、惩罚项）**锁死**了，官方要求干脆别传；
   而本软件不管接谁都带一个温度值（写作默认 0.85，校对拆书这类固定 0.3），于是一律被拒。
2. 更隐蔽的一层：软件的"参数被拒就自动重试"机制，把这类报错误判成了"模型名写错了，别重试"，
   所以连"去掉温度再试一次"都没走到 —— 你看到的就是原始报错。

现在**已知型号第一次就不带这些参数**，一次成功。覆盖：

| 家族 | 型号 |
| --- | --- |
| Kimi / 月之暗面 | `kimi-k2`、`kimi-k2.5`、`kimi-k2.6`、`kimi-k2-0905-preview`、`kimi-k2-thinking`、`kimi-k3`、`kimi-for-coding` |
| OpenAI 思考型 | `o1` / `o1-mini` / `o1-preview`、`o3` / `o3-mini`、`o4-mini`、`gpt-5` |
| DeepSeek 推理型 | `deepseek-r1`、`deepseek-reasoner` |

`kimi-k2-instruct` **不在其中** —— 它接受自定义温度（官方推荐 0.6），不该被一起锁掉。

### B. 新增「不发送采样参数」开关（中转站也能治）

设置在 **模型设置 → 采样参数**，温度三档下方：

> ☐ **不发送采样参数（温度 / top_p / 惩罚项）**

为什么需要它：按型号识别只能覆盖"叫得出名字"的模型。如果你用的是**中转站**、自己改过模型名、
或者填了 `kimi-latest` 这类旧名字，软件认不出来 —— 那就勾这一项，请求里**彻底不带**这些参数。

本版起不再只靠"猜型号"：

| 防线 | 什么时候起作用 |
| --- | --- |
| 型号识别 | 已知型号，第一次就不发 |
| **这个开关** | 任何端点、任何模型名都适用 |
| **自动记住** | 撞到一次这类报错后，本次使用期间该端点自动不再发，不会每次都多试一遍 |

勾上之后，温度那三档对它不再生效，界面会有一行小字说明——这是正常的，不是坏了。

### C. 报错时直接告诉你下一步

以前撞到这类错误，提示是"可能是模型名不对，也可能是参数不被接受"，等于没说。
现在会直接写：

> 请求被平台拒绝（HTTP 400）：这个模型不接受自定义采样参数（温度 / top_p 等）。
> 处理办法：到「模型设置 → 采样参数」勾选「不发送采样参数」后重试。

### D. 网页版「有新版本，刷新即可」真的能用了

这是 3.6.2 里埋着的一个隐蔽问题：版本清单文件被标成了"缓存一年"，浏览器再也不去问服务器
"有没有新版"，于是那条刷新提示永远等不到新消息（而且清缓存才恢复，很难想到）。

现在清单每次打开都会向服务器确认一次，**发布新版后，挂着的旧页面会在半小时内提示你刷新**。

## 二、维护与内部改动（不影响使用）

- 新增 `cleanup:quarantine` 命令：只读盘点待清理目录，不删除、不移动（给定期核查用）；
- 修掉发布检查把部署取证里的静态资源地址误报成文档失效的问题；
- 3.6.0 / 3.6.1 / 3.6.2 的开发文档移入 `docs/归档/3.6/`，并同步修正全部引用路径。

## 三、升级方式

| 形态 | 怎么做 |
| --- | --- |
| 桌面版 | 直接运行新安装包覆盖安装，作品与设置不受影响 |
| 便携版 | 下载新压缩包解压，把**旧目录里的 `data` 文件夹**拷进新目录 |
| 网页版 | 无需操作：刷新页面就是新版（旧页面会提示） |

## 四、仍然存在的边界

- 型号认不出、又还没勾开关时，**第一次仍会撞一次这类报错**，但会立即自动去掉参数重试成功，
  并记住这个端点；勾上开关后彻底不再试；
- "自动记住"只在**本次使用期间**有效（不擅自改你的配置）。想一劳永逸就勾上那个开关；
- 换回支持自定义温度的模型时，把开关取消勾选，温度设置立刻恢复作用。
