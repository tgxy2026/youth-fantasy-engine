## 六、B4 / B5 落地的具体口径（按产品确认执行）

**B4（证据层）**

- 展示位置：章后整理页「未来计划待重审」列表，每条右侧多一个「看依据」按钮（`aria-expanded`），展开后显示：
  - `依据：第 M 章的改动处`
  - `改前：……`（原本没有这段时显示「（原本没有这段）」）
  - `改后：……`（这段被删除时显示「（这段已删除）」）
  - 一行说明：「只在打标时留下片段，正文本身没有被复制成第二份。」
- 引用取「**真正变了的那一段**」：`changedSpan` 先剥公共前缀与公共后缀，再各截到 300 字并标注「已截断，共 N 字」。整章改写时开头往往没变，给开头等于没给依据。
- 3.6.1 之前打的旧标记没有 `evidence`：展开时如实说「这条标记早于 3.6.1，没有留下引用；重新改写一次这一章会带上依据」，**不伪造**。
- 存储：`futureImpact` 的 `ImpactMark` 新增可选 `evidence`（事件 id + 改前/改后片段 + 来源定位），仍只存几十到几百字节，不进正文副本。

**B5（只读视图）**

- 位置：图鉴详情字段分组下方，默认收起的「按语义看（身份 / 动机 / 状态）」，展开后三组各自列「槽位名 · 值（出处：字段名）」。
- 分组与槽位全部来自 `slotsForTab`（语义映射唯一真源），界面不自己列字段名；页签不参与语义映射时整块不渲染。
- 空值不占位；组里一个值都没有时给「这一组还没有填写内容」，与「当前模板里没有可用于这一组的字段」分开说。
- 底部固定一行：「这是同一份数据的另一种读法，不会写回、也不另存一份；要改内容请回表格改原字段。」
- 投影值**不可点击**（点回原字段另开条目）。
