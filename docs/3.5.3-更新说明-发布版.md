# 青春幻想引擎 3.5.3 更新说明

这一版修正了码字排行的日结规则，并加强云端项目在同步、恢复和清理过程中的数据保护。

## 码字排行

- 同一账号当天各项目的正文新增和删减先相抵，统计包含标点。日榜展示大于零的净增量。
- 周榜和月榜在北京时间零点后纳入上一天的正净增量。周一净增 2,000 字、周二净减 300 字，周榜和月榜仍累计 2,000 字。
- 撤回授权会移除日榜、周榜和月榜成绩。重新开启从零开始，服务器会拒绝上一轮授权的迟到上报。排行设置和帮助页已同步说明。

## 云端作品与编辑器

- 云端项目索引与实际状态不一致时会暂停相关操作并给出提示。维护人员可以先查看恢复预览，再对可核对的数据执行恢复。
- 永久删除和到期清理先隔离项目目录。索引更新失败时尝试移回，保留需要进一步核对的数据。
- 同步异常时提供更明确的处理提示，保留本地草稿与重试所需状态。编辑器切换项目、账号或存储后，旧保存结果不会写入新的位置。

## 内部整理

网页首屏减少了需要加载的代码。编辑器、表格、帮助和示范内容在打开时按需加载。

整理了同步合并、社区存储、认证路由及部分编辑器和表格逻辑，延续现有同步协议和社区数据格式。

排行适用于可连接社区的网页和桌面客户端。便携版提供本地创作功能。
