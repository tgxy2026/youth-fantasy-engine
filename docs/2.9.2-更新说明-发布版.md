# 青春幻想引擎 2.9.2 更新说明

> 发布日期：2026-10-09 ｜ 桌面安装版（Windows）
> 上一版：2.9.1（2026-10-08）

---

## 一句话

**2.9.2 是一次「让 AI 更听你的话」的版本。** 编辑器里的 AI 助手颉文姬，从「五个固定动作」升级成能听懂你的具体要求，并新增一套可以指定**写多少字、往哪个方向写、参考哪些资料**的「续写」；模型配置里能在几百个模型名中一搜即中，生成参数也能自己微调。同时把两处「算完即弃」的检查结果落库成可对比的趋势。

---

## 新增

### ⭐ 颉文姬「续写」—— 说清「写多少、写什么、参考什么」

**入口**：编辑器 → 顶栏 ✨（颉文姬）→ 编辑页 → **续写**（折叠区，默认收起）。

此前「续写」只有创意写作里那一套**整章级**的。现在编辑器里也能续写，而且是**可调**的：

| 能调什么 | 说明 |
|---|---|
| **续写字数** | 期望字数（旁边直接显示本章当前字数，方便你算该加多少） |
| **续写主要情节** | 你想让 AI 往哪个方向写 |
| **参考哪些资料** | **11 项可勾选**，默认勾 5 项 |

可勾的资料（默认勾选的标 ⭐）：

| 资料 | 说明 |
|---|---|
| ⭐ 本章细纲 | 续写要沿着本章既定目标走（最关键的一项） |
| ⭐ 主要角色 | 人物言行与口吻保持一致；本章出场人物由正文自动识别 |
| ⭐ 章节摘要 | 本章及前几章的压缩摘要（章数可调） |
| ⭐ 写作规范 | 人称 / 时态 / 标点等硬约束 |
| ⭐ 前文章节 | 往前带几章的正文（取每章**末尾**，兼顾衔接与文风；章数可调，上限 5） |
| 世界设定 | 世界设定 + 力量体系 + 名词术语 |
| 分卷大纲 / 全书总纲 | 本章在卷里的位置 / 长线方向 |
| 伏笔追踪 | 避免与既有伏笔冲突，也可顺手埋收 |
| 写作文风 | 按你的文风档保持一致 |
| 爽点节奏 | 续写的爽点安排参考 |

- 🔴 **没勾的一律不读**；勾多了超上下文时，界面会实时显示「**预计占用 N 字 / 预算 M 字**」，并把**具体哪几项因预算没带进去如实列出来** —— 绝不静默丢。
- 🔴 **结果落「建议段」**（写在原文下方的一个带标记的区块里），**你的正文一个字都不会动**；看过满意再自己并入。
- 生成**边写边出**（流式），不用干等。
- 📌 它与审读模式里的「续写方向」**并存**：那个只给思路、不生成正文，职责不同。

### ⭐ 颉文姬改稿：能填自己的具体要求了

**入口**：同上，编辑页。

以前那五个按钮（润色 / 扩写 / 精简 / 语气 / 视角）只把「动作名」发给模型，具体要往哪改全凭它猜。现在多了两个输入：

- **额外要求（选填）** —— 例如「偏向冷峻克制的叙述，少用形容词」。**五个动作各有一句不同的示例**提示你该怎么写（填过什么就照它办）。
- **期望字数** —— 例如原文 50 字、想扩到 200 字，填 200 即可（界面提示：AI 会尽量贴近，**实际以生成为准**）。

- 🔴 **不填就等于以前**：一个字都不写时，发给模型的请求与旧版**逐字一致**。
- 🔴 **动作的「纪律」仍在**：比如「扩写不得凭空造专名」「精简不丢设定交代」这类底线，会和你的要求一起发过去，并明确「**以你的额外要求为准，但不得放宽动作纪律**」。
- 不做记忆、不预填 —— 免得上一次的要求悄悄影响这一次。

### ⭐ 模型配置：几百个模型里一搜即中

**入口**：模型设置 → 模型配置 → 「获取可用模型」。

接入中转站时模型列表常有几百项，原来只能在选择框里敲前缀跳转。现在列表上方有**筛选框**，输入即缩小范围，并显示「**命中 N / 共 M**」：

- 空格分隔多个词按「**全部命中**」算（如 `qwen 27b` 只留同时含这两段的）；
- 忽略大小写、支持中间子串（`QWEN` 也能搜到）；
- 一个都没命中时提示「换个关键词，或在下方手动填写」。
- 云端端点与**本地 Ollama** 两处列表都加上了。

### ⭐ 模型配置新增「文本生成微调」

**入口**：模型设置 → 模型配置 → 「自定义系统提示词」正下方。

六个参数，各带**中文名 / 推荐值 / 因果说明**（说清「调大怎样、调小怎样」，不说好坏）：

| 参数 | 推荐值 | 说明 | 云端 |
|---|---|---|---|
| 核采样阈值 | 0.85 ~ 0.95 | 调低更保守更重复，调高更花哨更易出现别扭搭配 | ✅ |
| 候选词上限 | 20 ~ 60（0 ＝ 不限制） | 调低稳定但词汇贫乏，调高文风更活 | 仅本地 |
| 重复惩罚 | 1.02 ~ 1.10 | 压制复读；过高（>1.35）连虚词都回避、句子发硬 | 仅本地 |
| 惩罚回看窗口 | 512 ~ 1024 | 惩罚「回看多远」；⚠️ 不填时 Ollama 默认只有 64 词元 | 仅本地 |
| 词频惩罚 | 0 ~ 0.3 | 压掉反复出现的词（「翻」「冷笑」「缓缓」） | ✅ |
| 新话题倾向 | 0 ~ 0.5 | 调高更发散也更容易跑题，调低更聚焦 | ✅ |

- 🔴 **留空 ＝ 不下发**：一个都不填时，请求体与「完全没有这个功能」时**逐字节一致** —— 升级**不会**悄悄改变你现有模型的行为。（不给死默认值，理由同「自定义系统提示词留空则不注入」。）
- 云端不认的三项会**灰显**并注明「只对本地 Ollama 生效」，免得你调了却不知道没生效。
- 「生成温度」早就有独立入口（档位按钮），不在这里重复。

### ⭐ 检查结果会留痕了（新增两处趋势）

**入口**：检查工具页。

- **投稿前自检（行文分布）**：点「跑结构与伏笔」后，标题行右侧显示「**上次检查 N 条（刚刚）· 比上轮多/少/持平**」。
- **节奏与章末钩子**：跑完后同样出一行趋势（单位是「**个观察点**」，不带好坏色彩 —— 爆点变多不等于变好）。
- 🔴 **节奏的趋势只比同一个模型**：AI 的分析结果随模型而变，换模型后趋势重新开始，不会把两个模型的结果混成一条线骗你。
- 只记录统计值，**不存检查全文** —— 它的价值在趋势，不在于当第二个数据源。

### ⭐ 优化工单新增「按类型」视图

**入口**：检查工具 → 全书优化工单 → 工具条「**按章 / 按类型**」切换。

「按章」是执行改写的视角（原样保留），「按类型」则是看**全局**：同一类问题在全书出现几次、分布在哪些章，一眼看出哪类毛病最普遍。排序口径是「**严重度分档 → 出现章数降序**」，不搞加权公式 —— 一眼就能预判顺序。

### ⭐ 「设定变更」页会提示数据体检结果

**入口**：设定变更页（进出该页时静默跑一次）。

有 `冲突` 级问题时，页顶出一行提示（几条、去哪儿看）；**没有问题时，页面与以前一字不差**。只报数、不判定，逐条上下文仍在「检查工具 → 数据体检」。实测全库扫描只要 **11 毫秒**。

## 修复

### 🔴 酒馆控制面板：云端不认的参数，现在会灰显了

- **问题**：「候选词上限 / 重复惩罚 / 惩罚回看窗口」这三项是 **Ollama 专有**，接云端模型时根本不生效 —— 但界面照旧可以随便调，**而且不报错**。你会以为调了有用。
- 现在云端模型下这三项**灰显**并注明「只对本地 Ollama 生效」（与「上下文窗口长度」同一种处理）。
- 🔴 这条是排查「模型配置」同类问题时**顺藤摸瓜发现的** —— 你问的那句「酒馆那边是不是也有这种情况」，答案是**有**。

### 🔴 本地 OpenAI 兼容服务上，三个参数此前「调了不生效」

- **问题**：采样参数按「是否本地」判断该发哪些，但**本地跑 OpenAI 兼容服务**（LM Studio / LocalAI / GPT4All / Jan 等）**也算本地** —— 于是这三个 Ollama 专有参数被发了过去，再被静默丢弃。界面能编辑、实际没用。
- 现已改为按「**是不是 Ollama 原生通道**」判断，下发与界面灰显**共用同一个判据**，不会再分裂。

### 🔴 投稿前自检的趋势行，以前永远显示「与上轮持平」

- **问题**：这项自检对任何非空章节**恒定产出固定条数**的观察项，而趋势是拿「条数」比出来的 —— 于是每次都是「持平」，**这个功能等于白做**。
- 现在只记录**真正偏离参考区间**的那几条，趋势才有意义。

### 续写的示例文案：五个动作不再共用一句

- **问题**：五个动作的输入框提示语是同一句，等于没提示 —— 而每个动作要回答的其实是不同的问题（润色＝偏向哪一面、扩写＝扩哪一块、精简＝删什么、语气＝从什么改成什么、视角＝从什么换成什么）。
- 现在各有一句自己的示例，并加了防呆：**新增动作若忘了配示例（或又共用一句），测试会直接变红**。

### 前文章节：此前可能「丢的正是最该带的那一章」

- **问题**：勾了「前文章节」时，预算按**从旧到新**分配 ⇒ **最老的章先吃满**，章数一多，**紧邻的上一章反而被挤出**「未带入」。而这一项恰恰兼作衔接参照 —— 丢的正是最要命的那一章，界面还只笼统报个章数，你根本看不出丢了哪个。
- 现在改为**从紧邻章开始分配**（分配完仍按叙事顺序送出），并配了防回归测试。

## 安装

下载 `青春幻想引擎-Setup-2.9.2.exe`，双击安装即可。**覆盖安装不影响已有项目数据。**

> 若从 2.9.1 升级：项目数据、模型配置、酒馆设定与角色卡都会原样保留，不需要做任何迁移操作。
> 🔴 本版新增的「文本生成微调」各项**默认都是空的**，因此**不会改变你现有模型的任何行为**；想调再填。
