## 一句话

**上一个版本（2.4.1 / 2.4.2）有一个界面布局缺陷：某些页面的内容撑不满窗口，下方留出一大片空白。本版修掉了它。**

本版同时包含 **2.4.2 的全部内容**（世界观多套结构、docx 拆书、分平台预检、本章体检、导出增强等，详见下方第二节）。

## 一、🔴 修复：酒馆对话窗口下方的大片空白

**你会看到的现象**：

| 页面 | 现象 |
|---|---|
| **剧情推演** | 对话窗口只占了约一半高度，**下方留一大片空白**（实测约 490px） |
| **自由对话** | 同理，比剧情推演留白更多（实测约 487px） |

**顺带修正的一处**：编辑器（正文编辑）也受同一个原因影响，只是表现相反 —— 它的内容高度会**超出窗口**，多出来的部分既看不见也滚不到。

**为什么会这样**：为修「表格 / 卡片的表头滚动时从页头上面穿过去」，上一个版本把页面内容外面**多包了一层容器**，却没给这层容器高度。于是页面里那些「撑满整个窗口」的写法（高度写成「父层的 100%」）就**失去了参照物**，退化成「按内容高度」——
内容少的页面下方就空着，内容多的页面就顶出窗口。

换句话说是**一层容器的高度漏了**，不是单个页面的问题，所以它对所有「撑满型」页面同时生效。

**现在**：容器高度补回，页面重新撑满窗口。实测三处「下方空白」归零，且：
- 表格 / 卡片的**表头仍然正常贴住顶部**（当初挪动那层 padding 的初衷没有被破坏）
- 长表单页**照常可以滚动到底**
- 编辑器正文、缩进、高亮等行为**逐项复验不变**

> 这一条同时影响 2.4.1 与 2.4.2 两个版本，因此**建议 2.4.1 / 2.4.2 的用户升级到本版**。

## 二、本版同样包含 2.4.2 的全部内容

如果你是**从 2.4.1 或更早**升上来，本版一并带来 2.4.2 的全部更新：

### ⭐ 世界观 / 力量体系：母子结构（无限流刚需）
顶层一个**全书统一**的设定（**永远发给 AI**），下面可建任意多个**子世界 / 子体系**（副本、世界线、剧本各一套），
每个带「活跃 / 已完结」开关 —— **只有标为「活跃」的才发给 AI**，且会写明「另有 N 个已完结，未发送」。
只建一套设定的用户**感觉不到任何变化**。

### 一键拆书支持 .docx
Word 稿子不用再另存为 txt（另存会丢缩进）。**零新增依赖**（安装包体积没有变化）；
首行缩进按 Word 的段落属性还原成中文全角缩进；**读不到的内容会如实列出**（批注 / 脚注 / 页眉页脚 / 图片 / 公式 / 修订删除的文字）。

### 分平台投稿预检
挑「晋江 / 起点 / 通用」档位，看敏感词命中里**哪些类别属于该平台通常更关注的**，以及分章字数事实。
**只摆事实、不判合格与否**，并注明规则以平台后台为准。

### 本章体检
选一章，把已有的五个确定性引擎（连续性 / 伏笔 / 敏感词 / 错别字 / 文风）**一次跑完并分组呈现**，
全部本地计算、不发 AI 请求。

### 导出增强
导出时多了个**格式弹窗**（带实时预览）：章节标题（原样 / 补「第N章」/ 不带）、段落间距、卷标题开关、
**设定附录**、Markdown 标题层级。选项跨项目记忆；**不调任何选项时导出结果与旧版逐字节一致**。

### 备份体系第二期
备份列表不再需要把每份备份整包读出来算体积（**秒开**）；任意一份可**导出成独立文件**，也能**从该文件恢复**。

### 🔴 三处静默隐患修复
① 酒馆角色记忆整理被判「整份退化」时**记录位置照常前移**，那段对话被永久越过 → 现在退化时**不推进位置**；
② 早期版本把搜索密钥存在**另一处容器**里、会随加密同步文件走 → 已一次性迁移清理；
③ 同步合并还有**第三条「删了会复活」路径** → 按墓碑判据补齐。

### 内部加固
三个巨型组件完成收尾拆分；层级号收敛到统一真源；界面文案里残留的 markdown 星号清干净；
清理死代码、合并重复判断；**补上 4 项此前无测试覆盖的修复的回归断言**。

## 三、安装与升级

- 直接运行 `青春幻想引擎-Setup-2.4.3.exe`，覆盖安装即可，**原有项目数据自动保留**
- 从 2.4.1 / 2.4.2 / 更早版本升上来都不需要额外操作（数据迁移在首次启动时自动完成）
- 本版**不涉及任何数据结构变更**

## 四、数据与隐私

- 软件**不做账号体系**，不收集你的稿件
- 涉及 AI 的功能：**原文只发送给你当前选定的那个模型** —— 本地模型则不出本机；云端模型会上传到该服务商
- 模型密钥、搜索密钥等敏感配置**仅保存在本机**，不随云盘同步文件外流
- 云盘同步文件是加密的（内置密钥），**足以防误看，但不足以对抗蓄意破解**；涉密稿件请另用导出备份自行保管
- 本软件定位是**创作主权存证 + 质量自检 + 如实申报**，**不做也不参与**任何「反检测 / 洗 AI 痕迹」的事

## 五、已知事项

- 超大表格（3000 行以上）渲染偏慢，已记录待优化
- 云盘同步是**文件夹级**的，不是实时同步；换设备前请手动确认同步完成
- 拆书 / 创意写作末尾的「全书级设定汇总」**只写母级**（子世界需要自己填）
- 仅 Windows / 仅简体中文
