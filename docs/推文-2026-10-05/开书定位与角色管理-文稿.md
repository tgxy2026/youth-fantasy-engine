# 开书前先把这两块填了：定位，和人物

先交代两句。这篇同样是 AI 辅助写的，用途是把功能讲明白。这一期讲的是**最基础、也最容易被跳过去**的两个板块，你要是只想看新东西，上一期的 2.8.0 介绍更值。

上一期咱们聊了「灵感工具」里那两块硬活：把别人的完本一键拆成自己的设定表，把脑子里一句话开成一本书。底下有读者问了个挺关键的问题——拆出来的设定、开出来的大纲，总得**有个地方住**吧。

这一期就补这个家。

---

## 一、为什么这两块不能跳

多数人开书的第一周长这样：想出一个金手指，起了个主角名，开了第一章。

写到第二十万字才发现不对。金手指的代价越写越大，前后对不上；主角到底是天才还是废物，全书没说清；那个「反派」中途忽然变成亦敌亦友，可前三十章铺垫了什么，自己也想不起来。

毛病不在灵感，在**开书时没定盘**。定盘这活儿枯燥，但它决定了后面几十万字有没有地基。

所以软件把这两块做成了独立分组，没塞在设定表的角落里：

- **开书定位**——动笔前的商业与世界观定盘（作品信息 / 世界设定 / 力量体系 / 政治架构 / 经济基础 / 宗教信仰 / 司法制度）
- **角色管理**——人物建档与关系网（主要角色 / 次要角色 / NPC 角色 / 人物关系）

## 二、开书定位：把这几页填掉再动笔

这几页都是表单型的，一份档案一栏栏填。枯燥，但它就是这本书的宪法。

### 1. 作品信息：先想清楚卖给谁

这一页是开书的商业档案，五组模块：

- **基本信息**：书名、赛道、篇幅、更新节奏
- **平台与读者**：目标平台、读者画像、对标作品
- **卖点与差异化**：核心卖点、差异化亮点、开篇钩子
- **简介与物料**：一句话简介、正式简介、书封创意
- **风险预案**：切书线、备选方向

新项目刚开时这一页通常是空的。填满它，你至少知道三件事：这本写给谁看、凭什么让人点开、写在哪个平台。

挑两个最值得先填的栏说说。**核心卖点**要求一句话讲清凭什么是你，**开篇钩子**问的是第一章凭什么留住人。而**对标作品**别只填一部——填两三部，你才知道这个题材的读者在为什么买单。**风险预案**那栏（切书线 / 备选方向）是给中途卡壳留的退路，写大纲时顺手扫一眼，比写到一半推翻重来便宜得多。

> 📷 **截图**：`B02-开书定位-作品信息五组模块.png`

说句实在的：这些栏不会替你做决定，它只是逼你把决定写下来。**写下来才叫定位，只在心里过一遍那叫幻想。**

> 这一页改过名。老资料、老截图里看到的「作品定位」，就是现在的「作品信息」——2.7.2 那批只改了显示名没动数据，是同一个东西。

### 2. 世界设定：底层法则定了就别改

这一页是世界观的顶层档案，六组模块：世界总览、底层法则、社会与文明、成长地图、限制与禁忌、剧情钩子预留。

新人填这页最容易犯的错是**从上往下填**——先画地图，再排势力，最后才想规则，写到后面规则和剧情互相抽耳光。

推荐反过来，三层填法：

- **底层法则先定**（能量从哪来、代价是什么、什么做不到）——这一层定了就不改；
- **社会文明前十章展开**，读者一眼要看懂的部分，够用就行；
- **细节随写随补**，剩下的写到哪儿填哪儿，别在开书前把百科全书全写完。

**成长地图**那栏特别实在，它是个同心圆，从核心圈到最终圈。你要填的是「主角从哪儿出发，一圈圈走到哪儿」。这一栏填好，分卷的时候心里就有数了。

> 📷 **截图**：`B03-开书定位-世界设定与成长地图同心圆.png`

顺带提一个字段：这页里有个**世界终极真相**，装的是作者知道、角色不知道的那层（比如「主角体内的灵脉其实是某个东西种下的」）。它跟主线怎么扣上是你自己的事，软件不替你安排。但它逼你落笔。**藏了不写，等哪天作者自己忘了，这条线就白埋了。**

### 3. 力量体系：等级表是宪法，不是建议

> **这一页的名字和模块会随「作品题材」变。** 超凡题材下叫「力量体系」，都市现实、历史古代那几套会换成现实向的说法（如「能力资源 / 权谋实力 / 关系地位」）。题材是新建项目时定的，选完就别改，改了等于这页重写。

升级流的「物理法则」在这一页，四组模块：

- **体系总览**：等级总表、各境界战力量化、突破条件、瓶颈寿元
- **修炼路径与资源**：功法品级、天赋资质、辅助职业
- **规则与克制**：越级挑战规则、基础能力门槛、战力崩坏防范
- **与主角的接口**：金手指与体系的关系、限制代价、成长路线

这页最该认真填的是**各境界战力量化**，把每个境界的战力算成能比较的量——「这一层能毁一屋」「再上一层能毁一街」。量化之后你就知道第几章该让主角到哪一层，不会忽上忽下。

**越级挑战规则**同样要命：什么条件下能越阶打、代价是什么。一次两次是爽点，次次都越级，整本书的紧张感就没了。

> 📷 **截图**：`B04-开书定位-力量体系等级总表.png`

等级表定下来就尽量别动。读者已经接受了「炼气三层能干什么」，你中途改表，他们第一个反应是这书写崩了。

> 旁边那四页——政治架构 / 经济基础 / 宗教信仰 / 司法制度——是**并列**的，没有母页，各写各的。2.7.2 之后**完整项目一律显示**这四页，只有自定义项目才按「功能模块」勾选。这页也改过名，「经济体系」现在叫「经济基础」。

## 三、角色管理：几十张卡怎么分才不崩

三张卡加一张关系表。分档是按**信息密度**分的，该省的字段省掉，该给的一个不少。

### 4. 主要角色：字段最全，藏得最深

核心人物的完整档案，五组模块：基础信息、性格与内心、能力与成长、背景与关系、剧情功能。最里层还塞了价值观、恐惧与渴望、角色弧光、结局归宿——这些不是凑数，是写到一百章时唯一能救你的东西。

两个设计得知道：

**保密等级五档**：S·绝密（剧透）／A·重要（主线）／B·次要（支线）／C·琐碎（日常）／D·终结（弃用）。这一栏真正干的事是决定**谁看得到**、**谁先占上下文预算**，档位越靠前越优先塞给模型。给一个角色标了 S，他那些不能透的底就不会跟着数据一起走；标了 D 表示这条用完了，**任何情况下都不提供给 AI**，这条是封死的。多人协作或者把项目拿给别人看时，这两档就是防火墙。

**种族 / 所属势力 / 地理位置**都是**下拉选择**，取值来自对应的设定表，不许手填。手填就会出现「青岚宗」和「青兰宗」两种写法，检索和统计全乱——这种小坑最耗人。

> 📷 **截图**：`B05-角色管理-主要角色卡与保密等级.png`

**别称字段**记得填。正文里叫「铁柱」、卡里叫「王铁柱」，填了别称软件才知道是同一个人，不然判重会判成两个角色。

### 5. 次要角色和 NPC：按需给密度

不是所有角色都配得上开一张全卡。

**次要角色**是阶段性重要的人（宿敌、导师、关键配角）。四组模块，信息密度卡在主要和 NPC 之间：比 NPC 多了出身、性格矛盾、能力细节，比主要角色少了价值观、恐惧、弧光这些最深的规划。

**NPC 角色**是功能型的，一个模块，重点在**功能定位**：导师型 / 打脸对象 / 情报源 / 伏笔承载者 / 氛围组。

这一档的价值是防写崩。一个「王铁柱」，功能定位写着「损友 + 氛围组 + 温情线承载」，你写到第三百章都不会突然把他写成深藏不露的高手。

还有个实用操作：**戏份变了可以在三档之间升降级**。开场的小喽啰后来成了主要角色，把卡挪过去就行，不用重填。

> 📷 **截图**：`B06-角色管理-NPC角色卡与功能定位.png`

这三档是信息密度的分级，不是价值判断。别因为「这个角色不重要」就乱塞——NPC 卡里那一句功能定位，往往比一堆形容词管用。

### 6. 人物关系：关系会变，所以它留痕

关系表是台账式的表格，列有：人物 A、人物 B（都是下拉选择，不许手填）、关系类型（亲属 / 师徒 / 盟友 / 敌对 / 竞争 / CP 感情线 / 主仆 / 恩怨）、关系现状、知情度、关系起点、演变轨迹（按卷）、演变触发事件、关系终点、戏剧功能。

先说件容易踩的事：**「人物A → 人物B」是有向的**，A 是视角主体。同一个人对不同人的态度本来就不一样，所以 A→B 和 B→A 各算一条。判重也有规矩，**只有「同一对 + 同一方向 + 同一关系类型」才算重复**——同一对人可以并存好几种关系，既是盟友又在暗中提防，就各记一行，不冲突。

最要紧的一条设计：**关系质变是新增一行，不是覆盖原来的。**

举例：陈渊和萧景行，记录是「假善提携 → 暗斗 → 决裂 → 宿敌」。等你写到决裂那一卷，**新加一行**，把起点和终点写清楚，假善提携那条**留着**。这样回头翻能看见这条关系是怎么一步步走到今天的，写新卷时也不会把旧账抹了。

> 📷 **截图**：`B07-角色管理-人物关系表与关系图.png`

关系表默认是按人物分组的文件夹视图，看着像个文件柜。**切到「关系图」**&#x662F;另一个世界：能拖节点、滚轮缩放、点节点收起或展开关系边、拖空白平移画布，图例按关系类型着色。群像写到乱的时候瞄一眼图，比在表里翻半小时有用。

## 四、几句实在话

1. **这几页填起来是真枯燥。** 软件能做的是让你填的时候不丢东西、能被 AI 拿去用，它填不出好内容。定位和人物，还是得你自己想。
2. **填完记得回头看一眼。** 开书时的想法和写到一百万字时的现实往往不是一回事。改设定不难，难的是改完记得回正文里对一遍。
3. **这两块跟 2.8.0 是配套的。** 填好的定位和角色卡，正是上一期说的语义检索、参考资料的原料——你书里有什么，它才捞得出什么。空着卡让 AI 认你的书，它认不出来。
