## 使用说明

- **入门访问邀请码**：仅用于「进入网页版」。一个码可被同一人多次使用（本地浏览器记住后不再重输），但请勿把同一个码发给不同人——本表登记即可防重复外发。**服务端不强制一次性消费**，靠人工记录保证不串用。
- **云端同步邀请码**：用于开启「跨设备云端同步」。**每个码对应一个独立的云端存储槽位**，请勿多人共用同一同步码，否则数据会互相覆盖（后写覆盖先写）。建议一人一码。
- 两类码互不相通：要先「入门」再在该码所有者浏览器内「用同步码开启云端同步」。

## 增删邀请码

- 在服务端 `/opt/yfe-server/../` 的环境变量中维护（实际由 `server/yfe-feedback.service` 的 `INVITE_CODES` / `SYNC_CODES` 控制）。
- 修改后执行：`sudo systemctl daemon-reload && sudo systemctl restart yfe-feedback` 即生效，无需重新部署前端。
- 需要新批量生成时，用 `scripts/_gen_codes_tmp.mjs` 类似的脚本重新生成并追加。
