### 5.3 本轮新增的实机验证坑（已回写 `novel-studio-ui-livecheck`）

1. 编辑器工具栏是 `overflow-x-auto` 横向滚动容器 → Playwright `click()` 的 `scrollIntoView` 触发 scroll → HelpPopover 的滚动监听立刻关掉气泡 → 改用 `locator.evaluate(el => el.click())`。
2. 新建的空项目没有章节 → 编辑器整条工具栏不渲染 → 文档类断言必须在**示范项目**里做，且**点前先断言 `count() > 0`**。
3. 上一步打开的气泡会盖住侧栏「切换项目」→ 先点主区空白收气泡，再点并重试一次。
4. **验证期间别关 Electron 窗口** —— 报 `Target page, context or browser has been closed` **不是产品 bug**（本轮老大误关过一次）。
