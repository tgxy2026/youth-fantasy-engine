# 青春幻想引擎 3.6.2 更新说明

> 发布日期：2026-11-21　|　源码版本：`v3.6.2`

3.6.2 的主线是**投稿广场的连载能力**：能给作品建合集、把以前发的稿子归进去、按顺序连着读，并让每篇显示浏览量。
另外把编辑器里「切一章要重渲染整棵 800 行目录」的老问题修掉了。**数据格式没有变化**，直接覆盖安装即可。

## 一、你能直接看到的变化

### A. 投稿广场：连载作品可以建「合集」了

在「我的」最上面是新的「我的合集」：

- 填个名字就能建（最多 40 字，简介可选）；每人最多 20 个合集，每集最多 200 篇；
- 建好之后，**每篇投稿下面会出现「所属合集」下拉**——以前发过的稿子同样能放进去，不要求是刚发的；
- 合集内**按第 1 篇起的顺序**连着读，和广场「新的在前」相反（进合集是为了从头读故事，不是看动态）；
- 打开其中一篇时，标题下方显示「收录于《合集名》· 第 3 / 共 12 篇」，正文底部有上一篇 / 下一篇；
- 作者还能在「排序」里手动调整顺序，**正在审核的稿子也能排**（灰显，公开后回到这个位置）；
- 撤回或下架的篇目不出现在目录里，序号会跳号——那表示确实有一篇现在看不到，不是显示错误。

删除合集只删合集本身，里面的投稿不会被删，只是从合集移出。

### B. 每篇投稿显示浏览量

列表、详情、合集页都能看到浏览数。口径写清楚，免得误解：

- **只有真的打开详情才算一次**，在列表里刷过去不算——所以数字比「曝光」涨得慢，这是对的；
- 同一个人对同一篇 24 小时内只算一次；**作者本人打开自己的投稿不计**；
- 未登录的网页访客也计数，按设备去重，且不保存 IP；
- 合集页的「**合计浏览**」是各篇之和：同一个人读 10 篇会算 10 次，它是篇次，不是读者人数。

### C. 切章不再拖着整棵目录一起重渲染

800 章的长书里，以前每切一章、甚至每敲一个字，左侧 800 行目录都会跟着重渲染一遍。
本版修掉三处根因（目录组件没做记忆化、写回执监听跟着切章走、可拖拽面板每次返回新对象）。实测：

| 场景 | 修前 | 修后 |
| --- | --- | --- |
| 切一章，目录渲染次数 | 6 | 2 |
| 正文输入 10 个字，目录渲染次数 | 24 | **0** |
| 自动保存一次 | 4 | 4（合理：章节数据确实变了） |

### D. 网页版会提示「有新版本，刷新即可」

网页版开着不动时，若有新版发布，页面会出条提示，点一下刷新就拿到新版——不用自己猜是不是旧的。

### E. 存储快满时会提醒

项目占用接近配额时会在启动后提示一次（**不弹窗打断写作**），并说明怎么清理。

### F. 设置里多了「AI 质量（近 30 天）」

按功能统计 AI 建议的出现 / 采纳 / 拒绝 / 重生成 / 撤销次数与接受率，用来判断哪些提示真的有用。只记次数，**不记录你写了什么**。

### G. 投稿广场浮层支持 Esc 关闭

打开广场后按 Esc 可以关掉，且焦点会回到原来的位置——以前键盘用户只能一直 Tab 到关闭按钮。

## 二、修掉的问题

| 问题 | 说明 |
| --- | --- |
| 切章 / 打字时目录整棵重渲染 | 见上文 C，三处根因一并修掉，并加回归闸防止被改回去 |
| 合集卡片上的合集角标不显示 | 列表接口漏了合集信息，只有详情页有；已补齐 |
| 刚看完一篇，浏览量还是旧数字 | 浏览量在内存里合并落盘，展示时没算上未落盘的增量；已改为「落盘值 + 待写增量」 |
| 详情页点「收录于」没反应 | 合集浮层只挂在列表分支里，详情态没有渲染位置；已修 |
| 网页版切章偶发卡顿 | 见上文 C（这是那一现象的主要来源） |

## 三、工程质量（你看不到，但影响稳定性）

- **更新清单双源**：优先读发布清单，读不到回落到 Gitee Release；单个源出问题不会让「检查更新」失灵。
- **诊断包改为白名单组包**：新增字段默认不进包，避免以后加字段时不小心把你的正文带进诊断信息。
- **恢复演练**：对备份恢复流程做了实际演练（含失败与中断路径），结果记在开发记录里。
- **合集与浏览量**：新增 48 条服务端断言 + 11 条展示格式断言；合集另有 **31 条真机端到端**（真实服务端 + 真实前端产物 + 真浏览器，走完投稿→审核→建合集→归集→排序→阅读）。
- 全量单测 **511** 条通过；六维审计 complete（980 个源码文件、0 候选）；发版检查 FAIL 0。

## 四、升级与兼容

| 形态 | 怎么升 |
| --- | --- |
| 桌面版 | 直接运行 `青春幻想引擎-Setup-3.6.2.exe` 覆盖安装，项目数据不用动 |
| 便携版 | 用新 zip 替换整个目录（`data/` 是你的数据，替换前先复制一份更稳妥） |
| 网页版 | 刷新页面即可（`Ctrl+Shift+R` 强制刷新可立刻拿到新版本） |

- **数据格式未变**：3.6.0 / 3.6.1 及更早的项目可直接打开，没有迁移步骤。
- 已安装 3.6.1 的用户不需要先卸载。
- 投稿合集与浏览量是**服务端功能**：网页版随本次部署生效；桌面版 / 便携版通过同一个社区服务访问，同样生效。

## 五、已知限制

- 便携版不支持投稿广场（与 3.6.0 / 3.6.1 相同）。
- 合集暂不支持封面图、订阅追更、跨作者共建；也没有「按天浏览曲线」。
- 旧投稿没有历史浏览量，从本版上线后开始累计——这是有意的，不做假数据回填。
- 图鉴表格不显示「共 N 行」这类总数（数据本身完整，筛选与导出不受影响）。
- 搜索替换的「全书」范围只改正文，**改章名请回章节列表或本章标题框**。
