## 三、审计连带查出的真缺陷（已修）

### 3.1 创作参考：把「已排除」当成「未审」

`referenceCardsOf` 只区分 `kept`（是否确认），作者标为 **excluded** 的成果会显示成「未审」并且**可以被勾选发送**。
排除是作者的否定决定，与「还没看」不是一回事。修法：

- `ReferenceCard` 增 `excluded`，由 `state === 'excluded'` 置位；
- `buildReferenceBlock` 剔除并给 `reason: 'excluded'`，摘要显示「已排除 N」；
- 选择器把它设为**不可勾选**并标注「已排除（不可选）」；
- `REFERENCE_KINDS` 成为「哪些类型可当参考」的唯一判据（原先 `referenceCardsOf` 里手写了一遍 kind 判断）。

### 3.2 检索评测报告两处口径错误（G 包自检）

| 问题 | 后果 | 修法 |
| --- | --- | --- |
| `BenchReport.foreignLeaks` 写死 `0` | 报告像「测过且合格」，实际没测过串味 | 只有真的混入别项目行才算，且**按策略分别统计**；未混入时字段缺省（= 未测，不是 0） |
| `avgChars` 分母用「有标注的查询数」 | 空结果查询的 0 字被排除，平均值虚高 | 分母改为全部查询 |

新增断言：生产默认串味 0 条、旧口径确实会串（证明这道闸不是摆设）。

## 四、仍未处理（如实）

### 4.1 存量死代码 23 个（非本版引入）

分布在 `agentHost`（10）、`aiCore`（3）、`community`（2）、`revision`/`settings`/`tavern`/`templates`/`components`（8）。
**本轮不动**，理由：

- ACP 相关常量（`AGENT_WRITE_TOOLS` / `AGENT_WRITE_RETRYABLE_ERRORS` / `settingTabInfo` 等）是**外部 Agent 组件的契约面**，删除前需要确认它不经 TS 导入消费；3.5.4 刚完成 ACP 隔离，不在发版前动这块；

建议：单独开一次清理任务，按「先补 KEEP 理由或删除」逐条处理，不与功能版本混在一起。
