## 1. 复审决定与边界

保留 C1 窄屏与触摸、C2 全屏与打印导出、C3 本地模型边界、C4 端能力统一。删去未经证实的绝对判断，改为基于内容宽度、运行时能力和真实设备的验收。

| 原稿问题 | 修订决定 |
|---|---|
| 没有 md: 就是“全站零响应式” | 删除：当前已有容器查询、测宽分支与 ResizeObserver；先盘点真实缺陷，不重建现有适配 |
| 只按 window 宽度统一 JS 断点 | 导航沿用现有逻辑，内容优先测容器/复用容器查询，避免侧栏占位后内容仍误判 |
| 触摸尺寸只在窄屏放大，外包容器即可达标 | 改为触摸/粗指针环境也生效；真实可点击元素达标，不能只测空白外壳 |
| 所有横向滚动禁止，但表格又允许横滚 | 页面无横向溢出，明确表格/画布内部滚动豁免及操作条件 |
| 160% 缩放不能触发窄屏 | 删除错误目标：缩放减小可用布局宽度，进入紧凑模式可能正是正确行为 |
| Safari 一律仅视频全屏，手机必须隐藏地址栏 | 不按浏览器名硬编码，运行时探测并实测；无全屏仍能完成写作 |
| https 网页必然无法访问 localhost 模型 | 技术上删除绝对判断；产品上保留已有 P9 网页禁用策略，不能把条件可达推成开放需求 |
| 能力只有布尔值，改一行就代表平台能力变化 | 改为支持/条件支持/不支持/待确认状态和统一原因；真实行为仍受运行环境限制 |
| 必须等 3.3.3 公开发版才开工 | 改为接口与共享组件稳定后集成；基线盘点可提前，不以发版作为技术依赖 |
| 一页签一提交、55 页全真机三档全组合 | 按共享组件/页面族分包，模拟器覆盖全部，真机覆盖关键流程和高风险页，不虚报设备覆盖 |

**目标**：账号用户能取书、编辑、保存、同步；游客能编辑、重开回读及导出。游客无账号同步，不能强迫游客走登录取书验收。所有任务失败都有可达反馈与恢复入口。

不做：原生手机 App、专用手势、平板专属排版、同步协议重构、备份格式变更、模型服务部署或浏览器安全策略绕过。允许修正界面保存屏障接线/生命周期缺陷；若必须改数据核心，单列阻断缺陷并回归，不能以“布局版不动数据”为由放过丢稿。

## 3. C1 内容适配与触摸交互

### 3.1 P0 基线与布局规则

1. 先输出页面清单：页签 id、渲染组件、共享页面族、宽表/表单/编辑器/画布、关键弹窗、溢出现象、修复归属与截图编号。除项目内页，还覆盖登录、项目中心、设置、同步/冲突面板、导入导出及帮助。
2. 导航保留 compact <900 的现有口径；内容 narrow <520 作为初始设计阈值，不要求所有内容跟随 window 判定。优先复用容器查询；确需 JS 行为时共用布局测量工具，禁止各页重复订阅 resize。
3. 明确尺寸单位：CSS zoom 下测量使用现有布局坐标体系；offsetWidth/clientWidth 与 getBoundingClientRect 分别记清，已经是布局宽度不得再除一次 zoom。在 519/520/521、899/900/901 边界实测，防阈值振荡和重复折算。
4. 允许必要 CSS 媒体/容器查询，不以“当前 md: 少”禁止响应式 CSS。不改现有全局缩放语义，复用 foldVh/浮层定位换算；动态视口及安全区在现有高度体系内验证，避免二次缩放。

### 3.2 页面与控件策略

- **内容**：双栏改单栏，工具栏分组换行/更多菜单。图标条占位后的正文仍须可写。标签长文本可换行/截断并有可访问完整值，不用整页 overflow-x:hidden 掩盖被裁内容。
- **表格**：优先内部横滚，容器限于内容区，提供可见滚动提示；末列、行操作、行内输入和选择菜单均能到达。横滚不能挤出页面级滚动；卡片化仅为确有必要的个别页面，不强制全表重做。
- **画布/地图**：内部平移/缩放可豁免整页无横滚要求，但移动端必须有点击可用的缩放/复位/列表替代，不能只能鼠标拖拽。
- **命中区**：最小 44×44 CSS px，是本项目易用性目标，不宣称等同某项认证。窄屏及 coarse pointer/触摸使用场景生效，包括平板；输入框、菜单、关闭、行选择和图标按钮均纳入。小图标可保留视觉尺寸，但扩大实际交互元素，区域不能重叠或被邻居遮住。
- **弹窗**：短确认仍可居中，长表单窄屏采用近全屏/全屏。标题、关闭及确认始终可达，正文独立滚动，焦点圈定且关闭回原触发点；软键盘不能压住输入和确认。
- **编辑器**：更多菜单内原功能全部可达；中文输入法组合中不重挂编辑器、不误保存半个拼音；键盘展开后光标/当前行可见，保留选择、撤销和保存反馈。
- **旋转与恢复**：不丢草稿、不改变当前项目/章节；保持当前编辑位置或同一可见内容，允许因重新排版导致滚动像素变化，删除“不跳顶部”的绝对像素承诺。
- **触摸替代**：不能依赖 hover、拖拽或长按作为唯一入口；键盘焦点、读屏名称、文字状态与鼠标操作也要可用。

### 3.3 可量化判据

- 320/375/430 CSS px 下页面根横向溢出 ≤1px；豁免仅限有边界的表格/画布内部。页面无裁切，所有列/操作可达。
- 主要写作、保存、同步、关闭、导航、行操作交互盒宽高均 ≥44 CSS px，记录实际矩形；点中心及四边内侧可命中目标，不与相邻目标重叠。
- 320×568 跑账号完整链；375×667、430×932复测；游客独立跑本地保存/重开/导出。平板 768×1024 和 1024×768 验证触摸、弹窗与两栏；桌面 1280×800、窄窗口及 UI 100%/125%/160% 缩放回归。
- 软键盘开/关、滚动、旋转、抽屉返回、后台短暂切换后，草稿与当前章不丢；系统终止不承诺恢复尚未保存字符，已显示保存成功的内容必须重开存在。
- 性能 P0 记录固定设备/夹具基线；P1 冻结预算：相同流程交互 p95 不劣于基线 20%，且输入不能出现持续 >200ms 的可感知停顿。P0 明显失效的基线必须先给绝对改进目标，不能以“回归不差”接受不可用。超预算分析布局监听、重渲染与长任务，禁止每个按键遍历 55 页。

## 4. C2 浏览器全屏与证据包打印

### 4.1 全屏能力适配

桌面保留窗口桥；浏览器用 fullscreenEnabled、目标 requestFullscreen 等运行时能力探测，只有用户点击才请求。状态由 fullscreenchange/fullscreenElement 校准，处理 Promise 拒绝、fullscreenerror、Esc/系统退出与组件卸载，不乐观显示“已全屏”。支持与否随具体版本/页面权限确定，不按 Safari/iOS 名字一刀切。

不可用时入口给明确原因或在外观说明中解释；受支持但被拒绝时保留可理解反馈。无 API 的手机仍可使用现有专注布局，但必须称“专注模式”，不假称全屏，也不承诺地址栏被隐藏。

**验收**：桌面 Chrome/Edge/Safari 可用环境逐项记录版本、目标和进入/退出结果；Android Chrome 与 iOS Safari 真机验证当前行为。不支持时“降级通过”仅代表检测/提示正确，不代表全屏成功。进入、退出、外部退出及拒绝请求后，草稿/光标/选择与保存状态保持；编辑器不重挂。

依据（2026-11-01 查阅）：[MDN requestFullscreen](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)、[fullscreenEnabled](https://developer.mozilla.org/en-US/docs/Web/API/Document/fullscreenEnabled)。API 存在不保证本次调用获准，实施时仍需实测。

### 4.2 证据包打印入口与回退

复用同一 EvidencePack 和 HTML 排版源，保留 JSON。用户点击时预先打开打印页，再异步生成内容，避免用户激活消失后弹窗被拦；如被拦/不支持，退回下载自包含 HTML 并给打开/打印步骤。

- 复用现有转义与导出服务；正文、标题、引文不得以未转义 HTML 插入，不加载远程正文/凭据。Object URL 在页面加载/下载完成后适时回收，不能刚打开就撤销导致空白。
- 长表允许按行分页、重复表头；超长单元格允许跨页，不能承诺“整张表永不截断”。中文长段、空章、多个历史版本、时间戳、保留范围声明都不缺字。
- UI 写“打印 / 另存 PDF”；打印对话框由用户控制，点打印不能直接报“PDF 已保存”。取消打印不改书库。手机无 PDF 保存目的地时提供 HTML/JSON 回退，如实标条件支持。

**验收**：小样与长篇样例各导出，PDF 逐页检查章节/证据/时间/保留说明、分页与内容完整；HTML/JSON 同一数据快照。测试弹窗拦截、生成失败、取消打印、下载回退和手机分享/文件打开。不能用桌面 PDF 成功代替手机导出验收。

## 5. C3 本地模型端边界

**纠正 R2 遗漏的既定产品策略**：浏览器可能条件可达，不代表本项目已开放。现有 P9 明确在网页版账号/游客模式禁用本机与局域网模型；本版保留这条策略，不新增网页本地模型测试/连接入口。桌面版和便携版沿用已有能力与传输边界，不承诺便携版有桌面网络桥。

- 共用 localModelAccess/localModelPolicy：模型列表、设为当前、测试、用途路由、生成、嵌入及旧配置恢复都执行同一策略。配置保留可编辑，禁用项显示可点击/可聚焦说明，不能只提供触摸不到的 hover 提示。
- 文案写“本产品网页版不提供本机/局域网模型连接，建议使用联网模型或桌面/便携版”，不写“浏览器绝对不能访问 localhost”。**手机 localhost 指手机自身**，不能引导用户把电脑模型地址填为手机 localhost。
- 不靠模型品牌判断位置：复用规范地址、显式 local 标记、IPv4/IPv6/回环分类；兼容公网 OpenAI 端点。未解析域名不能宣称已证明是公网，也不在本版新增 DNS 探测/端口扫描。
- 被策略禁用的配置发请求前就阻止，不等待网络报错。允许形态的主动测试仍需超时、可取消、无正文/密钥日志；网络通用错误不能伪装成已精确诊断 CORS。普通联网模型和桌面桥不回归。

**验收**：网页版账号/游客对新旧本机配置均禁用，UI、用途路由、嵌入与实际调用零绕过、零请求；配置重开不丢。桌面/便携的隔离端点成功/失败/超时另测。未来若更改开放策略，须单列产品范围、路由和安全测试，不能仅改矩阵布尔值。

依据（2026-11-01 查阅）：[MDN Mixed content](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Mixed_content)、[Chrome 本地网络权限说明](https://developer.chrome.com/blog/local-network-access/)。这里只纠正平台绝对判断，产品限制以源码 P9 策略为准。

## 6. C4 端能力统一

先建能力契约，再接 C2/C3 入口；不能等所有功能做完才补矩阵。未来模块位置在 P0 确定并落文件后再写路径，避免把拟建文件当现存引用。

每项输出：能力 id、状态（supported/conditional/unsupported/unknown）、原因码、运行通道、可用动作/回退、说明文案键；另区分“平台不具备”与“产品策略禁用”。先评估产品策略，再评估运行能力；条件可达不能越过 P9。输入包含实际桥/API、运行环境、权限/最近测试；账号状态与浏览器能力分开。端类型只是输入之一，不能用“三端×布尔值”掩盖条件。

至少覆盖：全局老板键与页内遮挡、窗口/浏览器全屏、桌面直接 PDF 与浏览器打印、文件下载、本地模型通道、离线写作与联网同步。离线写作再区分“已加载页面可继续编辑”“断网冷启动”“保存可持久化”，不据 local-first 推出离线冷启动一定可用。

界面控制和运行环境相关手册提示共用原因码/文案；手册保留教程与操作步骤，不要求整篇文本由矩阵生成。不使用“全仓 grep 无类似句子”判唯一真源；测试各消费者使用同一解析结果，并禁止重复平台判断表。

**验收**：同一能力在入口、设置和手册状态一致；伪造缺桥/缺 API/权限拒绝/待确认输入时，同步更新提示与回退。正常路径需真实行为验证，改矩阵文字不能伪造支持。矩阵解析不发网络、不含 UI 依赖。

## 10. 二次复审补充：交互、持久化和覆盖口径

本节是 C1–C4 与 P0–P5 的补充要求，须纳入工作包与总验收。

### 10.1 全屏下浮层与打印安全

- Modal 当前使用 Portal。全屏根须包含菜单、确认、下拉、toast 及老板键遮挡的挂载节点；不能只全屏编辑区后让 body 下的浮层消失。优先选择包含所有 Portal 的根元素，若调整挂载点则统一 overlayScope/焦点/坐标体系，不在各弹窗单独补特判。
- 进入全屏立即打开保存失败提示、同步冲突、嵌套确认、行内选择菜单和帮助；都可见可点，退出后焦点/滚动锁恢复。切换页签、外部退出、重复进入失败不能遗留监听器或白屏。
- 打印页只接受本机生成的导出文档，保留标题/正文转义，避免标题/引文注入脚本；不得持有可操作原窗口的非必要 opener。打开方式与防弹窗拦截方案共同实测，不能为消除空白页引入任意 HTML 写入通道。
- HTML/JSON 从同一冻结 EvidencePack 导出，不能生成期间再次读新正文拼成混合快照。超大报告显示进度、可取消；取消后关闭本次临时空白页并清资源，不关闭用户其他页面。打印不提供完整历史保证，继续展示实际 retention。

全屏顶层行为参考 [MDN Fullscreen 指南](https://developer.mozilla.org/en-US/docs/Web/API/Fullscreen_API/Guide)，Portal 能否显示仍以本项目整合实测为准。

### 10.2 触摸、缩放与性能的测量协议

1. 分别记录布局宽度、可视视口、UI zoom、浏览器页面缩放与 DPR；布局阈值用既有布局坐标，命中区采用屏幕点按对应的 CSS 视口坐标测量。44×44 不因高 DPR 换算成设备像素；UI 缩放后仍测真实命中盒，不能把未缩放样式高度当结果。补 UI 低缩放档位、浏览器 200% 文字/页面放大和鼠标+触屏混合设备，不能禁用户缩放解布局。
2. 原生 checkbox/radio 可由关联 label 扩大点击区，无需把视觉图形硬撑到 44px；装饰图标、非交互正文不纳入目标。不可见/禁用的目标不算可达动作，必需能力不能以隐藏按钮规避验收。
3. 表格行虚拟化/textarea 自适应在宽度变化、键盘展开后重测；横滚后行内下拉、日期、末列保存可达。浮层需保持在可视区域，触摸拖动不能误触旁边删除，固定操作条不盖住输入法候选/最后一行。
4. 性能“p95 不劣于 20%”按同设备/构建/夹具测：热身后 3 轮，每轮至少 100 次固定输入/导航操作，记录样本数及各轮 p95，不能混设备或只挑最好一轮。定义输入延迟为输入事件到对应可见更新，布局响应单列；200ms 指实测延迟，不靠主观“卡/不卡”。
5. 开启/关闭抽屉、旋转、缩放各循环 20 次，检查监听器数量、资源释放及 UI 状态；不得把测试循环数写成现有脚本已通过。截图覆盖至少当前默认主题及一浅色主题，检查放大后文字/错误状态仍可读。

### 10.3 存储失败、后台恢复与身份切换

- 跨端“保存”继承 3.3.3 的真实落盘边界，桌面/便携等待后端确认，IDB 等事务提交。文件只读、磁盘/浏览器配额满、存储不可用、便携服务断开时保留草稿并显示未保存/失败，不能写已同步；提供重试及可用的导出退路。
- 短暂切后台与系统杀进程分开：正常编辑持续按现有策略保存，visibility/pagehide 只补尽力触发，不依赖 beforeunload 作为唯一落盘点；前台恢复重新校验账号、写入上下文、远端版本和任务状态。只保证已确认保存的数据重开可读，不承诺被系统杀死的未提交字符。
- Android 返回/iOS 导航离开、刷新、长时间断网再登录均覆盖；会话失效不清草稿，换账号后旧回包不写新库。游客数据不能悄悄变账号同步内容，跨模式迁移沿用已授权流程并单测来源保留。
- 浏览器私密模式/系统清除站点数据/OS 回收存储不等于软件可恢复保证。UI 如实说明本地数据保存范围；不把本版扩成新 PWA/离线冷启动工程。

生命周期依据：[MDN beforeunload](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event) 提醒移动端事件不可靠；验收必须包含从系统任务列表终止与重开，而非只点网页内返回。

### 10.4 帮助索引、能力时效与覆盖账

- C4 解析器保留无 window/document 的测试安全，运行状态用订阅刷新；登录/退出、桥缺失、请求拒绝后入口与帮助不保持旧状态。未知权限不自动请求，矩阵模块本身不做网络或用户授权调用。
- 复用既有手册静态内容/索引：环境说明通过统一组件附加，不把每次能力变化写回教程文件。变更 article revision、CONTENT_VERSION、verifiedAgainst/reviewedAt 及索引校验；“verifiedAgainst”只写实际核验版本。
- P0 为每页/形态列 route、可用能力、主路径、数据状态、设备层级、验收 id、证据编号。组件级测试可复用，但标准项目四个图鉴页均需覆盖，不能把一页截图复制给其他页。
- 无真实平板可用时，768/1024 模拟证明布局，不证明平板触摸；将真机平板触摸单列待验。手机 S-01 不要求真实硬件恰为 320px，320 边界由模拟补，真机按本机原生视口跑同一流程。
- 变更共享组件后，使受影响页面族的旧证据失效，重新跑该族和一组关键链；最终门禁在同一候选源码聚合，不因只改手册就要求重跑无关物理设备，也不沿用受影响旧结果。
