## 2. 修复清单（10 项）

### P1 · 两处「功能白做/漏判」

**① 采样参数的判据用错了维度：`local` 应为 `type === 'ollama'`**

- **证据**：`samplingOptionsOf()` 用 `if (p?.local)` 判「是 Ollama 原生通道」；而 `openaiChat` 只认
  `OPENAI_SAFE_SAMPLING` 白名单（`top_p` / `presence_penalty` / `frequency_penalty`）。
- **触发与影响**：**本地 OpenAI 兼容服务**（LM Studio / LocalAI / GPT4All / Jan…）也是 `local: true`，
  却走 openaiChat ⇒ `topK` / `repeatPenalty` / `repeatLastN` **界面可编辑、下发被静默丢弃**。
- 这与 2.9.2 本来要修的「云端调了不生效」是**同一类问题，只是换了对象**；三处界面灰显（模型配置 / 酒馆采样 / 酒馆窗口长度）
  也一并按 `local` 判 ⇒ 同一个漏判在三处各写一遍。
- **修法**：新增唯一判据源 `isOllamaSamplingChannel(p) = p?.type === 'ollama'`（`lib/modelSampling.ts`），
  下发与**三处界面**统一调它；酒馆的 prop 由 `local` 改名 `ollamaNative`（语义不再混）。

**② 投稿前自检的「趋势」永远显示「与上轮持平」**

- **证据**：`toObservations()` 对任何非空章**恒定 push 4 条**（四栏指纹各一条），
  而 `manuscriptLogged` 按 `obs` 全量落库 ⇒ `total` 恒为 4 ⇒ `diff` 恒为 0。
- **实机数据印证**：「上次检查 4 条 · 与上轮持平」——**这个功能等于白做**（正是 2.9.1/2.9.2 要消灭的那类「存了没用」）。
- **修法**：只记「偏离参考区间」的项（`obs.filter(o => o.notable)`）⇒ `total` ＝ 本期偏离项数，多/少才有意义。
  并补一条口径守护断言（改回全量记会立刻变红）。

### P2 · 六处

| # | 问题 | 修法 |
|---|---|---|
| ③ | 采样输入是**受控 `type="number"`**：输入「0.」这类中间态时浏览器把 `.value` sanitize 成空串 ⇒ 被当「清空」⇒ **小数点打不进去**（六项里四项是小数） | 改走项目既有 `NumberField`（本地 text 态 + 失焦提交 + 范围钳制）。⚠️ 2.6.0 巡检在酒馆那边踩过同一个坑，本轮等于**重犯** |
| ④ | `json:true` 的结构化任务**照发**作者填的惩罚项，与面板上「结构化任务不受影响」的承诺不符（温度确实固定了，惩罚没有） | `opts.extraOptions ?? (opts.json ? undefined : samplingOptionsOf(config))`；只抑制**兜底来源**，显式传入（酒馆）照发 |
| ⑤ | 投稿前自检的 `trend` 只在跑引擎时写入，**切章不刷新** ⇒ 显示 B 章内容却挂着 A 章的「上次检查」 | 加 `activeId` 依赖的刷新 effect（与 `PaceAnalysisPanel` 同口径） |
| ⑥ | 节奏面板取不到模型名时 `.catch(() => '')` ⇒ `trendOf(..., undefined)` **不过滤模型** ⇒ 混算 | `if (!model) { setTrend(null); return }` —— 宁可不出趋势，也不出假的 |
| ⑦ | `ChangelogHealthNote` 缓存判据缺 `rev > 0` 守卫（`checkLog.revisionOf` 有） | 补守卫，与之同口径 |
| ⑧ | `groupByIssue` 的 `action` 取**第一条**：同类型跨章时历史章给 `manual`、最新章可自动 ⇒ 汇总视图显示「需手动处理」，与按章视图口径打架 | 取「最可执行」的（`if (g.action === 'manual' && it.action !== 'manual') g.action = it.action`） |
