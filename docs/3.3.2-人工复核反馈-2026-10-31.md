## F6 · 老板键按下后像"整个应用被关了"，希望收进右下角托盘、点图标能恢复

**原话**：「桌面版按了老板键之后整个应用会被关闭掉，前端的窗口没有了，任务栏的图标也没有了，
需要在整个的应用列表里找到这个软件再打开才能恢复页面。能不能让这个应用关闭之后变成 Windows 右下角
这里边的一个小图标，让用户直接可以通过右下角这个折叠的小图标直接点开？」

**我的理解**
- 现象：按老板键 → 窗口消失、**任务栏图标也消失** → 用户以为程序被关了，只能从开始菜单/应用列表重新打开。
- 期望：藏起来之后**在 Windows 右下角托盘（通知区域）留一个图标**，点它就恢复窗口（相当于"藏到托盘"）。
- 现状（源码）：`electron/bossKey.cjs` 是 `win.hide()`，**不退出进程**；任务栏图标消失是刻意的（"老板键"要求）。
  但因为没托盘，站在用户角度就是"找不到了"。

**涉及位置（待改时看）**
- `electron/bossKey.cjs`（hide/show 与 `toggle`）
- `electron/main.cjs`：需新增 `Tray`（图标、tooltip、左键单击恢复、右键菜单：显示主窗口 / 退出）
- 图标资源：`build/icon.ico`（已有）；托盘图标建议单独一张 16/32px 的小图，避免托盘里糊成一团
- 相关红线：`window-all-closed` 现在是 `app.quit()` —— 若以后"关闭窗口 = 收进托盘"，这条要跟着改

**待确认**
1. 你希望的是「**只有按老板键时**才留托盘图标」，还是「**软件运行期间一直有**托盘图标」？
2. 托盘右键菜单要不要「退出」？（有的话，"关不掉"的顾虑就没了）
