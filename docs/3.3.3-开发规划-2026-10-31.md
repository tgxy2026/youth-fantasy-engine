## 3. A1 重复与表达观察

交付：检查工具/稿件体检增加可定位重复报告，不新增页签，不将修辞密集等同注水。

- 范围：当前章及按卷章顺序在其之前最多 10 章，不含后续章；设置允许 1–30 章。只读同项目正文，跳过空章，显示实际覆盖数。
- 本地先做标准化后的句/段完全重复、词组与近似重复候选，保留原文映射。定位包含 chapterId、正文指纹、段落/字符范围及短引用，不能只存段落序号。
- 专名、口头禅、引用、回顾及刻意复沓允许忽略；忽略有作用域、可撤销。跨章聚合同一重复组，默认前 5 组，可展开，新变体仍能出现。
- 修饰/心理描写密度最多为可选统计，不推断“无事件”。语义复核由用户主动触发，先说明候选片段、端点与预计预算；每批最多 10,000 字，超出分批或明确截断，不静默发送全书。
- 分清本地事实、AI 候选、未检测。纯本地同输入同版本一致，AI 不承诺逐字一致。缓存含项目、正文指纹、范围、算法/提示版本和模型配置；改正文使旧定位失效，提示重检。
- 取消和切项目后拒绝迟到回写；台账只存有上限的摘要，不复制全文成为第二书库。

**验收 A-01/A-02**：至少 60 组人工复核样本，确定重复、有意重复/引用、不重复各 ≥20，按作品拆分开发集与保留集。保留集本地确定重复精确率 ≥95%，完全重复召回率 ≥90%，分别报告 TP/FP/FN；近似和语义候选另计，不混入事实成绩。引用定位全部正确，原文不变；跨章聚合、忽略撤销和改文失效符合上述规则。

## 4. A2 章内变化清单

替代原“空转判定”。最多 3 条变化：目标、关系、信息、资源/地位、处境或情绪认知。铺垫、休整、内心变化同样有价值；不要求不可逆，不以地点改变自动判推进。

- 复用章后整理前校验正文指纹、生成版本和来源，过期设定变更不能冒充本章证据。
- 规则只整理已有可信事实，不凭词频生成事实；材料不足时可由作者主动调用 AI，不能无提示自动兜底计费。
- 每条给变化前后、原文短引用与定位，引文必须逐字匹配当前输入，不能定位则剔除。
- 结论限“发现变化线索 / 可供核对的线索较少 / 证据不足 / 未检测”，后两者不能显示通过或空转；钩子独立展示，不作双低阈值。
- “我不认同”仅本地记录，可清除；正文变化、取消、换书后迟到结果不覆盖新报告。

**验收 A-03**：至少 40 章独立标注，事件、铺垫/休整、情绪认知、证据不足四类各 ≥10；两人标注并记录分歧，按作品拆分保留集。已报告变化证据正确率 ≥90%，逐字引文定位率 100%，明确变化样本发现率 ≥80%；弃判率单列，不能全部弃判刷精确率。冻结模型/参数/提示版本，至少 3 轮并报告各轮成绩。

**共同降级 A-04**：无模型时 A1 本地照常，A2 仅可证事实或未检测；AI 区不冒充通过。未点复核时零模型请求，预算有上限、取消无迟到写入。不以伪端点结果替代真实模型质量成绩。

## 5. A3 模型能力来源与诊断

保留 capabilitiesOf 和现有请求协议边界。unknown 仍可走提示词约束 JSON，不能因名字未知拦普通任务。

1. 优先级：显式用户覆盖 > 同端点同模型且未过期的用户主动测试 > 内置推断 > 保守默认。上下文/输出限制、json-object、json-schema 分别记录；可解析 JSON 不等于支持结构 schema。
2. 缓存按规范化端点、模型、协议、配置指纹隔离；端点/模型/凭据配置变化失效，不存密钥本身。用户测试说明可能计费，可跳过、超时、取消，不作为首次启动必经步骤。
3. 401、429、网络错误标未知/暂不可测，不永久记不支持。失败解释实际采用的能力及来源、下一步，不泄露凭据。

**验收 A-05**：未知模型普通请求可用；用户覆盖重启保留且不被缓存反盖；同名不同端点不串缓存；网络/鉴权错误不污染能力；未主动测试时请求为零。

## 6. A4 失败单元重试与 B3 重启恢复（共用基础）

### 6.1 A4 执行与合并

- 复用已有断点，单元键含原文指纹、切分配置/版本、范围、抽取协议版本，另存模型/提示来源。即使字数/单元数相同，原文变更也不得错用旧产物。
- 单元状态至少 pending/running/succeeded/failed/cancelled，保存成功产物及校验信息、有限失败原因。默认只重试 failed，取消项由作者选择继续；运行中防重复点击。
- 按原序合并、判重；受影响的下游汇总标过期重算并单列请求数，不能把汇总算进“只发一个请求”的承诺。
- 复用已写入卷章映射，重试不得追加同一正文；设定草稿仍由作者确认提交。

**验收 A-06**：50 单元第 37 单元失败，抽取重试请求恰为 1，原成功 49 单元保持一致；下游额外请求明示。覆盖首尾、多失败、全失败、超时、取消、乱序回包与双击；不漏单元、不重复写章、不自动提交草稿。

### 6.2 B3 持久化与恢复

保留“先轻量进度，再产物”的开发顺序；**第一阶段仅显示历史进度，不称可续跑**。本版最终“只补剩余”要求成功产物可回读校验，修正原默认值与最终判据的矛盾。

- 创意写作沿用已有轻量记录，审查已落库阶段，不再建重复任务中心；不序列化 Promise、AbortController、密钥或整本原文到 meta。
- 拆书新增版本化任务头、输入/配置指纹、单元索引、独立结果存储。原文优先引用已落库章节，缺来源时重新选原文件并核指纹。
- 每单元先持久化结果再标 succeeded，失败暂停并明示。重启 running 变 interrupted，作者点击继续才请求模型。
- 绑定原项目和存储空间；项目删除、来源缺失、协议不兼容、产物损坏拒绝静默续跑。旧轻量记录可展示，不伪造可恢复结果。
- 初始容量预算：每项目最多 5 个可恢复任务、每任务结果 20MiB、合计 50MiB。超限暂停，不能淘汰未完成任务；P0 压测需改预算时记录依据并同步文档。
- 丢弃只清任务私有产物/索引，不删已确认写入书库的正文/设定。不引入全局队列；同任务多窗口用任务级执行权，owner/代次/指纹拒绝晚回包。
- 终态结果保留到作者明确清理；自动清理须有明确保留期，仅清无引用的终态私有产物。异常退出的孤儿结果先按任务索引对账，不能扫描后立刻删；备份恢复或导入新项目后本机任务默认停用并重新核验来源。

**验收 B-04**：请求途中、结果落盘前后、状态更新前后强杀重开；仅已持久化成功项跳过。尚未持久化的在途调用可能重发，不承诺外部计费 exactly-once。验证创意写作旧记录迁移、缺产物、损坏、容量满、双窗口竞争与丢弃；已落库章节不重复生成。

## 7. B1 云端新版更新本机

复用 applyCloudCopyInPlace、备份及恢复，不重新造覆盖实现；同时完善入口与执行安全边界。

1. 捕获账号、存储、projectId、binding、云端 revision；先过编辑器/表单保存屏障，再回读本机版本、未保存草稿和同步队列。本机干净才给直接更新，有改动转冲突流程。
2. 确认框写“替换为第 N 版，执行前创建备份”，不能提前写“已备份”。锁定用户确认的 rev；确认后云端推进不能静默换目标。
3. 下载校验、保留型备份成功后，写库前再次校验 owner 与本机版本；期间暂停该项目自动推送并阻止并发写，避免旧草稿覆盖新内容。
4. 写成功才推进基线；绑定失败、部分写入、备份失败、离线分别报告。先写后删不等于完整事务，部分失败给备份恢复入口，不宣称原样回滚。
5. 成功重载章节与视图，禁止旧 chapterId 继续保存；切项目后晚回执不改变新项目。恢复自动同步前重新读版本。

**验收 B-01/B-02**：正文逐字、表行字段、媒体及快照引用语义一致，projectId 不变，内部 id 允许按现有恢复规则重映射；baseRevision 为实际应用版。备份能还原原版；备份失败零覆盖；确认期间编辑/切项目/云端推进、队列并发、下载损坏、写入失败、绑定失败均有证据。失败不显示已同步，也不能把旧本机内容再次上传覆盖云端。

## 8. B2 注释校准与路径门禁

- 核对 src/server/electron/scripts 的现行“未接线/未实现”等断言，只改能由代码或测试证明过期的内容；保留有意未做边界，不机械清 TODO。
- 扩展现有引用工具的源码注释扫描：明确仓库根 docs 路径、中文/空格、行号/锚点；仅解析注释，忽略代码字符串、URL、通配模板。例外要说明理由。
- 临时夹具中验证；当前源码注释确定缺失必须非零退出，release-check 传递失败。历史归档保留快照口径，不要求全仓历史零失效。
- 路径存在不证明注释语义正确，人工清单与自动结果分记。

**验收 B-03**：有效/中文/空格/后缀通过；确定失效失败并给文件与位置；样例字符串/URL 不误报；工具异常不算绿灯。不在真实源码中制造坏引用测试。

- 撤销统一追加的“2MiB/30 张”新限额：它与已有压缩/总量体系重复，且可能限制旧项目。维持 `src/lib/atlas/quota.ts` 与调用方当前规则：网页版云端账号 32MiB 图鉴总字节限额、80% 预警，其他形态无这道图鉴硬墙；与服务端账号总配额分开说明。容量统计须覆盖实际支持的四页，P0 核对统计接线，不能照抄“两页”的旧注释。
- 替换按净增量；超额只阻止增加占用，删除/缩小和文字编辑仍可用。升级不自动删除或重压已有图片。异步解码/换行/换项目/保存失败保旧图，回包校验原条目和配置版本。
- 复用 filteredRows 草稿及只读/模板限制。详情宽度拖拽、层级联动先列“已有/缺失/不适用”，只补缺失；拖拽提供数值/按钮替代，不能成为触摸端唯一入口。

**验收 B-06**：四页编辑/撤销/保存失败、密度重开、图片增换删、净增量限额、超限减量、导入导出/备份/同步往返。编码字节、dataUrl 序列化包体积、服务端配额计量分别记录；本地成功不等于上传成功。不能缩减旧项目可编辑范围。

## 11. B6 字段转换与永久删除

- 仅自定义字段，内置字段保留显示名修改/归档，高版本只读配置禁改。
- 保持 TableRow.data 的既有序列化约定；数字类型转换不等于直接把全表字符串改成 JS number。编码、空值和显示格式由预览与现有 atlas values 解析共同验证；坏配置/读失败不能以空默认配置写回。
- 文本↔长文本逐值校验长度；数字↔文本精确可逆。“001”、科学计数法、超安全整数、空字符串/空值分别处理，不隐式归零或截断。
- 预览影响条目、不可转换值和引用/模板/筛选依赖；有不可逆值整批阻止，可另建字段由作者选择搬运，原字段保留。
- 执行前备份；schema/值原子更新或通过可恢复迁移记录完成，失败不留类型和值不兼容半状态。
- 真删除先显示影响数和依赖，确认后清定义、该字段值及可安全清理依赖；不能安全处理则阻止。说明可从操作前备份恢复，不声称绝对不可恢复。

**验收 B-07**：空值/超长/负数/小数/前导零/超大整数、无值字段、被引用字段、双窗口、取消、备份失败、写入中断及恢复往返；其他字段/项目不变，恢复后定义和值一致。

### 14.1 P0 数据契约与出口分类

| 数据族 | 落点和生命周期 | 同步/导出/恢复口径 |
|---|---|---|
| A1/A2 完整结果及引文 | 有上限的派生缓存，含输入指纹和算法/模型版本；checkLog 只存摘要 | 正文、恢复或导入重映射后失效，不能让旧定位指向新章 |

`src/lib/db/projects.ts` 的 exportProject 会收集项目 settings，`src/lib/sync/projectSnapshot.ts` 又把它制为同步对象。因此“存在项目设置”不等于“仅本地”。新增任务不能直接塞 settingsKV 后假定排除：必须分别验证项目包、项目快照、旧云盘整库同步和数据文件导出各出口。已有 creativeSession 历史记录的兼容处理要明确，不能悄悄删除。

参考 `src/lib/db/revisionJobs.ts` 的严格载荷写盘范式；是否复用其存储结构须审查领域和容量，不把新任务冒充旧修订任务。若新增 store，同步登记 IDB 迁移、桌面/便携 keyPath、sidecar、同步排除及项目删除清理。StoreOps 单次 bulkPut 不能代替跨 store、跨三后端事务。

### 14.2 真正落盘与操作恢复

- IDB 以事务提交为边界；桌面/便携 put 可能只更新内存。任务 succeeded、覆盖/字段迁移完成及“备份已创建”须等真实后端 flush/严格写成功，关键引用回读校验。刷新同一内存视图不能替代强杀重开。
- 复用 owner、recordOperation 与 submission 屏障，首次异步调用前捕获原 StoreOps，不能恢复时再取全局 ops。切书/登出/换存储只能使逻辑失效，不能撤回已发 I/O；已发写入保持原后端归属，必要时留恢复记录，不承诺“取消=零写入”。
- B1 备份完成与首次覆盖写之间持久化操作记录：原项目/绑定、确认 revision、备份 id、阶段；覆盖/基线写入/重载全完成才收尾。启动发现中断操作先阻止该项目自动推送，提供核验/恢复，不能把部分结果误上传。
- B6 预览绑定配置 revision 与数据指纹；确认前数据变化须重新预览。影响检查包含模板快照、AI 可写候选、摘要字段、索引/排序/搜索；不删历史备份里的原字段。
- B4 导入/转化明确全有或全无还是逐行提交；逐行模式返回每行状态且重试不重复。缺字段、未知字段、id 冲突、禁用目标页、空文件/损坏有明确处理，不能静默丢数据后称“往返一致”。

### 14.3 可复算质量和资源预算

1. A1 标注单位为重复组，多处出现不能重复计 TP；按原文范围和冻结匹配规则算命中。机械重复与“值得作者处理”分开：引用/有意复沓可折叠展示事实，不能判质量缺陷。精确率=TP/(TP+FP)，召回率=TP/(TP+FN)，零分母记未定义。保留集每类 ≥10 组且与开发作品隔离；60 组是最低样本数，不足以宣称所有文体有效。
2. A2 证据正确要求引文确实支持变化，不能只靠字符串存在得分。明确变化发现率以含明确变化的保留章为分母，每章至少一条正确变化才算发现；保留集四类各 ≥5 章，总集仍 ≥40 章。三轮各自达门槛，分歧复核而非只取最好成绩；自定义提示与冻结基准分记。
3. A1/A2 的 10,000 字上限之外，还按模型 token/上下文预算裁剪，含系统提示及输出预留，明示未覆盖范围。默认单次作者动作最多 3 次模型请求（含自动重试），更多批次由作者再发起，不能静默换付费模型。复用 promptGuard，把原文当资料，不执行其中指令。
4. 本地检测以 100 章×约 5,000 字固定夹具测默认前 10 章，P0 记录耗时/峰值内存/取消响应，P1 冻结预算。禁止全书段落两两比较；必要时索引、后台计算或分批，主线程持续阻塞时不能宣称可取消。
5. 原书、章节顺序、模型/提示、字段定义变化后旧单元不自动复用，提供新任务和旧结果只读查看。任务执行权接管递增代次并拒绝旧执行者回包，不能以进程内布尔锁冒充跨窗口互斥。
