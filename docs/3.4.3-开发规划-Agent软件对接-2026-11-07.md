## 二、优先级与执行顺序

1. **P0 并发和数据一致性**：先处理同目录多实例、多 profile、多标签及云同步检查与写入之间的竞态；无法保证时失败关闭并保留草稿。
2. **P0 互斥与故障恢复**：桌面设置页已有有限联调；补齐便携 UI、全部网络入口、在途租约、迁移与恢复的真实验证，并修复发现的绕行。
3. **P1 领域安全与扩展**：地图/画布、世界包、备份恢复、灵感改删、报告和任务台账已有部分实现；先补上下文归属、并发与故障保护，再扩未开放能力，每包开发和测试同时完成。
4. **P1 客户端与交付验收**：在隔离合成数据下复核 Codex 和其他客户端；源码稳定后重新构建、核对指纹与产物，完成用户明确授权范围内的桌面、便携和安装测试。
5. **最终复验**：源码或审计工具变化后重跑相应检查、全量与审计；按证据真实列出未覆盖项。封装、安装、发布、部署和推送分别遵守用户当次授权。
