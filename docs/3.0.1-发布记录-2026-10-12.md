### 🔴 本轮新踩：git 全局配了失效代理

`git config --global` 里有 `http.proxy` / `https.proxy = http://127.0.0.1:65457`，**该端口没在跑** ⇒ 任何 git 联网操作报
`Failed to connect to gitee.com:443 over proxy 127.0.0.1`。
**判据陷阱**：`curl https://gitee.com/` 同时是 **200** —— 因为 curl 走的是**环境变量**代理（另一个端口），
**git 却优先用 config 里的代理**。⇒ 别用「curl 通」推断「git 通」。

**正解（不改全局配置，逐条命令覆盖）**：
```bash
HTTP_PROXY= HTTPS_PROXY= http_proxy= https_proxy= \
  git -c http.proxy= -c https.proxy= ls-remote --heads https://gitee.com/tgxy2026/youth-fantasy-engine.git
```
实测：清空 config + env 代理后**直连成功**（远端 `main = ed3061c`）。
