# 青春幻想引擎 3.0.2 更新说明

> 发布日期：2026-10-13 ｜ 桌面安装版（Windows）+ 便携版
> 上一版：3.0.1（2026-10-12）

---

## 一句话

**3.0.2 把「同步」补到了能直连私有网盘的那一步**：新增 **WebDAV 与 S3 兼容直连**（群晖 / 极空间 / 坚果云 / MinIO / 阿里云 OSS …），修掉两处**界面缩放相关的定位问题**，并做了一轮**密钥外流加固**。

---

## 新增

### 1. ⭐ 私有网盘 / NAS 直连同步

**入口**：数据坞 →「云盘文件同步」

原先跨设备同步只有一条路 —— 把数据文件放进 OneDrive / 坚果云这类**同步目录**，由网盘客户端负责搬运。现在多了两条**直连**通道，不需要客户端在场：

| 协议 | 适合 | 覆盖 |
|---|---|---|
| **WebDAV** | 私人网盘 / NAS | 坚果云、Nextcloud、群晖 Synology、极空间、威联通、飞牛 |
| **S3 兼容** | 对象存储 | MinIO（自建 NAS）、Cloudflare R2、阿里云 OSS、腾讯云 COS、七牛、Backblaze B2 |

- **填好即用**：WebDAV 填服务器地址 / 远端路径 / 用户名 / 密码；S3 填端点 / 桶名 / 对象键 / Region / AccessKey / SecretKey（path 与 virtual 两种风格都支持）。
- **「测试连接」按钮**：开启前先探一次 —— 服务器是否可达、凭据是否有效、目录权限够不够，都会如实给出结论；**没测过不让开**。
- 🔴 **凭据只存本机**：网盘密码 / SecretKey 存在本机，**不进数据文件、不随同步上传、不写进备份**。
- 🔴 **三态口径与既有同步完全一致**：读不到远端时按「不可用」处理并回退本机数据，**绝不当成空库**去覆盖云端 —— 这条是「一次误写覆盖云端」的唯一防线，两种新协议与老通道共用同一套骨架。

### 2. 信任自签证书（WebDAV / S3）

自建 NAS（群晖 / 威联通 / 极空间）常用**自签证书**，默认会被拒绝。开关在两种协议的表单里都有：

- 默认**关**；只对**这一个同步通道**生效，其余流量不受影响。
- 打开后仍会拒绝**主机名不符 / 已吊销 / 已过期**的证书 —— 只放行「证书链不受信任」这一类。
- 公共网盘（坚果云 / Nextcloud 官方托管 / 各大云对象存储）**不需要**勾选。

## 修复

### 1. AI 伴写说明窗跑到屏幕外

**现象**：点正文编辑器工具栏的「钢笔」键，弹出的说明窗跑到鼠标右侧、部分跑到屏幕外被遮住。

**根因**：界面在宽屏下会自动放大到 108%，而窗口定位拿到的坐标是**放大后**的视觉坐标，写回样式时被浏览器**又乘了一次缩放** ⇒ 整体右移约 8%。1600px 窗口下，弹窗右缘超出触发键 **107px**。

**修法**：定位前先把坐标折算回未缩放的值，在这个坐标系里算位置与边界；放不下时向另一侧翻转。

⚠️ 这个毛病**窄窗口测不出来**（1200px 以下不缩放），只在宽屏上暴露。

### 2. 下拉浮层在宽屏下整体右移

**同一根因的另一处** —— 日历、日期选择、角色选择、自定义下拉、表格引用这 **5 个下拉**共用同一个定位函数，而它当时**一处折算都没有**。

现在一并修好：5 个下拉在 108% 缩放下与触发键**精确对齐**（实机实测：浮层左边缘 108.0 = 触发键 108.0；修复前偏移 8.6px）。

### 3. 🔴 导出数据文件会把 AI 密钥一起带出去（安全）

**来源**：读者反馈 —— 「把『导出数据文件』当备份，结果密钥被一起备份了出去」。

**核实**：成立。密钥住在全局设置里，而「导出数据文件」是唯一**不做过滤、整库倒出**的出口。

**修法（三层）**：

- 「导出数据文件」（桌面版 + 便携版）导出前**剥掉密钥类设置**，并在提示里如实告知剔除了几项；
- 「导出备份文件 / 导出迁移包」在出口处再挡一道 —— 项目设置里任何密钥类条目都不进包；
- 老版本遗留的**项目级密钥残留**，在打开项目时自动清理（此前只迁移不删除，会随备份出门）。

⚠️ **换机提示**：导出的数据文件**不含** AI 密钥，新机上需要重填一次模型配置 —— 这是刻意的取舍：**密钥不离开本机**。

⚠️ **如果此前把导出的数据文件发给过别人**，建议到对应平台**吊销并重签**那枚 Key。

- **本轮无破坏性变更**：老数据、老备份、老迁移包都能照常读。
