# 2.7.1 更新说明

## 2.7.1 · 开书定位多题材模板化 + 制度维度独立页签

⭐ **「世界设定 / 力量体系」不再是「一套东方修真表」**：开书时选一个**作品题材**，这两张表（连同新增的制度页签）就换成对得上的那一套。历史作者不会再看到「境界 / 灵根 / 寿元」，都市现实作者也不会被迫按修仙的口径填表。

**十个题材包**（统一四字命名，一个作品选一个）：

| | | | | |
|---|---|---|---|---|
| 东方修真 | 西方奇幻 | 都市异能 | 都市现实 | 历史古代 |
| 科幻末世 | 武侠江湖 | 悬疑灵异 | 游戏竞技 | 女频言情 |

- **一个包同时管两张表**：选「历史古代」，世界设定换成「天下大势 / 正统法统…」，力量体系换成「官职 / 军权 / 财力 / 声望」（页签显示名同步变成**权谋实力**）。不用两处各选一次。
- **换包只隐藏、不删除**：题材选错了随时能改。切换时旧字段的内容**原样留在库里**，切回原题材即完整恢复；切换时会给一次性提示，说清「多少项内容随之保留、多少项在当前题材下不适用」。
- 🔴 **没有超自然力量的题材（都市现实 / 历史古代 / 女频言情）不隐藏「力量体系」**，而是**语义弱替、结构不变**：页签从「力量体系」改叫**能力资源 / 权谋实力 / 关系地位**，内容整体换成「能力 / 权谋 / 关系」这套现实向的实力体系。作者的位置与操作习惯完全不变。
- 🔴 **老项目零变化**：默认题材是「东方修真」，其模板与本次改动**逐字相同** —— 老项目、示范项目打开后界面与字段一字未变。

⭐ **制度维度升为独立页签**（呼应社区反馈「历史类世界设定的颗粒度对不齐」）：

原来的「世界设定」是个什么都能装的大抽屉，政治、经济、宗教、司法都挤在里面、又只能记一套。本次把它拆成**一个总览 + 一排并列的制度抽屉**：

- **世界设定** 降为**总览**：这个世界长什么样、社会怎么组织、主角的活动地图怎么展开；
- 新增 **政治架构 / 经济体系 / 宗教信仰 / 司法制度** 四个页签，各自展开细节（政体与权力结构、货币财政与贸易、神系与教会、律法与刑罚…）；
- 四个制度页签**与「力量体系」同构**，天然支持**母子结构** —— 一本书里有多套制度时，母级写「天下通例」，**每个政权 / 邦国各建一个「子项」** 写它自己的制度，只有标为「活跃」的才发给 AI。这就解决了「我写的历史类世界，政治经济宗教司法极为丰富且差异极大」的痛点。
- 页签按题材**默认显隐**：历史古代全开，科幻末世开政治 / 经济，都市现实开政治 / 经济，西方奇幻开政治 / 宗教，悬疑灵异开宗教，东方修真默认**全关**（＝界面与老版本一致）。自定义项目仍可手动勾选开启。

⭐ **新建流程加「作品题材」选择**：新建项目表单与首启向导都新增题材下拉（默认东方修真），建库时即确定模板；已经建好的项目在「世界设定」等页签头部也能随时改。

🔧 **其他改进**：

- **子项称谓随题材变**（纯文案）：同一个「多份子项」机制，在历史包下叫**政权**、武侠包下叫**门派**、都市现实下叫**能力线 / 行业**、女频言情下叫**关系线** —— 让「一本世界多份档案」在作者眼里说人话。
- **「同步子项清单」**：制度页签各存各的子项清单时，可从本页签一键以《世界设定》的清单为**基准**对齐过来（新增缺失项、活跃态一并同步），省去在 N 个页签各建一遍政权列表。
- 数值类字段（等级 / 段位 / 阶序…）改为**显式声明**，不再靠字段名猜 —— 新题材模板里名字不含「等级」二字的数值字段也能被正确锁定、不让模型凭空编。

## 「AI 会读哪些字段」的口径（同步说明）

- 世界设定 / 力量体系 / 四个制度页签都走**母子结构**：**母级（全书统一）永远发给 AI；子项只有标为「活跃」的才发**，已完结 / 未激活的不发（尾部会写明「另有 N 个已完结，未发送」）。
- 页签内的「设定草稿箱」**不发给 AI**，只有点「AI 整理到上方字段」整理进正式字段后才发。
- 发给的是**当前选定的那个模型**（不是「不外发」）。

## 安装与兼容

📦 数据与 2.5.x / 2.6.x / 2.7.0 **完全兼容，直接安装即可**，无需迁移。默认题材为「东方修真」，与本次改动前的模板逐字一致 —— 已有项目打开后界面与字段不变。
