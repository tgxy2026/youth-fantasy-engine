## 4. 未覆盖（如实）

- 网页形态三家 CORS 预检**未通过 / 未完成**：Node OPTIONS 探测中 Anthropic 返回 403 且无 CORS 响应头；Gemini / OpenAI 请求失败（当前网络环境受限）。上述探测不等同浏览器预检，结论为 **blocked**，不得宣称网页可用。
- 新协议的结构化输出已按官方文档接入：Anthropic `output_config.format`（仅 `json-schema`）、Gemini `responseMimeType` + `responseJsonSchema`、Responses `text.format`。仍走 `outputProtocol` 能力闸：默认未确认即不下发，只靠提示词约束；用户确认后才下发。`ANTHROPIC_VERSION` 按官方 structured outputs 示例改为 `2026-10-21`。
- 新协议的模型清单自动拉取未接入（界面已提示手填模型名）。
- embedding / 语义索引未接新协议。
- 真实厂商端点实弹、真实模型质量、订阅额度稳定性均未验证。
- Bedrock Converse 与厂商私有协议按规划暂缓。

## 5. 下一步建议

1. 在允许启动浏览器的环境重跑 `contracts-evidence.mjs` 与审计，补齐两项运行证据。
2. 逐家实测网页形态 CORS，并按结果决定是否在网页形态显示对应协议。
3. 取得厂商当期官方文档后，再评估是否接入结构化输出字段（当前默认不下发）。
4. 真实端点纵切：连通性 → JSON 任务 → 流式长文 → 取消 → 用量 → 故障降级。
