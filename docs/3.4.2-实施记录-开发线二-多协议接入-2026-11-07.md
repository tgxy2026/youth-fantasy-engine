## 6. 收尾补充：接口协议可手动选择（2026-11-07 12:30 起）

**问题（首版缺口）**：3.4.2 首版只有「选平台预设」才会带出协议。自定义地址（自建 Anthropic 兼容网关、局域网远程 Ollama、路径不标准的中转）无法声明协议，只能继承上一个预设 —— 从 Anthropic 预设切到「自定义」再填别家地址，请求会按 Anthropic 协议发出，属静默错配。

**改动**

| 项 | 落点 |
|---|---|
| 协议切换补丁 | `src/lib/aiCore/core.ts` · `protocolSwitchPatch()`：一次同步 `protocol` / 存储键 `type` / `local`，并清空端点级能力确认 |
| 界面入口 | `src/components/settings/AIConfigPanel.tsx` · 编辑表单新增「接口协议」下拉；**放在 Ollama 分支之外**，切到 Ollama 后仍能切回 |
| 预设分组判据 | `presetList` 由 `editing.type === 'openai'` 改为 `protocolOf(editing) !== 'ollama'`（与 3.4.2 的协议 / 本地语义拆分对齐） |
| 门面导出 | `src/lib/ai.ts` 显式再导出 `protocolSwitchPatch`（禁 `export *`） |
| 手册 | `faq-multi-protocol` 增「自定义端点与远程 Ollama」，`revision` 1→2 |

**语义口径（为何不能只改 protocol）**

- 切到 `ollama` ⇒ `type='ollama'`、`local=true`（Ollama 原生免密钥）。
- 从 `ollama` 切走 ⇒ `local` **一律复位 false** —— `local` 是切换时强设的，继承会让联网端点顶着「本地」标记进本地预设组（探针实测复现）。
- 切到 `openai-chat` ⇒ 保留原 `local`（本地 LM Studio / LocalAI 仍免密钥）。
- 切到 `anthropic` / `gemini` / `openai-responses` ⇒ `local=false`，`precheck` 恢复强制密钥校验，网页形态也不再把该配置当本机端点禁用。
- 任何切换都把 `structuredOutput` / `reasoningWithStructure` 置未确认（那是**上一个端点**的结论）。
