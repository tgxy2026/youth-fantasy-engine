## 一句话

**开书定位全面重构**（题材只在建项目时选、完整项目全部显示页签、制度四页签改「并列结构」并扩到 81 个字段）＋ **关系图与时间线可视化升级 v2.0** ＋ **两轮六维审计修掉 30 个真问题**（含 3 个会静默丢数据/泄密的 P0）。

> 这份说明综合 **2.7.1** 与 **2.7.2** 两轮改动。**凡两版冲突，一律以 2.7.2 的最新形态为准**，下文已逐处标注「⚠️ 2.7.2 变更」。

## 新增

### 开书定位组重构（2.7.2 主体）

- **题材改到建项目时选** ⚠️ 2.7.2 变更
  题材（玄幻 / 仙侠 / 都市 / 科幻 / 历史 / 悬疑 / 校园 / 二次元 / 武侠 / 宫廷）现在在**新建项目**与**编辑项目**两处选择。《世界设定》页头部原本那个「切换题材」与「页签勾选」控件已整体移除。
- **完整项目全部显示页签** ⚠️ 2.7.2 变更
  以前会按题材隐藏部分页签（例如无超自然题材时藏起「力量体系」），现在**完整项目一律全显**；**自定义项目**按建项目时勾选的「功能模块」显示。**已建的老项目同样立即生效**，不影响已填内容。
- **题材只影响「填什么」，不影响「有哪些页」** ⚠️ 2.7.2 变更
  题材唯一的作用是：各页签里的**字段示例**随题材变化。写科幻的不再看到「笞杖徒流死」，看到的是「信用点 / 数据黑市 / 算力」；写都市的看到「议会民主制 / 财富差距」。**字段名与模块名完全不变** ⇒ 换题材不丢任何已填内容。
- **四张制度页签改「并列结构」** ⚠️ 2.7.2 变更
  《政治架构》《经济基础》《宗教信仰》《司法制度》**不再有「全书统一」那一层**，改成一条条平铺 —— 一个政权 / 一个地区 / 一个教派 / 一套律法各建一条，彼此独立。《世界设定》与《力量体系》**保持原有的母子结构**（全书统一 + 可建多个子世界 / 子体系）。
- **制度四页签内容扩充：46 → 81 个字段** ⚠️ 2.7.2 新增
  政治 20 / 经济基础 21 / 宗教信仰 20 / 司法制度 20。原《经济体系》更名为**《经济基础》**，《作品定位》更名为**《作品信息》**（只是显示名变化，您存的数据不会丢）。
- **示例随题材走（10 套）** ⚠️ 2.7.2 新增
  每张制度页签的填写示例都按题材各准备了一套（都市 / 科幻 / 奇幻 / 武侠 / 历史 / 修真 / 言情 / 悬疑 / 游戏 / 异能），约 180 条。
- **页签里的说明与问号提示全部重写** ⚠️ 2.7.2
  问号气泡现在会告诉您：这一页怎么用、条目总称是什么（政权 / 行业 / 教派 / 律法）、填的内容会不会发给 AI、以及**这套示例对应的是您选的哪个题材**。

### 关系图 ×2 与时间线 ×2 可视化升级 v2.0（引用数据不变）

- **人物关系图 / 势力关系图**：阵营着色 ＋ 凸包分组 ＋ 线型区分；势力图换力导向布局。
- 同一对实体之间**可存在多种关系**（平行边分离 ＋ 有向箭头），自定义关系类型的颜色自动分配。
- **历史事件轴 / 故事时间线**：补刻度、层次与色带；新增**等比时间轴**，空档自动封顶并画断裂符，避免长时间跨度把图拉成一条线。

### 酒馆模式

- **「结束本轮对话」改为全事务化**（2.7.1 起，2.7.2 补全）
  记忆、日记、本场数值、设定建议**全成或全不成** —— 中途点「中止」不会留下半截数据，重试从零开始。
  2.7.2 补上了记忆与日记（此前只保护了角色卡数值）：此前中止后重试会让同一段剧情被并进角色档案**两次**，且不可逆。

## 改进

- **历法设置收进一处**（2.7.1）：原先分散在「历史事件」「时间脉络」页头与表单内，现统一到右上角**「历法规则」**弹窗 —— 历法清单（新增 / 改名 / 删除）与规则（几年几月、每月几天）都在这里，改名会自动连带更新表里引用旧历法的行。
- **侧栏分组调整**（2.7.1）：「酒馆模式组」上移到「大纲规划」之下、「创作管理」之上。
- **保密等级真正生效**（2.7.1 起，2.7.2 补全）
  标了 **S（绝密 / 剧透）**的行，在**角色视角**（酒馆沉浸档）下不再进入 AI 上下文 —— 演员看不到结局；**D（终结）**任何视角都不进。
  2.7.2 补齐了三个此前漏掉的入口（母级设定、子世界 / 子体系、制度页签条目）。
- **AI 提示词与注入链路**（2.7.1）：去掉会被模型模仿的 markdown 星号、结构化任务固定低温、逐字引用定位前先剥强调（避免条目被静默丢弃）。
- **一键拆书 / 创意写作的末尾汇总支持多套** ⚠️ 2.7.2 新增
  这两个功能在末尾会把整本书收敛成「全书级设定」。现在它们能**识别原小说的多套结构** —— 一本书里有魏蜀吴三套政治体制，会落成**魏 / 蜀 / 吴三条独立条目**（而不是揉成一份、丢失差异），您可以分别修改、分别决定要不要发给 AI。

## 修复

### 会静默丢数据的三处（2.7.2 审计 P0）

| 场景 | 原来的问题 |
|---|---|
| 导入项目 / 恢复备份 | 多套条目的「活跃状态」全部丢失 —— 内容都在，但 AI 一条都读不到，且**没有任何报错**。已修：换 id 时同步重映射。 |
| 酒馆收尾点「中止」后重试 | 同一段剧情被并进角色档案**两次**（记忆无幂等机制，不可逆）。已修：记忆与日记一并纳入事务。 |
| AI 补全按钮 | 未配置模型时该按钮本该禁用，实际却能点开、走进内部才报错。已修。 |

### 其余修复

| 领域 | 修的问题 |
|---|---|
| 并列页签 | 点 A 条目的「删除」实际删掉的是当前选中的另一条（不可撤销）；新增条目时当前未保存的草稿会静默消失；删除失败无任何提示 |
| 末尾汇总 | 制度四页签的汇总结果写进了一层**永远不会被读取**的存储 —— 界面报「已更新 N 条」，重开页面一字未变。已改为正确落进条目。 |
| 知情权限 | 一场戏有 2 个以上 AI 角色时，「谁不知道什么」的事实边界几乎全量丢失（多角色名字拼在一起做整串匹配） |
| 上下文准确性 | 表格「另有 N 行未列出」的计数偏小、且本该入选的行不递补；「活跃 N / 共 M」在被保密等级拦掉后会把条目误报成「已完结」 |
| 表格 | 列宽偏好绕过统一存储；历法改名级联失败无提示；下拉列的帮助文案与「固定列不可改」自相矛盾 |
| 界面 | 10 处按钮尺寸类被覆盖；关系图与时间线等高布局；桌面数据条的死浮层分支；帮助气泡里的加粗符号会显示成字面星号 |
| 文案 | 35 处过时口径与冲突；指引您去找**已删除的按钮**；「稀缺资源」等字段名 9/10 题材下不存在；一个损坏字符（`年��人`） |

## 已知限制

- **自定义项目**的页签按建项目时勾选的「功能模块」显示（这是它本来的设计）；**完整项目**是全部显示 —— 两者规则不同是刻意的，不是 bug。
- **换题材不丢数据**：题材只换「示例」这一层，字段名与模块名完全一致 ⇒ 切回原题材内容照旧在。
- **老项目**（2.7.2 之前建的）也已按新规则生效：完整项目立即全部显示页签，题材随时可在「编辑项目」里改。

## 安装

下载 `青春幻想引擎-Setup-2.7.2.exe` 双击安装。

- Windows 会弹出「已阻止应用」提示 —— 点「更多信息」→「仍要运行」即可（本程序未做代码签名，这是所有国产小工具的通病）。
- 建议**先卸载旧版再装**：旧版残留的快捷方式可能仍指向旧程序目录。
- 若装完桌面图标没变，按 `Win + R` → 输入 `ie4uinit.exe -show` 刷新一下图标缓存。
