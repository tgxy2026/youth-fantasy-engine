## 一句话

**开书定位支持多题材模板**（世界设定 / 力量体系按题材铺开十套）＋ **关系图与时间线可视化升级** ＋ **保密等级 S 级真正生效**。

---

## 新增

### 开书定位多题材模板化
- 开书时可选**题材**（玄幻 / 仙侠 / 都市 / 科幻 / 历史 / 悬疑 / 校园 / 二次元 / 武侠 / 宫廷），选完后**世界设定**与**力量体系**按该题材铺开对应模块与字段，不再是一套通用模板。
- 新增 4 个制度维度独立页签：**政治 / 经济 / 信仰 / 司法**。
- **完整项目可手动补开被题材隐藏的页签** —— 老项目导入后不必回创作起点重选题材，在页签头部「显示页签」里勾选即可。

### 关系图 ×2 与时间线 ×2 可视化升级 v2.0（引用数据不变）
- **人物关系图 / 势力关系图**：阵营着色 ＋ 凸包分组 ＋ 线型区分；势力图换力导向布局。
- 同一对实体之间**可存在多种关系**（平行边分离 ＋ 有向箭头），自定义关系类型的颜色自动分配。
- **历史事件轴 / 故事时间线**：补刻度、层次与色带；新增**等比时间轴**，空档自动封顶并画断裂符，避免长时间跨度把图拉成一条线。

### 酒馆模式
- **「结束本轮对话」改为事务化**：记忆、日记、本场数值、设定建议**全成或全不成** —— 中途取消不会留下半截数据，重试从零开始（此前会重复累加角色卡数值）。

---

## 改进

- **历法设置收进一处**：原先分散在「历史事件」「时间脉络」页头与表单内，现统一到右上角**「历法规则」**弹窗 —— 历法清单（新增 / 改名 / 删除）与规则（几年几月、每月几天）都在这里，改名会自动连带更新表里引用旧历法的行。
- **侧栏分组调整**：「酒馆模式组」上移到「大纲规划」之下、「创作管理」之上。
- **保密等级 S 级真正生效**：标了 **S（绝密 / 剧透）**的行，在**角色视角**（酒馆沉浸档）下不再进入 AI 上下文 —— 演员看不到结局。此前这项只在文案上承诺、实际没实现。
- **AI 提示词与注入链路**：去掉会被模型模仿的 markdown 星号、结构化任务固定低温、逐字引用定位前先剥强调（避免条目被静默丢弃）。
