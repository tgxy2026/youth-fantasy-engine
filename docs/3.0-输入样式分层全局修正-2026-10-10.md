# 3.0 · 输入控件样式「分层」全局修正（2026-10-10）

> 承接：`docs/3.0-左下角设置区修复-2026-10-10.md` 里记为「已记录未改」的系统性隐患。
> 那轮只修了侧栏那一处；本轮做**全局修正** —— 让组件写的工具类真正生效。
> 状态：**已完成**（tsc 0 / eslint 0 / 全量单测 181 全绿 / 真机逐元素 diff + 截图核对）。

---

## 一、改的是什么

**一处 CSS**：把 `index.css` 里那条全局输入默认样式从**未分层**挪进 `@layer base`。

```css
/* 改前（未分层 —— 优先于任何命名层，压掉所有工具类） */
input, textarea, select { @apply bg-ink-800 border border-ink-600 rounded-md px-3 py-1.5 …; }

/* 改后 */
@layer base {
  input, textarea, select { @apply …同前…; }
}
input:focus, textarea:focus, select:focus { … }   /* 聚焦态**刻意留在未分层** */
```

**为什么聚焦态留在未分层**：焦点反馈（琥珀描边 + 光圈）是设计系统**统一**给的，不打算让各页面各写
一套；留在未分层它才能稳定压过组件里的 `focus:*`。→ 所以这轮**只有默认外观变成可覆盖**，
聚焦观感零变化。

## 二、真机影响面（改前 vs 改后逐元素 diff）

采集方式：真 Electron、固定主题（护眼）+ 固定缩放 100%、遍历 25 个页签，
逐个记录每个 `input/textarea/select` 的 computed `padding / font-size / border-radius /
background / border-color / color / 尺寸`。

**1097 个控件，901 个有属性变化**；按属性统计：

| 属性 | 变化数 | 说明 |
|---|---|---|
| 背景色 | 884 | 组件写的 `bg-ink-900/60`、`bg-transparent` 等终于生效 |
| 边框色 | 146 | 写了 `border-ink-700` 的终于按声明走（改前被默认 ink-600 顶掉） |
| 内边距 | 139 | `px-1.5 py-0.5`、`px-2 py-1`、`p-0.5` 等终于生效 |
| 圆角 | 108 | `rounded`(4px) / `rounded-lg`(8px) 终于生效（改前恒为默认 6px） |
| 字色 | 18 | `text-ink-200` 等终于生效 |
| **字号** | **0** | ✅ 全局规则**不设**字号，而工具类本就优先于"继承" ⇒ 字号一直是对的（无需担心） |

### 🔴 顺带修掉一个真错位（编辑器正文）

编辑器四图层（测量层 / 引用名高亮层 / AI ghost 层 / 正文 textarea）的源码注释明写
「盒模型必须与 textarea 逐项一致，否则两图层错位」。实测改前：

| 图层 | 元素 | 改前 padding | 改后 |
|---|---|---|---|
| 测量层 | div（`top-6 px-6 md:px-8`） | `0 \| 32 \| 0 \| 32` | 不变 |
| **正文** | **textarea（`px-6 md:px-8 pt-6`）** | **`6 \| 12`** ← 被默认值压掉 | **`24 \| 32`** ✅ |

⇒ 改前正文与高亮/ghost 叠层**错位 20px × 18px**（高亮标记压在错位的字上）；本改后四层一致。
打字机模式的光标纵向定位（依赖测量层与 textarea 同盒模型）同时被修正。

## 三、防回退：`tests/themeContrast.test.ts` 新增 2 道闸（32 → 34 passed）

1. **输入类默认样式必须在 `@layer base` 内**；
2. **未分层处不再允许出现 `input/textarea/select` 默认样式** —— 只放行聚焦态与 `::placeholder`
   （那两条是刻意统一的；`input:focus` / `textarea::placeholder` 因紧跟冒号不会被误判）。
   > 判定前先去注释，避免说明文字被当成规则。

## 四、验收

- **三闸**：`tsc` 0 ／ `eslint` 0 problem ／ 全量单测 **181 全绿**；
- **真机**：逐元素 diff 见上（无异常项）；表格页（伏笔 210 / 物品 250 / 地域 264 个单元格）与
  编辑器实机截图核对 —— 格子描边清晰、正文留白舒适；
- **可回滚性**：改动只有一处 CSS 包裹；若要回滚只需去掉 `@layer base` 包裹，但闸会立刻报红
  （这是刻意的：那条规则不该再回到未分层）。

> ⚠️ 一并说明：本轮**没有**动其它未分层规则（`.badge-*` / `.novel-textarea` / `::selection` /
> `.card-hover` 等）。它们同样有"压过工具类"的能力，但本次没有测到实际受害处；
> 若日后出现「某组件类名不生效」，先按同一思路查是否又被未分层规则压住。
