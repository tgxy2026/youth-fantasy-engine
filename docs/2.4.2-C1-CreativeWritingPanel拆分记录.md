## 二、🔴 本轮新增的四条踩坑（拆分器已全部吸收，见 skill `legacy-component-splitter.cjs`）

1. **import 区不能写死行数**：这个组件的 import 一直到第 51 行，原先写死「前 30 行」⇒ 静默漏掉
   `lib/creativeSession` / `autoContinue` / `theme` 那一批名字（症状：子组件报 `decideDraft` /
   `WORD_TOLERANCE` / `foldVh` 找不到）。已改成「扫到第一条真语句为止」。
2. **HEAD 必须含 return 内的根元素开标签**：原先只切了「头部那几个 div」，漏了
   `    <div className="mx-auto max-w-4xl">` ⇒ 主文件里多个并列顶层元素 ⇒ **TS2657**。
   TAIL 同理要含根元素闭合。
3. **多个并列顶层元素（两个 `<Modal>`）要用 `<>…</>` 包**：不包同样 TS2657。
   Fragment 不产生 DOM 节点 ⇒ **不影响实机指纹的 children 计数**（拆完指纹 9 项仍全等）。
4. **提 identifier 前要剥字符串与注释，但绝不能剥模板字符串**：
   - 不剥 `className="flex gap-1"` ⇒ `gap` 与模型字段重名 ⇒ 生成多余解构 ⇒ **TS6133**；
   - 把模板字符串整段剥掉 ⇒ `${fmtSavedAt(...)}` / `${MAX_OUTLINE_CHAPTERS}` / `${probe…}`
     里的真实引用丢失 ⇒ **TS2304**。
   两条顺序都要对（先剥字符串、再剥注释；模板字符串留着）。
5. 另：带类型注解的 `const pickInfo: RewriteCandidate | null = useMemo(...)` 原先没被名字提取正则覆盖
   ⇒ 子组件找不到 `pickInfo` / `pace`。已把正则放宽为 `^  const (\w+)(?::\s*[^=]+)? = `。
