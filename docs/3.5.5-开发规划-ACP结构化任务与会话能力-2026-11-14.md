# 青春幻想引擎 3.5.5 开发规划 · ACP 结构化任务与会话能力

状态：计划。基线为 3.5.4 已接入的七项纯文本功能。首个验收环境为 Windows x64 桌面版与 Antigravity；逐版本记录组件、模型、推理档位和实测支持范围。

## 源码复核与实施边界

- 当前 `acp:generate` 只接受 7 个任务标识。主进程每次发起任务会启动 Agent、建新会话并在结束后回收，运行层同一时刻只允许一个 ACP 操作。模型和推理档位依据会话返回的选项。多轮历史、流式取消、连续交互时的进程复用和批处理需单独设计。先用应用维护的有界对话历史验证多轮，组件支持可恢复会话时再择需使用，并实测隔离、回收与重启恢复。
- 接入按**调用点**识别。颉文姬手动简报与画布、手动摘要与批量／连写摘要、手动续写与自动连写分别验收。应用负责资料装配、结果校验和落库。每个新增入口同时核对按钮就绪、任务路由、IPC 白名单、后续模型子调用与结果采纳；ACP 路径必须能在没有 API 模型、密钥和模型窗口配置时运行。旧 API 提供方的上下文、重试、用途路由和参数只有已验证映射后才用于 ACP。
- 当前运行层限制单次输入 256 KiB，ACP 客户端限制输出文本 512 KiB、生成等待 180 秒，并要求回合完整结束。长任务评估实际组件窗口及延迟，使用有限上下文、分批和取消；未收到完整结果时按业务契约处理，不把部分草稿提交为成品。

## 3.5.5 工作包

| 工作包 | 纳入功能 | 实施及验收 |
| --- | --- | --- |
| ACP 结构化基础 | 按任务交付 JSON、固定字段、可定位文本和待审核写入 | 复用现有任务解析和校验。先探测当前组件可用能力；若只返回文本，宿主按任务解析并严格核验完整性、字段、枚举、长度和引用。拒绝截断、缺失和无效引用；只有现有业务规则允许时才展示部分结果。记录实际请求次数，禁止静默转用 API。 |
| 颉文姬审校 | 文字层校对、逻辑层校对、章节编辑意见（六维打分）、OOC、续写方向 | 校对位置以原文校验，失效或多义时禁用替换；结构化审读保留结果契约、展示和来源。验两个相同引文、取消迟到与切章。 |
| 颉文姬写库 | 设定补登、章后整理 | 复用实体比对、候选审阅与项目级保存。覆盖人物／势力／地点等实体，以及伏笔、人物关系和状态的变更。作者确认并核对记录版本后写库。 |
| 结构化设定与规划 | 表单、设定、角色卡、总纲／卷纲／细纲、表格的 AI 新增与补全；对话式填写；人物／势力关系、伏笔、时间脉络、爽点、支线、知情权限、章节总表和分卷台账的 AI 整理 | 复用各表字段、已有值保护、去重与保存规则。确认自定义模板的 AI 参考／填写开关、字段类型和生成期间模板变更保护。用有旧数据、有同名项和项目切换的作品验证。 |
| 后台写作 | 编辑器停笔伴写、手动触发伴写、自动续写与逐章连写执行链 | 用户主动开启，提示外发范围并可立即关闭。覆盖停笔、继续输入、限频、排队、取消、换项目／账号、模式排空。连写逐个处理初稿、去 AI 味润色、字数补写／压缩、自动审查与修正、章摘要及设定同步。用单章和连续两章验完整执行链，并记录 ACP 冷启动和端到端延迟。创意写作从设定奠基到跨批恢复的整页联调归 3.5.6。 |
| 酒馆 | 剧情推演、自由对话、重说、多候选和智能修订；推演报告、记忆、日记、回合收尾及每轮数值提取；角色卡、背景、故事和剧本的 AI 起草、小说角色转换、对话引导；跑团 KP、剧情推进与结算 | 主回复与其后的数值更新、摘要和记忆分别记录请求和提交结果，保留已有软失败行为。按作品／角色／会话隔离上下文，取消后不写入迟到结果。复验现有角色归属、输出协议和状态校验。嵌入不可用时采用已有或经实测的关键词路径。 |
| 嵌入 | 正文和设定向量索引的创建／增量更新／重建，参考资料向量索引及语义召回，酒馆同场语义记忆 | 3.5.5 交付能力探测、禁用提示和可用的关键词降级。取得并实测提供方的向量接口、模型标识及维度后才启用。无接口时向量本体列为外部能力阻塞，由 3.5.6 复核；文本输出不可充当向量，ACP 模式不隐式借用 API。换模型或维度时验证重建和旧索引处理。 |

先完成结构化输出与宿主校验，再接审校、补登和设定表，随后接后台与酒馆。沿用 3.5.4 三模式互斥、最小外发资料、租约、进程树与文件边界的验收要求。新任务只能走明示的 IPC 白名单；文件、终端和任意 MCP 工具权限继续拒绝。

每组至少验证无 API 模型配置、正常生成和结果落地、拒绝发送、错误输出、取消迟到、切项目／账号及旧数据兼容。完成后用同一安装候选复验 3.5.4 七项及 API、MCP、便携、网页路径。文件隔离和安装验收仍按 3.5.4 前置记录完成。
