## 记录约定
- 每一条新增时自动分配递增编号（如 `#001`）；**本清单编号与归档清单相互独立**，不要跨文件对照编号。
- 「类型」填 `Bug` 或 `优化`。
- 「模块」尽量填源码已有的标识（如 `chapterSeq` / `按卷建表` / `ProjectHub` / `DataDock` 等），方便后续定位。
- 「来源」填 `社区反馈` / `老大自测` —— 2.3.1 只收这两类；若是「回归」（新版本引入的）请注明。
- 「报告日期」填反馈当天日期。
- 处理动作（改了哪个文件、怎么改的）只在老大要求处理时回填到「处理结果」列。
