# 青春幻想引擎 3.1.3 · 更新说明（发布版草稿）

> 面向作者的措辞；发布前请主人过一遍语气与事实。
> 状态：草稿（功能尚未封装，说明书随发布一起定稿）

## 一句话

「种族生物」「物品资源」「国家势力」「地理风物」四个页签多了**图鉴视图**，
并且可以给条目**自定义字段** —— 设定表终于能按你自己的方式长，而不是按软件预设的栏目长。

## 图鉴视图（四个页签）

- 开放页签：**种族生物 / 物品资源 / 国家势力 / 地理风物**（都有「编号 + 名称 + 类别」，天生适合卡片墙）
- 卡片上两枚小标签是这张表的「类别 + 最关键的那一列」：
  魔兽看威胁等级、物品看品级、势力看实力等级、地方看危险等级
- 卡面默认摘要也各按自己的逻辑：魔兽看威胁/分布/能力，势力看实力/掌权者/剧情，地方看危险/风土/归属（都能改）
- 详情按语义分组：势力分「基本资料 / 实力构成 / 立国之基 / 关系 / 剧情关联」，
  地方分「基本资料 / 位置与范围 / 地貌与物产 / 归属与危险 / 人文与剧情」
- 右上角「表格 ⇄ 图鉴」可切换；**默认仍是表格**，老习惯不用改
- 卡片墙 + 点开看完整资料；宽屏时详情在右侧，窄窗口自动铺满并有「返回」
- 卡片密度三档（紧凑 / 标准 / 宽松），密度是**本机偏好**，不跟着项目走
- 卡片下面显示什么由你定：字段设置里勾最多 3 项摘要（不勾则用系统默认三项）
- 详情里**直接改**：点「编辑」就地修改，改完点「保存」——不用再来回切表格；**编辑回表格** 那个按钮还在（想连着改好几条时更快）
- 图鉴和表格**共用同一份草稿与保存**，不会出现"图鉴里改的表格里没有"；不想留就点「撤销」，只撤刚才在详情里动过的那几栏，表格里其它没保存的改动不动
- 能就地改的是**文字和下拉**；**编号 / 上级 / 地理位置 / 角色 / 日期 / 历法**这几类控件要回表格改（详情里那一行会标个小小的「表格」提示，不是坏了）
- 空的栏位默认收着，点「显示未填写字段」才露出来；进了编辑态会自动全露出来，方便一次补完

## 主图

- 详情里「上传主图 / 换一张 / 移除」；PNG / JPG / WebP，原图 ≤ 8MB
- 自动等比缩到最长边 1024px、压到 200KB 以内（不裁切、不放大、保留透明）
- **即选即存**，不用按保存
- 项目图片总容量：**只有网页版云端账号是 32MB**（到 80% 会提示）；容量满了只影响传图，文字照常写
- 桌面安装版、便携版、游客网页版的数据都存在你自己的机器上，**不设这个限额**（详情里会写「本机存储，不限」）——
  这些形态占的是你的硬盘，不是服务器配额

## 自定义字段

- 「字段设置」里新增字段：短文本 / 长文本 / 数字 / 单选 / 多选 / 是或否
- **改内置字段的名字也在「字段设置」里**（原表头那个「字段名」按钮已合并进来 —— 同一件事不该有两个入口）：
  展开「内置字段显示名」，留空＝用原名；只改界面上那几个字，不动数据、不动分组
- 可设说明、单位、候选值、所属分组、适用类别，以及「表格显示 / 详情显示 / 可搜索 / AI 可读 / AI 可写」
- **改名不影响已填内容**（字段名与存储键分离）
- 删除用「归档」——字段和内容都留着，随时恢复；本版不提供一键永久删除
- 两个开关是**独立**的：把「表格显示」关掉、却还开着「允许 AI 填写」时，字段设置里会明确提示
  「这一栏在表格里看不见，但 AI 仍会往里写」，字段列表也挂一枚「隐藏 · AI 会写」的小标签 ——
  免得哪天发现某个看不见的栏位被悄悄填了。真想挡住 AI，把「允许 AI 填写」一起关掉

## AI

- AI 新增 / 补全本行 / 整理三条路径都能读写自定义字段
- 只填你允许它填的字段；值会按类型校验（数字不是数字、单选不在候选里 → 跳过并告诉你）
- AI 读设定时，看到的是**字段名**与可读的值，不会看到 `cf_` 这种内部键

## 搜索

- 自定义字段的值可被搜到，**字段名本身也能搜**（搜"食性"就能找到填过食性的条目）

## 导入导出

- **导出 CSV**：列头是字段名；多选导出成「刀、盾」、是/否导出成「是/否」
- **导入 CSV**：认不出的列会明确告诉你，并且在图鉴页签可以**一键把它们建成自定义字段**
- **CSV 是通用交换格式，不是无损备份** —— 导出后会直接提示这一点：多维候选会被铺成一段纯文本、
  主图与附件根本不在文件里、换行以外的排版也还原不回来。要原样搬运（含字段定义与主图），
  用下面的「图鉴资料包」
- **图鉴资料包**（JSON）：字段定义 + 条目 + 主图，能在另一个项目里导入；同名字段自动复用，
  不同的自动新建并对应好数据（撞名会改成「食性（2）」这种，并告诉你为什么没合并）；导入只新增、不覆盖

## 按钮不再"骗人"

- 表头的「⋯ 更多」按内容自动改名：里面**只有导入导出**的表，按钮就直接叫「**导入导出**」并换成双向箭头；
  里面还躺着「清空全部」的表（人物关系 / 历史事件）仍叫「更多」，免得点开发现不是自己以为的东西

## 角色可以换页签了

一个人物写着写着从「NPC」变成「次要角色」，或者原本是主角、后来退成配角 —— 以前只能新建一张卡再一条条复制，
立绘还得重新上传。现在角色卡右上角多了「**移动到其他页签**」：

- 主要角色 / 次要角色 / NPC 三张卡之间**一键搬**，姓名、别称、保密等级、所属势力、地理位置、人物状态、
  立绘全都跟着走
- 三个页签的字段叫法不完全一样，系统按**含义**对上：「身份定位」与「身份」、「功法/技能」与「实力与功法」、
  「核心性格」与「一句话性格」、「说话风格」与「口癖/记忆点」、「首次出场」与「关键出场」都算同一项
- 目标页签**多出来的栏位会留空**（比如升级到主要角色后，多出一整块「性格与内心」等你去补），不会凭空编内容
- 往**信息更少的页签**搬时（比如主要角色 → NPC，会丢掉价值观、角色弧光这类深层设定），
  弹窗会**逐项列出会消失的内容**，并要你勾选「我确认」才能按下红色按钮 —— 这一下之后没有撤销
- NPC 卡的「年龄/性别/外貌特征」是一格装的：搬到主要角色时原文整段进「年龄/性别」、不拆词；
  反向搬回时把两栏用逗号拼回一格，一个字都不丢
- 移动前不用先保存，未保存的改动会一起搬过去；搬完左侧列表会告诉你去了哪一页

## 对话引导不再"聊完即丢"

写书时最常发生的事：AI 问到第 8 个问题（性格缺陷？核心动机？），电话来了，切出去再回来 ——
之前得从第一个问题重答。现在不会了：

- **关掉 / 切页签 / 换个窗口，对话都在**：重新打开会问一句「上次聊到第 N 轮回答（X 分钟前）—— 继续上次 / 重新开始」
- **默认不自动恢复**：先让你自己选，免得你以为是从零开始、实际接上了旧对话
- **关掉时会先问一句**「关掉后这段对话会保留存档，下次可以接着聊」—— 避免手滑丢掉
- 已经点过「填入表单」的会话不会再冒出来（存档随用随清）
- 存档**跟着项目走**（切项目不会串），**7 天后自动过期**，不会哪天突然弹出一段旧对话
- 只有 AI 开场、你还没回答过的会话不算数（不会提示"聊到第 0 轮"）

## 备份更省空间了（不丢功能）

- 备份改成「文字」与「图片」分开存：**图片没变就只存一份**，多份备份共用
- 备份列表里能看到每份的「文字多少 / 含图片多少」
- 恢复行为不变：文字按备份回滚，图片一并还原

## 已知限制（如实写明）

- 图鉴详情能就地改**文字与下拉**；**编号 / 上级 / 地理位置 / 角色 / 日期 / 历法**这类专用控件仍要回表格
  （详情里那几行会标「表格」，不是坏了）
- 字段**类型建好之后不能改**（先另建一个字段再归档旧的）
- CSV 导入暂时只做「新建字段 / 忽略」，还不能把外来列映射到某个已有字段
- CSV **不是无损备份**：多维候选会被铺平、图片与附件不跟着走（要完整搬运用「图鉴资料包」）
- 多选字段在表格里是勾选面板；候选值要在「字段设置」里维护
- 图鉴图片没有历史版本（备份里的图片只在最新一份里保留）
- 「表格显示」与「允许 AI 填写」是两个独立开关：关掉前者**不会**顺带禁掉 AI 写入，
  这种情况界面会提示，但需要你自己决定要不要一起关

## 本版修掉的问题（用法不变，但值得知道）

验收阶段一共查了 12 项，都是"数据会悄悄变样"那一类，逐条修完并复验：

- **备份恢复时图片可能张冠李戴**：多份备份共用图片时，条目会拿到别人的图
- **限定了适用类别的自定义字段整类消失**：给魔兽加的「食性」，表格、详情、搜索里都看不到（值其实还在库里）
- **对话引导的存档可能串到另一本书**：切项目太快时会写错地方
- **语义索引会绕过字段权限**：某字段设成「不给 AI 参考」，旧索引里那段文字照样会被召回到提示词里
  —— 现在改完这类设置会自动作废旧索引，宁可让你重建一次
- **图鉴资料包只做浅校验**：非法的字段值、谎报尺寸的图片能混进导入
- **更新版本写过的字段配置会被旧版覆盖**：现在遇到看不懂的格式会拒绝写入，并说明为什么
- **国家势力 / 地理风物导出的资料包被自己的导入器拒绝**
- **同名字段被硬合并**：字段名一样但含义、候选、单位不同时被当成同一个 —— 现在会另建并改名，并告诉你冲突在哪
- **CSV 往返会改内容**：长文本里的换行被折成空格、导回来类型丢失
- **图片"已更新"是假的**：落库失败也提示成功 —— 现在等真的写完才提示，失败会如实报错并保留原图
- **分批导入中途出错会丢掉已成功的行** —— 现在继续往下导，并把失败的那几行单独列出来
- **AI 回填可能在字段定义被改过之后写错位置** —— 现在应用前会核对基准，配置变了就整批作废
- **大纲页「新建 / 复制 / AI 新增」可能丢掉当前没保存的编辑** —— 现在换卡片之前会先把手上这份存好，
  存不上就留在原处并告诉你（不会假装没发生）
