二、本次已修（25 处 · 10 文件）

A · 本轮（09-20）自己改出来的 —— 重点

P1新页签「其他设定」漏登记编号前缀 · lib/autoCode.ts

schema 的 codeRule 承诺「MISC0001、MISC0002…」，而 CODE_PREFIX 里没有 misc-settings → 空表新增行走 CODE_PREFIX[tabId] ?? ''，得到的是裸 0001。

隐蔽点：只有表里已有 MISC 行时才靠 usedPrefix 救回来，而示范项目自带 3 条 MISC 行 → 平时完全看不出来。

已修：补 'misc-settings': 'MISC'。

P1伴写 Ctrl+Enter 未挡输入法 + 未校验开启态 · components/useNovelEditorGhost.ts

中文输入法按 Enter 是「选字」，此刻不该当快捷键（项目红线）；且手动触发路径**绕过了主循环的前置闸** —— 关着伴写总开关按下去会静默发一次真实模型请求（烧 token），而结果永远不会渲染（ghost 只在开启时才画），作者只会以为键坏了。

已修：补 isComposing 挡 + !companion || !aiReady 守卫；Alt+\ 同口径一并补。

P1高亮叠层重建后不回填 scrollTop · components/useNovelEditorHighlight.ts

高亮层是**条件渲染**（{highlightOn && …}）：从关到开时才新挂载，而新 DOM 的 scrollTop 恒为 0。 那个负责回填的 useLayoutEffect 依赖数组里**没有 highlightOn** → effect 不重跑 → 叠层停在顶部、与正文错位。

症状就是 2.0.1 修过的那个「上下滑动查看时经常不显示文本」：正文滚在中后段时打开高亮，可视区一片空白。

已修：deps 补 highlightOn。

P1界面文案里的 markdown 星号 · components/CreativeWritingPanel.tsx:583

title="…若**最后一章**明显没写完…" —— 原生 tooltip 不解析 markdown，会原样露出 **。 （三路独立命中同一处：扫描器 §8 + 两路子代理。）

已修：去星号。

三、待定 —— 需老大定夺

P0启动路径漏注册「读本地库快照」→ 墓碑闸失效 → 幽灵项目复活
数据安全 · src/lib/db/core.ts + src/lib/syncCore.ts
  • onDesktopLocalSnapshot 全仓只有一处调用（core.ts:407，在 enableDesktopCloudSync 内）。
  • 但启动时自动恢复云同步走的是另一条路（core.ts:283 的 applyDesktopCloudFromPersisted）—— 那条路上从未注册。
  • 后果链（有代码证据）：syncCore.ts:493 localSnapshotProvider 为 null → localSnap = null → local = cache（启动时刚被 configure 清空）→ localHasContent = false（:237）→ 墓碑判断 if (localHasContent && isDeleted(...))（:276）被短路 → 云端旧记录一律按「另一端新增」采用。
  • 触发：开启云同步 → 删除项目 → 防抖推送完成前关窗（或断网期间删除）→ 重启 ⇒ 删掉的项目复活并自锁。
  • 建议修法：把注册提到模块初始化（CLOUD_FILE_SYNC 块内、applyDesktopCloudFromPersisted 成功之后）， 让「读本地库快照」与「哪个路径开启同步」解耦。
  • ⚠️ 本轮没顺手改：它动的是云同步核心路径，静态检查证明不了行为等价 —— 需配「删项目 → 重启 → 断言不复活」的实机对照，建议单独一轮。

五、本轮方法论增量

  1. 「本轮引入的」≠「扫描器报出的」：§8 星号与 §15 isComposing 各只报 1 处，两处都是今天我自己改出来的。 改完立刻跑一次受影响的那支扫描器，比等下一轮全量审计便宜得多。
  2. 含 JSX 属性 / 反引号 / ${} 的片段，用分隔符式补丁器（patch-delim.mjs）： 本轮 23 处一次落盘、零转义问题。⚠️ 但 JSX 里加 {/* 注释 */} 不能插在 {cond && ( 与元素之间 —— 那是两个同级节点，语法直接崩（本轮踩到，tsc 报了一串 TS1005/1382/17015）。
  3. 「承诺 ↔ 实现」最高命中率的判据：同一文件里自己写着规则、自己又违反。 aiDataSources.ts 第 50 行写着「必须是真名」、第 64 行起全是别名 —— 这类自相矛盾不需要任何外部知识就能判定。
  4. 审「数字承诺」必须把文案里的数字与常量对齐，不能只看文案内部自洽： AIWriterBudgetPanel 写「1/4、不放大」，而常量是 ratio: 0.30 + 注释「不再封顶在出厂值」。
