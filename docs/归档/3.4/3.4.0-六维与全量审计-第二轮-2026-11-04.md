## 二、本轮真正修的产品缺陷：帮助文案的裸 markdown 星号

**现象**：帮助文案长期按 markdown 习惯写成 `**Ctrl + Shift + F9**`，但三个渲染入口都是**纯文本**：

| 入口 | 渲染方式 | 位置 |
| --- | --- | --- |
| 使用手册正文 / 摘要 | `whitespace-pre-wrap` | `HelpCenter.tsx` |
| 各页签「?」帮助气泡 | `whitespace-pre-wrap` | `HelpPopover.tsx` |
| 确认框正文 | `whitespace-pre-line` | `dialogs.tsx` |

⇒ 作者在界面上看到的是星号本身（`**Ctrl + Shift + F9**`），而不是加粗的 `Ctrl + Shift + F9`。

**影响面**：帮助文章 9 个文件共 **47 处**成对强调；`HelpPopover` 2 处（章节栏、表页签）；确认框 2 处（云同步删除、本章变化清单）。

**修法**（不引入 markdown 库、不改 47 处文案）：

| 文件 | 变更 |
| --- | --- |
| `src/lib/text/emphasis.ts`（新增） | `splitEmphasis()`：只认**成对** `**`；落单 / 空强调（`****`）**原样输出**，宁可显示星号也不吞字 |
| `src/components/common/EmphasisText.tsx`（新增） | 把分段渲染成 `<strong>`，其余照原样（换行由容器 `pre-wrap` 维持） |
| `HelpCenter.tsx` | 摘要与正文段落改走 `EmphasisText` |
| `HelpPopover.tsx` | **仅当 children 是字符串**时走 `EmphasisText`；函数 / ReactNode 内容不动 |
| `CloudSyncPanel.tsx` / `ManuscriptCheckPanel.tsx` | 确认框是纯文本语义，**去掉 2 处星号**（不引入富文本） |

**判据边界（已写进单测）**：`**a** 与 **b`（落单）、`****`（空强调）、`2 ** 3`（笔误）一律原样输出；无星号时零成本直通；强调段内的换行与中文标点逐字保留。

**证据**：`help-center-331` 实机新增 3 项 —— 正文不含 `**`、存在 `<strong>`、加粗后文字未丢（`Ctrl + Shift + F9` 仍在）；`tests/helpEmphasis.test.ts` **26/26**。

## 三、本轮修的工具缺陷（4 条扫描器误报）

| 扫描器 | 误报 | 根因 | 修法（依据） |
| --- | --- | --- | --- |
| scan §11 | `AssistantDock.tsx:23` 的 `40vw` 判为「未折算」 | 常量在第 23 行定义、第 49 行才 `calc(${DOCK_WIDTH} / var(--ui-zoom))` 折算，**按行判断看不到使用处** | 识别「同名常量在别处被 `$ {}` 引用且文件内另有 `--ui-zoom` / `foldVh(`」⇒ 不报 |
| ui U5 | `SafeImage.tsx:11/26` 判为「`<img>` 缺 alt」 | 这两行是**注释**里写的 `<img>`（文件头与 props 说明），真实 `<img alt={alt}>` 在第 42 行 | 跳过注释行后按「行内或后 300 字符内有 `alt=`」判断 |
| ui U5 | 4 个「可点击 div 无 role」 | 全是 `aria-hidden` 的**点外部关闭遮罩**（关闭另有 Esc / 再点触发键），2026-09-22 已判过 | `aria-hidden` 的装饰遮罩不进候选 |
| func F2 | `BOSS_ENABLED_KEY` / `BOSS_ACCEL_KEY` 判为「未引用组件」 | `export const Xxx` 被一律当组件，而它们是 **SCREAMING_SNAKE 常量** | 排除 `^[A-Z][A-Z0-9_]*$`（真组件名至少含一个小写字母） |
| prompt P4 | 3 处判为「要 JSON 却没有闭嘴条款」 | 项目 3.2.0 起统一走 `output: 'json-object'`（`aiCore/chat.ts` 映射成 `response_format: {type:'json_object'}`），规则只认旧的 `json: true` | 兜底检测加上 `output: 'json-object' / 'json-schema'`；标题改为「靠 response_format 兜住」 |

> 改的是**判据与代码约定的同步**，不是放宽标准：`output: 'json-object'` 与 `json: true` 在传输层完全等价；`aria-hidden` 遮罩、SCREAMING_SNAKE 常量本就不属于各自规则要抓的对象。死代码 A 类（3）、重复块（57）、循环依赖（28）等**真实候选一条没少**（见 §五对照）。
