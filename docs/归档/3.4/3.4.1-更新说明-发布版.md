## 一、AI 提示词系统第一阶段深度优化（7 个文件 · 14 处）

这一轮把全项目最常被调用的 14 处核心提示词逐条重写，目标只有一个：**让模型给得出能直接落地的方案，而不是正确的废话**。

| 模块 | 优化后 |
| --- | --- |
| 创作智囊 / 规划参谋 | 定位为参谋与脑暴智囊；每次给 2~3 个各有侧重的具象选项（常规爽文推进 / 高概念反转 / 人物宿命冲突）；推演时兼顾即时爽点、核心钩子与反派反制动机 |
| 取名建议 | 按人物 / 势力 / 功法地名分类，加入平仄与音韵指引，并给出知名主角与滥用字负面清单 |
| 敏感内容复查 | 厘清正常文学修辞与违规语境的边界，不再一刀切 |
| 文风体检 | 坏习惯词 / POV 越权 / 标点 / 长段节奏四维体检，明确「宁可少报不可误报」 |
| 术语去重 | 区分真实同义与「青云剑 / 青云门」这类异名异物，避免误合并 |
| 伏笔闭环审查 | 30~50 章跨度量化、悬空断头、埋收失衡、机械降神式回收四类判据 |
| 项目健康诊断 | 自洽度 / 主线推进 / 角色立体 / 伏笔健康四维打分，风险按严重度降序且给可立刻动手的建议 |
| 读者反馈分析 | 从追读、留存、流失点归因到憋屈、喂毒、崩盘、水文 |
| 灵感融合 | 正面引爆 / 对撞反转 / 反差深挖三种模型，产出 100~200 字高密度卡片 |
| 颉文姬（续写建议 / OOC / 审读） | 矛盾拉扯与悬念钩子；区分心境成长与 OOC；六维商业网文审读打分 |

| 设定更新侦测 | 聚焦长期演变、过滤琐碎动作、强制对齐原名 |

🔴 **结构契约一条没破**：不改任何解析键名、不破坏既有 JSON schema、提示词内不携带 Markdown 星号（避免污染正文）、保留关键单测断言。**已保存的自定义提示词不受影响**，模型设置里改过的内容仍按作者的版本生效。

## 二、审计工具：防「静默失明」自检

审计规则里写死了大量登记路径（图表清单、平台判定源、外置存储白名单）。文件一旦被搬走或改名，扫描器**不会报错，只会「什么都没扫到 ⇒ 0 候选」**——看起来是绿灯，实际是瞎了。3.4.1 给它补上开场自检：

| 自检项 | 拦住什么 |
| --- | --- |
| 登记路径全部存在 | 配置里写死的文件被搬走 / 改名 |
| 图表清单健康 | 清单被清空、重复或与「非图表」登记交叉 |
| 必要契约 id 唯一 | 契约表被改坏 |
| 静态扫描覆盖与源码一致 | **AST 实扫文件数 ≠ 真实 ts/tsx 数或为 0** ——「扫 0 个文件所以 0 候选」的假绿灯 |
| sidecar 符号可解析 | 外置存储白名单常量被改名，平台扫描少一项却不报错 |
| 工具提示路径有效 | 工具输出给用户的命令指向不存在的脚本 |

- 自检失败 ⇒ 报告写 `blocked` 诊断，**绝不可能是 `complete`**；有修复前实证（自检退出码 1 + 审计报告 `incomplete`）。
- 报告新增 `appVersion`、`toolFingerprint`、`selfCheck`，`report.md` 增加「本次扫描」段：版本、工具指纹、扫描文件数、图表清单、自检结果一目了然。源码指纹口径未改，既有证据链不受影响。
- 「审计审计者」规则覆盖扩到 `scripts/audit/` 全部子目录（此前只扫临时工具目录，对真正的工具代码失明）。
- 修掉一处工具输出指向不存在脚本的提示，并加了永久防护与回归单测。
