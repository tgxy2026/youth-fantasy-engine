## 二、优先级与执行顺序

1. **P0 当前互斥闭环与安全边界**：用当前源码验证真实桌面 UI、便携 UI、API 与 Agent 双方向互斥；针对发现的旁路、恢复与失败语义补齐实现和回归。
2. **P0 多窗口和数据一致性**：界定单宿主、多个 profile/不同资料目录、同一作品及云同步的作用域；建立真实冲突保护，无法保证时明确阻断。
3. **P1 按领域扩展**：先完成草稿/版本/授权/持久化等公共保护，再逐包实现地图、画布、世界包、恢复、酒馆及创作任务；每包开发和测试同时完成。
4. **P1 客户端与交付验收**：在隔离合成数据下复核 Codex 和其他客户端；源码稳定后重新构建、核对指纹与产物，完成用户明确授权范围内的桌面、便携和安装测试。
5. **最终复验**：源码或审计工具变化后重跑相应检查、全量与审计；按证据真实列出未覆盖项。封装、安装、发布、部署和推送分别遵守用户当次授权。

## 三、待开发和待复核：互斥与恢复

### 3.1 运行边界与入口盘点

- [ ] 明确同一宿主、`userData`、自定义数据位置、便携根目录、多个 profile 和多台设备的互斥作用域；本机文件锁不构成跨设备锁。验证共享作品或云盘目录时不同宿主不能各自错误放行写入。
- [ ] 逐项检查 `chatRaw`、协议驱动、流式响应、嵌入、模型测试/列表/卸载、酒馆独立 provider、联网检索及直接 `fetch`/主进程代理；形成入口清单和实际发送证据。不得把已有接线或静态搜索单独当作“全部入口无绕过”的证明。
- [ ] 验证桌面、便携、网页版和独立只读桥的预期行为：网页没有本机模式宿主时的限制须如实说明；旧安装包缺接口、服务失联、未知状态不能冒充桌面/便携的稳定模式。
- [ ] 确认 Agent 只读、写入、重放、启用和授权变更均受预期模式及项目权限限制；独立桥、老宿主、旧 enabled 配置及多窗口不得绕过约定边界。

### 3.2 任务、切换与故障恢复

- [ ] 对完整任务保持租约至流式响应体消费完成或取消得到确认；审查超时、网络断连、取消失败、后台索引、多步重试和迟到回执。若任务实际是否结束不明，禁止凭超时自动放行另一方向，设计可诊断且不丢草稿的恢复方式。
- [ ] 检查两方向切换的事务顺序：拒绝新任务、写入并回读切换中记录、排空旧租约、确认旧方向终止与目标就绪、持久化并回读稳定状态；对重复 ID、并发切换、取消、失败和崩溃逐项定义状态与用户提示。
- [ ] 验证并补全旧配置迁移：缺失、损坏、未知版本、`enabled` 缺失、旧版已启用、pending 标记、模式中断及遗留锁分别处理；不丢 API 配置、密钥、项目授权、请求账本和作品。
- [ ] 完善可信恢复和安全提示：核对原宿主/在途任务终止，保留锁和配置证据，获取恢复期间独占所有权，再安全回到 API；故障期间不能让另一宿主并行修改记录。重点覆盖标记无法创建/同步/清除、锁读取或隔离失败、回读失败及恢复中再次崩溃。不得仅凭 PID 或超时自动认定安全。
- [ ] 对 Windows 文件共享/锁和真实异常退出、目录权限、磁盘满/只读进行实测；若文件系统无法提供所需语义，设计降级阻断策略。真实断电与设备故障未测时保持未覆盖。

### 3.3 产品体验与说明

- [ ] 使用当前桌面和便携实际界面检查稳定/切换中/阻断、等待任务、取消、恢复确认与错误提示；跨窗口和重启后状态须来自宿主，不依赖单个页面缓存。
- [ ] 切换及恢复不得改变 API 密钥、模型配置、Agent 授权和未保存稿件；对人工编辑、同步、挂起任务和失败重试给出可理解反馈。
- [ ] 对照当前实现更新帮助、连接提示词和 [第三方 MCP 规范](3.4.3-MCP第三方开发者适配规范.md)；区分外部 Agent 自身模型与引擎 API，准确说明网页与未验证客户端的限制。

## 四、待开发：数据一致性与功能领域

每个领域先确定用户可见操作、项目和动作权限、数据归属、草稿与在途保存屏障、版本条件、幂等/冲突、失败恢复和 UI 同步；不以通用数据库写入绕过业务规则。

| 领域 | 开发内容与出口 |
| --- | --- |
| 跨窗口 / 云同步 | 对桌面多实例、便携多标签、其他设备和同步在途建立可证明的协调或原子版本条件；窗口或同步在检查后出现时仍不能丢写入。无法保障时拒绝并保留输入；现有单页锁和检测不是跨设备 CAS。（现状：单宿主所有权 + 多页面/云同步保守拒绝；仍未原子化，多设备未验证） |
| 地图 / 画布 | 制定对象创建、更新、删除、引用和顺序规则；覆盖坐标、图片、画布布局与未保存草稿，检测页面打开/保存中的冲突，落盘回读并按需刷新。现有摘要读取不代表写入开放。（已实现地图/地点/格子与情节卡/连线；底图图片修改不开放；页面打开时拒绝写入） |
| 世界包 / 备份恢复 | 设计跨项目目标身份、授权、预览、覆盖确认、ID 与引用重映射、版本、失败回滚；恢复过程保留可回退证据和作品，明确破坏性操作。（已实现预览+确认+安全预备份；世界包失败自动回滚；跨项目需 `world:read`） |
| 酒馆 / 创作和检查任务 | 按模式明确哪些任务允许启动；设计长任务进度、资源上限、取消、断连、结果确认、幂等、重启恢复及人工接纳；现有检查工具和报告读取只是部分能力。（Agent 模式下引擎模型请求被拒绝，AI 长任务不可用；本地检查与报告只读可用） |
| 既有写入补缺 | 复核章节、分卷、设定卡、表单/表格、世界设定、灵感的自定义模板、引用、删除/恢复、版本、草稿、权限和刷新；按实际缺口实施。（已补章节回收站列出/恢复；灵感仍只支持追加） |
| 工具发现与兼容 | 同步 `tools/list`、参数 schema、作用域、错误/重试语义、帮助和第三方规范；明确未开放项，按真实客户端结果记录兼容矩阵。（已同步 57 工具 / 19 动作 / 新错误码；真实客户端未复测） |
