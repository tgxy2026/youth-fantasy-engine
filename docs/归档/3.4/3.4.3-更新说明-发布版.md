# 青春幻想引擎 3.4.3 更新说明

> 一句话：**这一版把外部 Agent 软件正式接了进来 —— 引擎有「API 调用 / Agent 模式」两种互斥运行方式，Agent 可以按项目授权读写设定、章节与正文；同时把真实客户端联调发现的问题、以及作者反馈的 9 项界面问题统一处理完毕。**
> 3.4.3 **不改动已保存的作品数据与模型配置**，旧配置读进来自动补默认值；升级直接覆盖安装即可。
> 🔴 本版仍属**源码与限定场景验收通过**，不等于整版发布验收通过，未覆盖范围见第六节。

---

## 一、两种运行方式：API 调用 / Agent 模式

模型设置页新增「运行模式」分段开关，两者**互斥且真实生效**，不是切页面：

| 模式 | 引擎内置模型请求 | 外部 Agent 工具调用 |
| --- | --- | --- |
| **API 调用**（默认） | 正常：对话、酒馆、嵌入、模型测试、联网检索 | 拒绝（`MODE_BLOCKED`） |
| **Agent 模式** | 拒绝，避免两边同时改一份数据 | 按项目授权放行 |

- 切换会**先等待在途任务结束**并给出「切换中 / 不可用 / 已生效」三态；失败时保持阻断并提供「安全恢复」入口，不会静默丢数据。
- 模式状态由本机宿主真源判定，页面不自行猜测；桌面与便携已接模式服务、宿主闸与模型租约。
- 「API 模型」这一旧称在本版**全量改为「API 调用」**（界面、状态提示、宿主拒绝语、内置手册一致）。

## 二、Agent 能做什么（68 个可写工具 + 只读桥）

- **MCP stdio 桥**：随包分发 `yfe-agent.mjs`（本版 0.1.2）与 `yfe-readonly.mjs`，客户端配置可用通用 MCP JSON 或 TOML 格式；桥自动推导桌面 `agent-host.json` 位置。
- **按项目授权**：设置页只显示**当前打开项目**的授权卡（其它项目既有授权隐藏但保留、不清理）；支持**项目级 / 分类级两级全选**，21 项动作按「设定与表格 / 分卷与章节 / 灵感与地图 / 世界包与备份 / 检查与任务」分组。未勾选一律只读。
- 覆盖设定卡、表单、设定表、多套世界设定、分卷、章节正文与元信息、回收站、灵感、地图与画布、检查报告、任务台账等；**破坏性覆盖**（世界包引入、备份恢复）必须先 preview 再 `confirm`。
- 请求 `requestId` 幂等账本跨重启保留；宿主对鉴权、模式闸、归属、冲突、草稿保护、落盘失败均返回结构化错误码。

### 真实客户端联调后的修复

联调发现 11 项问题，本版按报告处理（逐项映射见 `docs/3.4.3-待处理问题台账-2026-11-10.md` 与 `docs/3.4.3-Agent模式真实客户端联调问题报告-2026-11-10.md`）：

- 68 个工具成功信封统一为 `{ok:true,value}`；`yfe_host_info` 透传真实 `connectionMode`，模式关闭后不再误报「连接可用」。
- 新增 `READ_ONLY_FIELD` 错误码；`list_data_tabs` 标注只读 / 自动字段；情节画布 `chapter` 读写语义统一（支持章节 ID 或唯一标题，读取补 `chapterId`）。
- `chapterNo` 明确由卷序 / 章序权威派生，补首章、跨卷末章、自由卷、新建章回归；适配规范同步订正（章节快照 / 台账措辞、版本以 `serverInfo.version` 为准）。
- 补断连故障注入矩阵：端口无人监听 `HOST_UNREACHABLE`、非 JSON 响应 `HOST_BAD_RESPONSE`、结果不明走 `request_status` 核对并拒绝复用同一 `requestId` 盲目重做。
- 账本查询刻意豁免模式闸（切回 API 后仍可核对收尾结果），已加注释与模式切换回归。

## 四、可靠性与数据保护

- **网络**：非流式模型响应与错误响应的正文读取纳入超时 / 取消范围，不再出现「取消后返回迟到正文」；桌面联网检索按 renderer 身份取消请求，旧桥无取消能力时丢弃迟到结果。
- **备份恢复**：预备份后、首次覆盖前复查草稿 / 存储阻断 / 归属 / 项目版本；在途逐次写入前后复查，中断返回 `OUTCOME_UNKNOWN` 与安全预备份编号；主数据成功但参考资料失败时返回 `SAVE_FAILED`（含 `mainDataSaved` / `preBackupId`），不再误报完整成功。
- **知识库**：便携版 `/api/kb-txn` 跨文件事务 + 滚转日志恢复；恢复独立资料时增加上下文复核，失效即停止且不清理暂存。
- **单机竞争**：桌面 / 便携按规范化数据目录加本机独占端口，跨形态互斥、目录别名与强杀后恢复均有隔离验证；便携重启复用 `.last-port` 里的上次成功端口，避免已有页面断连。
