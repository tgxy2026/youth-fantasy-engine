# 青春幻想引擎 3.4.2 更新说明

> 一句话：**这一版把「接哪个 AI、用什么协议说话」这两件事拆开了 —— 官方原生端点可以直接填，自建端点可以自己选协议，连不上的时候软件会自己退一步再试，而不是直接报错。**
> 3.4.2 **没有新增页签、没有破坏性结构变更**，升级直接覆盖安装即可；已保存的模型配置照旧生效。

---

## 一、可以直接接官方原生端点了（多协议接入）

以前模型设置里只有两句话能说：**Ollama 原生** 和 **OpenAI 兼容**。想用 Anthropic Claude、Google Gemini、OpenAI Responses 的官方端点，只能去找中转服务把它们转成 OpenAI 兼容格式。3.4.2 把这三种**官方线协议**直接做了进来：

| 协议 | 用在哪 | 说明 |
| --- | --- | --- |
| OpenAI 兼容 | 原有 15 个联网预设、自定义中转 | 行为与 3.4.1 逐字一致 |
| Ollama 原生 | 本机 Ollama | 行为与 3.4.1 逐字一致 |
| **Anthropic Messages** | Claude 官方 / 兼容网关 | `x-api-key` + 版本头、顶层 `system`、具名流式事件 |
| **Gemini generateContent** | Gemini 官方 | `x-goog-api-key`、独立流式端点、`systemInstruction` |
| **OpenAI Responses** | OpenAI 新接口 | `input` / `instructions`、`text.format`、独立事件族 |

**为什么费了这么大劲**：原来「线协议」和「本机 / 联网」是挤在同一个字段里的（10 多处按它判本地，另有 10 多处按它判协议）。直接往里塞新值，会出现「碰巧能用但不报错」的静默错配 —— 比如采样参数发错通道、用量记错来源。这一版先把两个语义拆成正交字段，再接协议，**旧的存储键一个没改**，老配置读进来自动补默认值。

顺带补齐的配套：结构化输出按各家当期字段落成（默认不强下发，仍走能力闸）、各协议自己的模型清单、Gemini 的批量 embedding、能力声明、以及手册里新增的多协议章节。

## 二、自定义端点可以自己选协议了

以前只能靠「选一个平台预设」把协议带出来。如果你用的是自建 Anthropic 兼容网关、局域网里的远程 Ollama、或者路径不标准的中转，**只能继承上一个预设的协议** —— 地址是 A 家、说话方式还是 B 家，界面不会报错，只会一直连不上。

现在模型编辑表单里多了一个「**接口协议**」下拉，选预设仍会自动带好，自建端点手工指定即可。切换协议时会同步清空该端点已拉取的模型清单与结构化输出确认，避免拿旧结论套新端点。

🔴 顺手修掉一只真虫子：从 Ollama 切回 OpenAI 兼容时，「本地」标记没复位，联网模型会顶着「本地」混进本地预设组。已修并补了单测锁住。

## 三、连不上时不再直接放弃（三家官方协议的兼容降级）

新接的三家协议以前**只发一次请求，收到 400 就报错**。真实场景里有两种很常见的「不是你的错」：

| 情况 | 现在的处理 |
| --- | --- |
| 推理系模型不接受 `temperature ≠ 1`（Responses 原话常含 `with this model`） | 自动撤掉采样参数，**重发一次** |
| 兼容网关不认 `output_config` / `responseJsonSchema` / `text.format` 这些结构字段 | 自动撤掉结构字段，**重发一次** |
| 流式 SSE 事件族不标准、解析不出内容 | 自动退成**非流式**再要一次 |
| 模型名写错 / 鉴权失败 / 额度不足 / 内容政策 | **一次都不重发**，原样告诉你真实原因 |

一次逻辑调用最多发 **3 次请求**，是同一本账（流式重试也计入）；耗尽即停，并且报错里写明「已发出 N 次请求」，不会让你以为只试了一次却付了三次钱。需要严格单次的 Chain（如续写规划）全程只发一次。用量记录里也会回填 `attempts`。

🔴 判据按协议分开写，不串味：不能把 OpenAI 那条降级规则照抄过来 —— 它把 `model` 当「配置写错」的关键词，而推理模型的原话就是 `is not supported with this model`，照抄会让温度 400 永远降不下来。

## 四、网页版：如实标注「未验证」，不伪装可用

网页版是**浏览器直连厂商**，能不能用取决于厂商是否允许当前网站跨域（CORS）。这一版没有新增服务端代理，所以：

- 新增一张四态台账（通过 / 阻塞 / 未运行 / 不适用），界面照它说话；
- 台账没有结论时，编辑表单与模型列表会显示琥珀色「**网页未验证**」徽标，并说明「浏览器直连、失败可能是跨域、密钥在浏览器可见」；
- 桌面版与便携版**文案逐字不变**（它们不受这条限制）；
- Ollama 在网页形态说「不连接本机（产品策略）」，不冒充 CORS 结论。

当前台账全部是 `not-run`：本机出网走代理，`Failed to fetch` 分不清「跨域被拒」和「网络不可达」，**既不写可用、也不写被拒**。拿到干净网络后逐家实测，把结论填进台账，界面会自动跟随。

🐛 顺带补上一个一直缺的功能前提：Anthropic 官方要求浏览器直连时带 `anthropic-dangerous-direct-browser-access: true`，以前从没发过 —— 网页形态下必被拦。现在仅网页形态下发，桌面请求逐字节不变。

**验收复核如实**：本版先出了一份独立复核报告，查出两项与规划不符的偏差（新协议缺兼容降级、网页形态缺 CORS 标注），**两项都已整改并补了证据**，不是带病发布。

**没有做、也不当作已通过**：

- 桌面安装包 GUI 启动与完整安装流程回归、便携 exe 实机；
- 写锁专项本轮未重跑（3.4.0 已覆盖，本版未触及写锁链路）；
- 真实模型质量双人盲评与提示词 A/B 实弹对照、双设备同步冲突、真实断电；
- 已知降级 R-1：创意连写的检查点与章节落库不是跨存储事务，极端崩溃时最坏会重写最后一章（界面已写明）。

## 六、版本边界与下一版

- **3.4.2 只交付「多协议接入」这一条线**（开发线二）。
- 原本同批规划的「**Agent 软件对接**」（开发线一）已由主人拍板**整体移到 3.4.3**，本版不启动、不写产品代码；其开工前仍需先定路线与条款条件，详见 `docs/3.4.3-开发规划-Agent软件对接-2026-11-07.md`。
- 暂缓项照旧：Amazon Bedrock Converse 与厂商私有协议、embedding 旁路的协议统一、网页形态的服务端 AI 代理。
- 红线不变：**AI 只辅助**；不做反检测 / 洗 AI 痕迹，只存证 + 自检 + 如实申报。

**升级提示**：

- **桌面版**：直接覆盖安装，程序数据在 `%APPDATA%\youth-fantasy-engine`，不会被覆盖；
- **便携版**：解压新包后，把旧包的 `data/` 目录整体拷进新包同级位置；

> 🔴 网页版说明：游客模式的数据只存在你自己的浏览器里，**不会上传到服务器、不跨设备**；跨设备需要登录云端账号。密钥由你自己提供，在网页形态下浏览器可见 —— 这是既有边界，本版没有改变。
