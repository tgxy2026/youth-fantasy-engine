## 5. 复核发现（与记录不一致或需修正）

### 5.1 `export-products-340` 在 Git Bash 下必失败（脚本缺陷，非产品）

- 现象：首次复跑在 EPUB 解包处失败 `tar: Cannot connect to F: resolve failed`。
- 根因有两层：① `/usr/bin/tar` 是 **GNU tar 1.35**，把 `F:\…` 当 `host:path`；② GNU tar **不认 ZIP**（EPUB/DOCX 都是 ZIP），改相对路径后报 `This does not look like a tar archive`。前序记录「11/11 通过」应是在 Windows 自带 bsdtar 的 shell 下跑的。
- 处理：脚本改用 .NET `System.IO.Compression.ZipFile::ExtractToDirectory`（不看扩展名，Windows 原生）。
- 结果：修复后 **11/11 通过**（产物字节数：md 287,414 / epub 332,870 / docx 507,544 / submission 1,370,710 / txt 287,293）。
- 判定：**验证脚本可移植性问题**，产品导出无缺陷。

### 5.2 桌面脚本的执行前提

`ELECTRON_RUN_AS_NODE=1` 与 `NODE_OPTIONS=…node-language-shim…` 会让 `_electron.launch` 直接 `Process failed to launch!`。清掉这两个变量后 24/24 与 3/3 均通过。已与项目既有口径一致，但**必须写进跑法**，否则会被误判成产品故障。

### 5.3 过期注释（P3，已修）

`src/components/common/MasterDetail.tsx` 的用法示例仍引用技术债整改中已删除的 `CARD_SHEET_CHROME_PX`。已改为不含该常量的示例，不影响行为。
