# 青春幻想引擎 3.4.0 更新说明

> 一句话：**这一版把「规划、资料、时光机、收藏、导出、灵感」串成了一条能往返的工作流 —— 从规划板进章、回来还在原地；资料绑定看得见；时光机恢复不再半途而废。**
> 三条主线：规划板与正文的往返保住现场、本章资料与快照的可验证、跨章节的整理与导出。
> 质量上补了「文件后端强杀」「三形态整页纵切」「六维 + 全量审计」三类证据；仍属**功能验收通过**，不等于所有环境都已实机验收（边界见第八节）。

---

## 一、规划板：进章再回来，还是原来那一屏（A）

以前从「章节规划板」点进正文，回来时展开状态、筛选词、分卷、滚动位置全丢，长篇里等于重新找一遍。3.4.0 把这份现场按**项目**记在本机：

| 项 | 以前 | 3.4.0 |
|---|---|---|
| 展开/收起 | 每次重置 | 按项目记住 |
| 分卷、状态、关键词筛选 | 回来即清空 | 原样恢复，**不会串到另一本书** |
| 滚动位置 | 回到顶部 | 回到离开时那一屏 |
| 目标章已被删除 | 静默落到别处 | 明确提示该章已不存在 |
| 读取失败 | 当成空列表 | 说明读取失败，不拿空数据覆盖 |

规划板仍是**只读视图**：不拖动排序、不改章节内容、不改正式顺序；「状态与正文对不上」依旧只提示 ⚠，不自动改状态。

### 章卡上直接看到资料绑定（A.3）

每张章卡多了一行「细纲：卡名 · 固定资料 N 条」，三种状态分得很清楚：

- **已绑定**：显示绑定的细纲卡名与本机固定的资料条数；
- **未绑定**：明确写「未绑定细纲」，而不是空着让你猜；
- **已失效**：绑定的细纲卡已被删除时如实标「已失效」。

口径上守死一条：**只读你亲手绑定的关系，绝不按章节名或细纲名去猜**。细纲页签没启用的项目不显示这一行。

## 二、本章资料：绑定、固定、关掉重开都还在（B）

- **绑定/解绑**与**固定/取消固定**都有明确反馈，关掉面板再打开仍保持原状态；
- 宽屏正文与资料并排；**窄窗**改为可收起抽屉，不压住写作区；
- 资料读取失败时**禁止写入**（避免把「读不到」当成「空」覆盖掉你的绑定），目录读取失败也不会假报「已删除」；
- 切换章节/项目时，迟到的旧结果不会覆盖新章节的资料（请求序号守卫）；
- 「固定」不等于「自动发送」：是否进 AI 上下文仍以续写清单里勾选的那份为准，本版没有暗中扩大发送范围。

---

## 三、时光机：恢复要么成功，要么什么都没动（C）

恢复历史版本改成**事务顺序**：校验目标归属 → 先把当前草稿按新版本留档并读回 → 落库 → 才改界面。

- 留档或保存失败 ⇒ **停止覆盖**，保留你的草稿并说明原因，不会出现「界面变了、数据没变」；
- 恢复后重开仍是恢复后的内容（有实机验证）；
- 恢复范围说明写清楚：**单章恢复不等于整本作品恢复**；
- 仍沿用每章 12 版上限与淘汰规则，**命名快照不是永久归档**。

### 命名快照（C.3）

可以给某个版本起名字、写备注（例如「投稿前定稿」），创建后会**读回核对**再确认落盘；与自动快照共用同一份 12 版额度。手动导出的项目包含这些快照，**自动备份不含**。

---

## 四、章节收藏集：把跨卷的章收到一起（D）

- 项目内命名、加/减成员、点开原章；**删除收藏集不会删除章节**；
- 默认按现有叙事顺序显示，不改变正式顺序、不复制正文；
- 成员章节被删后显示为**不可用**，可手动移除，不静默消失；
- 项目隔离：一本书的收藏集不会跑到另一本书里。

---

## 五、导出方案：按需选章，别每次都导全书（E）

- 「平台粘贴版 / Markdown / 投稿 DOCX」支持**选定章节**导出，导出前列出将要导出的清单；
- 可以把这套选择存成**具名方案**（按项目保存章节 ID），下次一键复用；
- 方案里有章节已被删除时**列出失效章节并拒绝直接应用**，让你先处理；
- 不选新选项时**仍是原来的全书导出**，老习惯不受影响；
- 文案里写明：**稿件导出不是完整备份**（真要搬家请用项目包）。

---

## 六、随手记：想到就记，还能跳回去（F）

- 写作面板可直接把一句话记进本作品的灵感夹，不需要模型；
- 可选关联到某一章；关联只存引用、不复制正文；
- 灵感条目上的关联章节是**可点的「打开 →」**，直接进那一章；章节已删只标「不可用」，不给你一个死链；
- 保存失败**保留输入**并明确报错；带着没保存的内容离开页面会被拦一下并再试一次。

---

## 七、数据安全：跨窗口写入不再互相覆盖

- 同一账号多窗口/多标签同时改设置时，用同源写锁（Web Locks）串行化，先比对旧值再写；
- 浏览器不支持 Web Locks 时**拒绝写入**，而不是降级成「可能覆盖」；
- 导入/恢复时对本章资料绑定、收藏集、导出方案、灵感章节引用做 **id 重映射**；映射不到的保留「失效」标记，不静默丢失、不误指到别的章。

## 八、质量与验证（说清楚做了什么、没做什么）

本版做的：

| 项 | 结果 |
|---|---|
| 类型检查 / lint / 构建 | 通过 |
| 全量单元测试 | **420 / 0** |
| 六维 + 全量审计（先契约证据再跑） | **complete，0 静态候选 / 0 失败契约** |
| 界面整页纵切（网页 / 桌面 / 便携三形态） | 各 **24 / 24**，写锁 3 / 3 |
| 文件后端创意连写强杀（桌面 / 便携） | **5 / 5 + 5 / 5**，每次强杀后数据文件均为合法 JSON |
| 本章资料绑定/固定/重开 | **9 / 9**（浏览器实机） |

本版顺便修掉的：

- 帮助中心、页签「?」气泡、确认框里的 `**强调**` 以前会**原样显示星号**，现在正常加粗（不影响正文与 AI 输出）；
- 审计工具 4 处误报（跨行常量、注释里的标签、装饰遮罩、已用 `response_format` 兜底的提示词）已修正，真实候选一条没少。

**没有做、也不当作已通过**：

- 真实模型的双人盲评（需要实弹与人力）；跨设备同步冲突与「云端下载为新书」的真机往返；
- 真实断电（模拟强杀 ≠ 断电）；第二本项目切换过程中的强杀；
- 已知降级 R-1：创意连写的检查点与章节落库不是跨存储事务，极端崩溃时最坏会重写最后一章（界面已写明）。
