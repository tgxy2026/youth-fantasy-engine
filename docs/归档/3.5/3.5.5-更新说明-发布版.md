# 青春幻想引擎 3.5.5 更新说明

这一版把桌面 ACP 从「七个纯文本入口」扩到了「结构化审校 + 设定整理 + 编辑器伴写 + 酒馆全链路」，同时把等待时间压下来一大截，并修掉了几处会让人卡住的稳定性问题。

**适用范围照旧**：ACP 仍然只对 Windows x64 桌面安装版开放。便携版是 API 和 MCP 两种模式，网页版沿用原来的模型入口。

## 一、ACP 能做的事情变多了

### 审校类（要求 Agent 返回结构化结果，由引擎逐项校验）

| 入口 | 交付 |
| --- | --- |
| 章节编辑意见 | 六维打分 + 逐条意见，分数、维度、引文位置都会核对 |
| OOC 人设偏离检查 | 角色维度比对，越界或漏字段直接报错 |
| 续写方向 | 多个可选方向，不落正文 |
| 文字校对 / 逻辑校对 | 按块发送，整章只确认一次授权 |

校验是硬的：截断、缺字段、引文对不上，都会直接报错，**不会把半份结果显示成完整结果**，也不会悄悄改用 API 模型。

### 设定与整理类

- 设定补登的「扫描本章」
- 章后整理
- 设定表的 AI 整理与模板补全

这些只产出**候选**（实体、伏笔、关系、状态、表格行、字段值），是否已登记由程序按名称与别称精确比对，写入仍然是你逐条勾选、点应用之后的事。

### 编辑器伴写

停笔与 `Alt+\` 手动触发都能走 ACP。它只发光标前正文与设定摘要：

- 首次触发会说明外发范围，之后同一 ACP 会话不再重复打扰
- 同一章节内复用同一个会话，换章自动换新会话，上下文不跨章
- 每句最多复用 6 次后自动重建，避免历史越滚越长

### 酒馆

剧情推演与自由对话的主回复、每轮数值结算、轮次摘要与角色记忆、推演报告、角色日记、角色卡与剧本起草、小说角色转换、访谈问答、修订建议、世界观条目起草，都能走 ACP。

**逐章连写与批量摘要仍用 API 模型**——它们要跑很多轮，不适合走 ACP。

## 二、等待时间

这是本版投入最多的地方。实测对照（同机、同一句伴写）：

| 版本 | 单次总耗时 |
| --- | --- |
| 3.5.4 / 初版接入 | 约 48 秒 |
| 本版（进程保活） | 约 4 秒 |
| 本版（会话复用） | **约 1.7 秒** |

做法是两条：

1. **预热 + 进程保活**：连接后不杀 Agent 进程，之后的任务复用同一个进程与 ACP 连接，不再每次重付 10~16 秒的冷启动税；
2. **会话复用**（仅伴写）：同一章内复用同一个 ACP 会话，省掉每次约 4 秒的建会话开销。

每个任务仍然新建独立会话，**上下文不会在任务之间串味**；空闲 10 分钟自动回收，配置变更、进程崩溃、传输异常都会自动重建。

**需要说明的白话**：本版每次重启应用后的**第一次** ACP 调用仍然要等约 12 秒建立连接，这属于 Antigravity 组件自身的冷启动开销（官方文档里也是 15~16 秒），我们只能把它挪到连接时，无法消除。

## 三、运行方式可选

「ACP 连接」里运行方式有两项，默认是**以当前 Windows 用户运行**：

- **当前 Windows 用户**：不需要创建账户或管理员批准，直接复用已有登录；但 Agent 及其子进程会用你的文件权限读写，请只连接可信的 Agent。
- **使用 Windows 隔离**：点「开通 Windows 隔离」后由管理员批准创建专用标准账户，再在该环境单独登录 Google。两种方式各自使用自己的登录资料，切换时互不覆盖。

界面上会如实写明当前用的是哪一种。

## 四、界面与操作

- **AI 伴写从「工具」菜单里拆出来**，成为工具栏上紧挨「颉文姬」的独立按钮；「工具」下拉只剩整理与检查、版本与检索、写作视图三组。
- **「本页指引」统一到左下角**：正文编辑、开书定位、伏笔追踪三个页签不再在页头重复放一个按钮，也修掉了「页头能点、左下角却写此页无」的自相矛盾。
- **设定检索图标方向纠正**：展开时箭头朝左（点它收起），隐藏时朝右（点它展开）。
- 文案整体做了一轮统一：人称统一用「你」、提示语标点统一、手册里过时的入口说明逐条更正。

## 五、稳定性

- **「ACP 进程退出未确认」不再需要手改文件**：异常退出留下的运行标记会在下次连接或点安全恢复时自动核对归档；只有进程树确实还在时才阻断。
- **安全恢复先清运行标记**：以前会先撞上一个空标记、失败两次才成功，现在一次过。
- **模式不可用时回到上次的模式页面**，不再落到一个你从没去过的页签。
- **退出应用会真正释放模式锁**，并加了 15 秒兜底，不再出现「重启后锁还挂着」。
- **ACP 建会话失败会重试一次**，并把 `-32603` 翻译成可读原因（网络 / 账号 / 额度），不再只丢一句通用错误。
- **异常退出留下的工作目录会自动清理**（启动后扫一次，停用连接后再扫一次），只清 `sessions/work-*`，10 分钟内还有改动的不动。

## 六、这一版不做什么

- 便携版、网页版**没有** ACP，这是架构决定的：ACP 要拉起本地 Agent 进程、管进程树与回收，依赖 Electron 主进程。
- ACP 模式下**引擎发不出嵌入请求**，语义召回会自动降级为本地关键词匹配，注入段标注「匹配度」而不是「相似度」。要恢复完整召回，切回 API 模式后重建索引。
- 逐章连写、批量摘要仍走 API 模型。
- 地图与地点、情节画布、世界包、备份恢复等写入类能力只对外部 MCP Agent 开放，ACP 不涉及。

## 七、升级提示

- 装新版前建议**完全退出**旧版（含托盘），否则可能留下旧的 Agent 进程。
- 如果你之前点过「安全恢复」或遇到过程序异常退出，新版不需要你做任何手工清理。
- ACP 第一次调用仍会慢十几秒，这是组件冷启动，不是软件卡住；界面上有「正在连接并读取模型选项…」的提示。
