# 青春幻想引擎 3.5.6 更新说明

这一版把 ACP 的覆盖面补齐到「几乎所有 AI 入口」，并修掉一批「零 API 配置下按钮点不动」「长任务到点必失败」的问题；界面侧新增一个独立的后台任务页，全书优化工单也改成可以按卷、按章选范围生成。

**适用范围照旧**：ACP 仍然只对 Windows x64 桌面安装版开放。便携版是 API 和 MCP 两种模式，网页版沿用原来的模型入口。

## 一、零 API 配置下，AI 入口不再"点不动"

上一版把 ACP 接进来后，仍有一批入口按"有没有配置 API 模型"来判断可用性：明明 ACP 已连上，按钮却是灰的，或者点下去只弹一句"未配置模型"。这一版逐个改了判据：

- 写作面板的 AI 健康诊断、表格类页签的 AI 整理与补全、角色与设定的 AI 起草、章节编辑意见、OOC 检查、续写方向、文字 / 逻辑校对
- 检查工具里的连续性、伏笔、节奏与章末钩子、读者视角审问、变化清单、按章反推写作规范、正文与细纲对照
- 一键拆书、情节推演画布、创意写作三阶段、联网检索的归纳步骤
- 全书优化工单的逐章改写与最新章设定整理

判断标准统一成「API 模型 或 可用的桌面 ACP 连接，任一就绪即可」。未就绪时的提示也统一了句式，说明是缺 API 还是缺 ACP 连接，不再出现"配了模型却提示未配"的自相矛盾。

**唯一的例外是投稿审核**：它要求待审正文只在本机或局域网模型上处理，ACP 适配器无法证明这一点，所以在 ACP 模式下会直接说明原因，不会悄悄换个通道跑。

## 二、长任务不再「到点必失败」

| 问题 | 这一版的处理 |
| --- | --- |
| 单次生成固定在 180 秒超时，逻辑校对、工单改写、拆书这类长任务经常撞线 | 上限放宽到 **5 分钟**，普通请求仍是 30 秒 |
| 超时后只有一句「ACP session/prompt 超时」 | 改成「已等待 300 秒，Agent 未在限时内返回」，并给出三条可操作建议：缩小范围、换更快的模型或推理档位、切回 API 模式重试 |
| 说不清到底能等多久 | ACP 设置页与使用手册都写明「单次生成最多等 5 分钟」，逻辑校对这类一两分钟属正常 |

## 三、上下文预算看得见了

「模型设置 → ACP 连接」新增上下文预算区：

- 按 **Agent + 实际模型** 装配窗口大小、发送上限与输出预留，手填值优先于会话回报
- Agent 没有回报窗口时，明说「按 32768 tokens 保守估算」，不再假装知道
- 发送量还会受运行层 **256 KiB** 上限约束，界面会标出这次到底按哪个值生效
- 酒馆控制面板的额度说明与这里同源，不再出现「0K 窗口」这种自相矛盾的说法

## 四、后台任务有了自己的页签

原先任务列表内嵌在左下角「界面与数据」工具栏里。那块工具栏为了给左侧菜单让空间常被折叠，一折叠就再也看不到任务——等于把「切页签不会中断」这个承诺的唯一可见入口藏了起来。

现在它是「工作面板」组里的独立页签，位置在**模型设置与使用指南之间**：

- 运行中：看进度、随时中止（只有你点才会停）
- 已结束：保留最近 5 条，点「查看」跳回发起它的页签；失败与中途取消都能回看原因
- 新建项目时它默认勾选、不可取消（关掉就真的无处可看了）
- 页签没打开时，任务完成的提示仍会以 toast 弹出，不会漏

## 五、优化工单可以选范围了

以前「生成工单」一次就扫全书。写到几百上千章时，这一下代价太大。现在生成前可以先选范围：

- 按卷折叠、按章勾选，支持整卷选择与半选态
- 默认选中**最近编辑的那一章所在的卷**，并按项目记住你的选择
- 显示「已选 N 章 / 共 M 章」；单次超过 100 章会提示「建议按卷分批」，但不拦你
- 再次生成只替换**所选范围**的条目，其它范围已生成的结果会保留

## 六、文案与进度的一批修正

真机上暴露的几处"读起来别扭"的地方：

- 校对进行中，红色按钮原来写「停止文字校对中（0/0）」——把动作和状态揉成一句，进度还是 0/0。现在按钮只写「停止校对」，状态与进度挪到下面一行：「文字校对中 · 已完成 1/3 段」；还没切分完时说「正在切分正文…」
- 颉文姬诊所的停止按钮在总数未知时不再显示 (0/0)
- 优化工单的运行进度在总数未知时说「准备中…」，不再出现「已处理 0 / 0 章」

## 七、手册

- 新增「后台任务」一篇，页签上的帮助按钮可直接跳转
- 「外部 Agent 协作」补「等多久算正常」与超时后的三种做法
- 优化工单补范围选择说明

## 已知限制

1. **每次重启应用后要点一次「连接已有会话」**——会话状态不跨进程保存，Google 登录态会保留
2. **投稿审核不参与 ACP**（原因见上）
3. Agent 不回报上下文窗口时按 32K 估算，可手填真实容量
4. 连续重连有时会长时间停在「正在连接并读取模型选项…」，属于外部 Agent 侧的状态，重试或重启应用可恢复
5. 便携版与网页版不提供 ACP
