# 青春幻想引擎 3.5.4 更新说明

这一版给 Windows 桌面版加上了第三种模型接入方式：除了原来的 API 和 MCP，现在还可以连接本机安装的外部 Agent（ACP）。同时修掉了几个只在特定路径下才出现的启动和登录问题。

**适用范围先说清楚**：ACP 只对 Windows x64 桌面安装版开放。便携版仍是 API 和 MCP 两种模式，网页版沿用原来的模型入口。

## 模型设置的三种模式

「模型设置」现在按运行形态提供三种模式，同一时间只运行一种：

- **API 模式**：用你自己配置的模型服务，和以前一样。
- **MCP 模式**：连接外部 MCP 客户端，供需要外部工具的场景使用。
- **ACP 模式**：连接本机的外部 Agent。首版只支持 Antigravity，按适配器分别保存组件位置、登录状态、模型和推理档位。

切换模式是有门禁的：正在跑的任务会先排空、确认运行时已退出，然后才提交新状态。切换和阻断期间只允许查询状态、取消和清理，不会让两边同时写同一份正文。便携版和网页版直接请求 ACP 会被拒绝。

## 能做什么，不能做什么

3.5.4 的 ACP 只覆盖**由你手动发起、能独立完成、以正文或文本报告交付**的纯文本任务，共七个：

| 入口 | 交付形式 |
| --- | --- |
| 手动续写 | 正文，沿用原来的预览与确认采纳 |
| 选区润色 | 正文，位置变了会拒绝旧结果 |
| 综合诊断 | 文本报告 |
| 爽点毒点 | 文本报告 |
| 黄金三章 | 文本报告 |
| 写作简报 | 文本报告 |
| 手动单章摘要 | 文本报告，可回填摘要框 |

依赖 JSON、固定字段或结构化落库的功能（结构化任务、后台伴写、酒馆、嵌入等）不在本版范围，后续版本处理。

发送前会确认接收方和资料范围；等待期间如果你改了草稿或资料，会保留你的输入，不会拿旧内容去覆盖。

## 组件、登录与模型

- 可以从 Google 官方渠道安装 Antigravity 组件，下载后会校验 ZIP 摘要、主程序与 helper 的 SHA-256，以及 Google 的 Authenticode 签名。
- 登录走组件自己的 Google OAuth 流程，认证地址只在登录过程中解析，不会回传给页面，也不会写进日志。
- 登录后可以读取会话提供的模型和推理档位（如 Gemini 3.8 Flash 与 Low / Medium / High），选择结果会保存；无效值会被拒绝，可恢复默认。
- 打包环境里组件的登录提示有时不走系统浏览器变量，本版改为同时解析组件自己输出的认证提示，仍然只接受 Google OAuth 的域名与路径。

## 修掉的问题

- **深路径和中文路径启动失败**：工作目录层级一深、或路径里带中文，组件会在解包阶段中断。现在每次启动都使用独立的短临时目录，会话目录和账号配置保持不动，退出时清理。短路径、中文路径、长路径和深账号目录四种组合均握手正常。
- **「其他设定」「分卷大纲」「章节细纲」等纯文本卡片上的立绘上传区**：这些卡片本来就没有人物立绘，之前却会显示上传入口，历史立绘数据还会被当成头像渲染。现在立绘只对角色卡开放，其他卡片既不上传也不显示。
- **ACP 设置排版**：组件已配置时的维护操作不再折进二级菜单，重新登录和退出账号直接排在「账号与连接」里，宽屏四个按钮同一行、窄屏自动换行；「取消 ACP 操作」和 Agent 选择框放在同一行。
- **桌面默认图标**：等比放大后可见边长从 205 像素增至 243 像素，安装包、主程序和应用内默认图标使用同一份资源。

## 需要你知道的限制

- **文件隔离还没有做完**。当前连接的 Agent 以**你自己账号的权限**运行，能读到你能读到的文件。请只连接你自己信任的 Agent，不要连接来路不明的适配器。独立标准用户沙箱方案已完成选型，验收通过前不作为已完成能力对外承诺。
- 本版的 ACP 只在 Windows x64 桌面安装版上验证过。其他平台、其他 Agent、以及从旧版本覆盖升级的路径未做完整验收。
- 七个纯文本入口里，逐入口的界面链路、诊断的完整与简略、取消与换号，以及正式安装流程仍在补验；已跑通的是合成输入下的协议、流式、取消和归属校验。
- 便携版不提供投稿广场，也不提供 ACP。
