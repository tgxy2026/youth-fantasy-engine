# 2.7.0 更新说明

## 2.7.0 · 自由章节 + 伴写文风多维多选 + 去 AI 味儿重做 + 表格批量导入导出

⭐ **正文编辑新增「自由章节」**：不必先建卷，直接就能「新建自由章节」——由一个默认隐藏的分卷收纳。自由卷恒排**全书最前**，且**自由章不占正文序号**（正片仍从「第 1 章」起）。自由卷禁删禁拖；建卷序号与卷计数只数真卷，不会被带偏。

⭐ **AI 伴写「文风补充」全面细化**：原来的两个固定项拆成 **3 组共 18 项**（人物 / 心理 / 环境 / 动作 / 感官 / 对白推进 · 情节 / 冲突 / 悬念 / 节奏 / 伏笔 · 情绪 / 画面感 / 留白 / 幽默 / 白描 / 细腻 / 古风），每一项都写了「怎么算做到」的引导语。互斥项（白描简练 ↔ 细腻铺陈、留白 ↔ 细腻铺陈）页面只提示、不禁用；一次选超过 3 项会提示「会稀释」。保留一句话自定义（默认空白、输入后生效），按全局记忆，切换项目沿用。

⭐ **去 AI 味儿统一重做**：相关规则此前散在续写与伴写两处、口径不一致，现收敛为**单一真源**（硬 tell 41 条 + 句式模板 9 条 + 正面原则 8 条 + 兜底说明），并首次挂到「整章改写」（此前完全没挂）；伴写、续写初稿、创意写作的润色模板同步生效。这是**文风质量**功能，只讲「怎样写得更像人」，不涉及任何检测绕过。

⭐ **表格类页签 · 批量导入导出**（社区反馈）：已有成体系的设定，可一次整批搬进项目。三种方式各取所需——

| 方式             | 适合情况             | 怎么用                                                 | 耗额度         |
| -------------- | ---------------- | --------------------------------------------------- | ----------- |
| ① 照着模板填        | 设定条理清晰 / 愿意手动整理  | 下载空白模板 → 填好 → 粘贴或选 CSV 文件（Markdown 表格、Excel 直接复制也认） | 否，纯本地解析     |
| ② 交给别的 AI 整理成表 | 散文式设定，想让外部 AI 誊写 | 下载「导入说明 / AI 提示词」→ 连原文发给那个 AI → 拿回表格粘进来             | 否，用外部 AI    |
| ③ 本项目 AI 智能拆分  | 懒得手动整理           | 粘贴内容 → 点「AI 智能拆分」，用当前配置的模型拆成多条（长文自动分批）              | 是，用本机已接入的模型 |

跨表引用存的是**名称字符串**（不是编号外键），所以只要名称与目标表逐字一致，**导入后勾稽关系天然成立**；对不上的名称只在预览里提示、绝不改写你的数据。

🔧 **其他改进**：

- 伴写偶发漏标点修复：折行处会按前后文补上「，」（此前会把两小句粘成一串），提示词另补一条硬要求；
- 六维审计修复十余处：云盘同步的密钥清理提前到**启动期**（没打开项目就开同步，也不会把含密钥的字段随项目文件带上云）、酒馆「结算期停止」不再抹掉已经生成的回复、表格批量导入中途失败时先前成功行先入库（避免重试重复写入）、若干界面文案与真源口径对齐。
