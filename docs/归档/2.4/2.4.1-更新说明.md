# 青春幻想引擎 v2.4.1 更新说明

> 发布日期：2026-09-22 ｜ 安装包：`青春幻想引擎-Setup-2.4.1.exe`（80.9 MB）
> 桌面版（Windows x64）。本项目**只做桌面版**，没有网页版 / 便携版。

---

## 一句话

**2.4.0 铺好了"能写、扛得住、可自证"的地基；这一版把它压实 —— 修掉一个会静默写错角色档案的隐患，收拾干净一批"小别扭"。**

这是一版**打磨与加固**：没有新页签，但有一处**数据安全修复**（强烈建议升级）和一批手感修正。

---

## 一、🔴 重要修复：多角色收尾不再"张冠李戴"

**症状**：酒馆自由对话里，一场有**多个角色**的对话点「结束本轮对话」时，AI 给 A 整理出的记忆
**可能被写进 B 的档案里**。

**为什么会这样**：收尾要逐角色整理记忆。整理过程中若有**某一位的记忆读取失败**
（比如存档在那一瞬间被云盘占用），程序会跳过这位、继续处理下一位 ——
但写回时用的**编号已经和角色错位了**，于是后面的记忆统统往前串了一位。
更糟的情况：串到最后一位越界，整场收尾直接中断。

**现在**：编号与角色严格对齐，读失败的那位**本轮跳过、不写**（并在收尾提示里如实说明），
其余角色的记忆各归各位。

> 这个 bug 是**静默**的 —— 界面照样显示「本轮已结束」，你不会收到任何报错。
> 所以这一条是本次升级的**首要理由**。

## 二、AI 相关的口径修正

| 你会感觉到什么 | 修了什么 |
|---|---|
| 你**刻意隐藏**的消息，不再被当成判定依据 | 推演报告与记忆整理在统计时漏过滤了隐藏消息 —— 你"藏起来"的内容反而进了 AI 的参考材料 |
| 酒馆未配模型时，**发送键直接变灰并说明原因** | 之前链路里没有"就绪守卫"，未配模型时点发送会一路走到模型层才失败（甚至被流式状态吞掉），你会以为"这功能坏了" |
| 写作预算面板的数字**和真源对得上** | 面板文案里把阈值（30% / 48000 字）**硬编码**了一份，改设置时两处会不一致 → 现在由同一份常量生成 |

🔴 顺带说明一个**判据问题**：酒馆的模型来源是「会话 → 控制面板默认 → 全局活动模型」这条三层兜底链，
而**不是**只看全局活动模型。所以"未就绪"的判定也严格走同一条链 ——
**你在控制面板指定的模型，只要能用，就绝不会被误判成"没配"**。

## 三、同步与存储

| 你会感觉到什么 | 修了什么 |
|---|---|
| 启动时自动恢复云盘同步，**不再和写盘锁打架** | 这条路径少了"存储不可写"的检查（手动路径有、启动路径漏了）—— 两处现在对称 |
| 同步快照**不再夹带本地专属配置** | 生成对比快照时补上了敏感键的排除逻辑 |

## 四、界面与手感

| 你会感觉到什么 | 修了什么 |
|---|---|
| 卡片页头**不再"从表头上面穿过去"** | 之前靠「容器内边距 24px」与「负外边距 12px」两者**恰好抵消**来定位，任一改动就会穿帮 → 改为不依赖这种巧合 |
| 编辑器正文与高亮叠层**严格对齐** | 双图层之间差了一个**滚动条宽度**，长行文字与高亮会错开几个像素 |
| 编辑器叠层**不再被朗读器误读** | 给装饰性叠层补了无障碍标记 |
| 复制申报说明**走统一入口** | 之前绕过统一封装直接调浏览器剪贴板，在部分环境下会静默失败 |
| 术语统一为「有未保存的改动」 | 之前两种说法混用（「未保存」/「未保存的修改」） |
| 跳转提示**不再写错版式** | 页面说明里残留的 markdown 星号（会原样显示成 `**这样**`）已清 |
| 「跳过」按钮**不再是看不见的幽灵键** | 首启向导的跳过键改用与同排一致的次级按钮样式 |

## 五、内部加固（你看不见，但下次改动更安全）

- **新增两道防回退测试**：酒馆的"在哪个模型上就绪"判定（含负面对照）、AI 数据来源清单与真实页签名的对账
- 修掉一个**扫描工具自身的缺陷**（它会把文件中第一处相同代码当成目标，导致误报）
- 一批"魔法数字"收敛到统一常量（下次调整间距/高度只改一处）

## 六、安装与升级

- 直接运行 `青春幻想引擎-Setup-2.4.1.exe`，覆盖安装即可，**原有项目数据自动保留**
- 从 2.4.0 / 2.3.x 升上来不需要额外操作（数据迁移在新版本首次启动时自动完成）

## 七、数据与隐私

- 软件**不做账号体系**，不收集你的稿件
- 涉及 AI 的功能：**原文只发送给你当前选定的那个模型** —— 本地模型则不出本机；云端模型会上传到该服务商
- 模型密钥、搜索密钥等敏感配置**仅保存在本机**，不随云盘同步文件外流
- 云盘同步文件是加密的（内置密钥），**足以防误看，但不足以对抗蓄意破解**；涉密稿件请另用导出备份自行保管

## 八、已知事项

- 超大表格（3000 行以上）渲染偏慢，已记录待优化
- 云盘同步仍是"文件夹同步"机制：依赖你所选的网盘客户端（OneDrive / WPS 云盘 / 百度网盘 / 坚果云 等）
- 本版本只提供桌面版安装包
