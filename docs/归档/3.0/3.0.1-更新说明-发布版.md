# 青春幻想引擎 3.0.1 更新说明

> 发布日期：2026-10-12 ｜ 桌面安装版（Windows）+ 便携版
> 上一版：3.0.0（2026-10-11）

---

## 一句话

**3.0.1 是「接着 3.0 打磨」的版本**：新增**正文批量导入**（一次把整本书的稿子拖进来），补上**首启向导的模型配置**（与「模型设置 → 模型配置」彻底同源），修掉主人反馈的**三个界面问题**，并跑了一轮**全量六维审计**（P0 / P1 均为 0，另修 8 处隐患）。

---

## 新增

### 1. ⭐ 正文批量导入 —— 一次把整本书拖进来

**入口**：正文写作 → 正文编辑 → 章节栏右上「**批量导入正文**」

- **支持格式**：`.txt` / `.md` / `.docx` / `.json`；**多文件批量**（最多 50 个，单文件 ≤ 20 MB）。
- **预览树**：导入前先看清楚 —— 卷名 / 章名**可以直接改**、逐章勾选、可删卷删章。
- **JSON 双向格式**：导出的 JSON 可以再导回来（换机搬运、跨版本搬运都稳）。
- 🔴 **纯本地**：不接 AI、不联网、不消耗任何额度。
- 与「一键拆书」**共用同一条写盘链路** —— 拆书的结果也能按同样的方式落库。
- 类型：导入弹窗里的「切分状态」提示做过一轮小修，现在能如实反映进行到哪一步。

### 2. 创作轨迹「选择章节」支持按卷折叠

章节多起来以后那个列表很长。现在：

- **卷标题行可点击折叠**（右侧显示该卷章数）；
- 多卷时标题栏提供「**全部收起 / 全部展开**」；
- 折叠状态用**卷标题**作索引（不是下标）—— 卷改名 / 增删之后状态不会串位。

### 3. 首启向导的模型配置，与「模型设置」彻底同源

以前首启向导自己维护一份「常用平台」短名单（云端 5 家、本地 2 家），豆包 / MiniMax / 混元 / 百川 / 零一万物 / Groq / OpenRouter / OpenAI 在首启里**根本看不到**，云端也没有「获取模型列表」的入口。现在：

| 改进 | 说明 |
|---|---|
| 预设**取同一份来源** | 与「模型设置 → 模型配置」共用 `ONLINE_PRESETS` / `LOCAL_PRESETS` ⇒ 云端铺全量 **14 个**、本地 **6 个**；以后加平台只改一处 |
| 「**获取模型列表**」对所有平台可见 | 本地 Ollama 走 `/api/tags`，云端 / 本地 OpenAI 兼容端点走 `/v1/models`；拉到清单后模型名可直接下拉选 |
| 回归守卫 | 新增 4 条源码闸，防止两边再次不同步 |

## 修复（主人反馈三连）

| 问题 | 根因 | 现在 |
|---|---|---|
| 写作面板「分卷进度」的**去写作按钮被压成竖排**（一个字一行） | 用了**定宽图标键**（`w-8` = 32px），文字塞不进去 | 换文字型导航键口径 → **横向一行**（实测 35×35px → 75.6×34.5px） |
| 模型设置 → 模型配置窗口**右侧一大片空白** | 列表态套了 `max-w-3xl`，宽屏下右半边空着 | 改**两栏**：左「模型列表 + 添加 + 语义检索」｜右「AI 用途路由 + 请求超时」；**高度自适应**，配多少模型就多高（实测死区 440px → 17px） |
| **并排按钮一高一矮**（AI 提示词「还原出厂」比「保存」矮一截） | 两者 size 不一致（`xs` vs `sm`，差 9px） | 统一为同 size。**顺带体检全仓并排按钮**，另抓出两处同类（灵感盒、字段别名弹窗）一并收敛 |

> 这三条都加了静态守卫，防止以后又退化回去。

## 其它改进与修复

- **全量六维审计**（2026-10-12）：11 支扫描器 + 2 道弱引用闸，红线专项全部干净（原生弹窗 / 裸剪贴板 / 内联视口单位 / z-index 魔数 / 循环依赖 0 组 / 真实 any 0 处）。真问题集中在「失败可见性」一类，共修 **8 处**：
  - **导出备份时读外置数据失败会静默吞掉** —— 会产出一份「记录齐全、内容全缺」的包，恢复时才发现。现已留痕。
  - **判定示范项目时读项目失败也静默** —— 万一读错，会白写一份全量备份。现已留痕。
  - **旧版数据探测失败**被显示成「没找到旧版数据」—— 现在会如实区分「探测失败」与「确实没有」。
  - 两处注释与实现互相矛盾、一处过期文档、一处死代码，一并清理。
- **新增两个清理入口**（来自审计登记的「能力缺口」）：
  - 备份管理页新增「**孤儿载荷清理**」—— 与既有的「孤儿备份清理」互为镜像（那个是「记录在、项目没了」，这个是「载荷在、记录没了」）；
  - 世界引擎页溯源条新增「**清除溯源**」—— 只清「引自 X」这条说明，**不动任何已引入的表内容**。
- **关于打赏**：致谢名单新增打赏用户「相念」。
- **导入图标朝向**：修正为向下（符合「导入」语义）。

## 说明

- **升级方式**：直接覆盖安装即可，数据不会动。装过 3.0.0 的通常可让应用内「检查更新」带你过来。
- **便携版**：把 `青春幻想引擎-便携版-3.0.1.zip` 解压到任意文件夹 / U 盘，双击 `启动.bat` 即用（本机需装 Node.js）。
- **本轮没有任何行为变更** —— 与 3.0.0 的使用方式完全一致。
