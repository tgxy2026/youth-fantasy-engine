---

## ⚠️ 先看这里：一处行为变更

### 「作品题材」默认不再发给 AI

**改了什么**：以前你在建项目时选的题材（比如「东方修真」），会**自动拼进每一条 AI 请求**里。从 3.0 起，**默认不再发送**。

**为什么改**：题材一旦发出去，就会悄悄影响 AI 的写法 —— 你可能只是想让界面显示「修真」的字段名，不希望它左右文风。发不发，应该由你说了算。

**想让它发，两条路**：

| 方式 | 怎么做 | 效果 |
|---|---|---|
| 项目级开关 | 项目编辑里打开「**把作品题材告知 AI**」 | 恢复旧行为，该项目的 AI 重新收到「类型：XX」 |
| 写成设定 | 在《作品信息》页的「**类型赛道**」字段里自己填（如「东方玄幻·升级流」） | **这段一直会随设定资料发给 AI**，比题材开关更可控 |

> 说明：题材现在只管「**开书定位组各页签的字段名与示例文案**」，不再影响 AI。

## 新增 · 3.0 八项

### 1. ⭐ 世界引擎 —— 把整个世界封存起来，给别的书引用

**入口**：世界构建 → 世界引擎

把你这本书的**整个世界**（世界设定、力量体系、四个制度页签、整个世界构建组）整个抽成一份「**世界包**」存起来，供**其它作品引用**。

两个动作要分清：

| 动作 | 含义 |
|---|---|
| **新建世界** | 把当前项目的世界**抽一份进来**（等于草稿） |
| **封存** | 把草稿**固化成不可变版本**（带锁图标） |

- 🔴 **关键边界**：原书改了，**已封存的世界版本不会自动跟着变**。想要新的，**显式再抽一份**。
- **为什么这么设计**：世界一旦被别的书引用就得**稳定**；要是自动同步，你改了这本、那本书的地基跟着塌，那才是灾难。
- **典型用法**：写同宇宙的第二本、第三本，直接引用这个封存版本，不用重新搭一遍世界。

### 2. ⭐ 跑团互动 —— AI 当 KP 主持一局

**入口**：酒馆模式 → 跑团互动

**你写行动，系统掷检定，KP 照着结果演。**

- 🔴 **检定由系统掷定**，掷完写进提示词 —— **模型照着它演，不许改写成败**（成败要是交给模型随机发挥，「游戏」就没有规则了）。
- 四样东西：**线索板**（这一局查到什么）、**同伴**、**秘密**、**结局判定**（按线索与秘密判定达成 / 接近 / 未达成）。
- 支持**存档、回滚** —— 一局玩崩了，退回去重来。
- 定位区分：剧情推演是**试演**、自由对话是**陪伴**、跑团是**一局游戏**（可玩、可分叉、可复盘）。

### 3. 章后整理 —— 写完一章点一下

**入口**：正文编辑器 → 颉文姬 → **整理**（第六个模式）

写完一章点一下，把这一章的**事实、伏笔、关系、人物状态**四类变化**一次抽出来**，你看过、勾选，再决定收哪几条进去。

- 🔴 若你回头改了前面已发布的正文，章纲里「这一章之后」的规划可能过时 —— 会主动标「**未来计划待重审**」，核对完点「已处理」清掉标记。**不偷偷用过时规划。**
- 与「补登」分工：**补登只管设定实体，整理一次过四类**，两个都在、各管各的。

### 4. 一致性审计 —— 自动查出设定自相矛盾

**入口**：灵感工具 → 检查工具 → AI 一致性深度自查

把世界观、角色、时间脉络交给 AI，对照检查**人名、时间、能力、关系有没有前后矛盾**；还能顺手粘一段正文一起核查。结果按**严重 / 中等 / 提示**分级，并给冲突依据。

### 5. AI 提示词透明 —— 看清 AI 到底收到什么

**两个入口**：

| 入口 | 能看到什么 |
|---|---|
| 模型设置 → **AI 提示词** | 每个 AI 功能的提示词**都能看、能改**（以前这些只写在代码里） |
| 各 AI 功能里的**问号气泡** | **这个功能读了哪些数据、明确不读哪些**（数据来源说明） |

以前你可能有两个误解：以为某个功能读了它其实没读的资料，或者反过来担心它把你的结局、伏笔真相整篇发出去。现在**界面说明与 AI 实际拼装的内容对得上** —— 不再各说各话。

### 6. 数值与言行一致

**入口**：酒馆模式 → 自由对话 → 右栏「本场状态」

角色的**数值**（好感 / 信任 / 精神）与它的**言行**对得上 —— 角色卡里写的「进度锁」（比如「还不熟，最多点头之交」）如果和你现在的数值档位对不上，会**给一行提示**，让你去同步改卡。

- 🔴 **只提示，不自动改你的角色卡** —— 卡是你的，改不改由你定。

### 7. AI 运行账本 —— 每次调用都留痕

**入口**：创作轨迹 → AI 运行账本

记的是：**这本书跑过哪些 AI 任务、成没成、产出多少条、消耗多少 token、耗时多久**。与「模型设置」里的消耗统计是**同一份数据**。

### 8. 作品版本冻结 —— 定稿归档，冻住不动

**入口**：创作轨迹 → 定稿与版本（右上角）

流程：**完成检查 → 内容指纹绑定 → 发布闸门 → 冻结版本。**

- 有阻塞项时，主按钮降级成「**仍要冻结（有 N 项未通过）**」 —— **闸门不硬拦，但会提醒你**。
- 🔴 两个细节：
  - **定稿冻结的版本不设上限、不会自动删除**，后续修订保留原版。
  - **「指纹只标注不重跑」** —— 版本指纹与当前稿对不上时，只显示「当前稿已改过」，**绝不自动重新冻结**。

## 新增 · 便携版（U 盘版）

**首次随 3.0 提供**：一个可以装进 U 盘 / 移动硬盘 / 本地任意文件夹的「**自带数据**」版本。

- 双击启动脚本 → 自动拉起本地服务 → 自动打开浏览器进入写作界面。
- **无需安装、不写注册表、不留 `%APPDATA%` 痕迹**，换电脑随盘即走。
- 数据全部在这一个文件里：`data/youth-fantasy-engine-data.json`（备份 = 复制这个文件）。
- 本地服务**只绑定 127.0.0.1**（本机回环地址），局域网里其他人访问不到；便携版本身也不含任何云同步。

**与桌面版的差别**：

| 便携版没有 | 原因 |
|---|---|
| 自动更新检查 / 云盘文件同步 / 系统托盘 / 安装卸载 | 依赖系统级安装或后台常驻，跑在浏览器里做不到 |
| 证据包直接导出 PDF | 改为**下载 HTML**，你自己 Ctrl+P 另存 |

**其余功能全部保留**：书稿编辑、世界观、时间线、关系图、AI 创意写作、酒馆对话、全文检索、导入导出等。

> **前提**：本机需装 **Node.js**（免费，约 30MB）。两个版本的数据格式完全相同，靠「整库 JSON 导入导出」互通。

## 其它改进与修复

| 项 | 说明 |
|---|---|
| 校对范围口径统一 | **AI 深度校对永远读完整正文**，旧的「简略模式」会误替换正文，**已移除**；只有「综合诊断」保留完整 / 简略两种范围 |
| 酒馆角色卡折叠态常驻 | 挂到故事下的角色卡折叠后，**切走页签再回来不会被重新展开** |
| 酒馆「未整理 N 轮」徽标 | 与右侧功能按钮**同规格对齐**，整行不再高低不齐 |
| 酒馆开场白前导空行 | 导入剧本时，开场白不再莫名多一个空行 |
| 酒馆角色卡字段归位 | 10 个细字段的界面名与存储键**统一**，并保留历史别名 —— 之前产出的文件仍能正确导入 |
| 便携版 4 项隐患 | 修服务崩溃 / Host 校验 / base64 抛错 / 导入取消卡死 |
| 备份载荷外置 | 备份、向量、知识库从整库 JSON 拆成独立文件，**双端同构**；老数据自动迁移、幂等 |

## 说明

- 本版为 **桌面安装版（Windows）+ 便携版**，安装包与便携版压缩包见下方附件。
- 数据与设置**向后兼容**，无需迁移；已有的项目、角色卡、故事剧本、会话记录都照常。
- 本软件**不做、也不参与任何「规避 AI 检测」的事情**。创作轨迹、证据包只做一件事 —— **如实记录你的创作过程，供你自己自证。**
- 「AI 辅助占比」统计的是「**AI 累计产出过多少**」，不是「成稿里有多少是 AI 写的」（AI 写完作者常会再改，改完就无法反推）。
