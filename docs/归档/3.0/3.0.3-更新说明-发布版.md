# 青春幻想引擎 3.0.3 更新说明

> 发布日期：2026-10-14 ｜ 桌面安装版（Windows）+ 便携版（Windows / macOS·Linux 两个包）
> 上一版：3.0.2（2026-10-13）

---

## 一句话

**3.0.3 换了一种更省事的便携版分发方式**（按平台两个小压缩包），把「参考资料」从单个页签里解放出来、**全项目可用**，并修掉一批近期反馈的界面问题。

---

## 便携版改版（本轮主线）

3.0.2 的便携版是「解压后双击即用」，但要求本机装 Node.js。这一版试着把 Node 运行时**内嵌进一个 exe**——技术上跑通了，**但包太大**：

- 单文件 exe **83 MB**，压缩后仍有 **39 MB**；
- 再把 Node 安装包一起塞进去 → 包体超过 **100 MB**，**Gitee 与 GitHub 都传不上去**。

所以本轮**放弃 exe 封装**，改成**按平台出两个压缩包**：

| 包名 | 内含启动脚本 | 适用 |
|---|---|---|
| `青春幻想引擎-便携版-3.0.3-Windows.zip` | `启动.bat` | Windows |
| `青春幻想引擎-便携版-3.0.3-macOS-Linux.zip` | `启动.sh` | macOS / Linux |

- 每个包约 **6.3 MB**（旧版 6.2 MB 基本持平）。
- **本机需要 Node.js 20 或更高版本**——包内 `使用说明-安装前必读.txt` 给了官网与国内镜像的下载地址，装一次即可。
- 使用方式不变：解压到任意文件夹 / U 盘 → 双击启动脚本 → 浏览器里打开。
- 数据**跟着文件夹走**，不写进系统目录；便携版也**跳过更新检查**，不会向外发请求。

## 新增

### ⭐ 参考资料全项目可用 + AI 弹窗一次性附加文件

**来源**：社区反馈「AI 补全时读不到自己放进『我的参考资料』的文档」。

**核实结论**：不是缺功能，而是**功能有了却读不到、也不好发现**——参考资料原先只在一部分 AI 入口里生效（要求带着「当前章节」才会注入，55 个功能页里有 16 个入口因此读不到）。所以这一版**不另造解析器，只补接线**：

- 放宽参考资料的注入条件：不再要求必须带当前章，**全项目的 AI 入口都能读到**（含全库检索与按章召回）；
- 「AI 补全」也接入参考资料，并按当前章优先取用；
- 新增**一次性附加文件**：在 AI 弹窗里临时丢一份文档进去，**不落库、不索引、关掉弹窗即丢**——适合「就问这一次」的场景（已接入 7 处弹窗）；
- 纯解析类任务（表格导入 / 行整理）明确**不读**参考资料，避免平白占用上下文。

## 修复

### 1. 同步设置在窗口模式下填不了

**现象**：把窗口调小后，侧栏里的 WebDAV / S3 配置表单底部被裁掉，**又滚不动**，密码之类的字段根本填不完。

**根因**：侧栏本身宽度固定，表单是**内联**在侧栏里的；而侧栏内容区有一段固定高度上限，表单撑出去的部分被**静默裁掉**。

**修法**：配置表单**改成弹窗**（点「配置 WebDAV 连接」/「配置 S3 兼容连接」打开）。弹窗自带滚动、按 Esc 或点遮罩关闭，并跟随界面缩放；侧栏只留「目录中转 / WebDAV / S3 兼容」三档选择。窗口再小也能把表填写完。

### 2. 本章体检的章节列表顺序乱

**现象**：「检查工具 → 本章体检」里挑章，列表是「第 1 章 → 第 11 章 → 第 21 章 → 第 2 章 …」。

**根因**：章节在数据结构里记的是**卷内序号**（每卷都从 1 开始），而那段列表把它当成了全书序号来排——卷与卷之间就串了号。

**修法**：改走全书唯一的「卷序 → 章序」口径，并把这个平铺下拉换成**卷 / 章树**：按卷分组、可折叠、可搜索（按标题或序号），章号用全书派生序号（序章 / 番外这类不计号的显示为「·」）。

### 3. 一键拆书「章节标题示例」只能看 3 行

输入框固定 3 行高、右边挂着滚动条，示例稍多就看不全。**改为自适应高度**：最少 3 行，随内容长高，超过 240px 才转内部滚动；窗口大小变了也会重新量一次高度。

### 4. 文风档的「管理文风档…」按钮被压扁

按钮比左边的下拉框矮一档，文字挤在格子里。**改为与下拉框同高同字号**，并加了防挤压处理，文字完整显示。

### 5. 一批内部审计修复（无界面变化，但都是真问题）

这一版跑了一轮**全量审计**（10 支扫描器 + 2 支字符串闸 + 2 个子代理），修掉：

- **本章体检的竞态**：体检要跑五个检查引擎（其中两个要扫全书），耗时可达秒级；期间若切到别的章，**前一张体检报告会挂到新章名下**且不会被纠正。现已改为「切走就丢弃结果，重跑即可」（体检留痕照常记录）。
- **孤儿章的排序**：章节所属的卷被删过之后，这些章会**悄悄排到「第 1 章」前面**。现在统一排到全书之后，与章节树里「未归类章节」的位置一致。
- **切章时留痕标注未及时清空**：快速切章会闪一下上一章的「结果已过期」。
- **章节树搜索「0」**：会把「不计入序号 / 自由卷 / 未归类」的章全列出来（它们在树上是「·」，看不出为何命中）。
- **搜索状态下点卷头没有反应**：清空搜索后那一卷会莫名收起。
- **重复文案**与**术语**统一（「章纲」→「章节细纲」）。
- 🔴 **顺带修好了一支审计工具自身的盲区**：它原先只认相对路径的模块引用，而代码库早已全面改用 `@/` 别名 ⇒ **依赖关系图整张为空**（表现为「循环依赖 0 组」这种看着很干净、其实是假结论）。已修好并同步回工具真源。
