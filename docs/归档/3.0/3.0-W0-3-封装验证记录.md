## 2. 封装过程（三步法，与 2.7.2~2.9.3 完全一致）

1. **首轮** `scripts/build-desktop.mjs`：出包，主 exe **246,238,720**（坏包）⇒ 报「主 exe 元数据缺失，开始补写」。
   🔴 **本轮首次遇到 skill 记录的「坑 B」**：脚本报 **`❌ 找不到 rcedit`** ——
   `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\` **整个目录不存在**（因 `signAndEditExecutable: false`
   让 electron-builder 根本不下载这套工具链）。
2. **外层补写（坑 B 正解）**：改用 `node_modules/electron-winstaller/vendor/rcedit.exe`，
   **在纯 ASCII 路径 `C:\rcedit-test\` 补写**（该 rcedit 不支持中文路径）→ 体积 **246,238,720 → 246,487,040**（回到基线）；
   再复制回 `win-unpacked/`。
3. **`--prepackaged` 重打**：主 exe **仍为 246,487,040**（未被覆盖 —— 这一步是成败所在）；安装包 102,874,788。
4. **`YFE_REUSE_OUT` 复用模式收尾**：日志 `主 exe 元数据校验通过（246487040 字节，与基线逐字节一致）`，交付到 `release/桌面安装版/`。
