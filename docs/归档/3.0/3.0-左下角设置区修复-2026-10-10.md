# 3.0 · 左下角设置区修复（2026-10-10）

> 触发：作者反馈「进入项目后，左下角（主题 / 界面缩放 / 全屏背景）那个可隐藏的设置区有问题」，
> 具体三条：① 调整窗口宽度时**自动缩放**不对劲；② 缩放比例**百分比显示不全，只看到一个「1」**；
> ③ 缩放比例输入框**比周围按钮高一截**。
> 状态：**已完成**（tsc 0 / eslint 0 / 全量单测 181 全绿 / 真机 11 项全绿）。

---

## 一、根因（两条真因 + 一条系统性隐患）

### ① 自动缩放的 resize 监听「只挂一次」—— 启动为手动就再也不挂

`App.tsx` 的「跟随窗口」监听写成**挂载时一次性判断**：

```ts
useEffect(() => {
  if (!isZoomAuto()) return      // 🔴 挂载时判一次
  ...window.addEventListener('resize', onResize)
}, [])
```

若本次启动时是「手动」（`yfe-ui-zoom-manual = '1'`），监听**永远不会注册**；此后点「自动」虽会
立刻按键当时的宽度算一次，但**再改窗口大小就不跟了**。

**真机复现**（改了 `window.innerWidth` 再派发 resize）：

| 启动模式 | 点「自动」后 | 改宽到 3200 并 resize | 判定 |
|---|---|---|---|
| 跟随（manual=0） | 1.32 | **1.40** | ✅ 正常 |
| 手动 → 点「自动」 | 1.32 | **1.32**（纹丝不动） | 🔴 监听未挂 |

### ② 缩放输入框的类名**大半是无效的**（Tailwind v4 分层坑）

`index.css` 里那条全局输入样式：

```css
input, textarea, select { @apply bg-ink-800 border border-ink-600 rounded-md px-3 py-1.5 text-ink-100 …; }
```

它**不在任何 `@layer` 里**。而 Tailwind v4 把工具类放进 `@layer utilities` ——
**未分层样式优先于任何命名层**，于是组件传的类名全被压掉。真机实测（除回 zoom）：

| 属性 | 组件写的 | 实际生效（全局） |
|---|---|---|
| 内边距 | `px-1 py-0.5` | **`px-3 py-1.5`（12px / 6px）** |
| 高度 | — | 34px（内容 21 行高 + 12 内边距 + 2 边框） |
| 背景 / 边框 / 圆角 / 字色 | `bg-ink-950` / `border-ink-700` / `rounded` / `text-ink-200` | `bg-ink-800` / `border-ink-600` / `rounded-md` / `text-ink-100` |

⇒ 48px 宽的框只剩 **22px** 可用，「132」正好被裁成「**1**」；高度 34px 比同排的 24px toggle 高出一截。
⚠️ 与侧栏宽度**无关** —— 任何宽度下都在裁（见下方扫描）。

### ③（顺带发现，系统性隐患，**本次未改**）

同一机制影响面不止侧栏：真机遍历 6 个页签，**38 处**输入控件的类名「写了但没生效」
（内边距 / 圆角 / 字号与预期不符）—— 例如某 `<select className="…px-2 py-1 text-11 bg-ink-950 border-ink-700 rounded">`
全部被全局值覆盖。危害以「观感略有出入」为主，唯侧栏那处因为**定宽 48px** 才恶化成「文字被裁」。
> 🔴 建议：把全局 input 规则移入 `@layer base`（Tailwind 的预置层），让工具类正常生效。
> 但这会一次性改变上述 38 处的观感（如 `text-12` 真的变 12px、`rounded-lg` 真的变 8px），
> **属于需要单独验证的一轮**，故本次不动、留此记录。

## 二、修复

| # | 改动 | 文件 |
|---|---|---|
| 1 | resize 监听改**常驻**（模式判定放进回调，非跟随早退） | `src/App.tsx` |
| 2 | 缩放 −/+ 键改 `size="xs"` ⇒ 与同行「自动」「全屏」「背景」统一 24px | `src/components/Sidebar.tsx` |
| 3 | 缩放输入框：需覆盖全局规则的一律加 `!`（`!px-1 !py-0 !rounded-lg`）+ `h-6`/`text-11` 与同排控件对齐 | 同上 |
| 4 | 顺带：`AutoTextarea` 的字号改走契约参数 `textClass`（原 `className="text-13"` 叠在默认 `text-12` 上，**靠 Tailwind 生成顺序侥幸生效**）—— 渲染值不变，不再看运气 | `src/components/SchemaFieldGrid.tsx` |

> 🔴 关于 `!`：项目里既有 `!py-2` / `!px-3 !py-2` 的写法，`!` 是本项目对「全局规则压工具类」的
> 既有处置手段，故沿用；并在这行上方加了注释说明**为什么必须加**，免得后人"清理"掉。

## 三、防回退：`tests/themeZoom.test.ts`（15 项）

| 组 | 判据 |
|---|---|
| `autoZoom` 纯函数 | 1000→100 / 1280→100 / 1440→104 / 1920→116 / 2560→**132** / 2880→**140** / 3840→140（封顶）；单调不减；恒落 100~140；未手动指定时 `getStoredZoom()` 走 `autoZoom` |
| 源码契约① | `App.tsx` **不得**再出现挂载时一次性早退 `if (!isZoomAuto()) return`；且 resize 回调内仍按当前模式判定 |
| 源码契约② | 侧栏缩放输入框的 className 必须**用 `!` 覆盖内边距**、且带**显式高度** |

> 判定前会**去掉整行注释** —— 注释里为讲清缘由引用了那句被删掉的旧代码，不能误伤。
