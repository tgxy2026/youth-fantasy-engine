### 🔴 打 zip 踩到两个坑（都已修）

1. **PowerShell `Compress-Archive` 用反斜杠** ⇒ 条目名是 `便携版-3.0.0\dist\index.html`。
   Windows 能用，但 **macOS/Linux 解压会得到一堆带反斜杠的文件名**（不展开成目录）——
   便携版明确支持 `启动.sh` ⇒ **不可接受**。改用 **7za**（输出标准 `/`）。
2. **7za 默认按 GBK 写条目名**（通用标志位 `0x0`、UTF-8 位**未置位**，实测字节 `b1 e3 d0 af b0 e6` = GBK「便携版」）
   ⇒ 非中文系统解压乱码。正解：**加 `-mcu=on`** 强制 UTF-8 文件名 ⇒ 标志位 `0x800` 置位、真名正确。
