## 二、判定不改 / 留待（防下轮重复提案）

| 项 | 理由 |
|---|---|
| `HistoryTimeline` / `StoryTimeline` 内联 zIndex | 局部 SVG 层内的相对层级，不参与全局 z 序（`zLayer` 注释已把「判定不收」的三类写明） |
| 十处 `getBoundingClientRect` | 全属**定位/拖拽坐标**计算，不是「量尺寸」；红线禁的是后者（应走 `offsetHeight`/`clientWidth`） |
| `FactionGraph` / `WritingGoals` 语义色 | 与主题无关的**数据语义**配色，非 token 漂移 |
| `Modal` 的 × 按钮 `ghost` | 关闭按钮非常规「静止无框」场景，判定不适用 |
| `dangerouslySetInnerHTML` 高亮层 | 前置已逃逸；属既有渲染方案，非本批引入 |
| `TavernPlot` / `TavernPlotChat` / `usePlotSummary` 缺 `useTavernReady` | 🔴 经复核**不违反**「酒馆链路就绪判据必须同源」红线（它们不读酒馆模型链路）；「体验一致性」属独立议题，**列为待定**，不在本批动 |
| F1「7/36 缺就绪守卫」 | 沿用 2026-09-27 判定：全部有 catch→toast 反馈，属 UX 优化非 bug |
