# 青春幻想引擎 2.8.0 更新说明

> 发布日期：2026-10-05 ｜ 桌面安装版（Windows）
> 上一版：2.7.3

---

## 一句话

**六个 AI 新能力一次到位**：语义检索（能记住你整本书）、多 Agent 模型路由、文风档、全书优化工单、参考资料库、市场雷达 —— 主线是**让 AI 真正读懂这本书，而不是每次从零开始读一遍**。

同时清掉了一批「看起来没事、其实没生效」的静默缺陷（六维审计两轮），并把**打赏页签升为必选**（覆盖安装会自动给老项目补上）。

## 新增

### #013 语义检索 / 向量 RAG

- **入口**：工作面板 → 模型设置 →「语义检索」。配好嵌入模型后点「重建索引」，写正文时上下文会多出一段〖语义召回〗，把**与当前章节真正相关**的旧章节片段带进来，而不是固定塞最近几章。
- **保密等级先于切块**：标记为 **D（终结）** 的条目**永远不进 AI**，**S（绝密）** 条目在角色视角整行剔除 —— 剔除发生在切块**之前**，不是召回之后再过滤，从源头就不外发。
- **降级不报错**：没配嵌入模型、或嵌入服务断线时，上下文照常生成，**只是没有语义段**，不弹错、不卡住。
- ⚠️ **需要自备嵌入模型**：本地 Ollama 默认只有对话模型，需先 `ollama pull nomic-embed-text`（或 bge-m3），再在面板里配上；也可以配 OpenAI 兼容的 embeddings。
- ⚠️ **索引不随项目走**：存在独立数据库里，**不进备份、不上云、不进整库 JSON**（设计取舍：避免每存一章就重写十几 MB）。换机或换数据目录后需重建一次索引。

### #014 多 Agent 模型路由

- **入口**：模型设置 →「AI 用途路由」三个下拉：**创作 / 审校 / 批量整理**。
- 可以给不同用途指不同模型 —— 比如创作交给 27B、批量整理交给 4B 省时间省钱。
- **全部留空时，行为与旧版逐字一致**（回落到当前模型），不配就完全无感。
- 被指向的模型被删掉时，该任务**自动回落当前模型、不报错**。

### #015 文风指纹 / 文风档

- **入口**：伴写面板 或 创意写作面板 →「文风档」选择器 →「管理文风档」。
- 投喂 1~2 段你自己的（或你喜欢的）文本 → 提炼成一份可命名的文风档 → 启用后写出来的东西会往那个风格靠。
- **按项目存**，跟书走 —— 换书各用各的，切项目自动失效，不会串味。
- 不启用任何文风档时**零变化**。

### #016 全书优化工单 + 逐章修订 + diff

- **入口**：灵感工具 → 检查工具 → 工单面板。
- 「生成工单」出一张按章分组的表格 → 勾选要改的条目 →「执行选中」→ 点条目看**修改前 / 修改后对照**。
- 🔴 **改写只动三个字段**（正文 / 字数 / 更新时间）+ 多存一条快照，其余一概不碰 —— 历史章被改也**不会顺手动你的设定表**。
- **中止不清账**：中途停掉，已经改完的保持「已改」，剩下的仍是待改，**不重复烧额度**。
- diff 配色：新增 = 绿、删除 = 红（界面已注明**与行情红绿无关**，只表示增删）。

### #017 知识库 / 参考资料

- **入口**：灵感工具 → 素材资料 →「我的参考资料」区。支持导入 txt / md / docx 或直接粘贴。
- 勾选启用后，写正文时上下文会出现〖参考资料〗段，只带 **top-K 相关片段**，不整篇塞进去撑爆窗口。
- **没配嵌入模型也能用** —— 自动降级为关键词匹配，只是没那么"聪明"。
- **还原备份后自动重建资料索引**（本版收尾新增）；没配嵌入时给**如实提示**，不静默。
- 口径：仅存本地，**默认不随备份走**；面板勾选「随包」后只随**手动导出**走，**自动备份恒定不带**。

### #018 市场雷达

- **入口**：作品信息页 → 页头「市场雷达」按钮。
- 出一份报告：趋势 / 平台契合 / 机会 / 风险，附**来源链接列表**与免责声明。
- 没配联网检索时给「去设置」引导，**不静默失败**；断网会明说失败原因。
- 🔴 **只做趋势参考**，不引导跟风、洗稿或抄袭；**由你主动点才跑**，不会后台自动跑。

## 改进

- **上下文窗口改必填** —— 模型配置里这一栏现在必填，未填的标「未填窗口」；填 `3000` 以下会提示「是不是把 K 当词元了」。配套的额度 / 档位建议也跟着窗口大小走（**工具不再替你猜窗口** —— 猜错的代价是长文中途被截断）。
- **设定检索同步字段显示名** —— 你给某列起的名字，在设定检索里同样显示，并且**检索也认新名**（此页只读，改名回原页签）。
- **色板收为单一真源** —— 全部颜色常量收到 `lib/palette.ts`，顺带把 65 处"随手写的任意值"换成具名档。**观感零变化**，属一致性收口。
- **架构拆分** —— `ai.ts` 拆成门面 + 实现（`aiCore/*`），`schema.ts` 拆成三段。无感，但为后面继续加页签腾出了空间。
- **关于页「打赏」页签升为必选** —— 右列顺序也调了：**致谢名单在上、收款二维码在下**；致谢名单更新为真实打赏者，说明改为「按打赏时间排序」。
  - 🔴 **覆盖安装会自动给老项目补上这个页签** —— 以前建项目时没勾的，升级后也会加上。

## 修复

| 领域 | 修的问题 |
|---|---|
| 云盘同步 | **「删了会复活」补上第四条路径** —— 两端内容一致时的墓碑判定此前漏掉，现在删除墓碑无条件生效 |
| 资料库 | **读失败不再静默降级成"空结果"** —— 改用严格读，读不到就报出来，不再把空值当结果落库 |
| 长任务 | 一键拆书等长任务**补回流式输出**（此前不传 `onToken` 走的是非流式，撞 180 秒总超时墙） |
| 渲染性能 | 看板 / 表单 / 酒馆等 7 处渲染期计算补 `useMemo`，不再每次重渲染都重算 |
| 静默吞错 | 酒馆 store 的空 `catch` 补留痕，异常不再被吃掉后无影无踪 |
| 关于页 | 「获取最新版本」区块两排按钮贴死、原生链接与按钮尺寸不齐 —— 补间距与分隔线，尺寸口径统一 |

> 本轮还做了一轮**提示词架构的回退**：曾尝试把重复句段抽成公共片段，事后判定违背「默认值就地声明」原则，**已整体退回**。功能无影响。

## 安装与升级

- Windows 桌面版，**按用户安装、不需要管理员权限**；支持自选安装目录，直接在旧版本上覆盖安装即可。
- ⚠️ 装到**没有写权限的目录**（例如 Program Files）会因权限不足而失败 —— 数据目录建议留在默认位置或自定的普通目录。
- 覆盖安装不会清掉已有项目数据；动手前建议先用「设置 → 备份」导出一份留底。
- ⚠️ **升级后语义索引与参考资料需重建 / 重新导入**（它们存在独立库里，设计上不随项目走）。
