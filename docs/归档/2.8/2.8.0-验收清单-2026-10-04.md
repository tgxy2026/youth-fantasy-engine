# 2.8.0 验收清单（2026-10-04）

> 用途：主人在预览环境（dev `http://localhost:5199`）**逐项验收** 2.8.0 改动。
> 版本：2.8.0（开发中，**未封装**）。台账：`docs/优化清单.md` #013–#018 + 六维审计修复。
> 每项给出：**入口路径 → 验收步骤 → 预期 → 前置条件**。打勾处供主人自记。

---

## 〇、验收前置条件（先看）

| 前置 | 说明 |
|---|---|
| **AI 模型** | 至少配好一个**对话模型**（设置 → 模型设置 → 模型配置）——#014/#015/#016/#018 及一切 AI 功能都需要 |
| **嵌入模型（关键）** | 本地 Ollama **当前只有对话模型、没有 embedding 模型**。若要验收 #013 语义召回 / #017 参考资料的**语义路径**，需先 `ollama pull nomic-embed-text`（或 bge-m3 等），并在「模型设置 → 语义检索」里配上；**不配**则只能验「静默降级不报错」路径 |
| **联网检索** | #018 市场雷达需要「模型设置 → 联网检索」配置（bocha / searxng / 自定义），否则只能验「未配置 → 给引导」路径 |
| **dev 环境** | 浏览器预览（Vite 5199）。桌面专属能力（如整库 JSON 落盘）在 dev 下表现不同，与本次验收项无关 |

## 一、六项新功能（#013–#018）

### #013 语义检索 / 向量 RAG

| 项 | 内容 |
|---|---|
| **入口** | 工作面板 → **模型设置** → 「语义检索」（嵌入模型 + 索引状态/重建索引） |
| **步骤** | ① 配嵌入模型 → ② 点「重建索引」→ 看索引块数 → ③ 打开某章写正文 → 看上下文「已带入」 |
| **预期** | ① 显示「已索引 N 章 / M 块 · 模型 X」；② 上下文出现〖语义召回〗段；③ 设一条 **D 级**条目 → 检索**召回不到**；④ **断开嵌入服务**再跑 → 上下文照常、无报错、无〖语义召回〗 |
| **口径** | 独立 IDB `novel-studio-vec`（**不进备份 / 不上云 / 不进整库 JSON**，故**换机需重建**）；S/D 剔除**先于切块**；索引空 ⇒ 零嵌入请求 |
| ☐ | 通过 |

### #014 多 Agent 模型路由

| 项 | 内容 |
|---|---|
| **入口** | 工作面板 → **模型设置** → 「AI 用途路由」（三下拉：**创作 / 审校 / 批量整理**） |
| **步骤** | ① 三下拉全留空 → ② 跑一次任意 AI 功能 → ③ 「批量整理」指向另一模型 → 再跑一次 AI 整理 |
| **预期** | ① 留空时**行为与旧版逐字一致**（回落当前模型）；② 批量整理请求打到所配模型（看模型名/日志）；③ 把被路由的模型**删掉** → 该任务**回落当前模型、不报错** |
| ☐ | 通过 |

### #015 文风指纹 / 文风档

| 项 | 内容 |
|---|---|
| **入口** | 伴写面板 或 创意写作面板 → 「文风档」选择器 → 「管理文风档」 |
| **步骤** | ①「管理文风档」→「从参考文本提炼」投喂 1~2 段 → 命名保存 → ② 启用该档写一段 → ③ 停用/无档再写一段 |
| **预期** | ① 生成可命名的文风档（含本地统计 + AI 归纳）；② 启用后文本体现该风格（人工感受）；③ 无档时**零变化** |
| **口径** | **按项目存**（跟书走，非全局）—— 换书各用各的，切项目自动失效 |
| ☐ | 通过 |

### #016 全书优化工单 + 逐章修订 + diff

| 项 | 内容 |
|---|---|
| **入口** | 灵感工具 → **检查工具** → 工单面板 |
| **步骤** | ①「生成工单」→ ② 按章分组表勾选一条 →「执行选中」→ ③ 点该条看 diff 对照 → ④ 对**历史章**执行一条 → ⑤ 中途「中止」 |
| **预期** | ① 表格可勾选（工具栏：全选 / 只看 error / 按章全选）；② 该章被改，且**只在 `chapters` 动三字段**（content/wordCount/updatedAt）+ `snapshots` 多一条；③ diff「修改前/修改后」正确，**新增=绿 / 删除=红**（界面已注明与行情红绿无关）；④ 历史章执行 → **设定表未变**；⑤ 中止 → 已改完的**保持「已改」**、剩下的仍 `pending`（不重复烧额度） |
| ☐ | 通过 |

### #017 知识库 / 参考资料

| 项 | 内容 |
|---|---|
| **入口** | 灵感工具 → **素材资料** → 「我的参考资料」区 |
| **步骤** | ① 导入一篇 txt/md/docx（或直接粘贴）→ ② 勾选「启用」→ ③ 写正文看上下文 → ④ 取消启用再写 → ⑤ 还原/导入一份备份文件 |
| **预期** | ① 导入后在列表可见；② 写正文时上下文出现〖参考资料〗且**只有 top-K 片段**（不整篇塞）；③ 关闭 ⇒ 上下文零变化；④ **未配嵌入** ⇒ 走**关键词匹配**（降级可用、不报错）；⑤ **还原后自动重建索引**（2.8.0 收尾新增，未配嵌入时给**如实提示**而非静默） |
| **口径** | 独立 IDB `novel-studio-kb`（`docs` + `bodies` 两 store）；仅存本地，**默认不随导出/备份走** —— 面板勾选「随包」后仅随**手动导出/导出备份文件**走，**自动备份恒定不带** |
| ☐ | 通过 |

### #018 市场雷达

| 项 | 内容 |
|---|---|
| **入口** | **作品信息**页 → 页头「市场雷达」按钮 |
| **步骤** | ① 未配联网检索时点按钮 → ② 配好检索后点按钮 → ③ 断网再点 |
| **预期** | ① 给「**去设置**」引导（不静默失败）；② 出报告：趋势 / 平台契合 / 机会 / 风险 + **来源链接列表** + **免责声明**（「来自联网检索 + 模型归纳，供参考」）；③ 断网 → 明确提示失败原因 |
| **口径** | **不引导**跟风/洗稿/抄袭，只做趋势参考；由作者主动触发，不后台自动跑 |
| ☐ | 通过 |

## 二、支撑与一致性改动（背景项，多为「无感」）

| 项 | 说明 | 验收方式 |
|---|---|---|
| **额度/档位跟随上下文窗口 + 窗口改必填** | 模型配置列表行「上下文窗口」**必填**；未填的标「未填窗口」 | 模型设置 → 新增/编辑模型 → 窗口留空应被拦；填 `3000` 以下→ 琥珀提示「是否把 K 当词元」 |
| **设定检索同步字段显示名（#011 收尾）** | 设定检索里，字段展示与检索**都认作者起的名字**（`f.alias ?? f.label`） | 给某列改名 → 设定检索里该字段同步显示新名（此页**只读**、回原页签改） |
| **色板单一真源 + U3 任意值收口** | `lib/palette.ts` 纯常量；Tailwind 补具名档（`w-11px`/`min-w-90`/`rounded-2` 等） | **观感零变化**（纯一致性，非功能）；由 `structureGates ⑨` 守住 |
| **六维审计修复** | 静默缺陷修复：#013 索引读失败不再吞空、#017 单篇重索引走任务中心可中止、#016 中止保留已改章等 | 无新界面；体现在上述功能「不静默失败」的行为里 |
| **架构** | `ai.ts` 拆门面（10-04）、`schema.ts` 三段拆（2.7.3，含在本工作区） | 无感 |

## 四、已知限制（非缺陷）

- **语义索引/参考资料不随项目走**：独立 IDB，换机/换目录需重建索引、重新导入（设计取舍：避免每存一章重写十几 MB）。
- **本地无 embedding 模型**：需先 `ollama pull` 一个，或配 OpenAI 兼容 embeddings。
- **dev 与桌面差异**：预览是浏览器版；桌面封装版才有整库 JSON 落盘等行为。
