# 青春幻想引擎 3.7.2 更新说明（2026-11-25）

> 从 3.7.1 直接升级，覆盖安装即可。本版以工坊风全站界面重构、全项目文案与 AI 提示词优化、软件内版本更新说明补全为主，**数据格式没有变化**。

## 一、工坊风全站界面统一（三形态全覆盖）

- **全站工坊深色视觉体系与基线对齐**：项目中心、57 个创作页签、网页版登录 / 注册 / 重置密码页统一接入暗黑曜石工坊风视觉语言；左侧图标轨、工作区目录侧栏、章节树与正文编辑器顶部横线对齐至同一 `48px` 基准高度。
- **左下角设置面板改从左往右弹出**：点击左下角设置按钮弹出「界面与数据」设置面板，宽度自适应并贴合侧栏边界，不再越界遮挡工作区内容，也不再占用顶部搜索栏空间。
- **全页签布局与按钮层级收口**：「关于打赏」页与「使用指南」改为与其他页签一致的对称铺满布局；全站页签右上角操作按钮统一高度与视觉对比度（带文字辅助按钮统一使用非幽灵层级），并对多窗口缩放与窄屏表现完成复核修正。

## 二、全项目 UI 文案整理与内置 AI 提示词升级

- **全站文案纠偏与表达润色**：梳理全项目界面文案与内置使用手册，更正过时页签数量、历史版本号与功能边界表述，统一提示词与报错说明的用语口径。
- **内置 AI 提示词精修**：围绕当前主流长篇写作与审校实践，升级去 AI 味、校对、一致性审计、颉文姬、改写、角色小传起草/整理等核心内置提示词，强化上下文遵循、分步判断与可落地修改建议，同时严格保持既有 JSON 结构与解析键名不变。

## 三、软件内「版本更新说明」补全

- **修复软件内看不到 3.7.x 更新说明的问题**：将 3.7.0、3.7.1 与 3.7.2 的版本更新摘要完整接入内置使用指南（版本变化篇）、关于页与更新提示弹窗，软件内升级前即可直接查看改动详情。

## 四、质量审计与修复

- 完成六维 + 全量审计，修复侧栏面板高度视口折算（`foldVh`）、5 处带文字按钮误用 `variant="ghost"` 改为 `variant="bare"`，并更新工作台入口审计探针适配工坊风图标轨与可收起目录。

## 验证与边界

- 类型检查 0、lint 0、全量单测 **524/524**、六维 + 全量审计 `complete`（0 候选 / 26 项工具自检通过 / 11 项运行证据全过）、红线 11–15 全部 0、结构化提示词输出约束 P4 **0/42**。
- 发布包一致性校验（`release-check`）在打包后全量验证。
