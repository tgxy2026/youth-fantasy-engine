## 一、这版做了什么

### 1. 第 4 个运行模式：WCP 模式（网页资料包）

- 「模型设置 → 运行模式」在 API / MCP / ACP 之后新增 **WCP 模式** 页签。
- 使用**独立本地视图态**：不调用 `switchConnectionMode`，不修改 `modeTransition.ts`；
  `modeStatus` 的 3 秒轮询只覆盖原三模式，不会把 WCP 选态拉回去；
  即使宿主处于 `switching` / `blocked`，WCP 页签仍可点可用。
- 顶部保留「当前后台在线模式」提示，明确 WCP 与后台模式并存、互不干扰。

### 2. 双层存储

- 全局偏好存 `meta`（键 `wcpGlobalConfig`）：默认后缀 `.md`/`.txt`、默认包形态 `delta`/`full`、
  摘要格式 `json`/`markdown`、前文章数、摘要章数、作者备注开关、单包字符预算。
- 单项目状态存 `settingsKV`（键 `wcpProjectState`）：底包勾选模块、上次导出时间、源数据指纹。
- 旧库空配置 / 脏数据读取一律回退出厂默认；显式保存空勾选仍视为「全不勾」。

### 3. 三档资料包与 5 大场景

- **Base（常驻底包）**：作品概览、世界设定、势力与地理、核心角色、人物关系、人物小传、
  写作规范、名词术语；只装长期设定，不掺当前章草稿；含文风与去 AI 味规则。
- **Delta（轻量增量包）**：当前章细纲、前文摘要与末尾正文、本章草稿、出场角色当前状态、
  物品持有 / 流转、未回收伏笔。
- **Full（完整独立包）**：底包 + 增量合并，同 id 段以增量快照为准。
- 5 大场景就近入口：
  - 正文续写 / 片段润色：`NovelEditor` 工具栏「WCP 接力」；
  - 大纲 / 细纲推演：`OutlineSheet` 页头「WCP 推演包」；
  - 连续性找茬：`CheckTools` 页头「WCP 找茬包」（不评分 / 不排名 / 不评级）；
  - 角色小传整理：`CharacterBioPage` 页头「WCP 小传包」。

### 4. 双段解析与候选直连

- `<<<WCP_BODY_START>>>` / `<<<WCP_CHANGES_START>>>` 双段切分；
  缺标记时按 `## 第一部分` / `## 变动摘要` / 尾部代码块退化识别；
  完全找不到第二部分时整段归 Part 1。
- JSON 走 `aiParse.parseLooseObject`（代码块、尾逗号、截断修复），不使用裸 `JSON.parse`。
- 归一化 6 类候选后直连 `chapterPostProcess` 的 `matchForeshadows` / `matchRelations` /
  `matchStatuses` / `matchResources` / `matchBiographies` 与 `settingLedger.classify`；
  勾选后仍走 `applyPostProcess`（只追加不覆盖、未登记不凭空建）。
- JSON 不完整时 Part 1 100% 保留，并提供「一键切换为 Markdown 清单模式」。

### 5. 内置手册

- 新增 `src/lib/help/articles/wcp.ts`（WCP 使用篇）与 `version-373.ts`（3.7.3 更新说明）。
- `CONTENT_VERSION` 33 → 34；手册覆盖 61 篇 / 180 段 / 58 个入口，缺口 0。

## 二、二次复核修正（2026-11-25）

在完成首轮实现后，按界面截图与源码逐项复核，修正了以下问题：

1. **正文编辑器 WCP 按钮外观**：改为与右侧「工具」按钮完全同款（透明底 / 透明边框 / 同悬停与展开态），不再使用带底色的独立按钮。
2. **模式页签互斥**：WCP 视图打开时，API / MCP / ACP 页签不再保持选中高亮，避免出现两个同时选中的单选。
3. **装入目录顺序**：TOC 改为与文件内 `world → characters → context` 的实际区块顺序一致；预算仍按优先级分配，不再出现目录与正文错位。
4. **底包 meta 文案**：不再写「场景：正文续写」，改为「常驻底包（不绑定具体任务）」；摘要格式行明确「底包不含输出契约」。
5. **显式全不勾**：作者在管理页取消全部底包模块后，导出时不再悄悄回落到出厂默认模块。
6. **完整包取材**：就近导出弹窗读取当前项目实际勾选的底包模块，不再固定使用出厂默认；增量 / 完整默认形态遵循全局偏好（大纲 / 找茬仍按场景推荐完整包）。
7. **候选失效与防重复**：粘贴文本或切换摘要格式后，旧候选立即作废；写入成功后清空勾选，避免同一批候选被重复写入。
8. **底包过期判定**：指纹纳入文风指纹与去 AI 味规则；这些规则变化同样提示「建议重导」。
9. **一次性附加文件隔离**：`buildProjectContext` 新增 `includeTempDocs` 选项；WCP 取材统一传 `false`，AI 弹窗里临时拖入的文件不会混进底包。
10. **裸 JSON 回复**：没有正文、只收到一个结构合法的变动摘要 JSON 时，归入 Part 2，不再把 JSON 当正文吞进 Part 1；非法 JSON 仍整段保留为正文。
11. **设定检索历史字段**：检索页只展示与表格 / 图鉴当前有效字段一致的键；删除或归档的自定义字段、隐藏列、旧模板字段不再与新字段并列显示。
12. **大纲 / 细纲包章号与细纲**：真机验收发现「章节细纲」导出的资料包丢失章号与细纲上下文；现由页面显式传入章号，`<wcp_meta>` 正确写入「章节：第 N 章」，并带入本章及相邻章细纲（编辑器续写场景仍以库内章号为准）。
13. **本章固定资料纳入续写增量包**：正文编辑器「本章资料 → 关联资料」里固定（Pin）的角色卡 / 设定表行，导出续写包时作为「本章固定资料」段一并带入；读不到或已失效的固定项只提示跳过，不阻断导出。
14. **网页登录 / 重置密码页恢复默认护眼主题**：服务端登录页从 3.7.2 的暗黑工坊风恢复为应用默认的护眼浅绿配色（`#e6f0e0` / 主色 `#44764e`），品牌 Logo 与 `theme-color` 同步恢复。
