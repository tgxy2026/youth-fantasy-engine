# 青春幻想引擎 3.7.6 更新说明（2026-11-28）

> 本版聚焦「自定义字段完善与全链路一致性加固」：从前端表单到检索、导出、AI 上下文、世界观打包、语义向量索引与数据体检全链路对齐单一真源。

## 一、核心功能增强

1. **纯表单、大纲与「其他设定」开放轻量自定义字段**
   - 「作品信息」「世界设定」「力量体系」「全书总纲」「写作规范」以及「分卷大纲」「章节细纲」「其他设定」新增「自定义字段」管理入口（支持短文本、长文本、数字带单位、单选、多选、是/否六种类型）。
   - 沿用不可变 `cf_<uid>` 存储键与归档机制，改名或换所属模块不丢数据；「世界设定 / 力量体系」的子世界自动继承母级自定义字段；纯表单进度条仅按当前有效未归档字段计数。

2. **设定检索、同名拦截与孤儿字段体检**
   - **Q-11 / Q-12**：统一设定条目取名规则（`resolveRowTitle`，条目名优先于自动编号），核实多页签自定义字段四层按 `tabId` 严格隔离，修复检索漏读 `fieldAlias` 别名问题。
   - **模板编辑器加固**：在模板编辑器的创建/改名环节接入 `builtinFieldNameConflict` 同名拦截，并收敛自定义字段可选类型为六种受完整控件支撑的基础类型（禁止创建 `other` 占位字段）。
   - **孤儿自定义字段体检**：放弃自定义模板前统计并提示受影响条目数；「数据体检」新增第 7 类「孤儿自定义字段」只读提示，不删除任何作者数据。

3. **全链路真源对齐与显式项目隔离**
   - **角色卡 CSV 导出/导入**：对齐 `EffectiveTemplate`，模板新增的自定义字段与改名均参与 CSV 往返。
   - **设定集导出（Markdown）**：对齐 `EffectiveTemplate` / `fieldAlias` / 纯表单自定义字段，消除 `cf_*` 原始键外露并过滤已归档字段。
   - **AI 上下文与语义向量索引**：`aiContext` 与 `indexer` 统一接入角色卡模板与纯表单自定义字段的 `aiReadable` / `archived` 前置过滤，纯表单设定正式进入语义向量索引。
   - **世界观打包与导入**：`worldPack` / `worldImport` 支持携带并重映射纯表单、子世界与卡片的自定义字段定义。
   - **显式 `projectId` 收口**：`exporter`、`aiContext`、`worldPack`、`indexer`、`search` 与 `loadAliasesFor` 在具备项目上下文时统一走 `*For(pid, ...)` 接口，防范异步切书竞态。
