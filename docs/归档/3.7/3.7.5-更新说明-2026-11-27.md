  - 详情区拆分为独立组件，自动封面同时支持列表缩略图与大封面展示；
  - 简介区去除实体边框底框，改为无框自然排版并扩大显示高度，过长时自动省略号截断；

- **「其他设定」去立绘与卡内多条独立明细**：
  - 移除「其他设定」页签误挂的人物立绘区与空占位，自适应卡内高度（不影响主要/次要/NPC 角色卡的立绘上传）；

- **表格页签视觉与滚动修复（Q-07）**：
  - 增加表头与数据列分割线、奇偶行微弱底色区分，并修复表头 `<select>` 筛选下拉文字垂直截断；

## 三、AI 校对档适配 128K~1024K 大上下文窗口

- 针对当前主流云端 API 普遍支持 128K–1024K 大上下文的现状，为「逻辑校对 / 颉文姬深度校对」新增按 `'review'` 路由模型窗口的分级预算策略（非本地模型且开启自动跟随时生效）：
  - **128K 起步**（`≥ 131,072`）：`24,000` 字（足以同时带入完整设定与参考资料）
  - **256K**（`≥ 262,144`）：`48,000` 字
  - **512K**（`≥ 524,288`）：`96,000` 字
  - **1024K**（`≥ 1,048,576`）：`160,000` 字
- 本地模型继续受显存 `numCtx` 保护，不盲目放大。
