| **B-2** | 导出续写包 + 真实网页模型实测（如 Gemini 网页版） | 1. 点击「导出续写包」，分别切换「增量包 / 完整包」「JSON / Markdown 清单」；<br>2. 填写一条作者补充说明，点「生成资料包」并下载 `.md`（或复制）；<br>3. **实机投喂 Gemini 网页版**（可选配合 Gem 存底包 + 对话传增量包），拿到双段回复 | 1. 改任意配置（形态/摘要/章数/说明）时旧预览立即失效，防止下载旧包；<br>2. 装入清单逐段列出字符数与 `完整 / 裁剪 / 省略`；<br>3. 文件包含 `<wcp_meta>` 目录、只读隔离声明、`<wcp_output_contract>`；<br>4. 网页模型按 `<<<WCP_BODY_START>>>` 与 `<<<WCP_CHANGES_START>>>` 正常吐出两段内容 | 组装单测已过 |
| **B-3** | 回流弹窗双顺序与候选入库 | 1. 打开「粘贴网页回复」，粘入 B-2 拿到的真实 JSON 回复；<br>2. 检查 Part 2 展示区是否清爽无重复；<br>3. **先点「比对成候选」再点「追加到章末」**（测引文核验先后顺序）；<br>4. 勾选 1 条可写入条目点「写入勾选条目」，留 1 条不勾选（或看未登记条目） | 1. JSON 正常解析时，**不再**在候选区下面重复出现原始 JSON 代码块；<br>2. 即使先比对再追加正文，基于新写正文的引文核验仍能命中并允许写入；<br>3. 未登记伏笔/关系/物品只提示、不可勾选（不凭空建条目）；<br>4. 仅已勾选条目写入对应记录（状态演变/小传/实体），未勾选条目零变动 | 二次复核已修 `showRawChanges` 与 `effectiveContent` |
| **B-4** | 润色包选区快照与无选区提示 | 1. 在正文选中一段话 → 点「导出润色包」，生成后查 `<wcp_context>`；<br>2. 不选中任何文字 → 点「导出润色包」；<br>3. 在无选区状态下打开回流弹窗点「替换选中片段」 | 1. 有选区时润色包准确带入该选中片段（不受弹窗失焦影响）；<br>2. 无选区导出时给出「会把整章正文作为待润色文本」info 提示；<br>3. 无选区点「替换选中片段」时**只弹 error 提示**，不再随后误弹「已替换选中片段」success 提示 | 二次复核已修返回值 |
| **B-5** | 畸形回复保底与现场切格式 | 在编辑器「粘贴网页回复」中输入带残缺 JSON 的回复（或仅纯正文） | Part 1「复制正文 / 追加到章末 / 替换整章（二次确认）」全可用；JSON 畸形时显示原文并亮出「一键切换为 Markdown 清单模式」 | 解析单测已过 |
