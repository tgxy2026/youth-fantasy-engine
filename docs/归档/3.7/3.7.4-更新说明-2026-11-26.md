# 青春幻想引擎 3.7.4 更新说明（2026-11-26）

> 从 3.7.2 直接升级，覆盖安装即可。**数据格式没有变化**。
> 本版包含开发期完成的 3.7.3（网页资料包）—— 3.7.3 没有单独发过版，从 3.7.2 升上来会一次拿到两批能力。

## 一、第 4 种接力模式：网页资料包（WCP）

「模型设置 → 运行模式」在 API / MCP / ACP 之外多了第 4 个页签 **WCP**。

- **不占用后台在线模式**：后台连着 ACP 或 API 时，WCP 页签照样能用，两者互不干扰。
- **三档资料包**：
  - **底包** —— 只装长期设定：作品概览、世界设定、势力地理、核心角色、人物关系、人物小传、写作规范、名词术语，外加文风与去 AI 味规则；
  - **增量包** —— 当前这一章要用的：本章细纲、前文摘要与末尾正文、本章草稿、出场角色当前状态、物品持有与流转、未回收伏笔；
  - **完整包** —— 两者合并，同 id 段以增量快照为准。
- **入口就在手边**：正文工具栏「WCP 接力」、细纲页头「WCP 推演包」、检查工具页头「WCP 找茬包」（只找问题，不评分、不排名）、角色小传页头「WCP 小传包」。

### 回复怎么拿回来

- 整段粘回「WCP 回流」，它按 `<<<WCP_BODY_START>>>` / `<<<WCP_CHANGES_START>>>` 切成「正文」与「变动摘要」；缺标记时退化为按 `## 第一部分` / `## 变动摘要` 识别。
- 正文可一键入章；变动里的候选（伏笔、关系、状态、物品、小传）**逐条勾选后才入库**，走章后整理同一套写入口：**只追加、不覆盖**，没登记的角色或物品不会凭空造出来。
- AI 返回的 JSON 不完整时**正文不会丢**：整段按正文保留，并提供「换成 Markdown 清单」开关重新解析。

## 二、桌面版：把资料写成本地 Agent 工作区（WCP-Local）

桌面版多一步：把这套资料按模块**写成一个个文件**落到本地目录，交给具备文件读写能力的本地 Agent（Claude Code、OpenAI Codex、Cursor、Windsurf、Antigravity、Cline 等）。

- **放在哪**：默认数据文件同级的 `wcp-workspaces/<书名>-<项目号前6位>/`，可在设置里改，也能一键恢复默认。写入前会做可写探活，遇到只读目录会提示改选。
- **怎么读**：目录里有 `AGENTS.md`、`CLAUDE.md` 与 `manifest.json` 索引，Agent 按需读文件 —— 不用把整包塞进对话，省上下文也少「中间遗忘」。
- **怎么开工**：页面有「复制启动提示词」，里面带工作区绝对路径，粘给 Agent 即可。
- **怎么保鲜**：打开软件 / 打开项目时若资料过期会提醒；支持手动一键更新与定时刷新。更新**只覆写变化的文件**（先写临时文件、落盘成功再改名，Agent 不会读到半截），**不留历史副本、不占额外备份空间，也绝不碰 `outbox/`**。
- **可选**：打开「同步全书历史章节」（出厂关闭）后，额外生成分卷分章的只读正文目录，供大上下文窗口的 Agent 自主翻查前文。

## 三、产物回流：outbox 文件夹

- Agent 把结果写成 `.wcp.json` 或 `.md` 丢进工作区的 `outbox/`，回到软件点「扫描 outbox」一键核对入库。
- 成功导入的文件默认**成对移入 `outbox/imported/`** 归档，防止同一份结果被重复导入（可在设置里关掉自动归档）。

## 四、网页版 / 便携版

没有本地任意写盘权限时，降级为**导出同样目录结构的 zip 工作区包** —— 解压后结构一致，照样能交给本地 Agent 用，不需要任何 API Key。

## 五、顺带改的

- **项目中心（首页）重新排过**：常用入口与最近项目的位置更集中，窄窗口下不挤。登录页与重置密码页恢复默认护眼主题，不再跟随暗色。
- **数据写入改原子写**：先写临时文件、落盘成功再改名，中途失败不会留下半截文件。
- 处理了一批审计提示级问题。

## 验证与边界

- 类型检查 0、lint 0、全量单测通过、六维 + 全量审计 `complete`（本轮审计提示级问题已处理）。
- **未覆盖 / 如实说明**：
  - 本地 Agent 工作区的实机联动只在本机按 Claude Code / Cursor 一类的常规读取方式验过，**没有覆盖所有列出的 Agent**；工作区路径若放在云同步盘，跨设备并发写入的行为未做压测。
  - 网页版 / 便携版的 zip 工作区包是**降级方案**，需要你自己解压后交给 Agent，软件不代劳。
  - WCP 的资料包质量取决于项目里已有内容的完整度：设定没填的地方，包里就是空的。
