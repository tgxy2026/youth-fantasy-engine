# 青春幻想引擎 3.7.1 更新说明（2026-11-25）

> 从 3.7.0 直接升级，覆盖安装即可。本版只加了一个页签、修了几处布局与跳转，**数据格式没有变化**。

## 一、新页签：角色小传

角色管理下多了「角色小传」（默认勾选，可在项目设置里取消），服务主要角色与次要角色：左边选角色，右边分两层。

- **上层：小传正文** —— 随便分段，写完整的人物传记，不受节点结构限制。
- **下层：重要节点事件轴** —— 分「开篇前（前传）」与「正文第 N 章」两段。前传节点可手动上移下移；带章号的节点按章号升序自动对齐，点「原文」直接跳回那一章。

## 二、内容从哪来：提拔、整理、起草

- **从状态演变提拔**：3.7.0 记下的状态演变，可以把其中关键状态一键提拔成小传节点，**这条不消耗 AI 额度**。
- **AI 从正文整理节点**：也可以走颉文姬「整理」，抽出里程碑候选 —— 勾选之后**只追加、不覆盖**已有正文与节点。
- **AI 起草 / 续写小传**：只生成预览，由你决定追加到末尾、替换还是放弃。单个角色可导出 Markdown。

## 三、图鉴详情可直接改关联

- 图鉴的详情面板里，**跨表关联与角色关联现在能直接编辑**，不用绕回表格页签改单元格。
- 保密等级的每个选项都补了说明，选之前能看清差别。

## 四、小修

- **布局与按钮规范统一**：角色小传与角色关系两处的间距、按钮层级收口（带文字的按钮不再用幽灵样式）。
- **节点类型支持自定义**：不再只有固定的几类，可自行增补。
- **示范项目补齐 11 名角色的完整小传**，打开就能看结构。
- **修掉三处**：角色卡之间的跳转、角色选择逻辑、按别称搜索时与小传条目对不上且折叠状态错乱。

## 验证与边界

- 类型检查 0、lint 0、全量单测 **524/524**、六维 + 全量审计 `complete`（1003 个文件 / 0 候选 / 26 项工具自检通过）、红线 11–15 全部 0、结构化提示词输出约束 P4 **0/42**。
- 发布前三形态（安装版 / 便携版 / 网页版）实机探针在本版发布流程中完成，结果见发布记录。
- **未覆盖**：语音转写真机链路仍需要你自备可用 Key（本版只验录音入口与配置闸）；角色小传的超长传记（数十万字单角色）没有做过性能压测。
