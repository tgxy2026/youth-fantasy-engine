## 二、修复的明确问题（红线）

### 1. 网页更新横幅内联 `92vw`（红线 11）

- 文件：`src/components/app/WebUpdateBanner.tsx`
- 问题：`max-w-[92vw]` 不随界面缩放的 `zoom` 折回；132% 缩放时视觉宽度超过视口，横幅可能被裁切。
- 修复：改为 `style={{ maxWidth: foldVh('92vw') }}`，走 `theme.ts` 的统一折算函数。
- 复核：复跑红线 11 = **0 处**。

### 2. 节奏曲线 SVG 颜色写在表现属性里（红线 12）

- 文件：`src/components/outline/PaceAnalysisPanel.tsx`
- 问题：`stroke="rgb(var(--ink-700))"` / `fill="rgb(var(--amber))"` 写在 SVG 表现属性中；部分浏览器会回退成黑色或透明。
- 修复：三处改为 `style={{ stroke: ... }}` / `style={{ fill: ... }}`。
- 复核：复跑红线 12 = **干净（均走 style）**。
