# 青春幻想引擎 3.3.4 更新说明

> 一句话：**这一版让青春幻想引擎在手机网页版、平板、以及桌面小窗口下真正可用。**  
> 重点是全站 55 个页签的响应式防截断、触控交互盒放大、酒馆与推演画布窄屏自适应、浏览器全屏与证据包打印导出。

---

## 一、全站 55 个页签响应式防截断：窄屏下内容不被挤爆

以前在手机浏览器、平板分屏或把桌面窗口缩窄时，有些页面固定双栏甚至三栏，容易把输入区挤成一条窄缝，或者表格撑破页面产生晃动的横向滚动条。

3.3.4 对全站全部 55 个页签进行了系统性的响应式与防截断重构：

| 页面板块 | 以前的问题 | 现在怎么处理 |
|---|---|---|
| **酒馆 4 大页面**<br>（跑团/剧本/剧情/角色） | 固定双栏/三栏，窄屏下列表把正文挤窄甚至把操作按钮挤出屏幕 | 容器宽度收窄时**自动切换为上下自适应布局**，列表与操作栏平滑换行，正文与输入区保留完整宽度 |
| **情节推演画布** | 固定 256px 章节栏挤占窄屏画布，375px 宽度下画布只剩 70px | 工作区收窄时章节栏与推演画布上下独立分层，画布保留完整操作空间，支持点击缩放与移动端平移连线 |
| **18 张宽表格** | 宽表撑破整页横向滚动，末列保存与操作按钮看不见 | 表格限制在内容区内部独立横滚并提供滚动提示，页面根节点严格零横向溢出，行内输入与末列操作触手可及 |
| **主从卡片与详情** | 窄屏下两栏强行并列；切卡离页返回滚动位置跳动 | 窄屏自动切换单栏；重写滚动恢复等待逻辑（同时等待可视高度与内容总高度稳定），切卡离页返回精确定位 |

## 二、触控环境优化：手小也能点得准（44×44px 交互盒）

在手机和平板等粗指针（coarse pointer）环境下：

- 关键保存、同步、关闭、导航、行内输入与操作按钮的**有效命中区域扩大到至少 44×44 CSS 像素**；
- 保持原先精致的视觉图标尺寸，同时扩大隐形点击盒，相邻按钮不重叠、不误触；
- 弹窗在窄屏下采用**贴合屏幕的近全屏展开**，标题与确定取消常驻可见，软键盘弹起时不遮挡确认按钮。

---

## 三、浏览器全屏与证据包打印 / 另存 PDF

- **全屏模式**：接入标准 Fullscreen API 运行时探测。全屏根挂载于文档顶层，保证所有 Portal 浮层（确认弹窗、菜单、全局老板键遮挡层）在全屏时依然正常可见可操作；
- **证据包打印**：创作轨迹的证据包新增“打印 / 另存 PDF”标准入口，预先建立打印上下文防弹窗拦截；如遇浏览器不支持或拦截，自动平滑退回到自包含 HTML 文件的安全下载，离线另存同样不丢字。

---

## 四、本地模型边界澄清与端能力对齐

- **网页版明确禁用本地模型**：严格遵循产品 P9 安全策略，网页版（账号/游客）不提供连接本机或局域网模型入口，统一明确说明文案，避免手机误填电脑端点；
- **端能力状态统一**：统一四种形态（桌面版、便携版、网页云端、网页游客）的能力解析契约，设置、外观、帮助手册与诊断信息保持绝对一致。

---

## 五、边界与已知限制（如实透明说明）

依据《3.3.4 开发规划》规范，本版实测与客观条件边界如下：

1. **创意写作恢复（承接 3.3.3 R-1）**：维持明确降级方案，断点按章记录；续写界面注明“*不承诺 exactly-once 事务，系统强杀最坏重写最后一章*”，但绝不会漏写、也不会冲掉你修改过的内容；
2. **本版未覆盖说明**：
   - 本版在 Edge / Chromium 模拟器下完成了 320×568、375×667、430×932 视口的 55 页面几何实测（根溢出 0px）与性能探针（输入 p95 17.4ms，导航 p95 134.7ms）；
   - **受物理设备与生产账号限制，本版未覆盖**：iOS Safari / Android 原生物理真机系统输入法手势深度走查、真实多端云账号并发冲突物理竞态、真实商业大模型双人盲评。

## 安装与升级

- **桌面安装版**：`青春幻想引擎-Setup-3.3.4.exe`（直接覆盖安装即可，原有作品、本地设置与离线备份完好保留）。
- **便携版（免安装）**：两个按平台分发的压缩包 ——
  - `青春幻想引擎-便携版-3.3.4-Windows.zip`（解压后双击 `启动.bat`）
  - `青春幻想引擎-便携版-3.3.4-macOS-Linux.zip`（终端运行 `bash 启动.sh`）
  需要本机安装 Node.js 18+；数据保存在 `data/` 目录中，整个目录随 U 盘即拔即走。
- **网页版**：[https://youth-fantasy-engine.online](https://youth-fantasy-engine.online)，浏览器打开即用，已同步升级至 3.3.4。
