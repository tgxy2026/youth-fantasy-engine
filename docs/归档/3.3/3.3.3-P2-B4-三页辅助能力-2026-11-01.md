## 1. 写作规范 `style`（保留 FormSheet）

### 1.1 导入 / 导出（`src/lib/forms/styleIO.ts`）

- 存储结构仍是 `模块名::字段名 → 字符串`；导出文件 `kind: 'yfe-style-sheet'`、`version: 1`。
- 只导出本页**已知字段**，**空值也保留**（"清空过"这个事实不能在往返中丢失）；未知/历史残留键不带走。
- 导入：`模块::字段` 精确匹配；只给字段名且全页唯一时也认，重名不猜；未知键忽略并列出，
  非字符串值跳过并列出；`tabId` 不符 / `kind` 不符 / 缺 `fields` ⇒ **整批拒绝**，不半批成功。
- 差异预览只列"导入值非空且与当前不同"的项；**导入空值不覆盖当前**（避免误清空）。
- 界面：`src/components/sheets/StyleTools.tsx` 的「导出 / 导入」按钮 + 预览弹窗；
  采用后只并入**草稿**，落库仍是作者按「保存」；取消零写入。
- 证据：`tests/styleIO.test.ts`（21 条）覆盖空值/多行/中文/未知字段往返、别页签与别类文件拒绝、
  空值不覆盖、部分采用、空表单导出。

### 1.2 按章反推规范（`src/lib/aiTasks/styleInfer.ts`）

- 作者选一章（只列有正文的章），材料上限 6,000 字，超出**明示截断**；一次调用，不自动重试、不换模型。
- 输出只允许本页已有字段键：`parseStyleSuggestions()` 丢弃编造 key、重复项、空值；
  结构不对当作"没有建议"（不猜、不修补）。
- 界面逐条显示「现有 / 建议 / 理由 / 原文引用」，默认只勾选"确实会改动草稿"的条目；
  点「采用选中」才并入草稿（一次 setState 合并），取消/关窗零写入。
- 提示词 `style-infer`（组：编辑与审校）已登记进 `PROMPT_ORDER` / `PROMPT_SETS`，可编辑。
- 证据：`tests/styleIO.test.ts` 的解析段（6 条）钉住只认已知 key、去重、代码块包裹、非法形状。

## 2. 写作进度 `progress`（复用现有能力，补专项证据）

- 盘点结论：Dashboard 已有「自动码字记录（near-7 自然日）」与「写作进度手工登记」两套视图，
  自动口径用于统计卡与预估，手工口径只服务下方柱状图，**不相加**；本次不新增页签能力。
- 抽出 `src/lib/stats/goalPace.ts`，把原先只写在 `WritingGoals` 里的口径变成可测纯函数：
  - 近 7 个**自然日**回填，缺日按 0 计入分母；
  - 无记录 / 日均 0 / 未设全书目标 ⇒ 不返回预计日期，并给 `reason`（界面如实说原因）；
  - 已达标 ⇒ `remaining = 0`，不给"还需 0 天"的日期。

  实际预估只吃自动记录；已改为"手工登记只作参考，不并入自动统计"。
- 证据：`tests/goalPace.test.ts`（19 条）覆盖含零值日的日均、7 天窗口端点、无记录/无目标/已达标、
  向上取整、手工数据不在入参。

## 3. 灵感素材 `ideas`（重复提示 + 转目标条目）

### 3.1 重复提示

- `findIdeaDuplicates()`（`src/lib/forms/ideasConvert.ts`）：归一后逐字相同，或字符二元组 Dice ≥ 0.8
  且长度 ≥ 6；短词（"雪"）不按相似度判重。
- **只提示**：行号列显示小黄点，悬停说明"与/近似于哪些编号重复"；不拦输入、不自动合并/删除。
- 用当前草稿值计算（`sortedRows + drafts`），刚改的文本立即提示，不必先保存。

### 3.2 转目标条目（先预览、确认才建行）

- 目标表：伏笔追踪（写「伏笔内容」）、支线剧情（写「支线目标」）、爽点节奏（写「爽点内容」）。
- 预览列出"会写入哪几列、值是什么、哪些重要列会留空"；未确认/取消/切换目标均零写入。
- 目标行：编号按 `nextAutoCode()` 补最小空号；备注写 `来源：IDEA0003`（同时是防重复的判据）。
- 重复点击同一来源：目标表已有同一 `来源：` 标记 ⇒ 只回报"已转过"，**不再建行**。
- 失败语义：目标行建失败 ⇒ 来源行一个字段都不改；来源标记保存失败 ⇒ 保留已建目标行并明确提示，
  不删作者确认过的成果、也不宣称原子回滚。
- 来源行成功标记：状态=`已用`、备注追加 `→ 已转 F0002（伏笔追踪）`；同一去向不重复追加。
- 界面：`IdeaConvertDialog.tsx` + 行内「转为目标条目」按钮（仅 ideas 表）。
- 证据：`tests/ideasConvert.test.ts`（35 条）覆盖近似/逐字判重、短词不判重、三目标映射、
  编号补缺、来源引用、重复点击复用、缺列/空素材拒绝、来源备注不叠加、末尾排序。
