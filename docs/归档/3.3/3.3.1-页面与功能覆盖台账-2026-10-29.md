### 动态分卷页实测（2026-10-30）

隔离示范项目、1440×900 下从运行期读取 `getVolumeTabs()`（探针 `.workbuddy/tmp/vol-tabs-probe.mjs`）：

| 项 | 实测值 |
|---|---|
| 页数 | **3 个**（示范项目三卷：`第一卷 风起云州` / `第二卷 剑鸣中州` / `第三卷 剑锁中州`） |
| id 形态 | `chapter-vol-<卷 id>`（卷 id 是运行期生成的，**不能写死进任何清单或测试**） |
| 名称 | `第N卷 卷名` —— 卷改名后页名随之变 |
| 类型 | `table`（每卷一张章节台账，每章一行），字段来自表格模板而不是 `modules`（实测 `modules` 为 0） |
| 页内说明 | 取自 `TabDef.description`，带卷名与「串联伏笔 / 时间脉络 / 爽点」的作用说明 |
| 分步引导 | 走**类型模板**而不是手写引导：id 为 `auto-chapter-vol-<卷 id>`，**3 步**（表格模板：一行一条 / 新增 / 保存） |

**三条口径**（写下来避免下轮重复讨论）：

1. **不计入手册覆盖度**：`tabsWithoutHelp()` 只按 `ALL_TAB_IDS`（55 个静态入口）算，动态页不在其中 ——
   这是有意的：卷是数据，不是功能页。它们的内容由《章节总表》一篇统一覆盖（同一套表格语义）。
2. **引导按卷独立记录**：记录键含卷 id，新建一卷首次进入会弹一次 —— 对新卷确实是「新页面」，
   但没有「同一卷改个名就重弹」的问题（键不含卷名）。
3. **不能把 `chapter-vol-*` 写进任何静态清单**：卷 id 运行期生成，写死必然过期。
   台账、测试、手册都只能按「类型模板」与「静态入口」两类分别讨论。

动态分卷由 `getVolumeTabs()` / `chapter-vol-*` 构造，不能把固定 `chapter-master` 当成已覆盖每个分卷。`geomaps` 是地图数据表而不是独立页签；实际地图入口是 `geography-map`。项目中心、登录/游客、首启、设置、弹窗和侧栏公共工具在静态页签之外，须按实际运行形态补充。

## 手册覆盖现状（P1，2026-10-29 三次补齐后）

内置手册已交付 **40 篇 / 83 段，覆盖全部 55 个页签**（`tabsWithoutHelp()` 返回空）。篇数与覆盖数都由注册表实时算出，界面标题行与「按功能查阅」底部显示同一份数据，不手工维护。最后一篇补的是「情节推演」（`page-plot-canvas`，事实取自 `schemaTabs` 的 description / tips 与 `PlotCanvas.tsx` 的实际行为）。

**不能因为「全覆盖」就当作「手册已完成」**：每页仍只有 1～3 段说明，独有按钮、边界情况、失败补救没有逐项教程；`verifiedAgainst` 只标到 3.3.1，后续界面改动需要同步复核。上表「手册、引导与证据」列中，未逐页人工核对独有入口的页面仍应为「待盘点」。

分步引导（P2 交付基础，P3 铺满，2026-10-29）：**55 个入口全部能拿到引导，且都有高亮锚点**（手写 6 条 + 表单/表格/卡片三类模板 31 条 + 18 个专用页的页头锚点）。模板用途文字取自 `TabDef.description`；18 个专用页只有「用途说明（居中）+ 页头说明（高亮）」两步，**未逐页人工核对独有入口**，其「手册、引导与证据」列仍应为「待盘点」。
