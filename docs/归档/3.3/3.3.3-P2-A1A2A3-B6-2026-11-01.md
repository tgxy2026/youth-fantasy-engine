## 1. A1 重复与表达观察（`src/lib/audit/repetition.ts`）

- 范围：当前章 + 按卷章顺序在其之前最多 N 章（1–30，默认 10），**不含后续章**；空章跳过并如实计数。
- 本地检测：标准化后的句/段完全重复、三字词组重复（单章 ≥3 次）、近似句候选（Dice ≥0.8，单列 `candidateOnly`）。
- 每条都带 `chapterId / start / end / quote`；`quoteMatches()` 可逐字复核定位，改文后由指纹与旧定位失效。
- 忽略：组 id = `kind:hash(标准化文本)`，正文一变即失效；记录在本机 meta `auditIgnore::<项目>`，可撤销。
- 缓存：`auditRepetition::<项目>`，含算法版本 + 参与章节正文指纹；界面只在指纹一致时展示，否则提示重扫。
- 界面：投稿前自检新增「重复与表达观察」区块（本地、不发 AI），覆盖数/跳过空章/确定重复/候选分别显示。

## 2. A2 章内变化清单（`src/lib/audit/changeList.ts` + `lib/aiTasks/changeList.ts`）

- 材料：`buildChangeMaterial()` 单次最多 10,000 字，超出**明确截断**（界面在确认框里写清"只发送前 N 字"）。
- 调用：作者点按钮 → 确认（1 次调用、可能计费、不会自动重试/换模型）→ 一次请求；可取消（AbortController）。
- 核验：`verifyChangeItems()` 把每条 `quote` 在正文里逐字定位；对不上/类型未知/重复一律剔除；最多 3 条。
- 结论：`found / few / insufficient / not-run`，**没有"通过/空转"**；0 条只显示"线索较少"。
- 缓存与反馈：报告 `auditChange::<项目>::<章>`（带章正文指纹）；「我不认同」`auditChangeDissent::<项目>`，只在本机、可撤销。
- 迟到保护：保存前用 `isReportCurrent()` 校验章 id + 指纹，切章/改文后的回包不写。
- 提示词：`chapter-change-list` 已登记进 `PROMPT_ORDER` / `PROMPT_SETS`，可在设置页编辑。

## 3. A3 能力来源与诊断（`lib/ai/capabilityProfile.ts` + `capabilityTest.ts` + `ModelCapabilityPanel`）

- 优先级：**用户覆盖 > 未过期实测 > 内置推断 > 保守默认**；`capabilitiesOf()` 新增端点 + 配置指纹参数。
- 缓存键：规范化端点（去协议/大小写/尾斜杠/userinfo/query）+ 模型 + 配置指纹（含协议/结构/推理）；
  记录本机 `aiCapability::*`，**不含密钥**；30 天过期，启动 `hydrateCapabilityCacheFromStore()` 只读不联网。
- 实测：一次很小的 JSON 请求，默认 15 秒超时、可取消；成功才写缓存；401/429/网络/超时/取消一律 `unknown`，
  **不写"不支持"**；能解析 JSON 对象 ≠ 支持 schema（schema 记 `unknown`）。
- 诊断：设置页显示来源、本次下发什么、实测时间、下一步；失败文案说明"不改变能力结论"。
- 真实请求链路：`chat()` 已带端点与配置指纹，实测结论能真正影响后续请求形态。

## 4. B6 字段转换与永久删除（`lib/atlas/fieldOps.ts` + `AtlasFieldManager`）

- 值一律是字符串：转换**只改校验/展示**，不改已填值；类型转换只有一次 schema 写入，天然无半状态。
- 逐值可逆：`001`、`1e3`、`-0`、`1.50`、超安全整数、非数字 → 整批阻止（不归零/不截断/不四舍五入）；
  文本↔长文本按 2000 字上限逐值检查，超限整批阻止。
- 永久删除：先出影响数与依赖（被卡片摘要引用即阻止，提示先解除）；执行前自动备份，建不成备份就中止；
  **先删定义、再清值**，清值失败只留不可见孤儿键，不会出现类型/值不兼容。
- 归档仍是推荐的隐藏方式（定义与内容都留着）。
