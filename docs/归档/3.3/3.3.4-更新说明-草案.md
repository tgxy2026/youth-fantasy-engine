# 3.3.4 更新说明（草案 · 未发布）

> ⚠️ 这是**草案**：本版尚未封装、未发布、未推送远端。发布前须补齐「本版未覆盖」一节的实测结果。

## 一句话

手机、平板与网页版的触摸操作真正可用了：命中区按 44×44 落地、表格在触摸下不再挤成一团、
地图能点击缩放、弹窗在窄屏近似全屏；能力边界（全屏 / 打印 / 本机模型 / 离线）现在有一份
**由同一份解析驱动**的「本机运行能力」面板，手册与设置不再各说各话。

## 新增与改进

### 触摸与窄屏（P1 / P2）

- **最小命中区 44×44**：文字按钮与图标键在触摸设备上扩大到 44（视觉尺寸不变、不撑高工具栏）；
  手写裸按钮（制度页条目删除、地图列表改名/删除、「点击改名」等）逐个收编，不再有 15×15 的危险小方块。
- **表格密度**：粗指针下行内输入 / 下拉 / 多行文本抬到 44 并换行增高，桌面密度保持不变；
  自定义下拉、历法、日期、角色、跨表引用五个选择器的**收起态触发器**与下拉菜单项一并在触摸下 44。
- **单元格编号 chip**（F01 / H01 跳转）与**长表单弹窗**（≥576px 档）在触摸下分别给到 44 与 96vw×92vh；
  短确认框仍居中。
- **地图画布**：新增可点的 ＋/－ 缩放（原来只有滚轮），帮助与状态条同步说明。

### 能力与一致性（P1 / P3）

- **「本机运行能力」面板**（使用指南页）：九项能力 × 四态（支持 / 有条件支持 / 不支持 / 待确认）+ 原因码 + 回退，
  文案与设置页（老板键、模型设置）同源。
- **浏览器全屏**：网页版与便携版从「完全没有入口」变成走浏览器 Fullscreen API；
  状态以 `fullscreenchange` 为准（Esc、系统退出会同步），被拒或环境不支持时给明确提示并指向「专注模式」。
- **证据包打印**：非桌面形态点「打印 / 另存 PDF」会**直接打开打印页**并唤起打印对话框（不再只下载 HTML）；
  只有在弹窗被拦或环境不支持时才退回下载，且不会谎报「PDF 已保存」。

## 已知限制（请如实告知使用者）

1. **续写的断点不保证严格事务**：断点记录与章节落库不是跨 store 事务（本地文件后端没有事务原语）。
   在写入途中被系统强杀时，重开可能**重写最后一章**；不会丢其它已确认保存的章节。界面已写明这一点。
2. **本机 / 局域网模型在网页版仍禁用**（产品策略，非能力缺陷）：请用联网模型，或改用桌面版 / 便携版。
3. **手机上的 localhost 指手机自己**，不要把电脑的模型地址填进去。
4. **打印排版**：长表分页、重复表头、超长单元格跨页沿用既有导出样式，尚未逐项实测（S-11）。
5. **全屏**：浏览器是否允许由页面权限与策略决定；不支持时请用「专注模式」（它不隐藏地址栏，也不等于全屏）。

- 真机：全屏进入/拒绝/外部退出、打印与文件目的地（S-08/S-10/S-11）；
