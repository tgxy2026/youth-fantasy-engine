# 青春幻想引擎 3.3.1 更新说明

> 一句话：**不会用的时候，软件自己告诉你。**
> 这个版本没有新页签，做的全是「找不到、看不懂、跳不到」这件事 —— 内置手册、页签引导、答疑助手，以及一批跳转与滚动的修正。

---

## 一、新增：内置使用手册

- **41 篇文章、覆盖 55 个页签入口**，全部**离线内置**，不联网也能查。
- 顶部搜索按「标题 / 关键词 / 段落标题 / 正文」分级加权，中文说法能对上功能名（说「字太小」能找到「界面缩放」）。
- 点搜索结果**直接落到那一段**，不是丢给你一篇文章自己找。
- 查不到就**如实说没找到**，并给栏目建议 —— **不会硬凑**一篇不相关的文章。

## 二、新增：页签聚焦引导

- 第一次进某个页签时，自动在关键入口上打高亮，配一句话说明「这里干什么」。
- 可以**跳过本页**（不再弹）、也可以随时**重看这页的引导**。
- 界面缩放到 130% 时高亮框仍然贴合目标，不会偏出去。

## 三、新增：使用答疑助手

- **不配模型也能用**：查手册、看片段、点开原文，一律可用；这时明确标注「这一条不是 AI 回答」。
- 配了模型之后可以问「这个功能怎么用」，但回答**必须附原文依据**：
  - 每条依据都能点开、回到手册里的那一段；
  - 依据必须**逐字出现在本次召回的原文**里，对不上就整条作废，退回手册检索结果；
  - 手册没覆盖的，就说没覆盖，不凭常识编按钮和菜单。
- 手册资源版本不一致时（外壳与内容包不同步），**暂停 AI 回答**并说明原因，手册文章照常可读。

## 四、新增：连续追问

- 「那还需要模型吗」「它会不会丢」这类**省略句**能接上：会拿**上一问的主题重新检索**，
  而不是把上一条回答直接塞给模型当资料。
- 回答上方会显示「**接着上一问：《…》**」，你能看出它在接哪一问。
- 上一轮的原文**不在本轮片段里**时，不会被当成本轮依据（校验口径一点没放松）。
- 说不清你指的是哪个功能时，**先问你要哪个**，并给出候选，不会默认成「刚打开的那一页」。

## 五、修正与改进

| 项 | 变化 |
|---|---|
| **左右分栏切卡片** | 右栏滚到中间后点另一张卡，**停在原处**，不再跳回顶部（角色管理 / 世界设定 / 制度四页签） |
| **打开章节** | 点**任何一章**都落到**该章末尾**、光标在文末，直接能接着写；章节列表首次打开**停在最新一章**（原本要往下翻几十行） |
| **检索 / 校对跳转** | 跳过去之后**能看见选中了哪一句**（此前只滚到附近，看不出是哪句） |
| **全文检索多处命中** | 拆成「第 1/3 处」，点第 2 处就落在**第 2 次出现**的位置 |
| **界面缩放** | 160% 下三位数输入不被裁；130% 下侧栏浮层不再压住「打开项目」 |
| **设定表方向键** | 同列上下行之间移动；数字框、日期框、下拉、折行的长文本**自动让行**（各自要用方向键） |
| **较真的小修** | 去掉混版本提示里一个「点了也没用」的按钮；混版本提示措辞与「手册没写」彻底分开 |

## 六、网页版

- 网页版**统一禁用本机模型**（浏览器访问不到你电脑上的 Ollama / LM Studio），并明确提示改用联网模型；
  桌面版与便携版不受影响。

---

## 七、已知限制（如实列出）

1. **真机未验**：Android / iPhone、以及手机上的软键盘、文件选择、切后台回收，本版只用桌面模拟触摸验证过布局与保存回读。
2. **中文标点自动配对**：本版做了代码侧彻查（组合输入期间不插手、只认「恰好一个中文左标点」），但**搜狗输入法的真实按键序列仍未收口**；如果你用的是搜狗且发现引号不配对，请把「打什么、出现什么」告诉作者。
3. **读屏软件**未做真实朗读验证（只校验了可访问性属性）。
4. **网页版部署**未在真实 CDN 缓存场景复核「外壳与内容包不同版本」的提示。
5. **连续追问**的判据用可控的假模型验过，真实模型下的措辞观感仍需你自己体会。

## 八、升级须知

- 模型配置、项目数据、备份格式**均未改变**，直接覆盖安装即可。
- 手册与「已看过哪些引导」记在本地，重装不会带到新机器（属于预期）。
- 若你之前关过页签引导，升级后不会自动重弹；想重看用页面右上角的「本页指引」，或首页「新手引导 / 使用手册」。
