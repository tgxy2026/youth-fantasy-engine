# 青春幻想引擎 1.3 使用说明

> 本版聚焦「可用性缺口」与「护城河加固」。轻量 AI 接入按计划延后至主要功能定型后再做。
> 所有新功能均已内嵌「？」说明气泡 / 按钮悬停提示，本文档为集中速查。

---

## 一、全文检索（P0 · 填最大可用性缺口）

**入口**：编辑器工具栏的 `⌘` 图标，或全局快捷键 **Ctrl / Cmd + K**。

- 一次搜遍**全书**：章节正文、角色卡（主要/次要/NPC）、全部设定表（国家/地理/名词术语/伏笔/关系网…）。
- 输入即出结果，按 **章节 / 角色 / 设定** 分组；中文按字/词切分、英文按单词，标题命中优先置顶。
- 键盘操作：`↑ ↓` 选择，`回车` 打开，`Esc` 关闭。
- 跳转逻辑：章节 → 直达正文编辑；角色 / 设定 → 直达所在页签。
- 纯前端、零依赖、可离线（便携版 / 桌面版均可用），不上传任何数据。

---

## 二、编辑器体验增强（P1）

工具栏新增四个按钮（在「放大镜」全文搜索替换左侧）：

| 图标 | 名称 | 作用 |
| --- | --- | --- |
| ⌘ | 全文检索 | 唤起 Ctrl/Cmd+K 命令面板（见上） |
| 👥 | 本章引用侧栏 | 列出**本章正文里出现过的已登记角色名 / 术语**，点击直达对应角色卡 / 术语表 |
| 🖍 | 引用名内联高亮 | 开 / 关正文里已登记角色 / 术语的琥珀色高亮标记 |
| 📖 | 本章大纲 | 跳转到「章节细纲」页签 |

**实现要点（兼容性）**：高亮采用「透明 textarea + 对齐叠层」方案，正文仍是原生 textarea，
**不破坏撤销栈**；叠层文字色随主题变量走，四套主题（暗色/护眼/午夜蓝/羊皮卷）均清晰可读。

---

## 三、时间线无环校验（P1）

在「故事时间轴」视图（人物关系网 / 故事时间线页签的「时间轴」模式）：

- 自动在**叙事顺序**上逐章比对「故事内时间」。若某章的故事内时间**早于其前序章节**，判定为「时间倒流」。
- 命中时在页面顶部给出**非阻断告警横幅**，并标出具体章节数；对应节点卡片加红色「倒流」角标，点击查看详情时也会提示。
- 可能是**有意倒叙**，也可能是**连续性漏洞**——仅作提示，不强制。建议在「表格视图」核对相关章节的「故事内时间」与「时间线检查」。
- 兼容现有 S 形蛇道布局与多历法数值体系（跨历法排序键 `历法值×1e10 + 故事内时间键`）。

## 四、关系图收起（P1）

在「人物关系图」视图（人物关系网页签的「关系图」模式）：

- 关系网已用 Fruchterman–Reingold 力导向布局自动排布（纯 SVG、零依赖）。
- **点击任意人物节点即可收起**：隐藏该人物及其全部关系边，快速给超大关系网「减负」。
- 被收起的人物汇总在图下方，显示为小标签；点击单个标签可单独展开，或用「展开全部（N）」一键恢复。
- 布局坐标由全部节点一次性算得，收起 / 展开后位置稳定不乱跳。

---

## 五、备份加固 · 迁移 / 换机（P1）

在「项目管理页 → 某项目 → 备份与恢复」弹窗，新增「迁移 / 换机」区块：

- **导出迁移包**：把整个项目（卷/章/设定/角色卡/每日统计/自定义选项）打包为单个 JSON 文件。
  - 可设密码：**AES-GCM 加密（PBKDF2 派生密钥，10 万次迭代）**，密码不出本机；留空则不加密。
- **导入迁移包**：选择文件即可恢复。加密包导入时会提示输入密码；导入成功后自动打开新项目。
- 与「自动备份」（每日 1 份 + 每 5 分钟滚动 60 份）分工：**自动备份在本机滚动保留防丢稿，迁移包用于跨设备搬运**。

## 兼容性说明

- 全文检索、引用高亮、时间线校验、关系图收起、迁移包导入导出，均建立在既有数据模型与存储适配器（`StoreOps`：IndexedDB / 便携 / 桌面）之上，未改动已有字段结构。
- 迁移包导入会生成**全新项目 id**（旧章节 / 联动行 id 自动重定向），不会与现有项目冲突。
- 验证：`tsc --noEmit` 0 错、`vite build` 0 错（约 1566 模块）。封装时只需将 `package.json` 的 `version` 改为 `1.3.0`，脚本会自动读取。
