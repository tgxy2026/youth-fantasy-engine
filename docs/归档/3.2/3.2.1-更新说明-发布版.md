## 青春幻想引擎 v3.2.1 —— 修好你反馈的标点问题，把 3.2.0 欠的账补上

这是 3.2.0 之后的**收口版**：修掉一个你实际遇到的 bug、修掉一个会让功能永久堵死的死锁，
再把 3.2.0 方案里写完却没接上的入口补齐。**不新增页签**。

### 先说你反馈的那个

- **中文标点自动配对，现在真的会补右半边的了** 🔴

  3.2.0 的更新说明里写了「打 `“` `《` `「` `（` 自动补右半边」，但你实测搜狗和微软拼音都不补。
  查下来不是没做，而是**做错了一处判断**：代码里「输入法正在选字就一律不插手」这道保护挡在最前面，
  而中文输入法**上屏标点时那个标志仍然是 true** —— 于是配对逻辑永远走不到。
  （微信输入法自己会补右半边，所以去年发版后一直没暴露。）

  本版把配对判断前置：组合态只在「恰好插入一个中文左标点」时才补，其余（选字上屏）仍照旧不打断。
  自动化实测：非组合态 `“` `《` `（` 三条全部补全；修前组合态只出左半边（正是你看到的现象），修后 `“”→“”`、`《`→`《》`。

> ⚠️ 真机复测还没做（需要人手动切输入法），这一条请你在自己的电脑上验一次。

### 还修了一个会让功能永久堵死的死锁

- **候选生成不会再"越用越满、最后再也生不出来"**

  候选稿的正文是存在"工作产物"里的，而**放弃 / 应用 / 过期都不会删掉那份产物**。
  单项目上限 200 份，攒满之后新候选就永远存不进来，界面提示「请先清理旧候选再生成」——
  可候选列表里根本看不到那些残留，你清理完再试还是满的。

  本版加了真正的回收器：**已放弃 / 已应用且超过 30 天**的旧产物会被自动回收
  （待审阅、正在应用、等核对的**一律不动**），并且只在配额不够时才触发，平时零开销。

### 这次多了什么

- **正文与细纲对照**（正文写作 → 本章资料）：点「开始核对」，把这一章的细纲逐项对照正文，
  给出五态结论 —— **已体现 / 部分体现 / 与计划不同 / 未体现 / 证据不足**。
  🔴 每条结论**必须附一句能逐字落在正文里的原句**，摘不出原句就强制判「证据不足」——
  不让它凭印象说"写了"。判「未体现 / 与计划不同」的可以一键落成检查报告、加入工单。
- **封存版本差异对比**（世界引擎）：封存了 v1 / v2 / v3 之后，可以选两个版本对比，
  按条目列出**新增 / 删除 / 修改**与字段前后值，未变的折叠、0 值不染色，可**复制成 Markdown**。
  纯只读 —— 不修改当前项目、也不动版本历史；两版内容一致时会明确写「两版内容一致」
  （指纹相同就是没改过，不是"差异太小看不见"）。
- **复检结论刷新后还在**：以前跑完复检，切页签或刷新就只剩空白。
  现在每章最近一条结论存在项目里（跟项目一起同步/备份/导出），
  面板空态会列「最近复检记录」，并且**区分「有结论」和「跑过但没跑成」** ——
  失败也留痕，不会让"没跑成"看起来像"从没跑过"。
- **换模板时会有横幅告诉你**：某个页签正在更换模板期间，它的草稿恢复 / 自动保存 /
  AI 填写回写 / 导入都会被拦下（避免新旧字段结构混进同一行）。以前只拦不说，
  你只会觉得"保存没反应"；现在顶部横幅**点名是哪个页签**、说明改动还在编辑器里没丢，
  迁移结束自动消失。
- **图鉴两处小改**：导入预览会显示这份资料包涉及哪些字段类型（单选 / 多选导入后要配选项，
  提前知道能少一次意外）；上传主图的规格提示改成跟随实际限制自动变化，不再写死数字。

### 工程侧（你看不到，但下次发版更快更准）

- 新增发版检查命令 `npm run release-check`：版本一致性、页签与板块数、产物体积、
  文档引用、外链、工作区状态一次过，分级 OK / WARN / FAIL。
- 修正 README 的一处事实错误：页签数写的是 50，实际是 **55**
  （「开书定位」板块一直有 7 个页签，表格里只列了 3 个）。
- 六维审计把 3 条红线清成了 0（复制走统一入口、视口高度随界面缩放、带文字的按钮不再静止无框），
  顺手清掉一批零引用的死代码，并把「该接未接」的入口逐条登记成待办
  （不为了数字好看而删掉实现）。

### 升级前请先备份

本版**没有数据结构变更**，升级不需要迁移；老项目的候选、检查报告、复检记录都照常可用。
仍建议升级前在「数据坞」里备份一次（安装目录与数据目录是分开的，
卸载重装不会动 `%APPDATA%\youth-fantasy-engine`）。

### 本版没做的

- **表格行虚拟化**（1000 行 × 60 字段仍慢）与**主包拆分**：推 3.3.0，不和验收混在一版。
- **10 个"该接入口"的能力**（写失败回执、检查↔候选关联、迁移回滚、字段换分组…）：
  逐条判完并写清了接法，但涉及关键链路改造，留作专项（清单见死代码清算报告）。
- 大表性能、跨设备同步等已知项与 3.2.0 相同。

### 已知限制（如实写）

1. **标点配对只做过自动化验证**，真实输入法（搜狗 / 微软拼音）请你自己复测一次。
2. **迁移中横幅只有单测**（数据源与订阅都钉住了），界面呈现还没真机过一遍。
3. **复检记录每章只留最近一条**，上限 60 章，超了淘汰最旧的。
4. **细纲对照的「证据不足」会偏多**：这是设计意图（宁可说不知道），不是故障。
5. **引文定位率可能很低**：伏笔 / 文风类问题的引文常来自设定表比对而非正文原句，
   显示「引文 0/3 可定位」是如实的，**不代表问题不存在**。
6. **主包体积** 1.66MB（gzip 533kB），网页版首屏偏慢；出厂数据已单独分包。
7. **未验证项**：真实端点三处对照、24 个固定样本对照、双设备同步、
   桌面 / 便携往返 —— 逐条见 `3.2.1-验收补证记录`。
