  --set-version-string FileDescription 青春幻想引擎 --set-version-string ProductName 青春幻想引擎 \

  --prepackaged "$PWD/$OUT/win-unpacked" -c.directories.output="$PWD/$OUT"

YFE_REUSE_OUT="$PWD/$OUT" node scripts/build-desktop.mjs
#   → 「主 exe 元数据校验通过（246487040 字节，与基线逐字节一致）」→ Setup 99,342,082

### 本轮新增的一个坑：rcedit `Unable to commit changes`

第一次调用直接 `Fatal error: Unable to commit changes`（**不是** REF 里记的「中文路径 → Unable to load file」）。
同一条命令**隔 3 秒重试即成功**（第 2 次 exit 0、体积立刻变成基线值）。
判读：刚 `cp` 出来的 246 MB 文件正被杀软/索引器扫，`BeginUpdateResource` 拿不到写锁 —— **重试即可**，
不需要换工具、也不需要换路径。下轮遇到同类报错先重试 2~3 次再排查。
