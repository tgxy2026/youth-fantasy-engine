## 🔑 关键设计决策

| 决策 | 依据 |
|---|---|
| `Set` → `Array` 转移表 | esbuild 打包后 `Set` 的 `has` 方法丢失，改用 `Array.includes` |
| `completeApplyCandidate` 不校验摘要 | 写盘失败由调用方通过回读摘要检测，本函数只校验状态 |
| 逐行 diff（非 LCS） | 候选文本 200-2000 行，O(n) 足够快；LCS 的 O(n*m) 可能卡顿 |
| 中文字数 = 汉字数 + 英文词数 | 简单混合统计，不区分中英文 |

## 🔴 已知限制

1. **Diff 算法**：首版用逐行对比，不引入 LCS。若需更精细的 diff（如行内字符级变化），后续替换。
2. **字数统计**：简单中英文混合统计，不区分中英文。
3. **写盘失败检测**：`completeApplyCandidate` 不校验 `afterBodyDigest`，调用方必须先回读摘要一致后再调用。
4. **崩溃核对**：仅覆盖「有 intent 无 receipt」和「有 intent 有 receipt」两种场景，其他场景（如 intent 被覆盖）需额外处理。
