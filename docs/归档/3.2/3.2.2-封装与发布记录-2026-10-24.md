## 二、封装三步法（本轮实走，含踩坑）

```
ELECTRON_BUILDER_7ZIP_PATH=.workbuddy/tmp/eb-7zip/bin/7za.exe node scripts/build-desktop.mjs   # ① 预期 exit 2
```

**① 首轮 exit 2** —— 但 **rcedit 又没找到**（脚本打印「❌ 找不到 rcedit，无法补写主 exe」）。
这正是 REF 坑二：`signAndEditExecutable:false` ⇒ electron-builder 不下载 `winCodeSign` 工具链 ⇒
`%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\*\rcedit-x64.exe` 不存在。
**正解照旧是 ASCII 路径 + `electron-winstaller` 的 vendor rcedit**：

```bash
mkdir -p /c/rcedit-test && cp build/icon.ico /c/rcedit-test/icon.ico
cp "<out>/win-unpacked/YouthFantasyEngine.exe" /c/rcedit-test/app.exe
./node_modules/electron-winstaller/vendor/rcedit.exe C:/rcedit-test/app.exe \
  --set-version-string FileDescription 青春幻想引擎 --set-version-string ProductName 青春幻想引擎 \
  --set-version-string InternalName YouthFantasyEngine --set-version-string CompanyName 青春幻想引擎开发组 \
  --set-file-version 3.2.2 --set-product-version 3.2.2.0 --set-icon C:/rcedit-test/icon.ico
# 246,238,720 → 246,487,040（回到基线）
```

**② `--prepackaged` 重打**（保住刚补的 exe；普通重跑会把元数据覆盖回默认值）：

```bash
node node_modules/electron-builder/cli.js --win nsis --x64 \
  --prepackaged "<out>/win-unpacked" -c.directories.output="<out>"
```

**③ 复用模式收尾**：`YFE_REUSE_OUT="<out>" node scripts/build-desktop.mjs`
→ 「主 exe 元数据校验通过（246487040 字节，与基线逐字节一致）」→ 复制到 `release/桌面安装版/`。

> 7zip EPERM 那一坑本轮**没有复发**：`ELECTRON_BUILDER_7ZIP_PATH` 指向已解出的 `7za.exe`，
> 日志出现 `resolved ELECTRON_BUILDER_7ZIP_PATH from environment variable`。
