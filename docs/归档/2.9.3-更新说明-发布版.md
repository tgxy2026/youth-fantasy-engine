# 青春幻想引擎 2.9.3 更新说明

> 发布日期：2026-10-10 ｜ 桌面安装版（Windows）
> 上一版：2.9.2（2026-10-09）

---

## 一句话

**2.9.3 是一次「把边角磨平」的版本**：自由对话的开场白不再伪装成你说的话、故事剧本能直接**追加**进已有故事、窄窗口下不再出现文字竖排与按钮被裁；另外还清掉了一批看不见的隐患（含一处「从云端备份恢复会被静默撤销」）。

---

## 新增

### ⭐ 故事剧本「导入」支持**追加到已有故事**

**入口**：酒馆模式 → 故事剧本 → **导入 / 追加**。

以前「导入」只能**新建一个故事**；现在弹窗顶部多了一排切换，可以选「**建为新故事**」或「**追加到已有故事**」：

| 追加模式下 | 行为 |
|---|---|
| 目标故事 | 下拉选择，**默认选中你当前正在看的那个故事** |
| 会补进去什么 | **词条 + 剧本** |
| 世界设定 | **不导入** —— 已有故事的世界观是它自己的，从别处复制来的那份并进去只会两种说法打架 |
| 撞名字 | 剧本 / 词条与目标故事里已有的重名 ⇒ **红字点出究竟是哪一个，拦下不导入**，改个名再来（不会悄悄替你改名，也不会自动加序号） |
| 故事名 | 可以不写（目标已经选了）；写了也不影响落地 |

- 🔴 还有一处**如实告知**：若你要追加的那个故事，世界设定还是「一整段」的老形态，追加词条时它会**自动转成第一条常驻词条**（内容不变，仍然每轮都带上），界面会提前说明。

### ⭐ 自由对话：开场白独立成「场景引入」

**入口**：酒馆模式 → 自由对话。

剧本的**开场白**以前显示成**你自己发的一条消息**（这是为了让模型把这一场接下去而刻意这么存的，但看起来别扭）。现在它单独渲染成一块居中的「**场景引入**」，不带头像、不占任何一侧，只保留「编辑」按钮。

- 老会话**零迁移**：翻回以前那场戏，开场白也会自动按新样式显示。
- ⚠️ 它对模型的含义**一字未变**（仍是「这一场的起点处境」），只是看起来不再像你说的话。

## 修复

### 🔴 「从云端备份恢复」不再被静默撤销

**症状**：开着云盘同步时点「从备份恢复」，界面提示「已恢复」并自动刷新，但刷新完数据**又回去了** —— 像是白忙一场。

**原因**：云同步下本机数据文件是「开启同步那一刻的冻结快照」，而恢复只改了内存里那份；重启后合并时，冻结的旧文件被当成「本地最新」优先，把恢复结果盖了回去。

**现在**：恢复成功后会**一并写回本机数据文件**，刷新后看到的就是恢复后的数据。

### 🔴 窄窗口下不再出现「文字竖排 / 按钮被裁」

**症状**：窗口缩小时，「历史事件」等数据表页的**标题与说明被压成一条竖缝**（一个字一行），右上角的按钮（保存 / 表格 / 时间轴 / 历法规则）被裁掉。

**原因**：页头是「左标题 + 右工具条」两栏，而工具条不允许压缩 ⇒ 宽度不够时**全由标题承担压缩**、被压到 0 宽。

**现在**：放不下时**工具条自动折行**（按钮全部可见），标题保底宽度不再被压塌。同一处问题还修了角色卡页、控制面板页，以及侧栏「界面缩放」那一行的标签竖排。
- 顺带说明：数据表本身一直是好的（超出时有横向滑条），坏的只有页头。

### 🔴 酒馆的「概率」现在能填小数了

**症状**：世界书词条 / 背景设定每节的「概率」输入框，想填 `0.5` 却打不出小数点 —— 输入 `0.` 就被改写回 `0`，只能填 0 或 1（等于这个功能形同虚设）。

**现在**：可以正常输入 `0.1 ~ 0.9`。

### 其它修复

| 项 | 说明 |
|---|---|
| 控制面板滚下去找不到保存按钮 | 页头**吸顶** + 右下角常驻**悬浮保存**按钮（原本页面 6500px 高，滚到「我的档案」时保存按钮在视口上方 2400px） |
| 「全部功能页签」里看不到「模型设置」 | 该页按分组列举页签，而「工作面板」这一组被漏掉 ⇒ 整组消失（模型设置就在这组），已补回 |
| 自由对话：本轮刚提到的关键词不当轮生效 | 世界书触发词原先要**等到下一轮**才注入；现在与剧情模式一致、**当轮就生效** |
| AI 参数标签「仅本地」有歧义 | 实际只有 Ollama 生效（本地 OpenAI 兼容服务同样不支持），已改成「**仅 Ollama**」 |
| 关于页的联网说明不完整 | 原文只说「检查更新」会联网，其实**默认开启的启动自动检查**也会；已如实补全 |
| AI 数据来源说明里有一条重复 | 「不读：D 级条目」被显示了两遍，已去掉 |
| 「清空全部」可能清不干净 | 原来并发发送、失败无提示；现在**逐条等待**，没删掉的会明确告诉你还剩几条 |
| 敏感词检测的说明数字对不上 | 文案写「约 120 字上下文」，实际是前后各 12 字；已改为与实现一致 |

## 说明

- 本版为**桌面安装版（Windows）**，安装包见下方附件。
- 数据与设置**向后兼容**，无需迁移；已有的项目、角色卡、故事剧本、会话记录都照常。
- 若你开启了**云盘文件同步**：本版修了「恢复被撤销」那一条，建议升级后**先手动同步一次**再继续使用。
