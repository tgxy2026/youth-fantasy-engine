## 1.0.0（08-25）· 基线版

**新增功能**：整套创作管理骨架 —— 29 个页签一次成型。

- 写作台：工作面板、正文编辑、章节总表
- 世界构建六表：国家势力、地理风物、种族生物、物品资源、历史事件、名词术语
- 角色管理：主要角色 / 次要角色 / NPC 角色卡
- 大纲规划：全书总纲、分卷大纲、章节细纲
- 创作管理：伏笔追踪、时间脉络、爽点节奏、支线剧情、秘密设定、设定变更台账

**有什么用**：把"写小说"这件事从文档里搬进结构化工具 —— 设定、大纲、章节、伏笔、时间线各归各位，
写到后面不会自相矛盾。

**优化**：无上一版可比。

## 1.1.0（08-25）

**新增功能**：**审校与备份体系**。

- 一致性审查、连贯性检查、**伏笔引擎**（埋了没回收会被揪出来）
- 错别字词库、文风审查、字数统计

- 角色分布统计、关系图谱、写作目标、模板库
- 帮助气泡与提示组件（HelpPopover / Tooltip）

**有什么用**：从"能写"升级到"**能查**" —— 写完能自动审连贯性、查伏笔回收、查错别字、看字数达标没；
数据能备份能导回。

**优化**：本版为当天连发之一，日志按天记录，无法细分（当天整体在补 UI 细节与备份面板问题）。

## 2.3.0（09-20）

**新增功能**：

- **其他设定**（新页签，卡片型）：世界构建的**兜底页** —— 前面几张专表都放不下的零散设定
  （天气历法的土规矩、货币换算、民俗禁忌、某个不上台面的潜规则）
- 正文编辑（页签化）
- 配套：界面偏好持久化、字数区间校准、云同步墓碑机制、Web Crypto 抽离
- 编辑器与酒馆相关组件继续拆分（地图、酒馆卡片各面板、推演场景等）

**有什么用**：过去"没地方记"的零散设定现在有地方放，**而且照样进 AI 的设定资料** ——
不会出现"正文里写了、AI 却不知道"的情况。

**优化**（本轮是"不加功能、只改结构"的版本，优化占大头）：

| 方面 | 具体 |
|---|---|
| **架构** | 任务层与存储层拆分为门面 + 域模块；五个巨型组件拆分；**全项目 `any` 归零** |
| **长篇创作** | 创意写作改为**两阶段分批**（先分批排大纲、再分批写正文）；起点自动判定；正文按大纲**切卷** |
| **缺口补齐** | **卷没排满就先补满该卷**、**章没写完就先补完该章**，而不是急着开新卷 |
| **字数** | 目标字数做成**硬校准**（±300 汉字，汉字口径），改写/扩写/续写结果一律过闸 |
| **伴写** | 新增「换一句」（换一个写法而不是同一句） |
| **校对** | 深度校对**拆成两块**（文字层 / 逻辑层），文字层不再读设定资料因而更快；判据加严 |
| **交互** | 折叠状态跨会话记忆；AI 就绪的按钮预先禁用 |
| **数据安全** | 云同步墓碑机制（删掉的记录不再"复活"）、数据文件身份校验、读失败时中止而非猜成空 |
| **稳定性** | 修掉表格列宽拖拽的崩溃（延迟执行的 updater 读到已清空的引用） |
