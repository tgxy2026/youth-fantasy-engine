## 4. 可复用手法（写新断言时）

- **故障注入不碰产品代码**：`page.addInitScript` 里 patch `IDBObjectStore.prototype.put`，按「store 名 + 记录特征」精确抛错。
- **mono 主题断言**：`document.documentElement.dataset.theme='mono'`，扫描前重新施加并校验（Vite 热重载会把主题打回默认，照旧扫描会假绿）。
- **多个 `<aside>`**：图鉴详情与左侧导航都是 aside ⇒ 要取「带 footer 的那个」，否则读到 null 会假 PASS。
- **模糊匹配陷阱**：`hasText:'编辑'` 会命中「在表格中编辑」⇒ 用 `/^\s*编辑\s*$/`。
