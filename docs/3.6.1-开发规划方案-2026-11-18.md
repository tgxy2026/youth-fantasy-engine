# 青春幻想引擎 3.6.1 开发规划 · 覆盖率债与未接线模块

> 起点：3.6.0 发布版（`v3.6.0`，2026-11-18）。本规划只处理 3.6.0 明确记账的两类欠账。
> 依据：`scripts/audit/coverage-ledger.json`（17 条零覆盖）与 `scripts/audit/unwired-ledger.json`（4 个 `gap`）。

## 1. 版本目标与边界

**目标**

1. **覆盖率债清零或降级**：17 个「零测试提及且属安全/数据/算法类」的文件，按风险分三批处理 —— 能补测的补测（并让台账条目消失），补不了的把风险写进代码注释与台账。
2. **4 个未接线模块全部定案**：每个给出「接线 / 保留 / 删除」的明确结论，不允许继续挂在 `gap` 上无人处理。

**边界（本版不做）**

- 不加新功能、不做 UI 重做、不改 3.6.0 已发布的契约（成果记录 schema、候选 `checkPayloadIds`、图鉴字段判定）。
- **不为覆盖率数字搭 DOM 测试基建**：优先把可测逻辑从组件里抽成纯函数，组件保持薄。
- 不写「只调用一次、无断言价值」的空测试凑数。

**贯穿纪律**

- 任何接线改动，必须先有对应测试（先红后绿）；台账条目减少必须与本版记录一致。
- 每个包结束跑：`typecheck` / `eslint` / 相关专项 / 全量单测；涉及同步或存储的必须附「失败路径」断言。

## 2. 覆盖率债：17 个文件分三批

### 批次 P0 · 数据与同步（4 个，先做）

这 4 个一旦出错是**数据丢失或静默不同步**，优先于其它。

| 文件 | 现状 | 补测方案 | 必须先有的失败路径断言 |
| --- | --- | --- | --- |
| `src/lib/agentHost/worldBackupOps.ts`（381 行） | Agent 侧「世界包引入 / 备份恢复」，覆盖现有内容，靠 preview + confirm + 安全备份 + 回滚兜底 | 把 Agent 桥与存储访问抽成**端口（依赖注入）**，单测用假端口跑；不引入真实桥 | ① 未 preview 直接执行 → 拒绝；② preview 与执行目标不一致 → 拒绝；③ 缺 `confirm` → 拒绝；④ 备份创建失败 → 中止且不动数据；⑤ 中途失败 → 回滚，并如实报告回滚结果（含回滚失败） |

## 3. 四个未接线模块的定案

| 模块 | 现状与重叠 | 3.6.1 定案 | 前置决策 |
| --- | --- | --- | --- |
| `revision/changeEvents.ts`（235 行） | 与已上线的 `outline/futureImpact` 解决同一需求：后者只按章号标记，前者更细（事件 + 前后引用 + 相关性复核 + 处置状态） | **接线，但只接「证据层」**：`futureImpact` 仍负责标记，展开某条影响时显示「依据」（前后引用 + 引用原文 ≤300 字）。**不引入处置状态机**（那是新流程） | 需确认：影响提示里展示证据的位置与文案 |
| `revision/generationInvalidation.ts`（275 行） | 风险已被 `aiTaskCenter.startTask`（拒重复发起）+ `sameCandidateRevision`（拒过期写回）覆盖；缺跨窗口租约 | **本版不接线**，改为「**固化现有两条闸**」：补测试钉住「重复发起被拒」「过期候选被拒」，并把本模块降级为 `retained`（写明「等出现多窗口并发再启用」） | 无（属技术判断） |
| `agentHost/modeAuthority.ts`（51 行） | 原型：连接模式切换的持久化授权（崩溃后失败关闭）；产品无切换入口 | **先定产品**：① 若「不暴露模式切换」→ **删除**（51 行原型，删了不影响现有 ACP）；② 若「暴露」→ 按 UI + 失败关闭 + 用户说明三件套做，并同步 ACP 隔离口径文档 | **需要产品决定**（本版唯一需拍板的项） |
| `templates/semanticView.ts`（191 行） | AI 侧已由 `consumers.ts` 的 `atlasFieldHintForAI` 承担；本模块面向界面投影 | **接线（只读视图）**：图鉴详情增加「按语义看」（身份/动机/状态 + 每项出处），复用 `readSemanticView`，**只读不改数据、不落第二份事实库** | 需定：投影值是否可点击跳到原字段 |

**完成判据**：4 个模块在本版结束时状态为 `wired`（已接线）或已从代码中删除；`unwired-ledger.json` 里不再有 `gap`。

## 5. 版本验收门禁

| 项 | 判据 |
| --- | --- |
| 覆盖率台账 | 17 条 → 0 条（或全部改为 `partial` 并写清剩余部分靠真机）；`零覆盖台账有效` 检查仍通过 |
| 未接线台账 | `gap` 数量 = 0；每条要么 `wired` 删除条目，要么 `retained` 写明触发条件 |
| 六维审计 | `complete`；自检项数只增不减；死导出未复核 0；结构约束 0 |
| 全量单测 | 全绿，且新增测试必须覆盖上表的「失败路径」 |
| 真机 | 桌面 / 便携 / 网页三形态打包验收各 17 项不回归（沿用 `packaged-acceptance`） |
| 文档 | 3.6.1 更新说明里逐条列出「哪条债清了、哪条改为保留及理由」 |

## 6. 明确不做

- 不为了「覆盖率数字好看」引入 React Testing Library / jsdom 整套栈：本版只把逻辑抽出来测。
- 不顺手改 3.6.0 的既有行为（尤其是成果记录状态机、候选过期判定、图鉴字段判定）。
- 不把 `A1/A2`（重复代码、近似模块）纳入本版 —— 那需要人工抽样，不属于可自动化的债。
