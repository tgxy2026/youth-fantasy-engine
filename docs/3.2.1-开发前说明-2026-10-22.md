## 六、本机环境坑（血泪）

| 坑 | 现象 | 正解 |
|---|---|---|
| **批量删文件** | `fs.unlinkSync` **0.24 s/文件**（安全层逐次检查），2 万文件≈1.5 小时 | `.NET [IO.Directory]::Delete('\\?\'+p,true)`／`[IO.File]::Delete(...)` ⇒ **252 秒** |
| `Remove-Item -Recurse` | 遇深层目录**中途静默放弃**，还看不见报错 | 同上，逐项 `try/catch` 记账 |
| **Playwright** | `ms-playwright` 缓存为空，`chromium_headless_shell-1248` 不存在 | `chromium.launch({ channel: 'msedge' })` **驱动系统 Edge，免下载内核** |
| 被占用删不掉 | `MethodInvocationException` | `Get-CimInstance Win32_Process` 按 `CommandLine` 匹配 tmp 路径 → `Stop-Process`；**只杀指向 tmp 的测试进程，绝不动主人的浏览器** |
| **PowerShell 读 UTF-8** | JSON 按 GBK 解码 ⇒ 中文路径全乱 + `ConvertFrom-Json` 抛「无法识别的转义序列」 | Node 写文件前置 `'\ufeff'`；读端 `-Encoding UTF8` |
| 同消息多 Edit 同文件 | 互相覆盖（踩过两次） | 用 `.workbuddy/tools/apply-many.mjs`（命中数≠count 整批不落盘） |
| `fs.cpSync` | 被 shim **静默杀进程**（零输出退 127） | 递归复制**自写** `readdirSync`＋`copyFileSync` |

## 七、网页版事实（你上次确认的口径）

| 形态 | 判定 | 数据在哪 | 跨设备 | 配额 |
|---|---|---|---|---|
| **游客**（未打赏，免费） | `WEB_GUEST` | 浏览器 IndexedDB，**不上传服务器** | ❌ 不通 | 无 |
| **云端**（打赏用户） | `WEB_CLOUD` | 服务器 `data/users/<uid>/`，按账号隔离 | ✅ **唯一支持跨设备** | 200 MB／人 |

- 判定源：`src/lib/app/platform.ts`。游客只注入 `__YFE_GUEST__`；云端注入 `__YFE_WEB__ + __YFE_PORTABLE__` ⇒ **网页版里任何 `PORTABLE ?` 分支必须先判 `WEB`**。
- 三处必读告知：首启向导首屏（`WelcomeWizard`）、项目页入口、登录页（`server/lib/authPage.mjs`）。
- 32 MiB 图 / 200 MB 文件上限**只对云端账号**生效。
- 邀请码＝打赏凭证＝找回密码凭证（用户名＋码一起校验）。台账权威源 `/opt/yfe/data/users.json`；10-22 交接记录为 **3 未发 + 2 已发待注册 + 5 已用**，操作前查询实时台账。
- 部署：`bash server/deploy.sh <www|server|both>`；SSH `ssh -i C:/Users/18223/.workbuddy/deploy-keys/yfe_huawei root@115.120.232.153`。
- 🔴 `deploy.sh` 里 vite 构建**会被 safe-delete 批量闸拦**（清 `dist/assets` > 50）⇒ 先 `mv dist dist-archived-<ts>`，**别关安全开关**。
