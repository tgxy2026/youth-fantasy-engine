# 青春幻想引擎 3.1.0 更新说明

> 发布日期：2026-10-16 ｜ 桌面安装版（Windows）+ 便携版（Windows / macOS·Linux 两个包）
> 上一版：3.0.4（2026-10-15）

---

## 一句话

**3.1.0 把「打开项目后不知道从哪接着写」「想从大纲反查章节」「两台设备同步分叉了怎么办」这三件每天都在发生的事，串成了一条能走通的路**，并新增了第九个预制主题「纯黑白」。

这一版没有堆新页签，主线是**把已有的东西连起来** —— 少翻页、少搜索、少担心。

---

## 一、接着上次写：工作面板变成「继续创作」入口

**问题**：打开一个写了很久的项目，第一眼是满屏统计数字，但「我上次写到哪了」得自己翻章节树。

**3.1.0 的答案**：工作面板顶部新增**继续创作**区域 ——

| 入口 | 说明 |
|---|---|
| 最近编辑章节 | 一键回到上次写的那一章 |
| 未完成章节 | 状态还在「构思 / 细纲 / 草稿 / 修改」的章节，直接点进去接着写 |
| 未用灵感 | 记下来还没用上的点子 |
| 未回收伏笔 | 已经埋下、还没填的坑 |

- 每条建议都**标明来源**，可以「忽略」或「延后 24 小时」，忽略状态只存在本机界面偏好里，**不进项目数据**。
- 空项目会显示一份**项目起步清单**（建卷 → 建章 → 写正文 → 导出备份），随时可跳过、可重新打开。
- 未配置 AI 时这些入口**照样完整可用**。

---

## 二、章节规划板：按卷看全局，点一下进正文

工作面板内新增**章节规划板**（只读视图）：

- 按**卷**分组，每张卡显示标题、摘要、状态、字数。
- 可按卷、状态、关键词**筛选**。
- 卡片直接点进正文编辑器。
- 空摘要、空正文会给出提示，但**不会自动改你的数据**。

> 说明：这是**只读**视图，不改章节顺序、不建新数据。想调顺序请到「章节管理」。

---

## 三、同步冲突中心：分叉看得见、恢复有保障

**背景**：多设备同步时，如果两边都改过同一个东西，软件会把另一边的版本另存为「冲突副本」并提示你。但此前你**看不到清单**、也**没有恢复入口**。

**3.1.0 的答案**：

- 云同步标题旁新增**冲突入口**和未处理数量角标。
- 每条冲突显示：发生时间、数据类型、记录名称、双方内容。
- 章节冲突支持**查看差异**与**原位恢复**；其他类型至少可查看结构化值、**导出完整双方数据**。
- 恢复前**自动建立项目备份和章节快照**；如果冲突发生后本机又写了新内容，会**阻止覆盖**而不是硬来。
- 恢复完成后有明确结果提示（含「云端同步尚未完成」这类中间状态），失败时**不会**悄悄刷新页面把恢复结果冲掉。
- 冲突记录可标为已处理、可删除；删除前有确认。

> ⚠️ 冲突数据**不会回传云端**。

## 四、第九个预制主题「纯黑白」

左下角主题栏新增**纯黑白**（排在八个彩色预制主题之后、彩色自定义按钮之前）：

- 界面背景、面板、输入框、菜单、弹窗统一 **纯白**；文字、图标、边框、光标、焦点轮廓统一 **纯黑**。
- 悬停、选中、聚焦、禁用、成功、警告、错误**不靠颜色深浅区分** —— 改用轮廓粗细、线型、图标和文字。
- 码字热力图、状态徽章、实心按钮、禁用按钮都做了对应适配。
- 一键启用、重启保持、切回其他主题无残留。

> 面向偏好白底黑字（包括干眼症）的使用者。这是**显示偏好**，不作任何缓解或治疗的效果承诺。

## 五、资料提及反向导航：从角色反查章节

角色卡 / 设定表行上新增**放大镜入口**（悬停显现）：

- 点开列出**所有提到这个名字的章节**，按卷序 + 章序列出，显示命中次数、命中的是主名称还是别称、以及首次命中的上下文。
- 点击结果直接跳到对应正文。
- 纯读功能：不建索引、不落库、不改数据。

---

## 六、角色页签支持批量导入 / 导出

**主要角色 / 次要角色 / NPC角色**三个页签右上角新增「导入」「导出」：

- **导出**：把现有角色卡导成 CSV（Excel 直接打开）。
- **导入**：三种方式任选 ——
  1. 照着「下载模板」填好再粘回来（本地解析，**不消耗任何 AI 额度**）；
  2. 下载「导入说明 / AI 提示词」交给别的 AI 整理成表；
  3. 直接粘贴散文式设定，用**你已配置的模型**自动拆成多条。
- 导入前有**预览与校验**：重复、缺必填、名称对不上都会标出来，勾不勾由你定。
- 「姓名」是必填列；「所属势力」可多选（用中文逗号分隔）；**人物立绘不在 CSV 里**（图片传不了，导入后单独上传）。

## 七、修复

这一版经过**两轮独立复核 + 两轮全量六维审计**，修掉的问题里有几条是真正会咬人的：

### 数据保护

| 问题 | 后果 | 现在 |
|---|---|---|
| 云端不可用时恢复章节，会用陈旧缓存把本机覆盖回去，并删掉离线新增的章节 | **丢稿** | 恢复只保存本次实际写入的记录，禁止旧缓存整库镜像；本机保存先于云端推送 |
| 恢复期间切换项目，原章节可能被写进**另一个项目** | 数据错配 | 入口捕获项目身份，等待期间上下文变化即中止 |
| 冲突后只改了摘要 / 分卷 / 顺序，恢复时未被识别 | 静默覆盖 | 覆盖保护扩到全部业务字段 |
| 恢复落盘失败仍自动刷新 | 恢复结果只在内存，刷新即失效 | 未确认落盘不刷新，并保留待处理冲突 |
| 导入新角色时，当前卡片**未保存的编辑会丢失** | **丢稿** | 切换前显式落库；手工新建 / AI 新增两条路径一并修掉 |
| 仅有卡片标题的角色导出后**丢名字**、导入时同名不判重 | 往返丢数据、重复建卡 | 姓名缺失时用卡片标题兜底，导出 / 判重 / 落库三处口径统一 |

### 显示与交互

| 问题 | 现在 |
|---|---|
| 「纯黑白」下实心主按钮变成白底白字、禁用按钮发灰 | 按组件语义覆盖，白底黑字 + 虚线边框表达禁用 |
| 「纯黑白」下码字热力图四档**塌成一档**（0 字和有字长得一样） | 改用线型 / 粗细 / 填充区分五档 |
| 「纯黑白」下部分分段控件的**选中态看不出来** | 补外轮廓双线 |
| 短英文名的提及摘要定位到不相干的词（搜 `Ed` 却截在 `edition`） | 计数与摘要共用同一次匹配结果 |
| 自定义项目里点「去登记今日字数」**毫无反应** | 未启用该功能时不显示入口（而不是点了没反应） |
| 从规划板跳到第 3 章后，点侧栏「正文编辑」打开的**还是第 3 章** | 跳转意图按本次操作覆盖 / 清空 |
| 跑团输入框按 Ctrl+Enter 时，中文输入法**未上屏的半成品**会被提交 | 补齐输入法组合判断 |

## 八、已知问题

1. **多设备并发同步仍可能「同代覆盖」** —— 需要协议级的条件写入，会动到后端兼容，本轮未改。
2. **冲突中心还没有分页 / 类型筛选 / 体积显示 / 保留期限**；冲突副本会一直累计。**自动清理策略未做**（涉及不可逆删除，会单独确认后再实现）。
3. **章节规划板还缺「更新时间」与「状态与正文不一致」提示**；超长篇（300+ 章）的读取性能尚未专项优化。
4. **「纯黑白」的图谱 / 地图 / 情节画布 / 结构节奏带仍保留语义色** —— 已确认要补齐，排在 3.1.1。
5. **打包版的冲突中心界面与真实双设备（目录中转 / WebDAV / S3）同步**尚未做完整验收。

> 第 2–4 项已列入 **3.1.1 版本规划**（`docs/3.1.1-版本规划-2026-10-16.md`）。

## 九、升级与安装

- **升级**：直接覆盖安装即可。项目数据在本机，**不需要迁移**，旧项目、备份、便携版数据照常打开。
- **桌面安装版**：下载 `青春幻想引擎-Setup-3.1.0.exe`，双击安装。
- **便携版**：`青春幻想引擎-便携版-3.1.0-Windows.zip`（`启动.bat`）/ `青春幻想引擎-便携版-3.1.0-macOS-Linux.zip`（`启动.sh`），解压即用。
