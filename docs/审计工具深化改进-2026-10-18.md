## 本次补强

| 漏检类型 | 改进 |
|---|---|
| 正则匹配注释/示例、把“写了函数”当“已接入口” | TypeScript AST补充，区分实际调用、导入、类型与回调传递；候选注明位置及置信度 |
| 同时替换草稿与选择，错误保存/未保存场景漏验 | 扫描变更处理函数，并把保存失败、保留选择、实际存储结果列为必需运行证据 |
| 只检查新增预设，遗漏编辑下拉入口 | 独立契约要求new/edit两条路径；单一路径不能报完整通过 |
| 请求头合并大小写、语法边界遗漏 | 离线调用真实生产函数，经Headers规范化检查鉴权单值、默认行为、非法名、换行/NUL及非ByteString值 |
| 零彩色误当严格黑白、CSSOM属性名错误 | 共享绘制扫描正确读取fill-opacity/stroke-opacity，合成自身/祖先透明度；把无法识别的绘制属性单独列为unknown |
| 只扫SVG，漏HTML情节卡片与节奏纹理 | 同时检查相关HTML内联色、边框、渐变纹理；保留纯白地图填充专项 |
| 图表未打开、只有图标、样本为空却报绿 | 同时检查主题、实际绘制样本、各图表数据标记；缺样本属于未验证/受阻 |
| 时间轴整页不在手工清单里 | 登记8类图表并自动列出新的mono感知组件；未登记要求人工确认或补覆盖 |
| 候选只列前10/15条 | 默认展开候选循环清单；原始日志完整保存，仍可用YFE_AUDIT_FULL=0取旧精简输出 |
| 单测/扫描成功直接写“全量通过” | JSON/Markdown统一报告，区分executed、unverified、blocked、failed、人工销账；各规则必须有证据 |
| 未提交源码变更后复用旧绿色报告 | 整个src/electron内容指纹；不只依赖commit号。执行中变化或旧指纹都拒绝沿用 |
