# 文案与用词规范（2026-11-18 · 3.6.1 立）

> 目的：让「按钮 / 提示 / 手册 / 引导」用**同一套标准**，而不是每处各写一版。
> 适用范围：`src/**` 里所有面向用户的文本 —— 界面文字、`title` / `aria-label` / `placeholder`、
> 确认框、Toast、错误信息、帮助弹窗（`HelpPopover`）、使用指南、内置手册、分步引导。
> 不适用：代码注释、给模型看的提示词（那里是"指令"不是"文案"）、协议原文。

## 一、八条规则

| # | 规则 | 说明与例子 |
| --- | --- | --- |
| 1 | **人称统一「你」** | 不用「您」「用户」「本人」。写「你的稿子」，不写「用户的稿件」。 |
| 2 | **术语只用一个名字** | 见下表。同一个东西不许两套叫法（如「使用手册 / 使用指南」只能留一个）。 |
| 3 | **用户文案不写应用版本号** | 不写「v1.9.1 起」「3.6.1 新增」。唯一例外：手册里陈述「从哪个版本开始支持」这类事实（如「3.5.6 起可走 ACP」），且**不写进按钮与提示**。 |
| 4 | **标点用中文全角** | 逗号、句号、问号、感叹号、冒号、分号、括号、引号「」全用全角；破折号 ——；不用半角逗号夹在中文里。 |
| 5 | **按钮＝动作，≤8 字** | 动词开头：「保存」「导出全部数据」「标记为已处理」。破坏性按钮写清对象与后果（「删除副本」「清空全部关系」），且必须二次确认。不用「确定 / 提交 / 好的」这类空词当主按钮。 |
| 6 | **错误＝三段** | 「发生了什么」+「有没有影响」+「下一步怎么做」。禁止只写「失败」「出错了」。例：`导入失败：磁盘写满了（原有作品未受影响）。` |
| 7 | **能力边界照实写** | 做不到就写「暂不支持」并给替代路径；不用「敬请期待」。不承诺「永远 / 绝不 / 保证」（除非是硬规则，例如「不会自动删除」）。 |
| 8 | **帮助双轨，各有分工** | 页面里的「?」只讲**当前区块**（字段含义、选项影响）；左下角「本页指引」是**进页分步引导**；跨页流程（拆书 → 参考 → 审读）去**使用指南 / 使用手册**搜。三者不互相抄一遍。 |

## 二、术语表（写文案时照这张表）

| 概念 | 唯一写法 | 不要写 | 备注 |
| --- | --- | --- | --- |
| 导航单位 | **页签** | 标签页、选项卡、Tab | 侧栏里的一页 |
| 表格的一行 | **记录** | 条目、数据行、一行数据 | 「新增一行」添加的是记录 |
| 设定内容项 | **条目** | 记录、项 | 伏笔、事件、势力、术语等"内容条目" |
| 人物 | **角色卡** | 人物卡、角色卡片 | 页签叫「主要角色 / 次要角色 / NPC」 |
| 跨项目设定包 | **世界包** | 设定包、世界设定包 | |
| 模型 | **模型** | AI 模型、大模型 | 「大模型」只留在讲本地部署 / 显存时 |
| 帮助页 | **使用指南**（页）/ **使用手册**（页内可检索的知识库） | 帮助文档、说明书 | 入口按钮统一叫「使用指南」 |
| 章后整理 | **章后整理** | 整理本章（按钮名除外） | 按钮仍叫「整理本章」 |
| 未来计划提示 | **未来计划待重审** | 未来影响、待处理 | 清标记的按钮叫「已处理」 |
| 同步冲突 | **冲突副本** | 冲突记录、冲突数据 | 面板叫「同步冲突中心」 |
| 模板 | **模板** | 样式模板、schema | |
| 可点区域 | **按钮 / 入口 / 面板** | 控件、tab 按钮 | 描述位置时用「右上 / 左下角 / 页头」并确认真的在那儿 |

## 三、位置描述要能对上界面

写「在 XX 点 YY」之前先确认那个按钮真的在那儿。踩过的坑：

- 「本页指引」在**左下角侧栏**，不在页头（页头只有「?」）。
- 导出入口在**左侧「章节」栏右上角**，不在正文工具栏（2.8.0 起移走）。
- 「新增一行」在表格**右上**。

## 四、怎么写"失败"和"边界"

| 场景 | 写法 |
| --- | --- |
| 操作失败且有替代 | 说清结果 + 影响 + 替代动作：「这份备份的载荷已缺失，无法恢复。可改用更早的一份备份。」 |
| 操作失败但数据安全 | 明确安抚：「另存失败：…（原有作品未受影响）」 |
| 能力不存在 | 「暂不支持…；可以改用…」 |
| 结果不明 | 「恢复已执行但未确认落盘，请重新打开项目核对」——不要写「已完成」 |

## 五、自查方式

| 检查 | 命令 / 位置 |
| --- | --- |
| 手册结构与覆盖 | `node tests/build-test.mjs helpCenter`（覆盖 57 个入口、内容自检 0 问题） |
| 引导锚点是否还在页面里 | `node tests/build-test.mjs pageGuide` |
| 界面一致性（ghost 按钮、色板、可达性） | 六维审计 `scripts/audit/legacy/audit-ui.mjs` 输出 |
| 文案不齐 / 提示词裸拼 | 六维审计 `audit-label-consistency` / `audit-prompt` |
| 一次性全量抽样 | 临时脚本 text-audit（放在 .workbuddy/tmp 下，不入库）：抽出面向用户的中文串并按规则分类 |
