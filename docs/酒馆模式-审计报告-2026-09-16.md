## 一、P0：会导致功能做错

### P0-1　归档后「重说 / 编辑 / 隐藏 / 删除 / 在场调度 / 改数值」全部没挡 ✅复核
- **承诺**：`TavernFree.tsx:841`「本轮已于 …结束（只读）」、`:1160`「这一场是只读归档了」、`:857` 收尾确认框「结束后这一场会变成只读」。
- **实际**：只有发送被挡（`TavernFree.tsx:504`）。
  `reroll()`（`:620`）**没有 `endedAt` 守卫**，会真调模型并 `store.saveFreeSession()` 落库；
  消息工具条在 `:1128-1134` 把 `canReroll / onSaveEdit / onToggleHidden / onDelete` 照常挂上；
  「在场调度」（`:1052`）与右栏数值输入（`TavernVarsPanel`）也没判。
- **后果**：作者以为归档了，随手点「重说」就把归档正文改了 —— 而记忆与日记是按归档那一刻整理的，两边立刻对不上。这正是 `:503` 注释想防的事。
- **修法**：算一个 `readOnly = !!session.endedAt`，传进 `TavernMessageBody` 的 ops 与 `reroll()` 开头；同时收起在场调度与数值输入。

### P0-2　记忆占位符「暂无 / - /（还没有发生过任何事）」不清洗 ✅复核
- **承诺/期望**：空层的占位不该算内容（"空层不占额度"是项目红线）。
- **实际**：提示词让模型写的占位有四种（`summarize.ts:54` 「暂无」、`:299` 「（还没有发生过任何事）」、`:302/:303` 「暂无」、`:304` 「-」），
  而清洗只在 `memory.ts:154` 一处：`/^（暂无）$/` —— **只认带全角括号那一种**。
- **后果**：`暂无` / `-` / `（还没有发生过任何事）` 成为永久记忆内容 → **每轮注入 system 白占字数**；
  且 `status.ts:48` 的 `countEntries` 按非空行数计 → 状态栏显示「未爆的雷 1」「纪念日与待办 1」，作者以为真有内容。
- **修法**：把占位正则放宽成 `/^[（(]?(暂无|无|还没有发生过任何事)[）)]?$/` 并单独把孤立的 `-` 清空；或统一让提示词只写「（暂无）」。

### P0-3　小说角色转换：第 3 章容器标题没有解析锚点 ✅复核
- **实际**：`import.ts:54` 的提示词要求模型输出 `〖第 3 章 · 行为规范〗`，但同文件 `T` 表（`:95-110`）**没有「行为规范」这一项**。
  `normalizeTitle` 会剥掉「第 3 章 ·」剩下「行为规范」，匹配不到任何字段 → 落进 `rest` → 追加到上一栏。
  子代理实测：严格按提示词格式输入时，`knowledge` 字段变成 `"〖待补〗（原著未交代）\n〖第 3 章 · 行为规范〗"`。
- **为什么一直没发现**：`tests/tavernImport.test.ts:106` 只断言 `knowledge` 含「【待补】」，容器标题污染它查不出来。
- **修法**：`T` 表加一项 `chapter3: /^行为规范$/`（该 key 不被读取，等于丢弃容器行）；顺手把断言补严。

### P0-4　控制面板与示例在教作者用已废止的 `【】` ✅复核
- `TavernControl.tsx:1078`（客观描写 hint）：「写法固定：用**【】**包住、独立成行」——协议 v1.7 已废止【】，且同一项实际的提示词是「写在（ ）里」（`prompt.ts:329`）。
- `TavernScriptFields.tsx:34`（开场白 placeholder）：`例：【雨点砸在卷帘门上】\n（她把钥匙转了一圈，没抬头）今天不卖了。` —— **同一个示例里两种括号**，自相矛盾。
- **修法**：两处都改成 `（ ）`。

### P0-5　收尾失败会留下半截记忆 + 重复日记，会话却不归档
- **实际**：步骤①是**逐角色循环**、每轮都落库（`roundEnd.ts:100-129`），而水位线与 `endedAt` 要等整个流程返回才写（`TavernFree.tsx:381-389`）；
  日记追加**没有按会话去重**（`store.ts:601-614`，每条新 `uid()`）。
- **后果**：4 位角色整理到第 3 位失败 → 前 2 位记忆与日记已落库、会话**未归档**、水位线**未推进**；
  作者再点一次「结束」，记忆会重算（幂等），但**日记被追加第二遍**。
- **修法**：先全部算完再统一落库（或 `appendJournalEntry` 按 `sessionId` 去重）；失败时把已完成部分连水位线一起归档。
