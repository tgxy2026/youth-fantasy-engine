# 青春幻想引擎 3.5.0 更新说明

> 一句话：**这一版新增「投稿广场」——登录账号即可投稿、浏览、点赞点踩与评论，经过规则初筛和管理员确认后公开；并新增自愿参加的日 / 周 / 月码字排行。桌面版与网页版共享社区内容，便携版保留全部写作功能、不启用广场。**
> 3.5.0 **不改动已保存的作品数据与模型配置**，升级直接覆盖安装即可；作品、快照、云端同步照旧。
> 🔴 本版为**轻量首版**，属源码 + 隔离环境 + 已部署线上接口验收通过，不等于整版发布验收通过，未覆盖范围见第六节。

## 一、投稿广场（本版核心）

入口在**正文写作组**页签栏，与「正文编辑」同级；项目中心另有一个浮层入口，两种形态共用同一套数据。

- **投稿**：标题、正文（最长 10,000 字）、最多 3 个标签；草稿按账号隔离保存在本机，写一半关掉不丢，保存失败不阻塞输入。
- **浏览与互动**：广场列表、长文详情、点赞 / 点踩（可切换、可取消）、评论、举报、我的投稿。
- **三级审核，人工拍板**：规则初筛只**提级**不判违规 → 本地 AI 建议（可选，需自行配置本地模型；网页版不调用本机模型）→ **管理员确认后才公开**。AI 建议不能替代人工判断。
- **版本绑定**：审核决定必须绑定具体版本；编辑已发布作品会生成**新版本待审**，旧版本继续展示、不整体下线；撤回或下架之后的迟到回执**不会**把内容恢复成公开。
- **匿名如实**：公开载荷只带展示名（自定义昵称或「匿名用户」）与「是否作者本人」，**不带账号 ID、登录名或跨内容关联标识**；选择匿名不会回落成昵称。
- **评论分流**：仅「检查完成且零命中」的评论自动显示，命中规则、判断不了、检查异常的一律进待审。
- **内置示例**：广场首次启动会有一条标注为示例的公开作品《给明天留一盏灯》，走真实投票 / 评论接口；管理员下架后不会因重启复活。

## 二、码字排行（完全自愿）

- 按**日 / 周 / 月**展示，口径是**含标点的项目正文净增字数**（删章记负、回收站恢复对冲、删卷连带扣减），周月先累加每日增减再排名，展示值最低为 0。
- 独立的有符号日账本，**不改变**「写作进度」原有的字数语义；导入、备份恢复、云端拉取属于直接写表，**不计入**排行。
- 关闭授权后立即停止展示与上报；撤回后重启授权**不会**恢复旧数据。
- 上报只传日期与数量，且只在应用可见、账号可用时按分钟级节流尝试，联网恢复后会重试。

## 三、账号与资格

- **注册默认开放**，邀请码改为可选（同时兼作云同步资格凭证）。
- **社区能力与云同步资格分离**：新注册账号默认**没有**云同步资格，但**不影响**投稿、浏览、点赞点踩、评论；需要跨设备同步作品时由运营单独开通。无该字段的存量账号视为**已授予**，不会被静默降权；服务端闸门在 `/api/data`、`/api/blob`、`/api/v2/*`，前端提示不算控制。
- 管理命令新增 `sync <用户名> on|off`、`role <用户名> [角色]`。

## 四、三形态差异

| 形态 | 投稿广场 | 说明 |
| --- | --- | --- |
| 桌面安装版 | ✅ 可用 | 经服务器共享社区内容；登录后可投稿与互动 |
| 网页版 | ✅ 可用 | 与桌面版同一套服务端，游客仍为本地存储 |
| 便携版 | ⛔ 不启用 | 页内明确显示不可用，**不访问**社区接口；写作、AI、同步等原有功能不受影响 |

## 五、阅读与界面

- 阅读正文**使用可用窗口宽度**，段落间距更紧凑；字号 14 / 16 / 18 / 20 可切换并在本机记住（**不改写正文存储**）。
- 广场宽屏为右侧排行竖栏（288–320px），窄屏折叠为可展开区域（前 5 名 + 精简说明）；列表 / 详情 / 投稿预览 / 评论 / 工作台重新排布，窄屏无横向溢出。
- 修复网页版「本机作品」按钮在云端账号信息行被挤成竖排并溢出面板的问题。
- 帮助中心与使用手册补全社区相关条目（投稿、昵称 / 匿名、排行、审核、云同步资格、备份、酒馆背景与 PDF 等口径）。

## 七、版本边界（如实说明，未覆盖 ≠ 已通过）

1. **多设备排行合并与设备时钟偏差**未做真实多设备实测；只做了单进程模拟，时钟偏差、重复上报、冲突合并仍需设计与验证。
2. **真实本地 AI 模型审核效果**未验证（超时、截断、误判率都没有数据）；审核结论始终以管理员确认为准。
3. **容量与性能未压测**：5000 篇 / 50000 评论的上限、万级数据分页耗时均未实测。
4. **社区存储为单实例 JSON**：多进程 / 多实例部署会互相覆盖，部署前必须确认单实例；备份方式是拷 `<DATA_DIR>`，停用是删 `<DATA_DIR>/community/`。
5. 三端运行证据矩阵仍为 **0/27 unverified**；真实多窗口 / 多标签业务交错、真实断电、跨设备同步冲突、安装升级流程按既定范围**未覆盖**（排除不等于已验证）。
6. 未实现：**独立申诉工单**（现引导至既有反馈渠道）、**无邀请码用户的账号找回路径**（待决策：人工核验 / 邮箱 / 手机号）、存量 `cloudSync` 资格盘点与灰度、合规前置（实名 / IP 归属地 / 备案 / 安全评估）。
7. 便携版社区为**有意不启用**，不是故障。
