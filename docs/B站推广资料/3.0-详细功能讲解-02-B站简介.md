## 一、简介正文（可直接粘贴）

青春幻想引擎 · 详细功能讲解 第 2 期：正文写作

这一期讲整套软件的核心现场——「正文编辑」。要讲的不是它长得像不像某个编辑器，而是：它知道你在写小说。

【编辑器有什么】
· 章节状态六档（构思/细纲/草稿/修改/完稿/已发布），改一个状态全书统计自动跟着动，不用维护 Excel
· 目录能跨卷拖，按卷建表、章节号全局连续，不会出现"两个第 5 章"；旁边有回收站，误删能捞回来
· 一键排版、敏感词检测、错别字校对、全文搜索替换——全部离线、不用 AI，随时能用
· 写作体检三件套：伏笔闭环看板、连续性校验（查时间线倒流 / 人物状态冲突）、文风体检
· 时光机：删错了能回滚，回滚前先给当前内容存快照，每章保留最近 12 版
· 小黑屋（不写完不许退出）、打字机模式、专注模式、14–28 号字号
· 导出：TXT / Markdown / EPUB / DOCX / 平台粘贴版；支持本章、全本、按卷、按章逐一导出

【重头戏：AI 助手「颉文姬」六模式】
诊室（深度校对 + 综合诊断）· 编辑（润色/扩写/精简/改语气/换视角）· 审读（六维打分 / OOC 检查 / 爽点毒点）· 简报（开写前给方向）· 补登（专有名词抽出来补进设定表）· 整理（一章过四类变化）。

🔴 改稿永远写在原文下方当「建议段」，原文一个字都不动——不满意一键清掉，原文纹丝不动。

【怎么拿到它】
软件永久免费、开源、无广告、无后门。打开软件里「关于打赏」页 →「获取最新版本」，有网盘链接和提取码一键复制。更新公告发在 B 站主页、公众号和 QQ 交流群。
