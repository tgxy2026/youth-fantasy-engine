## 一、简介正文

系列第 4 期，讲动笔之前要做的两组——「开书定位」和「角色管理」。一句话概括：先把"这本书卖给谁""主角是谁"想清楚，再动笔。

【本期看什么】

· 作品信息：开书第一份商业档案——基本信息、平台读者、卖点差异化、简介物料、风险预案。核心卖点、开篇钩子、对标作品写清楚，写法才有方向。

· 世界设定：世界观顶层档案。重点讲"三层填法"——底层法则定了不改、社会文明前十章展开、细节随写随补；别一下填几千字，世界是舞台不是字典。还有同心圆"成长地图"，跟分卷规划对齐。

· 力量体系：升级流的"物理法则"。等级表 + 各境界战力量化（如玄丹毁一屋、化神毁一街），给战斗描写立标尺，防战力通胀。等级表是宪法，正文发布后尽量不改。

· 四个制度页签：政治架构、经济体系、宗教信仰、司法制度，并列的"世界运转说明书"。题材只换字段名和示例，页签一个不少。

· 角色管理：主要、次要、NPC 三档角色卡，字段一个比一个简。"种族 / 所属势 / 地理位置"是下拉，选项取自设定表，根治"同名异写"；保密等级 D 档任何情况都不给 AI。

· 人物关系：关系变了新增一行不覆盖，演变过程本身就是素材；右切关系图能拖能缩放，还有"知情度"跟创作管理联动。

🔴 顺带说清：商业定位决定写法，不是写完再找读者；这套档案就该在动笔前填。
