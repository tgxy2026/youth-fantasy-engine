## 一、简介正文

系列第 5 期，讲「世界构建」这一组——十个页签，把整个脑子里的世界落成一份能查、能联动、改不乱的档案。

这一期看什么：

· 国家势力——"上级"列指向本表，自动长成一棵可折叠的势力树；内部派系是冲突富矿，别把势力写成铁板一块。
· 势力关系——同盟 / 敌对 / 贸易台账，能出一张力导向"势力图谱"，现场加一条关系图立刻重画。
· 地理风物——🔴 单列「距离与行程时间」必须填：十个时间 bug 里有八个是路没算错；"地图格子"是隐藏列，别手填。
· 地图编辑——本期的视觉重头戏：格子地图自己涂，粗档一格十公里铺大陆、精档一格一公里画宗门；子范围必须画在父范围内；还能叠加伏笔、角色、时间线，写到哪章发生在哪，就能在那儿看见埋过什么坑。
· 种族生物 / 物品资源——神族挂世界终极真相；贵重物品用"流转轨迹"记清楚谁给谁。
· 历史事件——倒推法填（从结局倒推到开篇），"真相"和"民间流传版本"的落差本身就是剧情；支持自定义历法跨历法排序。
· 名词术语 / 其他设定——专有名词进术语表防"同物两名"；其他设定是兜底页。
· 世界引擎（3.0 新加入）——把整本书的世界抽成"世界包"封存，可跨作品复用：新建世界 = 草稿，封存 = 不可变版本，原书改了不会偷偷跟着变。
