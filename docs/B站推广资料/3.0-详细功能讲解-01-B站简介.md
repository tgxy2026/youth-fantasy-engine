## 一、简介正文（可直接粘贴）

青春幻想引擎 · 详细功能讲解 第 1 期

系列开场 + 工作面板这一组三个页签（写作面板 / 模型设置 / 使用指南）。

【系列怎么分】
八份视频，每份十分钟以内，按侧栏分组来切：① 开篇+工作面板 ② 正文写作 ③ 灵感工具 ④ 开书定位+角色管理 ⑤ 世界构建 ⑥ 大纲规划+创作管理 ⑦ 酒馆模式 ⑧ 运营维护+数据安全。每份都能单独看，不用从头追。

【本期看什么】
写作面板 = 全书仪表盘。打开软件第一眼就是它：累计字数、完稿章节、未回收伏笔、近 7 日产量四张统计卡；未回收伏笔超过 5 条卡片自动转红——挖坑快于填坑，是烂尾的头号信号。还有自动记录的码字日历、分卷进度、创作健康提醒、完稿预估、角色出场分布。
模型设置 = 集中管 AI 怎么跑，本地 Ollama 与云端 API 自由切，AI 消耗统计只在本机、不联网不上报。
使用指南 = 软件自带的一张地图，把「从零开书」排成了 1 到 10，点哪跳哪；日常高频用的其实就五六个页签。

🔴 AI 是可选增强。不接模型，所有手动功能照常，AI 按钮变灰但不报错、不卡你。

【怎么拿到它】
软件永久免费、开源、无广告、无后门。打开软件里的「关于打赏」页 →「获取最新版本」，有网盘链接和提取码一键复制。更新公告发在 B 站主页、公众号和 QQ 交流群。
