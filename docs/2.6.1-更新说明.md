# 2.6.1 更新说明（含 2.6.0 内容一览）

> 2.6.0 与 2.6.1 相隔一天发布，这份说明合并覆盖两版内容——从 2.5.x 直接升级的用户看这一份就够了。

## 2.6.1 · 看板娘设置 + 拆书 AI 切分 + 章节树体验修复

⭐ **看板娘设置**：项目管理首页按钮升级为「看板娘设置」弹窗——开关、上传自定义立绘（自动压缩到 200KB 内，透明背景 PNG 效果最佳）、一键恢复默认；弹窗里改动，首页立绘即时联动。

⭐ **拆书章节切分 AI 识别**：一键拆书遇到正则认不出的非标标题（如「01|风起」这类自创格式），现在可以在面板里填几条**章节标题示例**，由 AI 识别切分边界。防幻觉闸：AI 报回的每一行都在原文里逐字核对，编造的行直接弃用、回退按字数拆分的兜底逻辑；不填示例则完全维持原行为。

⭐ **可关闭内置背景**：左下角外观区新增「背景」开关，可以隐藏金色书本与房子的线稿背景；全屏开关紧跟「全屏」标签摆放、与背景开关同排，外观区更整齐。

🔧 **章节树折叠保持**（社区反馈）：正文编辑页已折叠的卷，在新增章节、切页签、重开项目后**不再被自动展开**——折叠偏好按项目记忆，写到后卷的作者不再被「全部掀开」。

🔧 **打开项目定位上次章节**（社区反馈）：打开项目不再恒落第一卷第一章，直接回到**上次编辑的位置**；落点章所在卷自动展开并滚动到高亮行。

## 2.6.0 · 结构对照 + 配比爽点带 + 全量审计修复

⭐ **大纲页结构对照条**：选好结构模板（三幕式 / 十五拍 / 起承转合 / 网文三卷式）后，「章节细纲」页只读显示每个节拍对应的章号范围（如「建置 1-5 章 · 对抗 6-16 章 · 解决 17-21 章」），当前编辑章所在拍自动高亮——写细纲时随时知道这一章落在故事的哪一拍。模板与创意写作 / 检查工具共用同一份选择。

⭐ **配比图爽点分布**：「全书结构配比」在理想 / 实际两条字数带之下新增第三条「爽点」带——把「爽点节奏」表里排好的爽点按章节号折算到各拍（悬停看拍名与类型明细），看的是离散事件的分布；与字数带互相独立，新书只排了爽点也能看。

⭐ **全功能巡检 + 六维审计修复**（约 60 处）：灵感融合卡片补上「基于灵感 #N」溯源标注；AI 助手失效入口指针、必选模块说明等 8 处 P1 全修；新增 danger/success/info 语义色体系——浅色主题下状态文字对比度修到 WCAG 达标；**修复数字输入框吞小数的精度回归**（温度、top_p 等参数不再被四舍五入成整数）；全站文案直引号 / 列表符 / 术语实名统一。
