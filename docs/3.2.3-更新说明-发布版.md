## 青春幻想引擎 v3.2.3 —— 大表快了一个数量级，保存不再「以为存上了」

> 本版三块：**① 大表打开/滚动重做（300 行从 12 秒到 0.17 秒）② 便携版保存不再静默丢失 ③ 可靠性与 AI 失败行为收口**。

### 第一部分：大表（伏笔、时间脉络、角色关系等宽表）

**你看到的**：三百行的表，切进去要等十几秒；一千行的表基本打不开，只能干等。  
滚一下卡一下，全程风扇响。

**实际发生的**：两个毛病叠在一起 ——  
① 每一行的「跨表引用」控件和「下拉选项」都**各自把整张表读了一遍**（300 行 × 1 个引用列 = 读回 90,300 行，放大 301 倍）；  
② 所有单元格**一次性全挂进页面**（300 行 × 74 列 = 22,200 个单元格、12.5 万个节点）。

**现在的行为**：

| 指标               | 3.2.2        | 3.2.3             |
| ---------------- | ------------ | ----------------- |
| 300 行 × 74 列 打开  | 12,199 ms    | **≈ 170 ms**      |
| 1000 行 × 74 列 打开 | 180 秒内打不开    | **≈ 190 ms**      |
| 单元格输入            | 651 ms（P95）  | **≈ 30–40 ms**    |
| 滚动一步（120px）      | 113 ms       | **≈ 25 ms**       |
| 页面节点 / 挂载行数      | 125,340 / 全量 | **6,652 / 12–15** |
| 内存占用             | 142 MB       | **57–65 MB**      |

做法是两条：读取上提到表格级（每列只读一次）、行窗口化（只挂视口附近的行，首尾用撑高占位行保持表结构）。  
表头吸顶、列宽、横向拖拽、树形层级、筛选、跳转聚焦都没有变。

> ⚠️ 如实说明：这些数字来自固定夹具 + Edge headless 的正式基线（生产构建、5 开 / 30 输入 / 20 保存 / 20 筛选 / 60 步滚动），  
> 不包含真实输入法打字。你自己那张特别大的表，第一次打开可能比上表慢一点（首次建索引），之后就快了。

### 第二部分：便携版「保存了但没存上」（网盘/杀软环境必看）

**你看到的**：把数据放在 OneDrive / 坚果云 / 百度网盘的同步目录里，偶尔出现  
「界面显示正在保存，然后一直转」；关掉重开发现这次改动没了。

**实际发生的**：便携版写盘是「先写临时文件、再改名覆盖」。  
Windows 上网盘客户端、杀软、索引器会**短暂占用**那个刚写完的文件，改名这一步被拒（`EPERM`）；  
旧代码不重试，于是这一次保存**被直接丢弃**，而界面还停在「正在保存」——  
既不报错、也不落盘，最坏的一种失败。

**现在的行为**：

- 改名失败会**自动重试 5 次**（约 0.6 秒，跨过一次扫描窗口）；
- 仍然失败就**明确报「保存失败、原文件未改动」**，不再让你以为存上了；
- 失败后不会留下半个文件，重试一次就能正常保存。

**顺带修的同类问题**：桌面版、云端、便携版现在共用同一套「条件写」保护 ——  
两个窗口同时改同一份数据时，后保存的**不会悄悄覆盖**先保存的，而是提示冲突、让你先导出草稿。

### 第三部分：可靠性与 AI 失败行为

- **导入保护**：导入旧版本/新版本数据文件时会校验格式版本，  
  不再出现「新版本的文件被静默接受、再保存就把整库抹平」。
- **在途编辑 / 切项目 / 关窗**：三端（桌面、便携、网页游客）都实测过「正在写的时候切项目、关窗口」，  
  结果是**要么旧、要么新，不会写坏**。
- **AI 拒答**：模型因内容政策拒绝时，提示会说明「这是平台拒答，不是你的密钥/模型名/参数出错」，  
  拒答文本不会被塞进正文。
- **AI 超时**：到设置的「请求超时」就放弃（默认 300 秒，设置里可调 30–3600 秒），不会无限转圈。
- **AI 取消**：再触发一次即掐掉上一次在途请求（旧的那次不会回来盖住新的）。
- **界面布局**：小窗口到 768×1024、缩放 125%/160%，55 个页签共 385 组组合逐页量过，**没有溢出**。

## 已知限制（不冒充已验证）

- **安装器「双击安装 → 启动 → 读写」链路**这一版没有实跑（只验了 `win-unpacked` 直接启动的 `SMOKE_OK`）；  
  便携版没有在真实 U 盘上跑过。
- 真实模型质量、双设备同步、实体输入法（搜狗 / 微软拼音）实体键盘 —— 都需要环境或你亲手试。
- **伴写请求超时后界面没有任何提示**（设计如此：伴写失败静默、连续失败才熔断提示）。  
  觉得需要单独提示的话告诉我。
- 大表还有五项没测：项目冷启动、远端定位、A/B 项目交错、longbook 正文输入、100 行批量保存。
- 三端兼容专项运行单元 14/26（4 个安装/设备类契约仍未覆盖，等安装后真机）。
