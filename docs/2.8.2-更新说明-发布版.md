# 青春幻想引擎 2.8.2 更新说明

> 发布日期：2026-10-05 ｜ 桌面安装版（Windows）
> 上一版：2.8.0（本次同时含 2.8.1 与 2.8.2 两批改动）

---

## 一句话

**酒馆模式对齐 SillyTavern** —— 从「能演」做到「演得住」：背景设定与故事剧本升级成**世界书**（每节自带触发词、概率、四色灯），注入额度**跟着模型窗口走**，剧情推演有了**分支树**，自由对话补上了**检查点回滚**和**语义召回**，同场角色放宽到 6 个。

同时修掉三个「看起来没事、其实没生效」的静默缺陷 —— 它们不会报错，只会让你以为功能在正常工作。

## 新增

### 世界书 · 背景设定 / 故事剧本（精细触发）

- **入口**：酒馆模式 → 背景设定（剧情推演）/ 故事剧本（自由对话）。
- 一句话总纲之外，**每一节都能写自己的触发词** —— 提到「城南」才带上城南那一条，而不是整份塞进去。
- 每节还能设**命中概率**（1 = 必中，0.5 = 一半概率）。
- ⭐ **四色灯**（对齐 SillyTavern 的蓝圈 / 绿圈 / 🔗 / 停用，换成契合本项目的名字）：
  - **常驻**：每轮都带
  - **触发**：命中触发词才带
  - **引荐**：只在被别的词条递归带出时出现（正文里提到它 → 再激活它，递归 2 轮、不重复）
  - **休眠**：本次不参与
- **没设过灯的条目按老语义推断** —— 触发词留空就是「常驻」，等于升级前的行为，**旧数据一字不变**。

### 注入额度：跟模型窗口走，两层分开算

- 原先写死的「全量注入 2400 字」拆成**两层**：
  - **固定层** = 一句话总纲 / 世界设定 → 窗口的 **8%**（下限 2400、上限 12000）。**超了不许保存**（保存时会明确告诉你超了多少）。
  - **动态层** = 触发词命中的词条 → 窗口的 **15%**，可在控制面板调到 **5%~35%**。
- 两层**各算各的、互不挤占** —— 小窗口模型也不会出现「总纲存得下、却注不进」。
- 超额度时**按优先级逐条取舍**（先留常驻 → 再留直接命中 → 最后才砍被引荐的），**不再把某一条切一半**；被舍弃的条目会在注入情况里如实列出。

### 多候选（重说保留旧版）

- **入口**：酒馆控制面板 → 多候选开关。
- 开启后「重说」不再覆盖原回复，而是**存成候选**，消息下方出现 `‹ 2/3 ›` 翻页可来回对照。
- **开关关闭时行为与旧版逐字一致**（不写候选、不出现翻页器）。

### 剧情推演 · 分支树视图

- **入口**：剧情推演左栏底部的「分支树」开关（**一场分支都没有时不显示**，少一个控点）。
- 从某场分出来的推演会**缩进挂在它下面**，底栏显示「共 N 场 · M 个分支」。
- 纯显示开关、**零数据改动**（不新增字段、不存父子关系，父子由分支命名反推），平铺态与旧版逐字一致。
- 父不在当前筛选结果里（或根场已被删）的**孤儿分支仍会显示**并标注，不会「一筛选就凭空消失」。

### 自由对话 · 检查点 / 回滚

- **入口**：自由对话右栏第三段「检查点」。
- 随时存一个检查点（可命名），之后一键**回到那一刻** —— 消息、**在场角色的记忆**、本场数值一起还原。
- **回滚还能撤销**（只留一层快照，不做无限套娃）。
- ⚠️ **务必知道**：自由模式的记忆是**角色级、跨会话共享**的 —— 回滚会影响这位角色**在别的对话里**记得的事。确认弹窗与界面都已明示。只想丢消息、不动记忆的话，用「重说」或删单条。

### 自由对话 · 语义召回（默认关）

- 长对话里早期内容会被上下文预算裁掉、Ta 就真的忘了 —— 开启后按相关性把**本场**早先的片段补回来。
- **只捞本场**（不会读到别的对话）；**默认关**（开启要发嵌入请求，会产生费用）。
- 没配嵌入模型或服务断线时静默降级，不报错、不卡住。

### 同场角色放宽：3 → 6

- AI 同时扮演的角色上限从 3 提到 **6**，位置总数放到 **8**。
- AI 名额占满后，新增的位置**默认落「在场不出声」** —— Ta 依然在场、可被提到、记忆照算，只是不占发言名额，也不再挤占上下文。
- 上限口径抽成**单一真源**（此前三个文件各写一个数字，改一处漏一处会**静默丢角色**）。

## 改进

- **主从双栏独立滚动**（社区反馈）：次要角色多的时候，右侧详情不再跟着左栏一起滚到底 —— 两栏各自滚动。角色卡 / 细纲卡 / 酒馆会话列表三处生效。
- **示范项目内容补全**：新建示范项目后，各页签都有可参考的示例内容。
- **界面上 5 处字面星号**：帮助说明里写的 `**加粗**` 会原样显示成星号（帮助气泡是纯文本渲染）—— 已改为「」。

## 修复

### 三个「看起来没事、其实没生效」的缺陷（本版最该升级的理由）

| 缺陷 | 实际影响 |
|---|---|
| 控制面板的**动态额度百分比从未接线** | 你把比例从 15% 调到 30%，**界面仍按 15% 显示、也按 15% 卡保存**，而引擎按 30% 注入 —— 显示与真实行为不符 |
| 回滚检查点后**旧索引不重建** | 回滚到不足 12 条消息时，语义召回会继续捞「**已经退回去、不曾发生**」的片段 —— 比不召回更糟 |
| **「固定层额度」从未真正用于注入** | 小窗口模型（如 8K）下会出现「**总纲存得下、却注不进**」：按界面提示存了 2400 字，注入时被砍掉一半 |

### 其余修的问题

| 领域 | 修的问题 |
|---|---|
| 存储层 | **关同步前落盘没查返回值**（写失败返回 false 而非抛错，只挂 catch 会整个漏掉，下一步却要切回本地并重启）；三处空 `catch` 补留痕；**备份开关读失败**此前被静默当成「你没勾选」，导出会悄悄剔掉参考资料 |
| 云同步 | 数据体检的「清理幽灵索引」**没挡云同步不可用期** —— 那时分条在云端、本地读到空值，会被误判成幽灵删掉索引，云端恢复后该会话永久消失 |
| 迁移 | 历史事件的「结束时间」回填用错了变量，纯老数据第一次打开会漏补（第二次才自愈） |
| 世界书 | 整份关键词闸与词条闸的**大小写口径不一致**（同一关键词可能一层判中、一层判不中）；超额度逐条取舍存在**优先级反转**（低优先级但很大的条目留着、高优先级但很小的条目被砍） |
| 用量明细 | 打开发用量明细会**真的发出嵌入请求**（只读统计不该花钱/联网） |
| 界面规范 | 四色灯的色值走了裸色板而非主题 token（换主题时不跟随）；角色卡片行内删除键尺寸与同类操作不一致；两处面板的首屏加载缺卸载守卫 |

## 安装与升级

- Windows 桌面版，**按用户安装、不需要管理员权限**；支持自选安装目录，直接在旧版本上覆盖安装即可。
- ⚠️ 装到**没有写权限的目录**（例如 Program Files）会因权限不足而失败 —— 数据目录建议留在默认位置或自定的普通目录。
- 覆盖安装不会清掉已有项目数据；动手前建议先用「设置 → 备份」导出一份留底。
- 本版**无数据迁移动作** —— 老项目打开即用，世界书相关字段全部是可选扩展。
- 若你用过语义检索 / 参考资料，索引仍建议重建一次（本版修好了回滚后索引不重建的问题）。

## 已知限制

- **自由对话的记忆是角色级、跨会话共享**：检查点回滚会影响该角色在别的对话里的记忆（界面已明示）。
- **语义召回需要自备嵌入模型**（本地 Ollama 需先 pull 一个嵌入模型，或配 OpenAI 兼容 embeddings）；不配则自动走关键词降级。
- **同场角色上限 6** 是折中值：本项目是「AI 分饰全员」架构（模型需要认识所有在场角色），人数会线性吃上下文 —— 用不上的角色建议挂「在场不出声」。
