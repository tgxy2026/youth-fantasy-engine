## 1. 口径（这一版为什么可信）

| 项 | 定义 |
|---|---|
| 指标 | `open`（切到表格页签→首屏可用）· `input`（单元格输入）· `save`（点保存→已落盘）· `filter`（表头筛选）· `clear`（清筛选）· `scroll`（滚动一步） |
| 样本 | open 5 · input 30 · save 20 · filter 20 · clear 20 · scroll 60（另有 1 次预热不计分） |
| 统计量 | nearest-rank：P50 / P95 / 最差 |
| 滚动步长 | 固定 **120px/步**、**页面内计时**（不含 Playwright 往返） |
| 保存确认 | **按主键读单条**轮询（2~5ms），整表回读只在最后做一次且不计时 |
| 行数判据 | 读界面自己的「共 N 行」，期望值由夹具**独立算出**（不读界面对答案） |

**为什么样本量是这些数字**：nearest-rank 的 P95 在 n=5 时等于**最大值**、n=10 时也接近最大值 ——
一次 GC 或一次多等的轮询就能把它顶穿（实测 small 连跑两次：P50 只差 0.06ms，P95 摆了 +9.7/+19.4ms）。
所以 save/filter/clear 一律凑到 20 个样本，让 P95 真的是 P95。

## 3. 阈值（v8 起按后端分开）

| 项 | guest medium | guest large | portable medium | portable large |
|---|---|---|---|---|
| openP50 / openMax | 1000 / 2000 | 2000 / 3000 | 1000 / 2500 | 2000 / 3500 |
| inputP95 | 100 | 120 | 120 | 150 |
| saveP95 | 1000 | 1500 | **2000** | **2500** |
| filterP95 / clearP95 | 500 / 500 | 800 / 800 | 800 / 800 | 1000 / 1000 |
| scrollP95 | 50 | 60 | 60 | 80 |

**为什么便携单独一套**：便携的保存是「整库 JSON 过 HTTP + 原子写盘」（实测 P50 ≈ 0.86~0.95s，偶发 1.5s），
网页端是 IDB 事务（≈60ms）。差一个数量级不是「慢」，是**机制不同**；共用一套阈值只有两种结局 ——
要么便携永远判红，要么把网页端的闸门放到形同虚设。

## 4. 退化闸（v6 新增，v9 定稿）

`--mode compare` 以前只算差值、判定仍看绝对阈值 ⇒ ①「比上次慢 5 倍但没超上限」判通过；
② small/tree/mixed 没有阈值 ⇒ **永远判不通过**（等于这三类没有闸）。

现在：

- 相对判据 `REGRESSION_LIMITS`：P50 超基线 20%、P95 超 30% 即 `regression-failed`；
- **噪声地板按指标定**（差值小于它算噪声）：open/input 15ms、save 30ms（2×15ms 轮询）、
  filter/clear 20ms（读「共 N 行」的轮询）、scroll 5ms；
- 判定顺序：相对退化 → 绝对阈值 → 才算 `comparison-passed`。

实测校验：`small`、`tree`（都无绝对阈值）**`comparison-passed`**；`portable/medium` **`comparison-passed`**。
回归守卫：在 `tests/tablePerformance.test.ts` 里钉住三条 —— 同速不报、+3ms 抖动不报、10→40ms 必报。

## 5. 覆盖边界（明确没做的事，别当成已验）

| P0 余项 | 现状 |
|---|---|
| 项目冷启动（项目中心→首屏） | **未覆盖**：现有夹具都从「已进入项目」开始计时 |
| 远端定位（跳转聚焦到远处行） | **未覆盖**：需要从「数据体检/地图跳转」UI 入口驱动，属独立 harness |
| A/B 项目交错切换 | **未覆盖**：`project-switch` 夹具已生成，但没有对应的测量流程 |
| longbook 正文（500 章/百万字输入） | **未覆盖**：属正文编辑器，不是表格链路 |
| 100 行批量保存压力 | **未覆盖**：行窗口化后一次只挂 12~15 行，逐行驱动 100 行要先滚 8 屏 |
| 安装包 / 实体设备真实环境 | **未覆盖**：需封装口令 |

这五项都不是「调阈值/加一个指标」能补的，需要各自的 harness；本报告只冻结已覆盖的六项指标。

🔴 每次重采都是**口径变化**，不是性能回归。跨版本数字只能并列陈述，不能用 `compare` 下结论 ——
执行器会明确拒绝（`Incompatible baseline environment, fixtures, measurement or thresholds`）。
