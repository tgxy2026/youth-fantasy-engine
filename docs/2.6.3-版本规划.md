# 2.6.3 版本规划 —— 应用内「检查更新」（自动查最新版 + 更新说明 + 双下载入口）

> 主人哥哥 2026-09-30 拍板四项：① 自动检查**默认开**；② 更新说明**直接同步 Gitee 上的 md**；
> ③ 下载入口 **Gitee + 夸克** 两个；④ 版本 2.6.2 → 2.6.3，本轮开发。

## 一、为什么这样做（现状 → 决策）

| 现状 | 决策 |
|---|---|
| 关于页只有「打开网盘下载页 + 复制口令」，**不联网检测**（代码注释里明写「刻意不做联网版本检测」） | 改为联网检测，但**只提示、不静默下载、不自动安装** |
| 服务器已于 09-21 彻底清理，跨设备同步只靠云盘文件夹 | 🔴 **不复活服务器**：版本源直接用 Gitee 公开 API，运维成本为零 |
| Gitee `GET /repos/{o}/{r}/releases/latest` **匿名可查**（实测：返回 tag/name/body/附件直链，且 `Access-Control-Allow-Origin: *`） | 作为**唯一版本源**；本地版本号来自 `package.json`（env.ts 的 `APP_VERSION_LABEL`） |
| 夸克网盘**没有公开 API**，无法程序化查询 | 只做**镜像下载渠道**（链接沿用关于页现有常量，抽到单一源） |

附带好处：刚做的网络代理是 session 级的，检查更新走同一出口 ⇒ 内网 / 自建中转的用户也能正常检查更新。

## 二、功能设计

### 2.1 检查时机与节流
- **启动后延迟约 3 秒**异步检查一次（不阻塞首屏、不影响启动速度）
- **每天最多自动检查一次**（记 uiPrefs：`update-last-check` 日期）
- 关于页有「检查更新」**手动按钮**（不受节流限制，点了就查）
- **失败一律静默**：网络不通 / Gitee 限流 / 解析失败都不弹错误（🔴 绝不用错误弹窗骚扰作者；手动点检查时才给出「暂时查不到」的轻提示）

### 2.2 版本比较
- `v2.6.3` → `[2,6,3]`，**逐段数字比较**（🔴 字符串比较会把 2.6.10 判成小于 2.6.2）
- 只有**严格大于**当前版本才提示；相等或更小不提示
- 当前版本取 `APP_VERSION_LABEL`（dev 环境是「开发版」→ 不参与比较，直接跳过自动检查）

### 2.3 更新弹窗（UpdateDialog）
- 标题：发现新版本 `vX.Y.Z`
- 正文：**Gitee Release body 原样渲染**（轻量 markdown：`##` / `###` / `-` 列表 / `**加粗**` / 段落）
- 按钮四枚：**Gitee 下载**（安装包直链，从 assets 里取 Setup.exe）、**夸克网盘（备选）**、**稍后提醒**、**跳过此版本**
- 「跳过此版本」记 uiPrefs（`update-skip-version`），该版本不再提示

### 2.4 下载动作
- 桌面版：走新增的 `openExternal` 主进程桥（系统默认浏览器打开直链）
- 浏览器 dev：无桥时降级 `window.open(url, '_blank')`

### 2.5 开关
- uiPrefs 布尔偏好 `update-auto-check`，**默认 true（开）**，关于页可关
- 关掉后不再自动检查，手动按钮仍可用

## 三、合规与红线（必须守住）

1. 🔴 **只发一个 GET 请求，不带任何用户数据**（不上传项目名、机器信息、版本号以外的任何东西）
2. 🔴 **不静默下载 / 不自动安装 / 不阻断使用**——只提示，决定权在用户
3. 🔴 **更新说明来自 Gitee，等同于外部输入**：一律走 React 文本节点渲染，**禁用 `dangerouslySetInnerHTML`**（XSS 面）
4. 🔴 失败静默；开关可关；「跳过此版本」可跳过
5. 夸克为**人工同步**，可能落后于 Gitee → 弹窗里注明「网盘由作者手动同步，可能稍慢于 Gitee」

> 🔴 **版本决策**：**不单独立版本，并入 2.6.3**（主人哥哥 2026-09-30 定）。

### 6.1 根因（一句话）

`App.tsx` 用**条件渲染**（`renderContent()` 同一时刻只挂一个页签组件），**切页签＝旧组件卸载**；
长任务状态多住组件 `useState`。病根**分两类**：**A 类**＝卸载清理主动 `abort()`（任务被杀）；
**B 类**＝无卸载保护（后台烧额度、结果写进已卸载组件蒸发）。

### 6.2 拍板五项（2026-09-30）

| # | 决策 |
|---|---|
| 1 | 并发＝**真并行**（任务中心**不做全局队列**） |
| 2 | 切页签＝**轻提示**（toast `info`，不阻断、不重复） |
| 3 | 结果回填＝**回到发起页签自动显示** |
| 4 | keep-alive **先不做**（只要问题能解决即可） |
| 5 | **不独立版本，仍旧 2.6.3** |
