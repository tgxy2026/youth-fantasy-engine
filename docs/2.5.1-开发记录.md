## 二、逐项实录

### B2 · 真·全屏切换

- **主进程**（`electron/main.cjs`）：`window:setFullscreen` / `window:isFullscreen` 两个受控 IPC + `enter/leave-full-screen` 状态推送。启动行为不变（最大化保留标题栏），全屏态不跨启动记忆。
- **preload**（`electron/preload.cjs`）：`electronWindow` 桥（setFullScreen / isFullscreen / onFullscreenChange 退订式订阅）。🔴 接口命名随 Electron 官方大写 S——单测抓到过 preload 小 s 与接口层大 S 不一致的真 bug。
- **渲染层**：`desktop.ts` 提供 `toggleFullscreen` / `installFullscreenShortcuts`（**运行时探测**，node 单测才能注入 mock）；App 挂全局快捷键（F11 切换、ESC 仅全屏态退出，不干扰弹窗关闭）；侧栏「全屏」开关仅桌面版渲染，状态跟随实际态（F11 直按 / 系统级变化都会同步）。
- **实机抓到的真 bug（`c988a17`）**：Windows 上 `enter-full-screen` 事件触发瞬间 `win.isFullScreen()` **还没翻转**（读到旧值 false）→ 推送旧值 → 开关永远显示「关」。修法：事件只当信号，延迟 120ms 读实际值再推。

### D1 · 「写作导师」身份预设

- 架构：`ReaderLens` 支持自带问题集（`questions?`，**缺省 = 读者三问，读者路径零变化**）；`questionsOf(lens)` 是问题集单一源；normalizeQuestion / parseReaderProbe / groupNotes / readerProbeToText 全参数化。
- 导师四问：主题句（theme）/ 核心冲突（conflict）/ 人物弧光（arc）/ 代价（cost），文案全自撰、避开立场禁词。
- system 提示词从「你是读者，不是编辑」泛化为「按赋予的身份来读」——导师看结构概念、同样不谈语法标点。
- 🔴 换身份必须清结果（旧 key 套新分组会全变「没提」）。
- 测试 45 断言：导师四问 / 分组 / 兜底（认不出的 key 落问题集第一问）/ **读者三问零回归**。

### A3 · 灵感夹 + 灵感融合

- **侦察推翻规划前提**：灵感启发页原本只有「取名生成器 + AI 辅助规划对话」，**不存在「灵感卡」数据结构**——比规划预设的「多选改造成本高」更上游。三条预设路径全部落空，升级为重大判定，拍板**新建灵感夹**（补全「灵感存下来 → 变情节」完整链路）。
- `inspirationBox.ts`：一句话条目（settingsKV 存储、随项目走）；trim / 逐字去重 / 200 条上限（超限拒绝、不静默丢）。
- `aiTasks/inspiration.ts`：勾选 2+ 条 → 融合 1~3 个情节创意；提示词钉死「融合 ≠ 拼接」；`basedOn` 溯源（越界编号剔除去重）；空结果重试一次、两次皆空如实返回。
- `PlotCanvas`：CardType 新增 `idea`（灵感融合，绿）——**不进 HEADER_TO_TYPE**（与 beat 同规则，AI 简报永远产不出 idea 卡）。
- 四处注册齐全：aiTasks 门面 + PROMPT_ORDER/PROMPT_SETS、aiWriterBudget（`inspiration-fuse` 0.5 档 + 测试 LEGACY 同步）、aiDataSources、门面 export。
