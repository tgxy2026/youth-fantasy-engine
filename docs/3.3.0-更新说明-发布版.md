## 青春幻想引擎 v3.3.0 —— 界面重新排过一遍，AI 不再「假装完成」

> 本版三块：**① 整套界面按验收意见重排（卡片、侧栏、工具栏、地图）② AI 失败时不再谎称成功 ③ 长等待随时可以叫停**。

### 第一部分：界面重排（桌面端与网页版同一套）

**项目卡片**：底部那排功能键原来挤得很小，现在加高加大，仍然一排、不出卡片框。

**左下「界面与数据」**：

| 位置 | 变化 |
|---|---|
| 外观设置 | 只留**主题 / 字体 / 背景**三样，不再堆密度开关 |
| 界面缩放 | 「自动」与「− 比例 % +」合成**一条自适应宽度的胶囊**，随侧栏拖动一起变长，与上下几条左右对齐；数字框不再被上下小箭头挤得显示不全 |
| 界面密度 | 挪到缩放的右侧，**一枚键切换**紧凑 / 舒适（点一下切换，显示当前档） |
| 云盘文件同步 | 切到「舒适」后最右侧的帮助问号**不再掉到第二行** |

**正文工具面板**：「AI 伴写」原来是个自定义块（颜色比同类亮一档、像小标题），现在与「校对本章 / 伏笔闭环看板 / 连续性校验 / 文风体检」**同一副长相**（同色、同行高 42px）。

**地图**：打开时按你画的图形**自动适配**（内容约占画布八成，不再是缩在中间一小块）；区域名改成**屏幕恒定字号**，放不下的先不画、放大后自然出现 ⇒ 实测首屏地名重叠从 **10 对降到 0 对**。

### 第二部分：AI 失败时不再谎称完成

这是本版最要紧的一组修复。以前失败会被"揉"进一句模糊的成功提示里：

| 场景 | 以前 | 现在 |
|---|---|---|
| 批量重生成摘要 | 有几章失败也弹「全书完成」 | **逐章记账**：哪些已落库、哪些失败、总表是否同步分开说；有失败绝不写「完成」 |
| 校对本章 | 失败与「没发现问题」看起来一样 | 失败有明确结构锚点与文案（`data-proofread-failure`），不装通过 |
| AI 整理 | 模型返回解析不出来，被说成「这段文本里没有可抽取的信息」 | 分**五种成因**（解析失败 / 修复后为空 / 确实没找到 / 全重复 / 全无效），面板红框给诊断，通知也按真实结果说话 |
| 审阅与候选 | 只给局部预览、过期与已应用混在一起 | 完整原文与候选都能看、**全部留档**（含过期/已应用/放弃）、过期明确标「需核对」；放弃状态保存失败不再报成功 |

### 第三部分：长等待可以叫停

- **批量重生成摘要**：跑起来同一位置变「中止」（中止 ≠ 回滚：已更新的章节保持已更新）
- **三个 AI 审计**（伏笔深度分析 / 连续性深度审计 / 文风体检）：各自补「停止」，只在运行时出现
- **分包加载失败**：可以真重试（换新实例，不是骗人的按钮）
- **图片加载失败**：给可读占位，并能手动重试

### 第四部分：写作现场更不容易丢

- 同页**切章再切回**：现场（光标、滚动、选中）不再丢 —— 判据改看**数据侧**正文，而不是切换那一帧的编辑器内容
- **设定检索里内联改字段**：保存失败不再「假成功」，失败就留在原地、给可操作原因
- **慢保存 / 失败保存**：手工草稿保留，切页签、收起、窗口变窄都不丢
- **角色页**：跨失败与导航的草稿保留；模板版本与失败提交可恢复

### 第五部分：网页版（同一份代码）

- 新登录页：护眼绿两栏（左品牌「让想象，自成宇宙。」/ 右表单「欢迎回来」），登录 / 注册 / 忘记密码齐全
- 游客入口优先：不注册也能先把软件用起来（数据只在浏览器本地，不上传）
- 云端账号：跨设备同步；账号隔离与会话替换已验证

### 已知限制（没有验的，就不会说成能用）

1. **第二台实体设备**上的同套验收未做（换机、不同 DPI / 系统主题）—— 四配置里唯一还空着的一格
2. **真实输入法与读屏软件**的人工验收未做（代码层键盘/焦点/aria 已覆盖，真机 IME 与读屏仍待你实机确认）
3. 主包 1.80 MB（gzip 584 kB），超过 700 kB 提示线 —— 已知限制，不影响功能
4. 酒馆模式里 `prompt.ts` 的原文包裹仍有一处历史遗留（promptGuard 未包），动它要先读酒馆工程红线文档
5. 跨项目 / 跨存储的读取组合（要两套真实后端）未验
6. 便携版/网页版不内置模型：AI 功能需要你自己配 API Key 或本地模型
