### 6.4 B3-1 另存为新书（2026-10-31）

| 文件 | 作用 | 证据 |
|---|---|---|
| `src/lib/sync/projectAsCopy.ts` | 纯函数：云端清单 + 已下载分片 → `ProjectBundle`（不改前缀、不换 id） | projectAsCopy **24/24** |
| `src/lib/sync/projectPullWrite.ts` | 下载 → 还原图片 → 计划 → `importProject()` 落成**全新项目** | tsc / eslint / 全量 |
| `src/components/app/CloudSyncPanel.tsx` | 冲突时启用「两份都留（另存为新书）」；「用云端覆盖本机」仍禁用 | **仍需真机视觉验收** |

四条取舍：

1. **id 重映射全部复用 `importProject()`**，本模块不另写一份。卷 id、章 id、台账行 `tabId`（内嵌卷 id）、快照 `chapterId`、`worldSubActive::` 子项活跃态、两套设置前缀都在导入实现里，另写必然漂移。
2. **副本不绑定云端**：避免两本本地作品抢同一个 `cloudProjectId`。要让它也上云，回到面板点「上传这本到云端」另建一本。
3. **副本不带自定义下拉选项**：当前快照协议只产十类分片（`customOptions` 不在其中）。界面会如实列出，不假装完整。补该分片属协议变更，需单独评估并升 `SNAPSHOT_PROTOCOL`。
4. **`localDirty:false` 是语义不是绕过保护**：写入目标是新项目，原项目的未同步改动仍安全留在本机。

已知限制（不要当已完成）：入口只在 `WEB_CLOUD`，未做真机验收；云端清单只带名称 / 题材 / 形态 —— 本机没有原项目时，简介 / 封面 / 自定义功能无法恢复（已列入 `omitted` 并在界面提示）。

四条取舍：

1. **恢复写新 revision**，不把删除版「退回去」：倒退会让握着删除版基线的离线设备判成云端回滚，甚至用旧基线把别人的版本盖掉。
2. **只清 `kind==='project'` 的墓碑**：记录级墓碑（删掉的章节等）是事实，恢复整本书 ≠ 撤销它们。
3. **找不到内容版就如实失败**（410）：不假装恢复出一本空书。
4. **恢复后不自动上传本机**：云端 revision 变大，本机绑定基线自然落后 → 面板显示「云端有新版本」，沿用「只提示不自动应用」。

四条取舍：

1. **只允许已进回收站的作品**：绕过回收站物理删，会让离线设备手里的旧基线既无墓碑、也无版本可比对 —— 那正是「删了复活」的温床。
2. **不删共享对象库**：内容寻址对象可能仍被其他项目 / 其他版本引用；项目目录删掉后，对象交给 `object-gc` 按引用与宽限期回收。自检第 9 条用「另一个项目上传同内容命中 reused」钉住了这一点。
3. **配额释放 ≠ 磁盘释放**：索引条目删除后配额立刻回收，磁盘空间等 GC；界面文案必须把这两件事分开说。
4. **删除后自动解除本机绑定**：否则本机会一直显示「云端已经没有这本了」。

### 6.12 桌面端同步整链自检（2026-10-31 09:20）

`electron/syncSelftest.cjs` + 开关 `--desktop-sync-selftest=<服务器地址>`：
主进程往自己的窗口注入点击/输入，走**真实渲染层**跑完整条链路，再从服务器读云端状态做判据。

```
electron . --no-sandbox --user-data-dir=<临时目录> \
  --selftest-user=<一次性账号> --selftest-pass=<密码> \
  --desktop-sync-selftest=http://127.0.0.1:8323
```

16 步：账号 → 桌面登录 → 渲染层登录态 → 首屏 → 建书 → 写正文 → 面板 → 上传 → 下载为新书
→ 基线一致 → 改稿自动推 → 云端内容核对 → 模拟另一台设备 → 冲突三选一 → 保留本机并上传 → 云端内容核对。
输出 `SYNC_STEP_OK/FAIL <步骤>` 与 `SYNC_SELFTEST OK|FAIL <通过数>/<总数>`，失败时把界面快照写到
`.workbuddy/tmp/selftest/`。退出码 0 = 全绿。

约定两条：
- **用一次性账号**（首次自动注册，需服务端 `YFE_REGISTER=open`）：每次运行都会新建一条桌面会话，
  单账号 20 台上限会被跑满。
- **服务端要与 dist 同源**：`YFE_WWW=<dist>`，桌面加载的就是那份产物。
