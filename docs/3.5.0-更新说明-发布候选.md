# 3.5.0 更新说明（发布候选）

3.5.0 新增投稿广场，为创作者提供轻量的片段分享和交流空间。

- 注册账号即可投稿、浏览、点赞、点踩和评论。投稿最长一万字，经过规则初筛和管理员审核后公开；评论按较轻的审核规则处理。
- 可选择使用自定义昵称或以「匿名用户」显示；广场内置示例故事。
- 阅读正文使用可用窗口宽度，段落间距更紧凑；阅读字号可调整并在本机记住。
- 可自愿加入每日、每周、每月码字排行，按包含标点的项目正文净增字数统计。关闭排行授权后停止展示相关数据。
- 桌面版和网页版通过服务器共享社区内容；账号不需要云同步资格也能参加社区，有资格的账号可继续使用云端作品同步。
- 便携版保留原有写作功能，投稿广场暂不可用。

本版本定位为轻量首版。多设备排行合并、设备时间偏差、真实本地 AI 模型审核效果等仍将持续完善；投稿审核由管理员确认，AI 建议不能替代人工判断。桌面版或网页版无法连接服务时，社区功能不可用。

本地全量测试 445/445，隔离服务和已安装桌面版社区流程通过。2026-11-10 已部署网页和服务端，线上接口核查覆盖注册、资格、投稿审核、互动、评论、排行与撤回；实际桌面及网页完整跨端写入流程仍以最终验收记录为准。
