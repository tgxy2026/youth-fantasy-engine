# 青春幻想引擎 3.0.4 更新说明

> 发布日期：2026-10-15 ｜ 桌面安装版（Windows）+ 便携版（Windows / macOS·Linux 两个包）
> 上一版：3.0.3（2026-10-14）

---

## 一句话

**3.0.4 把一批「切个页签、重启一下就回到默认值」的界面习惯真正记住了**，同时修掉一轮代码审计发现的同步与弹窗问题，并给 Electron 主窗口启用了进程沙箱。

这一版没有新增页签，主线是**手感**——少点几次、少调几次。

---

## 界面习惯不再丢（本轮主线）

**来源**：社区反馈「正文编辑页的设定检索栏，用右上角『面板』按钮隐藏后，切到别的页签再回来又冒出来了」。

**核实结论**：这不是个别功能的毛病，是**一类通病**。软件切换页签时组件会整体卸载、重新挂载，凡是用普通内存变量存的开关都会回到初始值——切页签丢一次，重启软件再丢一次。

3.0.4 把这类「这台机器上这个人的界面习惯」统一收进本地偏好（沿用项目里既有的 `yfe-ui:` 命名空间）。这一轮纳入的开关：

| 位置 | 记住什么 |
|---|---|
| 正文编辑 | 设定检索栏显隐（本轮反馈的源头）、引用侧栏显隐、引用高亮 |
| 一键拆书 | 「写入章节」「汇总表单」两个勾选项 |
| 故事时间轴 / 历史时间轴 | 状态筛选、时间比例（均匀 / 按实际）、隐藏的轨道 |
| 剧情推演 | 画布简报模式、场景列表的分支树视图、本场信息展开 |
| 数值面板 | 取值范围条带展开 / 收起 |
| 角色表 | 「隐藏已退场角色」 |
| 首页看板娘 | 精灵双击收边状态 |

- 只记**界面习惯**，**不进项目数据**，也就不跟着项目导出 / 云同步走——换台机器重新点一次即可。
- 默认值一律是「老用户升级后和现在看到的一样」，不会因为「记录里没有这一项」就变成收起或隐藏。

## 修复

### 数据保护：外置载荷迁移写失败时不再丢原始内容

外置存储写入失败（磁盘满、目录只读、跨进程写入异常）时，迁移流程原本**只告警不报错**，结果会误判该部分迁移成功、把主库里的原始内容删掉。3.0.4 给迁移加了严格的写入入口：**写不进去就抛错、保留源数据**，同一批里其它部分照常继续。

（日常写入的错误语义不变，只有迁移路径变严格。）

### 下拉选项不再被「迟到的旧数据」覆盖

切换页签或切换列之后，之前触发的异步读取可能晚一步返回，把当前列表覆盖成上一个列表的内容。现在给每次加载编了号，**只有最新一次请求的结果能更新界面**。

### Electron 主窗口启用进程沙箱

主窗口的 Electron 沙箱原先是显式关闭的；核查后确认 preload 只用到受限的 `electron` 接口、API 全部经 `contextBridge` 暴露，没有需要完整 Node 环境的理由，因此改为**启用沙箱**。这是 Electron 官方的安全建议项。

### 两处文案说清楚了

- **背景设定**：帮助文本原先写「分节触发词留空＝每轮都注入」，实际仍由「整份关键词」先决定要不要加载。已改为按真实门控逻辑描述，状态标签同步修正。
- **表格行操作**：帮助气泡原先声称每行都有删除 / AI 补全 / 新增子条目，实际这些按钮会受母表身份、AI 能力、层级配置限制。已改为「按表格能力显示，不适用则隐藏」。

## 已知问题

- **多设备并发同步仍可能同代覆盖**：两台设备同时基于同一个版本写入时，双方都可能报告成功、后写的覆盖先写的。这需要协议级的条件写入（比较版本后再提交）才能根治，会影响到不同同步后端与旧版本的兼容，因此**本轮没有动**，留到方案确定后单独排期。
  现阶段建议：多机写作时**避免同时推送**，推完确认另一台同步完成再动。
- 本轮改动**没有运行过上一版的完整回归清单**中的人工部分；自动化门禁（类型检查 / 代码规范 / 全量单测 / 真浏览器实机验证）已全部通过。
