## 三、设计

### 3.1 W2-5a 收尾（`useFreeRoundEnd`）入任务中心 —— 本项核心

把四处组件状态换成 `useTaskRunner`：

| 旧 | 新 |
|---|---|
| `const [ending, setEnding] = useState(false)` | `endT.running` |
| `const [endStage, setEndStage] = useState(null)` | `endT.task?.progress ?? null` |
| `const [endResult, setEndResult] = useState(null)` | `endT.result`（关掉弹窗时 `endT.clear()`，保留「关掉即焚」语义） |
| `const endCtlRef = useRef(null)` + `stopEndRound` | `endT.run(fn)` 的 `ctx.signal` + `endT.stop()` |

- `ownerTab: 'tavern-free'`，`kind: 'round-end'`，`title: '结束本轮对话（整理记忆）'`，`writes: ['tavern']`。
- 🔴 **取锁纪律照保**（审计 P1-3：取锁必须在 try **之外**）：
  在 `run` 的 fn 内，**第一件事**就 `acquireSummaryLock`；取不到 ⇒ **throw**
  （交给任务中心如实记 `failed`，`notice` 也会弹给作者 —— 比原来「只 toast 一句」更不容易漏看）。
  `releaseSummaryLock()` 放在 fn 自己的 `finally` 里（`startTask` 不提供用户钩子）。
- 🔴 **中止 ≠ 失败** 照旧：`isCancelled` 判据不变（真源 `lib/ai.ts`）；任务中心侧
  `abortTask` ⇒ `signal.aborted` ⇒ 任务记 `aborted`，**不弹完成提示**（作者自己按的）。
- 🔴 **落库与 setState 的关系**：fn 里照旧 `store.saveFreeSession(...)` +
  `setSession/setMems/setProposals`。切页签后组件已卸载 ⇒ 那几个 setter 自然失效，
  **但数据已落库**（这正是「切走不丢」的语义）——回来后重新加载即可。
- 🔴 **卸载本地模型仍排最后**（#11）：fn 内最后一步，失败只提示、绝不判失败。

### 3.2 W2-5b 「未整理场次」提示（§13 F3）

- 判据**纯派生**：`pendingMessages(session).length` —— 每次渲染现算，**不进任何 state**
  （方案原话：该提示若常驻，其状态不能放组件 state）。
- 位置：自由对话页会话头部给一行角标/提示条：「本场还有 **N 轮**未整理 —— 点『结束本轮对话』才会写进记忆」。
- 🔴 只在 `N > 0` 且该场**未结束**（`!session.endedAt`）时显示；点提示条=调既有的 `endRound`（不新增入口）。

### 3.3 为什么**不动** `useFreeTurn` 的流式状态（留档理由）

- `streaming` / `streamText` 与 `abortRef`（**代次令牌**：切会话或按停止就换掉，在途请求回头
  发现 `abortRef.current !== ctrl` 即知自己「过气」、只落库不接管界面）**强耦合**，
  把它搬进模块级 store 等于把「代次令牌」这套并发语义整体重写；
- 收益侧：每轮回复是**秒级~几十秒**的短任务，切页签丢的影响远小于几分钟的收尾；
- 风险侧：`useFreeTurn` 的注释里已记录过一次「finally 漏判代次令牌导致停止键失效」的事故 ——
  这块**改错会直接让停止键失灵**。
- ⇒ **本项只搬收尾**（方案点名的痛点），流式那处留到 §10.3 #11 跑团一并评估
  （它要重做酒馆页的长任务层，届时一次到位）。

## 五、边界与红线（照做）

- 🔴 **切页签绝不中止任务**（`useTaskRunner.stop` 的注释就是这条）；只有作者点停止才 `abort`。
- 🔴 **取锁必须在 try 之外**（审计 P1-3，已有事故记录）；`releaseSummaryLock` 放 fn 自己的 finally。
- 🔴 **中止 ≠ 失败**，判据一律走 `isCancelled`，不用 message 正则。
- 🔴 **卸载本地模型排最后**且失败不判失败（#11）。
- 🔴 **不重写 `useFreeTurn` 的并发语义**（见 §3.3）。
- 🔴 不新增「结束本轮」入口（F3 的提示条复用既有 `endRound`）。
- 🔴 改完必须**实机验证**（§11.1 L1 原文：静态检查证明不了行为等价）。

## 六、验收

- `tsc --noEmit` 0 ／ `eslint src tests` 0 problem ／ 全量单测全绿（新用例须归批）。
- 单测：`useFreeRoundEnd` 已无 `useState`/`useRef` 持有长任务状态（**源码闸**）；
