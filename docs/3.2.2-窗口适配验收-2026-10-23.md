# 3.2.2 窗口适配验收与接手说明

更新时间：2026-10-23 21:07。用户要求覆盖**项目内部**，按常规平板窗口正常使用和视觉协调推进；随后因额度不足要求交接。当前修改均在工作区，尚未提交、封装或发布。

## 已完成的调整

- `WorkspaceSidebar.tsx`：实际布局宽度按窗口宽度 / 界面缩放计算；小于 900 时改用快捷栏与菜单抽屉。菜单和设置各有入口，设置可直达工具区。抽屉关闭时保留隐藏 Sidebar，以继续订阅后台任务通知。
- `Sidebar.tsx`：外观与云盘配置按需展开；缩放固定分行；桌面工具区限制高度并内部滚动。抽屉中整体滚动，避免放大后菜单与设置分别只剩一条缝。宽屏拖拽偏好保留，实际宽度有限制。
- `CloudFileSyncBar.tsx`：只在 sidebar 形态折叠配置，故障提示仍可见；项目管理页面的 panel 形态不折叠。
- `App.tsx` / `index.css`：主内容 `min-w-0`，命名容器 workspace 按实际内容宽度调整留白、页头和面板；不是只看整块屏幕的断点。
- 作品信息、大纲等页头重新排布，避免标题变竖排；角色详情允许立绘换到下一行；SchemaFieldGrid 按实际容器宽度排列标签与输入框。
- MasterDetail、世界设定、制度、创作轨迹在更窄的内容区上下排列目录与详情，仍各自滚动；地图和有实际对话的自由对话页面重排面板。
- 正文窄窗口下，章节目录和设定检索改为可打开的抽屉；没有选章时也能打开目录。状态栏可横向滚动，正文底部留白在窄窗口减少，避免撑出可见区域。
- 共用 Modal 增加左侧抽屉对齐，沿用焦点约束、Esc、遮罩和嵌套弹窗机制；Electron 最小窗口改为 768×600。

## 接手优先级

1. 当前全部页面最终巡检已完成，无需从头再扫。建议人工再看最终证据目录中的主要页面截图，尤其 1024 横屏大纲、768 竖屏角色/正文/对话、160% 小窗。
2. 发布前可靠性探针最后一次并发运行在重载阶段超时，只完成 12 项；应**单独重跑** `node scripts/audit/probes/revision-reliability-probe.cjs`，此前改动前后均有 16/16 的完整证据，不能把最后一次 12 项算 16 项。
3. 完成发布前报告的最终产物检查、文档引用与差异检查；审阅改动后再决定提交。用户尚未要求封装或发布。
4. 实体平板触摸、软键盘弹出、不同 DPI/浏览器、真实模型、原生文件对话框和安装器链未证明；保留为后续设备/发布阶段验收。

## 复现入口

依次运行，避免同时启动多套 UI 探针造成资源竞争：

```powershell
node scripts/audit/probes/workspace-layout-probe.cjs
node scripts/audit/probes/tablet-interaction-probe.cjs
node scripts/audit/probes/sidebar-layout-probe.cjs
```

探针自行清理进程，资料和截图保留在每次新建的 `.workbuddy/tmp/` 子目录；不删除恢复 bundle 或真实书库。开发探针已改为独立 Vite 缓存。此前导航定位和并发加载超时属于取证过程问题，不作为产品缺陷记账。
