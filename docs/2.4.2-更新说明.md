> 发布日期：2026-09-23 ｜ 安装包：`青春幻想引擎-Setup-2.4.2.exe`（约 81 MB）
> 桌面版（Windows x64）。本项目**只做桌面版**，没有网页版 / 便携版。

## 一句话

**这一版同时补上了「无限流作者最缺的那块拼图」和「三处会静默出错的数据隐患」。**

## 一、⭐ 世界观 / 力量体系：母子结构（无限流刚需）

**为什么做**：无限流的结构天生是两层 —— 顶层一个统一的世界观与力量体系（主角从哪来、跃迁规则是什么），
下面每个副本 / 世界线 / 剧本各有一套自己的设定。此前只有一张单表，要么混着写，要么开新项目分成好几本书。

**现在怎么用**：

| 层 | 是什么 | 会不会给 AI |
|---|---|---|
| **母级（全书统一）** | 只有一份，写跨世界通用的那层 | **永远会给**（即使暂时空着也保留） |
| **子世界 / 子体系** | 想建几套建几套，每套一套完整设定 | **只有标为「活跃」的才给** |

- 左侧列表第一项固定是「全书统一」，下面是你建的子世界，各带一个**活跃 / 已完结**开关
- 右侧编辑选中的那一层，**母级与子级用同一套字段**（该页签的几个模块照旧填）
- 界面会明确标出你正在填哪一层（母级带「全书」徽标），避免母子同名字段填错地方
- **已完结的子世界能删**，删除时会自动从活跃列表里清掉
- 多个子世界可以**同时活跃**（活跃到 3 个会给个提醒）

🔴 **AI 那边看得到什么**：母级 + 活跃子世界，并在段末写明「另有 N 个已完结，未发送」——
**不会让你误以为 AI 读过全部**。只建了一份设定的用户**什么都感觉不到变化**（界面上不会多出任何多套控件）。

## 二、一键拆书：支持 .docx

以前只能粘 `.txt`，Word 稿子得先另存为纯文本，而另存为会丢掉缩进、章节结构也容易乱。

现在直接选 `.docx` 就能拆，**首行缩进按 Word 的段落属性还原成中文全角缩进**（跟编辑器里的正文口径一致）。

- **零新增依赖**：走软件自己的解析实现，不引第三方库 —— 安装包体积一点没变
- 兼容 Word 存的两种压缩方式，也能读我们自己导出的 docx
- **读不到的会如实告诉你**：批注、脚注尾注、页眉页脚、图片、公式、修订中删除的文字都会列出「未读取：…」，
  宁可多一句话，不会静默丢
- 选错格式会直接给办法：`.doc` 会提示「请在 Word 里另存为 .docx 或 .txt」

## 三、投稿前：分平台预检 + 本章体检

**分平台预检**：挑「晋江 / 起点 / 通用」档位，看两类信息 ——
① 敏感词命中里**哪些类别属于该平台通常更关注的**（按类别标出重点，不是给你打分）；
② 分章字数事实（字数 / 段数 / 最长段），与常见投稿习惯的参考区间对照。

> 口径说明：只摆事实，**不判合格与否、不做风险打分**；分档规则随时可能变，界面里一律注明「以平台后台为准」。

**本章体检**：对选中的一章，把软件里已有的五个确定性引擎（连续性 / 伏笔 / 敏感词 / 错别字 / 文风）
**一次跑完并分组呈现**。全部本地计算，不发 AI 请求，手动触发。
以前这五件事分散在四个不同入口，现在一个按钮看全。

## 四、导出增强

点导出时多了个**格式弹窗**（带实时预览）：

| 可调 | 选项 |
|---|---|
| 章节标题 | 原样 / 自动补「第N章」 / 不带 |
| 段落间距 | 段间空行 / 紧凑单换行 |
| 卷标题 | 包含 / 不包含 |
| **设定附录** | 勾上就把设定集转成纯文本接在文末 |
| Markdown 标题层级 | 整书降 1~3 级（**并稿时避免标题打架**） |

选项**按人记忆、跨项目生效**；不调任何选项时，导出结果与旧版**逐字节一致**（有测试钉住）。
「第N章」的序号遵循章节编号规则（标了「不计入序号」的章保留原标题）。

## 六、🔴 数据安全：这一版修掉的三处静默隐患

本轮做了一轮全量审计（八支扫描器 + 四路并行审计 + 逐条回源码复核），修掉 44 处问题。其中三处值得单独说：

| 隐患 | 你会遇到什么 | 现在 |
|---|---|---|
| **记忆退化时仍然推进水位线** | 酒馆某位角色的记忆整理被判定为"整份退化"（新版内容不足旧的 40%）时**不覆盖**（对），但**记录位置照常前移** —— 那段对话被**永久越过**，以后再也总结不到。界面还提示「本次未覆盖」，暗示可以重试 | 退化时**不推进**位置，那段对话下轮仍会被总结 |
| **老库里的检索密钥仍有第二载体** | 早期版本把搜索密钥存在另一处（`tavern.settings`），这个容器会整条随加密同步文件走 —— 界面却承诺密钥不上传 | 新增一次性迁移，**顺手清理**（幂等，跑几遍都一样） |
| **同步合并又一条"删了会复活"路径** | 云盘合并时，某条本地已删的记录若基线比对走上第三条分支会**被云端旧值补回**（同族另外两支早修了，就这支不对称） | 按墓碑判据补齐，并补了防回退测试 |

另外两类：**关窗前的最后一次写盘**此前把"没返回值"当成功（真失败会静默丢）；**酒馆两处中止信号被吞掉**（点了停却继续跑）。

## 七、内部与手感

- **三个巨型组件完成收尾拆分**（颉文姬 1033→91 行 / 创意写作 982→73 / 酒馆控制面板 913→114）——
  不是重构功能，是把「状态 / 界面 / 逻辑」三层摊开，**为后续改动降风险**。做法是机械搬迁 + 实机指纹比对 + 负面对照，界面表现逐项全等
- **层级号收敛到统一真源**：页内吸附表头、吸附首列等 16 处的层级数字改为从同一处取，不再是散落的魔数

## 八、安装与升级

- 直接运行 `青春幻想引擎-Setup-2.4.2.exe`，覆盖安装即可，**原有项目数据自动保留**
- 从 2.4.x / 2.3.x 升上来不需要额外操作（数据迁移在新版本首次启动时自动完成）
- ⚠️ 世界观 / 力量体系仍是**同一套字段**，老库里的内容原封不动待在「全书统一（母级）」里，**不需要迁移**
- 拆书支持 .docx 是**新增可选项**，原来的 `.txt` 流程完全没变

## 九、数据与隐私

- 软件**不做账号体系**，不收集你的稿件
- 涉及 AI 的功能：**原文只发送给你当前选定的那个模型** —— 本地模型则不出本机；云端模型会上传到该服务商
- 模型密钥、搜索密钥等敏感配置**仅保存在本机**，不随云盘同步文件外流
- 云盘同步文件是加密的（内置密钥），**足以防误看，但不足以对抗蓄意破解**；涉密稿件请另用导出备份自行保管
- 本软件定位是**创作主权存证 + 质量自检 + 如实申报**，**不做也不参与**任何"反检测 / 洗 AI 痕迹"的事

## 十、已知事项

- 超大表格（3000 行以上）渲染偏慢，已记录待优化
- 云盘同步是**文件夹级**的，不是实时同步；换设备前请手动确认同步完成
- 拆书 / 创意写作末尾的「全书级设定汇总」**只写母级**（子世界需要自己填）
- 仅 Windows / 仅简体中文
