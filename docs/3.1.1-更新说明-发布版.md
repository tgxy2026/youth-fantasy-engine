# 青春幻想引擎 3.1.1 更新说明

> 发布日期：2026-10-17 ｜ 桌面安装版（Windows）+ 便携版（Windows / macOS·Linux 两个包）
> 上一版：3.1.0（2026-10-16）

---

## 一句话

**3.1.1 把「能用」磨成「顺手」**：冲突副本看得清了、章节状态提示说实话了、第九个主题「纯黑白」补齐了、模型配置能加自定义请求头了 —— 另外修掉 1 处 P1 与 18 处 P2，其中三条是会咬人的（章节顺序在四处各有一份实现、「已开启同步」却一直没同步、检索设置读失败会覆盖真配置）。

这一版没有新页签，主线是**把上一版留下的边角磨平**，并让界面上说的和实际做的一致。

## 一、第九个主题「纯黑白」范围补齐

3.1.0 引入「纯黑白」时**主动保留**了三处范围差异。这一版全部收干净：

| 原先还带颜色的地方 | 现在 |
|---|---|
| 人物关系图 / 势力关系图 | 连线改**线型**（实线 / 虚线 / 点线 / 点划线），节点改**形状**；图例同步换成线型示意 |
| 地图编辑 | 图层环改**线型**、地块层级改**深度线型**、点阵收成二值 |
| 情节画布 | 卡片改**边框线型 × 粗细**，图例同步 |
| 结构节奏带 | 填充改**纹理** + 二值分隔线 |
| 写作目标燃尽图 | 实际值**实线** vs 目标值**虚线** |
| 两条时间轴、正文缩进导向线 | 语义色改由**线型**承载，1px 细线的透明度混色一并收进二值 |

- 判据是「**同一类节点同形、不同类不同形**」—— 去掉颜色也分得清，**不靠深浅**表达状态。
- 切回其它主题时，语义色**原样恢复**，不因这一版改动而丢失。
- 顺带修掉一个老毛病：**切换主题不触发图表重渲染**（原先图表在渲染时取一次固定色值就不再变）。

> 面向偏好白底黑字（含干眼症）的使用者，这属**显示偏好**，不作任何缓解或治疗的效果承诺。

## 二、同步冲突中心：分页 / 筛选 / 体积

多设备同步分叉时产生的**冲突副本**，原先是一次性全部读出来渲染 —— 记录一多，打开就卡，也看不出「数据文件为什么变大」。

| 新增 | 说明 |
|---|---|
| 分页 | 按发生时间倒序，每批 50 条，底部状态条提示已加载 / 总数 |
| 类型筛选 | 按数据类型（章节 / 项目 / 分卷 / 设定表 / 表单）与「已处理 / 未处理」筛选；未处理数量沿用入口角标 |
| 体积显示 | 每条显示副本大小；顶部给出**冲突数据合计占用** |

**自动清理仍然不做**：保留期限与大小上限**先展示、不自动删**。删除是不可逆的，策略要单独确认后再实现 —— 这是本项目的既有口径，不是遗漏。

## 三、章节规划板：更新时间 + 状态提示

- 每张章节卡新增**更新时间**（相对时间，如「3 天前」）。
- 对「状态与正文对不上」的情况给出提示：标着「完稿 / 已发布」却**没有正文**，或标着「构思」却已经写了几千字。
- **只提示、不自动改** —— 沿用「不擅自替作者决定」的口径。提示文案是陈述事实（「状态标为完稿，但正文为空」），不是质量判断。

## 四、模型配置支持自定义请求头

**来源**：读者反馈 —— 订阅制网关（代表场景 **OpenCode Go**）要求请求带额外的头才肯认，界面上没有任何地方能加，只能收到 400。

**做法是通用能力，不是专用后门**：

- 「模型配置」新增**键值对形式的自定义请求头**，在请求出口统一注入（对话、模型列表都走同一条路）。
- **浏览器不允许设置的头**（`User-Agent` / `Cookie` / `Host` 等）会**明确告诉你被拒绝**，而不是默默丢掉 —— 避免「设了却没生效」这种最难查的状态。
- 内置 **OpenCode Go 预设**：地址 `https://opencode.ai/zen/go/v1`，预置 `x-opencode-session` 会话头占位（可填任意 UUID）；预设说明里写明**仅 OpenAI 兼容的模型可用**。
- 自定义头保存在**本机**（属敏感键，不随导出 / 备份 / 云同步带走 —— 界面上有明确提示）。
- 存量模型（没有自定义头）的请求**逐字节不变**，升级不影响任何既有配置。

## 五、长篇读取：测过之后，决定不改

计划里留了「章节规划板读取优化」两条路线。**先测量，再决策**：

| 实测（真 Chromium + 真 IndexedDB） | 结果 |
|---|---|
| 521 章 / **110 万字**全量读取章节 | **8 ms** |
| 切回「写作面板」端到端首屏 | 121 章 **76 ms** → 521 章 **74 ms**（**不随篇幅增长**） |

⇒ 判定**读取成本可接受**，本轮**不引入新的元数据存储**（那会牵动同步 / 备份 / 迁移，成本远高于它省下的 8 ms）。
文档里记下了「何时该重测」的触发条件：章数 > 1000、正文 > 500 万字、或首屏 > 300 ms。

## 六、修复（1 P1 + 18 P2）

这一版经**三轮全量审计 + 一轮独立复核**，最值一提的几条：

| 问题 | 说明与修法 |
|---|---|
| **「按叙事序拉平章节」有四份各自实现** | 四份实现里，未分卷章节**有的被丢掉、有的不排序**，其中三处（黄金三章 / 伏笔章号 / 投稿稿正文）**连「卷要按顺序排」都没做** —— 卷的传入顺序一旦不是实际顺序，全书顺序就悄悄错。现已收敛为**唯一真源**，并新增静态闸禁止再手写 |
| **「已开启云同步」却一直没同步** | 启动时接不上同步目标（网盘未就绪 / 文件不可读）会**静默回退本地存储**，而界面上照样显示「已开启」，作者以为一直在同步。现在会**明确告警「同步未生效：改动只写在本机」**并提供重试；那条静默退路也补上了痕迹 |
| **检索设置读取失败会覆盖真配置** | 读不出来时原先被当成「没有配置」，一保存就把真配置（含密钥）整条覆盖掉。现在区分「没有配置」与「读不出来」，读不出来时**不写盘**并如实提示 |
| **纯黑白的 SVG 颜色下发方式无效** | 给 SVG 的 `fill` / `stroke` 直接下发主题变量**是不生效的**（表现属性不解析 `var()`）⇒ 地图地块退化成**实心黑块**，而当时的断言只查「有没有彩色」—— 黑不算彩色，于是**一路全绿**。现改为样式下发，实机断言升级为**只认纯黑或纯白** |
| **两条时间轴从未进入任何检查清单** | 从 3.1 起它们既没被改过、也没被测过，成了唯一还带彩虹色的地方。现已补齐并纳入实机检查点 |
| **自定义请求头编辑器的草稿会被父级覆盖** | 编辑过程中面板重渲染会把未保存的改动悄悄丢掉（上一轮「切换预设补会话头」的修复也被它抵消）。改用稳定键比较，不再用副作用同步 |
| **同名请求头大小写不一致会重复** | `Authorization` 与 `authorization` 并存导致请求头重复；现按小写名合并，切换预设也会一并算上会话头 |
| **其余** | 云同步后台拉取失败不再静默、图表 promise 补上 catch、关窗写盘与迁移失败留痕、配置面板 877 行拆分 |

## 七、已知问题

1. **多设备并发同步仍可能「同代覆盖」** —— 需要协议级的条件写入，会动到后端兼容，本轮未改。
2. **冲突副本的自动清理仍未做** —— 保留期限与上限已展示，删除策略待单独确认（不可逆操作）。
3. **打包版的冲突中心界面与真实双设备（目录中转 / WebDAV / S3）同步**尚未做完整验收。
4. **「纯黑白」下的线宽 / 形状审美**需要使用者本人过目（功能上已严格二值，观感取舍因人而异）。
5. **内置背景图案在纯黑白下不做反色** —— 保持原样，避免全屏阈值处理破坏文字渲染。

## 八、升级与安装

- **升级**：直接覆盖安装即可。项目数据在本机，**不需要迁移**，旧项目、备份、便携版数据照常打开。
- **桌面安装版**：下载 `青春幻想引擎-Setup-3.1.1.exe`，双击安装。
- **便携版**：`青春幻想引擎-便携版-3.1.1-Windows.zip`（`启动.bat`）/ `青春幻想引擎-便携版-3.1.1-macOS-Linux.zip`（`启动.sh`），解压即用（需自装 Node.js 20+）。
- **权限说明**：桌面版会往安装目录解压运行文件、往用户数据目录写数据；便携版只读写自己的文件夹，不写注册表。
