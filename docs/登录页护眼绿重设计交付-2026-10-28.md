# 登录页护眼绿重设计交付 · 2026-10-28

本次完成网站独立登录/注册页的布局与交互重设计。按最终确认，保留分栏、排版、月轨书页装饰，将深蓝紫方案调整为与默认「护眼」主题一致的浅绿配色。合入目标为 `codex/3.3.0-frontend`；本次不发布生产环境、不推送远端，不改变版本号，也不代表 3.3.0 整版验收完成。

## 实施前检查

- 开始时开发分支基点：`c7bf169`。原有 `docs/3.3.1-开发规划-2026-10-26.md` 未提交改动保留且不纳入本次提交。
- 主应用使用 React 18、TypeScript、Vite 8、Tailwind 4、Lucide；登录页实际由 `server/lib/authPage.mjs` 直接输出 HTML/CSS/JavaScript，不依赖主应用初始化。
- 页面入口、认证与游客跳转在 `server/index.mjs`；客户端使用现有 `/api/auth/login`、`/register`、`/reset`，成功后仍返回 `/`。会话 Cookie、密码哈希、邀请码策略、限流及数据保存方式保留。
- 主题依据为 `src/index.css` 的 `[data-theme='eye-care']`，默认设置由 `src/lib/settings/theme.ts` 确认。服务端独立页仅复制必要色值，不读取浏览器主题存储、不加载整个应用样式。
- 原始构建通过；已保存修改前 HTML、五种尺寸截图及公开网站旧页截图。未使用服务器私钥、账号或真实模型。
- 最初建立登录页专用分支。核对主分支时发现其仍为 3.2.3，因此另做隔离兼容检查；依用户后续指示，最终只并入开发分支，主分支保持原状，完成后删除登录页分支。

## 设计与修改范围

- 桌面品牌区 / 登录区约 54% / 46%，卡片最大宽度 440px。平板、手机改为单栏；低高度桌面缩小留白，内容可纵向滚动。
- 页面底色 `#E6F0E0`、卡片 `#F1F6EC`、主要文字 `#2B3A22`、品牌绿 `#44764E`，与默认护眼主题对应。次要文字略加深，保证可读性。
- 保留「让想象，自成宇宙。」和轻量 SVG 月轨书页。装饰使用绿调，无 Canvas 粒子、外部字体、图片下载或新依赖。
- 完成登录/注册切换、密码显示/隐藏、字段错误关联、明显焦点、加载指示、取消等待、高对比度模式和减少动画支持。
- 邀请码仅在需要邀请码的注册态出现；不增加确认密码要求。忘记密码、游客数据说明、云端配额与导出说明、桌面/便携版下载入口全部保留。
- 找回密码页面沿用现有独立布局；认证协议、服务器配置、安全响应头、数据库和业务工作区未修改。

## 边界、回滚与后续使用

本次没有发现未修复的登录页实现缺陷。移动端验收为真实浏览器中的视口模拟；实体手机软键盘、安全区域实机及真实读屏设备尚未验证。200% 检查使用等效 CSS 视口，不冒称已做实体设备或整版发布验收。

在开发分支执行以下命令可复验（浏览器为本机 Edge；使用隔离测试账号）：

```powershell
npm run verify
npm run build
node scripts/verify/auth-entry-layout.mjs
node scripts/verify/auth-entry-integration.mjs
node scripts/verify/frontend-independent-pages.mjs
```

回滚时找到本次标题为 `feat(auth): redesign login with the default eye-care palette` 的提交，在开发分支使用 `git revert <该提交哈希>`。这会恢复旧登录页及相应脚本，不操作用户数据；原有未提交规划文件不在该提交中。专用分支删除后，提交仍由开发分支保留，可正常回滚。

网页登录页属于 `server/`，单独重建 Vite 前端不会更新服务器上的登录页。后续正式发布时需包含服务端改动，沿用现有部署及自动回滚流程；本次未执行生产部署、安装、打包发布或远端推送。
