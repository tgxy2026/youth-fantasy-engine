# 青春幻想引擎 3.2.0 更新说明

> 发布日期：2026-10-21 ｜ 桌面安装版（Windows）＋ 便携版（Windows / macOS-Linux）
> 上一版：3.1.3（2026-10-19）
> 发布页：Gitee `releases/tag/v3.2.0` ｜ GitHub `releases/tag/v3.2.0`

---

## 一句话

**3.2.0 是一次「让 AI 改稿留痕、可核对」的版本。** 以前 AI 改完直接覆盖正文，你只能事后去「时光机」翻旧稿，也说不清"改完到底改好了没"。这一版把改稿拆成你能看见的四步：**先审 → 再应用 → 改完复检 → 报告留档**。另外补了一批日常手感：正文旁边多了「本章资料」抽屉，图片到处都能拖进来，图鉴能换排序，中文标点会自己配对。

本版**不新增页签**。

---

## 新增

### ⭐ 候选审阅：AI 的稿子先放这儿，你点头才进正文

**入口**：创作轨迹 → **候选审阅**

- AI 产出的整章改写稿先落到这里，**不直接覆盖**你的正文。你比对差异后决定「应用」还是「放弃」。
- 🔴 **应用前会比对正文**：如果这期间你自己改过这一章，它会**拒绝**并说明原因 —— 绝不覆盖你的编辑。
  唯一例外是"正文既不是产出前的、也不是产出后的"，那种情况会明说「需要你手工核对」，而不是硬写。
- 整章改写的产出也会登记到这里，**关掉页面 / 切页签后仍找得回**；你在创意写作页点「替换」或「丢弃」，这里的候选会同步变成「已应用 / 已放弃」。
- 应用过程是「记意图 → 写盘 → 回读比对 → 回执」：**中途崩溃不会留下半截正文**。崩了重开，候选会显示「上次中断」，再点一次会接着做完。

### ⭐ 改完复检：区分「改过了」和「改好了」

**入口**：检查工具 → 逐章修订 → 每章标题旁

- 以前执行完只标「已完成」—— 那只是"这条命令跑过了"，错别字可能一个没动。
- 现在改完会用**本地五个检查引擎**（错别字 / 敏感词 / 重复 / 设定冲突 / 节奏）复检，每章标题旁给结论：
  `复检：原问题已清` / `还剩 N 条没解决` / `复检没跑成`。
- 🔴 **不耗 AI 额度**（纯本地）。复检本身出错只记警告，**不会把已经落库的正文报成失败**。

### ⭐ 检查报告留档与回看，带证据快照

**入口**：创作轨迹 → **检查报告**

- 只有查到「冲突 / 注意」级问题才留档，**全绿的书一份都不存**（不占空间、不刷屏）。
- 每条带：来源、章名快照、级别、原文引文，以及「引文 N/M 可定位」。
- **证据快照**：报告落库那一刻就把引文与段号记下来 —— 它回答的是"当时到底有没有证据"，
  而不是"现在还能不能定位"。正文后来被改过，也能翻出当时的记录。

### ⭐ 本章资料抽屉：写这一章要盯的东西，一次看全

**入口**：正文写作 → 工具栏「本章资料」图标

三段合一：

| 段 | 内容 |
|---|---|
| **细纲** | 本章绑定的细纲，按你当前模板的实际字段显示（字段改名、加槽位都不用改代码） |
| **固定资料** | 你手动钉住的角色 / 设定条目，切章不丢 |
| **正文引用** | 本章正文里出现的已登记名字，带别称归并 |

- 细纲里提到的人名 / 条目会给**可点的建议**：点了才固定，**不会自作主张改你的绑定**。
- 点条目直达**那一条具体记录**（不是只跳到页签）。
- 绑定只记稳定 ID，**切项目不会串资料**（跨项目的引用在读取时就被过滤掉）。
- 抽屉打开时会自动收起左侧「设定检索」栏，关掉后恢复你原来的偏好 —— 三列并排会把正文挤得太窄。

### ⭐ 图片到处都能拖

头像、项目封面（新建 / 编辑两处）、图鉴主图、地图底图、看板娘、人物立绘两格 —— **共 7 处**。

- 图片拖到那块区域就上传，不用先去点按钮；拖拽与点选走**同一条**压缩与落库通路，规则完全一致。
- 拖错东西会明说原因：`这里只收 PNG / JPG / WebP，而「大纲.txt」不是` / `拖进来的是文件夹` / `是空文件`。
- 🔴 **拖到页面空白处不会把页面顶掉**（以前浏览器会拿这个文件替换整页，未保存的正文当场没了）。
- 拖拽不会干扰正文选区拖动、章节树拖拽调序。

### ⭐ 图鉴能按三种顺序看

**入口**：图鉴视图右上角

按编号 / 按名称 / 按最近编辑。**只改这一屏的排列，不写库、不动导出**；想真正改顺序仍旧改「编号」列。

### ⭐ 中文标点会自己配成对

打 `“` `《` `「` `（` 会自动补上右半边、光标停在中间。

不再依赖输入法自身设置（搜狗等未开该功能时同样生效）；英文引号与粘贴一律不插手，输入法选字期间也不打断。

## 改进

### 诊断不再报喜不报忧

工单顶部显示「已检 X/Y 章 · 发现 N 个问题 · 留档 N 份」；**没检成的章会点名列出**，
不会再出现"诊断完成、没有问题"其实漏检了一半的情况。中止后剩余章记「未检」，不刷成 100%。

### 实体保留自检（只提示，不判定）

改写后哪些已登记的人物 / 势力名没再出现，章标题旁提一句，并说明属于哪个页签。
**只提示不判定** —— 少提一次名字常常是合理润色，丢没丢设定由你判断；不接阈值，就不会用假警告刷屏。

### 结构化输出可以开了

模型设置里可声明端点支持 JSON 结构化输出（`response_format` / `format`），JSON 类任务更稳。
**默认关**；开了之后若端点报 400，会自动撤掉对应参数重试一次并如实说明。

### 额度有硬上限

整章改写一条最多 **6 次**调用、一次性任务最多 **3 次**，到顶就停并告诉你停在哪，不在后台空烧额度。

### 网络卡住不吞字

流式停滞超时会中断，并把**已收到的片段**带出来，说明「已收到 N 字未采用」。
🔴 **半截正文不会整章落库** —— 覆盖一半比不落更糟。

## 数据与兼容

- 本版新增两个本地数据 store（修订任务、工作产物），IDB 版本迁移**自动完成**。
- 老数据没有本版新加字段时一律**退化显示**，不猜、不编（例如老报告没有章名快照 ⇒ 回看用当前章名）。
- 工作产物（候选正文、检查报告）是**本地专属**：不上云、不进同步、默认不进备份包。
- **覆盖安装不影响已有项目数据**；模型配置、酒馆设定与角色卡原样保留。

## 已知限制（如实写）

1. **复检结论不跨刷新**：任务中心的运行结果只在当次会话内可见；刷新后要看结论请去「检查报告」。
2. **引文定位率可能很低**：伏笔 / 文风类问题的引文来自设定表比对而非正文原句，显示「引文 0/3 可定位」是如实的，**不代表问题不存在**。
3. **实体保留自检只报告**，不阻断落库。
4. **大表仍然慢**：一张表 1000 条 × 60 自定义字段，打开约 17 秒 —— 表格没有虚拟化，登记 3.2.x 专项。
   章节列表**本来就有虚拟化**：500 章 / 101 万字打开正文编辑页 264ms。
5. **主包体积** 1.67MB（gzip 540kB），网页版首屏偏慢；出厂示范数据已单独分包。

## 本版没做的

- 计划与实际的自动核对（`planCompare`）、世界差异对比（`worldDiff`）—— 属后续里程碑。
- 表格虚拟化（见上）。

- 六维审计（11 支扫描器 + 六契约）状态 **complete**：静态缺陷候选 0、失败契约 0、六契约全通过。
- 真机验证（真实 Chromium / 真实 Electron，不用模拟）：

## 安装

| 平台 | 文件 |
|---|---|
| Windows 桌面 | `青春幻想引擎-Setup-3.2.0.exe`（94.72 MB）双击安装，**覆盖安装不影响已有数据** |
| Windows 便携 | `青春幻想引擎-便携版-3.2.0-Windows.zip` → 解压后运行 `启动.bat` |
| macOS / Linux 便携 | `青春幻想引擎-便携版-3.2.0-macOS-Linux.zip` → 解压后 `bash 启动.sh` |

> GitHub 上的附件用 ASCII 名（`youth-fantasy-engine-Setup-3.2.0.exe` 等），与历史版本一致；Gitee 上是中文名。
> 便携版数据放在解压目录旁边，**不写系统目录**，可直接放 U 盘。

> 🔴 从 3.1.x 升级前建议先在「备份与恢复」导出一份。项目数据会自动迁移，但备份是唯一回退手段。
