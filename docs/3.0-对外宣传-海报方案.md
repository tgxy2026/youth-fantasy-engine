# 3.0 对外宣传 · 图片文字海报方案（两组合计）

> **用途**：3.0 对外宣传不再发长文帖子，改「**图片文字海报**」——因为帖子字多没人看。
> **产出形态**：两组海报，均为**带中文文字的图**，发帖时多图连发。
> **出图工具**：本地 ComfyUI + **Qwen-Image 2.1**（`qwen_image_2.1_int8_convrot`）。
> **制定日期**：2026-10-11 ｜ 示范项目《吞天神脉（示范）》· 东方修真 · 3 卷 21 章。

## 〇、先看结论（重要前提）

### 🔴 核心判断：Qwen-Image 2.1 只能扛「少字大字」，扛不了「整版小字」

实测结论（来自 `comfyui-cn-poster-text` skill）：

| 文字量 | Qwen-Image 2.1 表现 | 可用性 |
|---|---|---|
| 标题 + 版本号 + 副标题（**3 行以内大字**） | 字形锐利、笔画完整、零乱码 | ✅ 直接可用 |
| 7~10 行中字（**功能清单式**） | 大部分可读，个别笔画偶有瑕疵 | ⚠️ 需多跑种子挑选 |
| **20 行以上小字**（整版功能表） | 大面积糊字 / 乱码 / 漏笔画 | ❌ **不可用** |

### ✅ 已定口径（2026-10-11 主人拍板）

| 决策项 | 定案 |
|---|---|
| **A 组画法** | **PIL 排版 + AI 底图** —— 字用固定中文字体（微软雅黑 Bold）保证绝对清晰、风格统一；AI 出底图氛围 |
| **B 组画法** | Qwen-Image 2.1 出图（少字大字，氛围为主） |
| **海报比例** | **竖版 3:4** → 1024 × 1365 |
| **底图风格** | 🔴 **现代设计 · 科幻感**（抽象光带 / 电路网格 / 数据粒子 / 科技蓝渐变色），**不绑定修真题材，通用** |
| **底图数量** | 先出 **3 张**（3 封面用；A 组 10 张卡可共用） |
| **出图节奏** | **直接提交进 ComfyUI 队列自然排队**（不抢主人哥哥正在跑的批次），出图后收集 |
| **出图节奏（正文）** | 先确认封面风格 → 再批量出 A 组 10 张卡 → 再定 B 组 |

> 🔴 **2026-10-11 修订**：主人哥哥明确「**不要用程序硬搓图**」→ 弃用 `procedural_bg()` 程序化底图，改**文生图模型出底图**。
> 底图脚本 `docs/海报产出/gen_bg.py`（科幻风格 + 队列模式）。

## 三、技术方案（ComfyUI 直连链路）

### 为什么走「直连」而不是 App 工作流
本地 ComfyUI 是精简版（`依赖文件\` 只剩 `wf_resolve.py`），且 App 工作流挂参考图时容易 400。
→ 按 skill「坑13」，**自建标准 API 链路**最稳：零参考图依赖、参数 100% 可控。

### 链路（Qwen-Image 2.1 INT8，实测 14~20 秒/张 @1024²）

```
UNETLoader(qwen_image_2.1_int8_convrot)
  → LoraLoaderModelOnly(qwen-image-2.1-fix-v1.0-comfy, 1.0)
  → APG(eta 1.0 / norm_threshold 10.0 / momentum 0.3)
  → FreSca(scale_low 1.0 / scale_high 2.0 / freq_cutoff 8)
CLIPLoader(qwen3vl_8b_int8_convrot, type="qwen_image")
  → TextEncodeQwenImage21(clip, prompt, negative_prompt, resolution=<见下>)
VAELoader(qwen_image_2.1_vae_bf16) → VAEDecode → SaveImage
KSampler: steps 20 / cfg 3 / sampler seeds_2 / scheduler sgm_uniform / denoise 1.0
```

🔴 `TextEncodeQwenImage21` **自带 latent 输出**，**不要再挂 EmptyLatentImage**。

### 尺寸

| 用途 | 尺寸 | 说明 |
|---|---|---|
| **竖版海报（本方案）** | **1024 × 1365** | 3:4，手机竖屏友好（已在 `gen_bg.py` / `make_poster.py` 写死） |

### 底图生成与收集（生产流程）

底图脚本：`docs/海报产出/gen_bg.py`（Qwen-Image 2.1 直连，科幻风格）

```bash
# ① 提交进队列（不阻塞，把 pid 记录到 pids.txt）
python gen_bg.py --submit-only 2001 2002 2003

# ② 稍后（主人批次跑完后）收集产出 → 自动落到 底图/
python gen_bg.py --collect

# 或：阻塞轮询模式（少量图时用）
python gen_bg.py 2001 2002 2003
```

| 路径 | 作用 |
|---|---|
| `底图/科幻_seed*.png` | 收集到本地的底图 |
| `raw output\海报底图\` | ComfyUI 原始产出 |
| `pids.txt` | 提交记录（seed \| prompt_id），供 `--collect` 用 |

### 套底图排版

```bash
python make_poster.py --idx cover-manual --bg 底图/科幻_seed2001_xxx.png --out 封面1.png
python make_poster.py --idx 3 --bg 底图/科幻_seed2001_xxx.png --out 第3张.png
```

> ⚠️ 底图上已带光效，排版时建议**局部压暗**文字区（脚本已有底部暗角，可视需要调 `make_poster.py` 的 `draw_cover_generic` 加半透明遮罩提升可读性）。

### 关键纪律（来自 skill 实战踩坑）

1. **文字写死**：每处文字明确写「写入『XX』」+ 字号占比 + 位置 + 颜色。
2. **负向词必备**：`blurry text, fuzzy letters, garbled characters, 字形模糊, 笔画粘连, 乱码字母, 立体泡沫字, 发光糊成一团`
3. **居中靠种子挑选**：模型有 ±15px 偏差，**多跑 5~6 个种子**再挑（看左右留白差 `pad_diff`）。
4. **字体锁定**：写「粗壮的现代无衬线中文黑体（思源黑体 Heavy / 微软雅黑 Bold）」，明确排除手写体/宋体/装饰体。
5. **不要 3D 字**：明确写「扁平平面字，不要立体挤出、不要金属浮雕、不要外发光」。

## 五、备选方案（若 Qwen 中文仍不满意）

| 方案 | 优势 | 代价 |
|---|---|---|
| **Ideogram 4**（本地已有 `ideogram4_fp8_scaled`） | 文字渲染最强，多行也稳 | 出图较慢，画风偏设计稿 |
| **Qwen 出底图 + PIL 后期叠字** | 排版 100% 可控、字体统一 | 需处理中文字体，排版要手工调 |
| **纯 PIL 排版**（无 AI） | 最可控、最快、字体绝对清晰 | 没有美术氛围，偏"表格"感 |

> 可可建议：**A 组（信息为主）可考虑 PIL 排版 + 轻底纹**，**B 组（氛围为主）用 Qwen 出图**——
> 功能清单本来就该清晰如表格，硬让 AI 画反而糊。
