## 第二轮（下午）：缺口优先 + 正文补齐 + markdown 净化

**老大三点**：① 修正文里的 markdown 星号；② 缺口补齐能不能用到**正文**（第 21 章只 2200 字 →
先补到 4000 再往下写）；③ 拿真实长篇跑一轮「排纲 → 写正文」。
中间补一条口径：**卷大纲完整就按它排细纲，不完整则补细纲时一并把卷大纲补全**。

### 结论：能实现，且示范项目当场生效（已实证）

关键＝怎么知道"第三卷该到第 30 章"。示范项目三种真实写法实测：

| 卷卡 | `本卷章数预估` 实际值 | 解析结果 |
|---|---|---|
| 第一卷 风起云州 | `第1-10章，约四万六千字` | `{1,10}` 完整区间 ✓ |
| 第二卷 剑鸣中州 | `第11-20章，约四万六千字` | `{11,20}` 完整区间 ✓ |
| 第三卷 剑锁中州 | `第21章起（已写第21章，约2200字）` | `{21,21}` 只有起点 → 用每卷章数推定上界 = `21+10-1` = 30 |

⇒ 缺口 = **第 22-30 章（9 章）**，正是老大给的例子。**不需要**加"必须排满整卷"的限制。

### 四项决策（老大拍板）
① 有缺口时**只补缺口、不新开卷**（补满后下一批才排新卷）；
② 卷边界**三级取用**（本卷章号范围 → 本卷章数预估 → 单章式文本用每卷章数推定上界）；
③ **卷大纲完整 → 只按它排细纲；不完整 → 补细纲时一并补全卷大纲**；
④ markdown 清 **星号 + 行首 `#` + 整行 `---`**。
