### 比对方法（可复用）

- **新增功能**：逐版比对 `src/lib/schema.ts` 的**页签**（＝功能清单，1.0 的 29 → 2.3 的 49）
  + `src/components` / `src/lib` 的**模块从无到有**。这比看提交信息更客观。
- **优化**：工作日志（`.workbuddy/memory` 累积保留 08-24 起）+ `docs/` 的审计修复记录（2.1.0 起）。
- ⚠️ **教训**：写脚本批量把日志内容抽出来落盘会**触发敏感内容审批**（日志里夹着 API key 等）。
  正确做法是用**只读检索**（Grep）定向取要点，不要把日志内容批量转存成新文件。
