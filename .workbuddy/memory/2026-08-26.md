## 封装前最终代码审查（#36–#39）

通读 AI 全链路（ai/aiTasks/aiScope/aiContext/useAIReady + AIAssist/AIOrganize/EditorModals/WritingTools/TableSheet/CharacterSheet/FormSheet），修复 3 处：

1. **流式总超时误杀慢模型（真实 bug，ai.ts）**：原 `fetchWithTimeout` 的 180s 硬计时器在流式响应开始后就倒计时，慢模型生成超 180s 会被中途 abort，且中止错误没在流式分支转成友好提示，UI 会显示裸 "AbortError"。
   - 修复：`fetchWithTimeout` 新增 `onResponse(clearTimer)` 回调；流式分支把清总超时交出去，由 `readSSE` 在收到**首个 token**时调用 → 首字出来即代表模型活着，慢流不再被一刀切。
   - `readSSE` 新增 `onFirstByte`；流式分支用 try/catch 把用户取消转 `AICancelled`、超时转友好中文提示。
   - 顺手修掉一个隐患：流式分支原本会**重复发两次 HTTP 请求**（先非流式 fetch 检查 res.ok，再流式 fetch 一次），重构为单次 fetch（仅按 `o.onToken` 决定是否挂 onResponse）。
2. **ProofreadCheck 静默吞错（真实 UX bug，EditorModals.tsx）**：catch 里取消与真实错误都走 `setAiDone(true)` 且不显示任何信息；网络错误时作者无提示。修复：新增 `aiError` 状态，仅在真实错误时显示（取消仍静默保留部分结果）。
3. **WritingTools 三 AI 共用 streamText 并发串台（边缘）**：AI 取名/敏感词复核/一致性自查共用一个 `streamText` 且未互斥，连续点击会互相覆盖预览。修复：三个处理函数加彼此 loading 互斥守卫。

### 修复的真实 bug（4 处，均 tsc+vite build 双验证 0 错）
1. **AI 校对「替换此条」改错位置（EditorModals.tsx `replaceIssue`）**：原 `text.indexOf(iss.quote)` 永远命中正文【第一个】匹配；同一句式重复出现时会改到错误那句。改用 AI 标注的精确下标 `iss.at`（命中则用之、否则回退 indexOf），并在替换后按位移重新锚定其余问题的 `at`，避免连续替换继续漂移。
2. **敏感词一键替换残留（sensitiveWords.ts `replaceHits`）**：原按扫描顺序逐个 `split/join`，短词若包含于长词会被先替换、导致长词残留（如先「赌博」→■■，再找不到「网络赌博」）。改为按词长**降序**替换。

## 第六批：滚动条双条问题复发修复（终版方案）

- 用户反馈（上轮修复后复发）：编辑区出现**两个滚动条**——一个挡字可操作、一个新出现不挡字但鼠标滚不动。
- 根因：`.novel-textarea` 类自带 `overflow-y: auto; scrollbar-width: thin`，且定义在 Tailwind utilities 之后（同特异性后者胜），**高亮叠层的 Tailwind `overflow-hidden` 被覆盖失效** → 叠层自身变成可滚动容器，内容超高冒出第二条滚动条；叠层 `pointer-events-none` → 不可操作。
- **终版方案（滚动权唯一化）**：
  1. `index.css` `.novel-textarea` **删除 overflow-y:auto / scrollbar-width**，类不再携带任何滚动行为（注释注明）；
  2. textarea 改 `absolute inset-0 z-10 overflow-y-auto px-6 md:px-8 pt-6 pb-3`（覆盖整个编辑区 padding-box → 滚动条天然贴最外缘：铺满=窗口右缘、限宽=文本块右缘；自身 padding 24/32px 死区 > 滚动条 8px → 不压字；全编辑区唯一滚动元素）；
  3. 高亮叠层/测量层：去掉 `py-1.5`（内容起点统一 top-6=24px，三层严格对齐），`overflow: 'hidden'` **inline 压制**（inline 特异性最高，无视 CSS 顺序覆盖）。
- 经验：**共享 CSS 类不要写 overflow，滚动行为一律归元素自身 Tailwind 类 + inline 压制叠层**；叠层（高亮/测量）绝不允许成为滚动容器。
- 验证：tsc 0 错；vite build 0 错；dev server HTTP 200。
