## 地图拖拽 v5：嵌套视觉回归 + 父框恒定（咸鱼哥二次反馈）
咸鱼哥驳回上一版「boxes = 自身测量八边形」的改法：「完全失去了互相嵌套的功能」。要求：有数据按面积比例，无数据按层级深度给「适当比例」的默认（父比子大，嵌套可见）；同时拖子时父框大小恒定、子在父框内被钳制、出不去。

### 核心模型（终版）
**递归包含框（enclosure）= 自身测量八边形 ∪ 所有子孙包围盒 ∪ 留白 PAD_REGION(24)**
- 有测量：八边形按面积/跨度比例 → 父框天然包裹子孙八边形（嵌套可见）
- 无测量：默认尺寸按 `depthMap` 缩放 `DEFAULT_HW * 0.72^depth`（最深 18 为下限），父级自然比子级大
- 渲染层加 `data-region-id / data-leaf-id / data-handle-id` 属性方便测试精确定位

**拖拽期间「父框锁定」= `dragLockBox` state**
- pointerdown 捕获：父级「渲染包含框基准」→ setDragLockBox({id: parent.id, box: 基准 enclosure})
- boxes memo 中该 id 直接返回锁定的基准框，忽略 dragOverride → 拖拽过程中父框视觉恒定
- pointerup 清空

**钳制边界 = 父级「自身测量框」（不含子、不含留白）**
- 必须用自身框而非带留白的渲染框，否则子到达留白边缘后松手会撑大父框并集
- 拖拽子地点时钳在父自身框内 → 松手后并集（子仍在框内）= 自身框 → 父框大小前后完全一致
