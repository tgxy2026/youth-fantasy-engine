## 2.0.1 优化：编辑器高亮错位/长章卡顿 + AI 改稿只剩标点（提交 388dae3）

### 问题 1 编辑器（桌面版）

老大反馈：① 文本加载较慢、异常，上下滑动查看时经常不显示文本；② 编辑页面不会自动延展，最后一行编辑常被盖住一半。

- **根因① 叠层错位（对应"滑动不显示文本"）**：NovelEditor 是 **textarea + highlightRef 双图层**，
  `highlightOn` 开启时 textarea 设 `color: transparent`，肉眼看到的字**全来自叠层**。
  叠层用 `dangerouslySetInnerHTML` 整块重建，**DOM 一换 scrollTop 就被浏览器重置为 0**，
  而 textarea 停在原处 → 两图层错位、可视区空白。旧代码的同步只挂在 `onScroll` / `onContentChange` 上，
  **覆盖不到"叠层自己重建"这条路径**。
  修：`highlightHTML / activeId / fontSize / pageWide / focusMode / showSearch` 变化后以 `useLayoutEffect`
  立即回填；scroll 改 rAF 合并同帧写入；加容器 `ResizeObserver` 兜底；卸载 `cancelAnimationFrame`。
- **根因② 切章残留（对应"加载慢/异常"）**：`deferredContent` 是 120ms 防抖镜像，切章后 120ms 内叠层
  渲染的**仍是上一章正文**。修：切章 effect 里同步 `setDeferredContent`，不走防抖。
- **根因③ 长章卡顿**：`referenced` 用 `refNames.filter(r => text.includes(r.name))`＝**O(引用数×字数)**，
  再叠上 `buildHighlightHTML` 的 `split` + 逐段 `escapeHtml` + `join`，每 120ms 防抖全跑一遍。
  修：新 `scanRefHighlight` 单次正则 exec 流式拼接，一次同时产出 html 与命中 Set；
  `escapeHtml` 先探测再替换；超 `HIGHLIGHT_MAX_LEN`(6 万) 降级纯文本。
- **根因④ 最后一行被盖**：textarea 底部仅 `pb-3`，无 scroll-past-end。
  修：textarea 与叠层统一 `pb-[40vh]`（已验证 Tailwind 确实生成 `.pb-\[40vh\]{padding-bottom:40vh}`），
  末行可推到屏幕中上部。**两图层盒模型必须逐项一致**，否则内容总高不同 → 滚动同步必然错位。

### 问题 2 AI 编辑（润色/扩写仅输出个别标点符号）

- **根因（脚本对照已验证）**：`parseObjectArray` 先按 `'['` 切片；当返回值本身就是**单个 JSON 对象**
  （`{"rewritten":"…","notes":"…"}`，正是 AI 改稿的标准形态）时，`JSON.parse` 成功返回**非数组对象**
  → `!v` 为 false 跳过兜底分支 → 末尾 `Array.isArray(v)` 失败 **return []** → `obj.rewritten` 恒为空
  → 永远退到 `humanText` 文本兜底，抽出来的残骸就是几个标点。
  对照实验：旧实现对该形态**条数=0**；新实现条数=1 且正文完整（数组 / `{list:[…]}` / 含方括号等形态均未回退）。
- 修：`normalizeParsed` 统一归一化三种形态（数组 / 单对象 / `{list:[…]}`）。
- 加固：`ai.ts` 新增 `ChatOptions.temperature` 透传 + `DEFAULT_TEMPERATURE`(0.85) / `JSON_TASK_TEMPERATURE`(0.3)；
  0.85 会让模型在 JSON 外夹带寒暄，抬升解析失败率。
- 兜底：`hasSubstance` 拦掉"只剩标点"的抽取结果；JieWenJi 界面无有效内容时改红框明确提示 + 重试建议，
  `applyAdvice` 从静默 return 改 `showToast`，杜绝"改稿完成 + 一片空白"的误导。

- 验证：`tsc --noEmit` 0 错；`vite build` 4.79s 通过；解析用例 6/6 通过；`dist-check`、`test-parse.mjs` 均已删。

- 附带：老大宣布 2.0.0 收官（产出见 2026-09-04 日志），后续进入内容创作期，**版本节奏约每月一次**。
