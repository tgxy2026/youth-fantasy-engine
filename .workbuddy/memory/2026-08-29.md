## #003 加固：云端加密 + 排除 AI key + 按钮重定位 + 反馈直读（晚·已上线）
- 老大要求：①云端同步数据加密；②AI key 不随同步上传；③三个浮层按钮（云端同步/退出体验/反馈）挪到项目管理主页左下角避免遮挡侧栏主题切换与编辑器字号；④确认反馈能否由老巴迪直接 SSH 读。
- **加密（serverStore.ts）**：上传前用同步码派生密钥加密载荷，`rev` 明文保留（服务端做版本守卫）。安全上下文(HTTPS/localhost)走 Web Crypto **AES-GCM**（真加密）；**HTTP 公网降级 XOR 混淆**（非密码学强度，仅防服务器磁盘明文）。载荷字段 `stores`→`enc`（前缀 `a1:`/`x1:`）。服务端 `feedback-server.mjs` 改读/写 `{rev, enc}`，存 `/var/lib/yfe/sync.json`，不可读明文。
- **排除 AI key（修正此前误判）**：AI 配置实际在 `meta` 库（key=`aiProviders`/`aiActiveProviderId`/`aiConfigMigratedToGlobal`，非 settingsKV）；AIAssist 界面明写"仅本地保存，不上传"。新增 `EXCLUDED_META_KEYS`，`db.ts` 加 `cloudStore` 包裹层：这些 key 的读写回退本地 idbOps——不进云端缓存、不同步、不被拉取覆盖。seedFromLocal 播种时也剔除。
- **按钮重定位（App.tsx）**：WebTools/FeedbackButton 去掉自身 `fixed` 浮层，改由 App 在项目管理主页(`!projectId`)统一包 `fixed bottom-4 left-4` 容器渲染；项目页内不再浮浮层。验证：`fixed bottom-4 right-4` 残留仅为 ProjectHub 作者头像装饰图（非按钮），无误。
- **反馈直读**：`/api/feedback` 现在把正文 `text` 一并写进 `/var/lib/yfe/feedback.jsonl`（每行为含 id/ts/ua/ip/text/hasFile 的 JSON），原始 multipart 仍存 `fb-<id>.bin`。→ 老巴迪可直接 `sudo tail /var/lib/yfe/feedback.jsonl` 读反馈，**无需用户下载中转**。
- **重要约束**：当前部署为 HTTP，`crypto.subtle` 仅在安全上下文可用 → 真 AES-GCM 需先上 HTTPS（#13，顺带保护 AI key 传输）。已向老大说明，建议届时部署 Let's Encrypt（免费）。
- **同步机制澄清（答复老大）**：同步是**自动**的（每次写操作 800ms 防抖后自动推送；页面加载时 pull 一次），非手动、非定时轮询；是否同步由 localStorage `yfe-sync-code` 是否存在判断（即是否用正确同步码开启过）；同一同步码=单云端槽，若两人共用同码会数据互相覆盖（last-write-wins），故该码是老大个人特权码、勿外借。
- **部署**：`build:web` 重建(已先 `mv dist-web dist-web.oldbak` 避 safe-delete)→ scp 前端+服务端三件套 → `sudo cp` 配置/JS→`sudo systemctl restart yfe-feedback`→`sudo rm -f /var/lib/yfe/sync.json`(清旧明文)→`sudo nginx -s reload`→覆盖 `/var/www/yfe`。线上验证：鉴权401/200、上传密文200、GET 只回 `enc` 无明文、冲突409、坏包400；反馈 text 落盘已实测(末行含 text，随后清空测试条)。tsc --noEmit 0 错、server `node --check` 通过。本地 `dist-web.oldbak` 已清。
