### 2. Ollama 联网：能，但不是「本地」
- Ollama **0.18.1**（2026-03）起有 web search，但端点在 **`https://ollama.com/api/web_search`（云端）**，
  本地模型要用必须先 `ollama signin`（免费账号）＋走 OpenClaw 插件；`localhost:11434` 上**没有**这个端点（实测 404）。
- 对本项目：我们走的是「**自己查好再喂给模型**」的预检索架构，所以本地 Ollama 用「搜索接口」档即可；
  「模型自带联网」档对本地 Ollama **无效**（它没有 tool calling 到 ollama.com 的通道）。
- 实测 `ollama.com/api/web_search`：带 `Origin` 的 POST 返回 401 且**无 `access-control-allow-origin`**，
  OPTIONS 预检 **405** —— 它只给服务端客户端（Python/JS 库）用，**浏览器/Electron 直连会被 CORS 拦**。
  → 不能当我们的「自定义搜索接口」。**不必为它改代码。**
  ⚠️ 测 CORS 一定要带 `Origin` 头；不带时缺 ACAO 是正常的，不能据此下结论（第一次就这么误判过）。
