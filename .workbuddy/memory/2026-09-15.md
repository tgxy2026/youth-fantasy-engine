### 2. 联网检索（控制面板「七、联网检索」）
- 现状查证：**硅基流动 API 本身不提供联网搜索**（网上那些方案都走第三方中转让或客户端自建 SearXNG）。
  实测 `api.bochaai.com` 返回 `Access-Control-Allow-Origin: *` → **浏览器/Electron 可直连**；
  智谱 `web_search` 无 ACAO 头 → 直连会被 CORS 拦。故主推博查 + 留自定义接口。
- 三条素材路由：`off`（默认，模型已有知识 + 粘贴素材）/ `model`（模型自带联网，如实标注「取决于模型」）/
  `api`（我们查，博查或自定义）。**每次起草都如实回告用的是哪一种**，查失败也不静默（照常生成但显示原因）。
- 新增 `src/lib/webSearch.ts`（检索 + 通用结果提取 + 渲染）、`src/lib/tavern/draft.ts`（素材管线 +
  角色卡模板 + 来源裁决）、`src/components/TavernDraftBits.tsx`（三处共用的素材/来源组件）。
- 控制面板新增「七、联网检索」段（原七/八顺延为八/九），参数说明进 `paramGuide.ts`。
