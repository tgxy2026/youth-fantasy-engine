## 发布后修复：撑满型页面塌掉（酒馆对话窗口变小 / 编辑器被裁）

老大报障：**剧情推演**与**自由对话**的对话窗口变小、下方留一大块空白。

- **根因＝`3a9575c`「页头冻结」的副作用**：那次把 padding 从滚动容器 `main` 挪进内层 div，
  却没给内层 div 高度 ⇒ `renderContent()` 不再是「高确定的 main」的直接子 ⇒ 子元素的
  `h-full`（height:100%）失去参照、退化成 auto ⇒ 撑不满。
  当时只顺手修了**加载占位**（`h-full`→`min-h-[50vh]`），没意识到**整类撑满型页面**都受影响。
- **同根因、两类症状**（实测纯 CSS px、可用高 862）：
  剧情推演根高 372（留白 **490px**）、自由对话根高 375（留白 **487px**）；
  编辑器反过来 —— 根高 **1391** 而 main 是 `!overflow-hidden`（可用 926）⇒ **465px 被裁且滚不到**。
  只修报障的那两类会漏掉编辑器，是「顺手多量一个页签」才暴露的。
- **修法一行**：内层 div 补 `h-full` —— `className={`h-full ${isEditor ? '' : 'p-6 lg:p-8'}`}`。
  补完后与「padding 还在 main 上」的几何完全一致。
- **定位手法（值得复用）**：改源码**之前**先在页面注入 `main > div { height: 100% !important }` 做
  **阳性对照** ⇒ 三处空白立刻归零 ⇒ 根因当场锁定，不用读代码猜。
- 验证：新增回归 `ui-page-fill.mjs` **11/11**；🔴 负面对照（去掉 `h-full`）**如期变红**
  （490 / 487 / −465，与预期一一对应）；粘性表头 7/7、编辑器 23/23、编辑器缩进 27/27、
  自由对话 14/14、控制面板 20/20；tsc 0 / eslint 0 / **106 入口全绿** / vite build 通过。
- ⚠️ 该缺陷**已随 2.4.1、2.4.2 两个安装包发出**（`3a9575c` 属 2.4.1 那批）⇒ 要对外修正必须**重新封装**；
  未擅自封装，已报老大定夺。
- 沉淀：skill assets `ui-page-fill.mjs` + skill 文档新增「包裹层的 h-full 副作用」一节
  （含两类症状对照表、阳性对照手法、「量贴底不能拿根自己的底比」这条假绿教训）。
- 顺手清掉上一轮漏删的 workspace 副本 `ui-242-zlayer.mjs`。
