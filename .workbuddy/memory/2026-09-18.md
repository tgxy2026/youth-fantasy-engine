## 追加：ESLint 11 处 warning 全部清零（依赖数组治理）

老大问「11 处 warning 都是什么内容，能否修复处理」→ 逐条读源码分成三类后全部修掉，
`eslint src` 从 **11 warning → 0 problem**。11 条**全是** `react-hooks/exhaustive-deps`，
但性质完全不同，不能一把梭（MEMORY 里那条「11 warnings 别盲改」是对的）。

### 三类性质
| 类 | 条数 | 位置 |
|---|---|---|
| 🔴 真漏依赖 | 3 | `SettingSearch` 索引 effect 少 `hiddenTabs`；`TableSheet.filteredRows` 少 `drafts`（**真 bug**）；`TableSheet.tableFields` 读 `tab.columns` 只写 `tab.id` |
| 函数身份（普通函数被当依赖） | 3 | `BackupManager.load`、`TableSheet.validateCodes`、`TableSheet.cellVal` |
| 写法/派生值 | 5 | `CharacterSheet`/`FormSheet` 的 `[tab.id]`→`[tab]`；`HistoryTimeline`/`StoryTimeline` 的 `calValueOf` 内联进 useMemo；`SettingSearch.subOptions` 少 `activeTop` |

### 🔴 修出一个真 bug
`filteredRows` 依赖 `[sortedRows, colFilters, selectColNames]`，却经 `cellVal` 读 **drafts** ——
即「正按某列筛选时编辑该列单元格，命中结果不重算」：把某行改成不再匹配筛选词，**行不会消失**，
要等保存/刷新才对。修法：`cellVal` → `useCallback([drafts])`，再加进 `filteredRows` 依赖。
实机对照有判别力：修后编辑 → 命中行 **1 → 0**；未修版会停在 1。

### 两个"不能直接补依赖"的坑（靠改调用方 / 换依赖形态绕开）
1. 🔴 `SettingSearch` 索引 effect **不能直接依赖 `hiddenTabs`**：Set 每次 memo 重算都新建引用 →
   effect 重跑 → `setDocs` → 再渲染 → 循环。改为派生的**内容字符串**
   `hiddenTabsKey = [...hiddenTabs].sort().join(',')`（按值比较，真变了才重建）+ 一行 disable 注释说明。
2. 🔴 `TableSheet` 聚焦 effect 依赖 `onFocusConsumed`，而 App 传的是**内联箭头** → 补进依赖会让
   effect 每次渲染重跑、2.6 秒的高亮清除定时器被反复重置（**高亮永不消失**）。
   正解不是删依赖，而是**把调用方改成 `useCallback`**（`clearFocusRow`）—— 两处调用一起受益
   （`CharacterSheet` 依赖里本就含它，同病）。
